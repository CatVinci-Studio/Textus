# Textus official Agent runtime bridge

`host.mjs` launches the official [DeepSeek Harness SDK](https://github.com/deepseek-ai/deepseek-harness) at **0.2.1-rc.2** (reviewed upstream commit `687f282e8625c6b8d11ff58211a90524be2e4317`). Its `sdk-minimal` profile owns the execution loop, tools, retries and protocol. `document-tools.mjs` is a Textus Cordis plugin for snapshot reads, reviewed edits and authorized background images. The original MIT license is included in `LICENSE.deepseek`; dependency packages retain their own licenses.

`cli.mjs` launches installed official **Codex** and **Claude Code** CLIs using their existing login. A JSON output schema carries document proposals through the same review pipeline. Claude's built-in tools and ambient MCP servers are disabled; Codex runs in a temporary directory with a read-only sandbox. This document integration does not offer unrestricted project shell/file editing. Images are generated through Harness or manually through Textus.

Install isolated dependencies with `npm ci --prefix harness`; test with `node --test harness/*.test.mjs`. `node scripts/prepare-harness.mjs` stages the pinned runtime, dependencies, licenses and the matching Node executable into ignored application resources. The preparer installs missing locked dependencies and selects Node for the Tauri target, verifying official download checksums for cross-builds. Node’s license is staged with the executable. The desktop build hook runs preparation automatically. Never commit staged resources or credentials. The macOS build is verified; other platforms need native packaging verification.

Credentials enter the sidecar through stdin, then into the official child environment; they are never arguments, frontend values or on-disk configuration. Each turn uses a private temporary home and replays Textus's existing, privacy-controlled history. Rust kills the owned process group on cancellation and removes its temporary home. The paid image bridge is authenticated over loopback, registers only for authorized Create/Edit tasks and reuses Textus's quota and permission checks.

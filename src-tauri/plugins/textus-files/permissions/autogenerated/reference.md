## Default Permission

Everything Textus's iOS document access needs.

#### This default permission set includes the following:

- `allow-pick-document`
- `allow-pick-folder`
- `allow-read-text`
- `allow-read-data`
- `allow-write-text`
- `allow-list-folder`
- `allow-remembered`
- `allow-begin-access`
- `allow-share`
- `allow-haptic`

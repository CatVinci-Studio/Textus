## Default Permission

Everything Textus's iOS and Android document access needs.

#### This default permission set includes the following:

- `allow-pick-document`
- `allow-pick-folder`
- `allow-create-document`
- `allow-read-text`
- `allow-read-data`
- `allow-write-text`
- `allow-list-folder`
- `allow-create-entry`
- `allow-rename-entry`
- `allow-move-entry`
- `allow-delete-entry`
- `allow-trash`
- `allow-remembered`
- `allow-begin-access`
- `allow-share`
- `allow-haptic`
- `allow-appearance`

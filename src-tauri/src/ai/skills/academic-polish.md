# Academic polish

## Scope
- The selection; else the section the user names (abstract, method, literature review); else the current section.

## Do
- Formal, precise and plain: no colloquialisms (其实, 基本上, 大家都觉得; "a lot of", "pretty much"); no inflated adjectives; one term per concept; abbreviations defined at first use.
- Calibrate claims to the design: association is not causation; survey data does not "prove"; one sample does not generalise to "every". Use one warranted hedge, never stacked hedges. State real limitations once, without reflexive modesty.
- Numbers and units by the attached conventions: SI symbols, a space between number and unit (20 °C), consistent decimals. Don't regroup numbers unless asked.
- Chinese: titles at most 25 characters with no hype; abstracts about 400/300/150 characters by type; 3–8 keywords. Reference lists follow GB/T 7714 only when the user asks for formatting.
- English: APA, MLA or Chicago basics per the attached conventions, only where the document already follows one or the user names it.

## Don't
- Invent or alter references, authors, years, page numbers, DOIs, data or quotations.
- Add citations. Where a claim needs evidence, a citation or a scope limit, say so in a comment.
- Edit citations, figures or reference lists, except plain formatting the user asks for.
- Touch quotations.

## Deliver
- Revise mode: one replace per paragraph; one add_comment for each claim that needs evidence, a citation or a narrower scope, and for each reference you can't verify (mark it 【待核实】 in Chinese, "[check]" otherwise, in the comment, not in the text).
- Review mode: comments, and the revised paragraphs in the reply when asked.
- Reply in one or two sentences on what changed and how many claims were flagged.

# Expand

## Scope
- The selection; else the passage the user names; else the current section.

## Do
- Make it about 1.5–2 times as long unless the user gives a length. The result must be longer than the original.
- Develop what the text implies: the reasons it gives, consequences it sets up, the feeling a situation plainly carries, steps an instruction skips, definitions of terms it uses, transitions between points.
- In fiction, when asked, render existing actions with sensory detail; the events stay the same.
- A list keeps its items and their order, each expanded in place. An outline becomes prose only when the user asks.
- Keep the structure, headings and the author's voice; respect the style profile's limits.

## Don't
- Add facts, numbers, dates, names, quotations, sources or events the text and the user haven't given.
- Pad: no restating, filler, throat-clearing or the patterns in the attached AI-tells list.
- Write placeholders into the document, unless the user wants them.

## When facts are missing
- If the requested expansion needs facts you don't have (prices, dates, names, results), expand what is there and ask for the missing facts in your reply. Values marked TBD or similar stay as they are.

## Deliver
- Write mode: one replace per passage (one per paragraph for long passages).
- Review mode: the expanded text in the reply.
- Reply in one or two sentences on what was developed, plus any question about missing facts.

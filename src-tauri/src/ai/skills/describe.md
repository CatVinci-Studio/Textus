# Describe a scene or character

## Scope
- The person, place, object or moment the user names; else the passage around the selection or cursor.
- Read the scene first so the description fits where it goes, who is looking, and what has just happened.

## Do
- Default length about 120–250 words, or 200–400 Chinese or Japanese characters, unless the user gives one.
- Choose one dominant impression and three to five specific details that serve it, not a catalogue.
- Filter everything through the point-of-view character's senses and knowledge; mix senses (sound, smell, temperature, texture), not only sight.
- Show character through action, habit and belongings rather than lists of adjectives.
- Keep the scene moving: weave description into action; don't freeze time for a paragraph unless the text already does.
- Prefer concrete nouns and verbs over stacked adjectives.
- The library entry for the person or place is the source of truth for appearance, age, traits and layout; never contradict it.
- Fiction: where the text and the library are silent you may invent small sensory detail. Non-fiction (essay, memoir, travel): render only what the text already implies; add no events, people or facts.

## Don't
- Add named characters or new events.
- Use stock phrases ("a tapestry of", "vibrant", "bustling"), empty stacks of four-character idioms, or the other patterns in the attached AI-tells list.
- Change dialogue or narration around the description.

## Deliver
- Write mode: insert_after the paragraph the description belongs to, or replace an existing description to deepen it. One proposal.
- Review mode: the text in the reply.
- Reply in one or two sentences on what was added. If you invented details the user may want to keep (a scar, a room's layout), suggest recording them with New library entry… in the project menu.

# The Textus name and logo

Textus's code is open source under the [MIT License](LICENSE): use it, change it and share it, for any purpose, as that license says.

The name "Textus" and the Textus logo (the quill icon) stand for the app that CatVinci Studio makes and releases at [textus.md](https://textus.md) and [github.com/CatVinci-Studio/Textus](https://github.com/CatVinci-Studio/Textus). The MIT License covers the code, not the name or the logo.

So a version you build and share from this code:

- has its own name and icon, not "Textus" or the quill;
- doesn't present itself as Textus, or as made or endorsed by CatVinci Studio;
- may say where it comes from: "based on Textus" is welcome.

These are fine without asking:

- building Textus from source for yourself;
- packaging an unchanged release for a package manager, under the name Textus;
- naming Textus when you write about it, compare it or teach it;
- a plugin or theme for Textus that says it is for Textus ("… for Textus").

For anything else, ask at studio@catvinci.com.

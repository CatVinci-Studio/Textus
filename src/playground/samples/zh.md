# 欢迎使用 Textus

Textus 是一款所见即所得的 Markdown 编辑器。点一下就能直接写：Markdown 符号只在光标所在处出现，**加粗**、_斜体_、==高亮==、~~删除线~~ 和 `行内代码` 写的时候也清清楚楚。

## 列表与待办

- [x] 打开在线体验
- [ ] 在行首输入 `## ` 试试
- [ ] 按 Ctrl+/（Mac 上是 ⌘/）查看 Markdown 源码

## 表格

| 功能 | 写法           | 效果       |
| ---- | -------------- | ---------- |
| 标题 | `# 标题`       | 一个标题   |
| 链接 | `[文字](网址)` | 一个链接   |
| 公式 | `$E = mc^2$`   | $E = mc^2$ |

## 公式

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

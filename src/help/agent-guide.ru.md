# Руководство по функциям Textus AI

В Textus встроен ИИ для работы с текстом — Textus AI: автодополнение, проверка грамматики и диалоги, в которых ИИ читает и правит ваш документ. В этом руководстве — как подключить сервис, что умеют функции ИИ и как с помощью папки проекта, профиля стиля, картотеки, инструкций и навыков настроить Textus AI под себя.

## Подключение сервиса

1. Откройте **Настройки > Textus AI** и выберите нужный сервис в разделе **Подключение > Провайдер**.
2. Разверните **Вход и учётные данные** и войдите в аккаунт или введите API-ключ — в зависимости от того, что поддерживает сервис.
3. Для варианта **Свой сервер** (любой сервер, совместимый с OpenAI: локальные модели, прокси) укажите базовый URL, ключ, если он нужен, и название модели, затем сохраните.
4. В разделе **Помощь с текстом** выберите модель в строке **Вспомогательная модель**, а в разделе **Чат Textus AI** — в строке **Модель чата**.

Вход выполняется в браузере. Поддержка изображений, поиска в интернете и правок документа зависит от выбранного сервиса и модели.

Встроенный список моделей содержит только модели по умолчанию для каждого провайдера (для Anthropic — Claude Sonnet 5.5 для чата, Claude Haiku 5.5 для автодополнения и проверки грамматики). Нажмите **Загрузить модели** в строке «Список моделей» раздела **Подключение**, чтобы получить актуальный список провайдера и выбрать из него любую модель.

Для **Doubao (Volcengine)** создайте API-ключ в [консоли Volcengine Ark](https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey) и там же включите модели, которыми хотите пользоваться: запросы к модели, не включённой для вашего аккаунта, Ark отклоняет.

Сочетания клавиш ниже указаны для macOS; в Windows и Linux вместо Cmd нажимайте Ctrl, а вместо Option — Alt. Если вы меняли сочетание, текущее указано в разделе **Настройки > Сочетания клавиш**.

## Функции ИИ

### 1. Автодополнение

Во время набора у курсора появляется серое продолжение текста. Нажмите <kbd>Tab</kbd>, чтобы принять его, или <kbd>Cmd</kbd>+<kbd>→</kbd>, чтобы принять только следующее слово, а остальное оставить в подсказке. <kbd>Esc</kbd> убирает подсказку. Минимального объёма текста нет: автодополнение работает с первого же предложения документа.

Продолжение можно запросить и явно — сочетанием <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> или через контекстное меню (курсор должен стоять в конце абзаца): вы получите более длинное продолжение и до трёх вариантов, между которыми можно переключаться сочетаниями <kbd>Option</kbd>+<kbd>[</kbd> / <kbd>Option</kbd>+<kbd>]</kbd>.

В разделе **Настройки > Textus AI > Помощь с текстом** можно выбрать **тон автодополнения** (как в документе / официальный / непринуждённый / академический / лаконичный). Если документ входит в проект с профилем стиля или картотекой (см. раздел **Настройте Textus AI под себя** ниже), автодополнение учитывает и их.

### 2. Проверка грамматики

Возможные ошибки подчёркиваются. Наведите на подчёркнутое указатель или поставьте в него курсор, чтобы увидеть пояснение: **Применить** (или <kbd>Option</kbd>+<kbd>Enter</kbd>, когда курсор стоит на ошибке) вносит исправление, **Пропустить** убирает замечание. <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> сразу проверяет текущий абзац.

### 3. Панель ИИ

Полный диалог ведётся на панели справа от редактора. Открыть или закрыть её можно кнопкой **Textus AI** (робот) в правом конце строки заголовка окна или сочетанием <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>.

- **Свой диалог у каждого документа**: у каждой вкладки свой диалог, и при переключении вкладок панель переключается вместе с ними. **Новый диалог** в заголовке панели начинает всё заново (если остались правки без решения, панель сначала спросит).
- **Режимы**: в поле ввода их три. **Написание** добавляет в документ новый текст (продолжение, новый абзац или раздел) и только добавляет: если текст выделен, пишет после выделения. **Разбор** отвечает, обсуждает и оставляет комментарии, ничего не меняя. **Правка** меняет уже написанный текст. Каждое изменение в режимах «Написание» и «Правка» — предложение, которое вы принимаете или отклоняете. Панель открывается в режиме, заданном в разделе **Настройки > Textus AI > Чат Textus AI > Режим по умолчанию**.
- **Упоминания через @**: введите `@` в поле ввода, чтобы выбрать текстовый файл из папки проекта; он прикрепится к сообщению.
- **Прикрепление файлов**: кнопка **+** слева от поля ввода прикрепляет к сообщению PDF, документ Word, презентацию PowerPoint, таблицу, изображение или обычный текстовый файл. Всё, кроме изображений, локально превращается в текст и передаётся внутри сообщения; изображения отправляются в исходном виде провайдерам, которые умеют их видеть (если провайдер их не видит, Textus сразу об этом предупредит, а не отбросит изображения молча). Длинный файл отправляется частично, и тогда на его метке появляется «(сокращено)».
- **Поиск в интернете**: если включить его в разделе **Настройки > Textus AI > Чат Textus AI** (для провайдеров, которые его поддерживают), Textus AI сможет сам искать в интернете, когда это нужно для запроса.
- **История**: кнопка **История** (часы) в заголовке панели ИИ показывает прошлые диалоги, сгруппированные по папкам. Нажмите на диалог, чтобы снова открыть его вместе с его документом и продолжить.
- **Ошибки**: если запрос не удался, чат объясняет, что это за проблема и что делать (проверить ключ, подождать, выбрать другую модель), а ниже показывает сообщение самого провайдера.

Кнопка **Открыть в отдельном окне** в заголовке панели переносит диалог в отдельное окно — это удобно, если у вас второй монитор. Это окно следует за вами: стоит переключиться на другую вкладку или окно, и вместе с ними сменятся документ, заголовок и выделение, а предложенные правки попадут в тот файл, который вы сейчас редактируете. У каждого окна редактора может быть только одно такое окно; кнопка **📌** в его заголовке держит его поверх редактора.

### 4. Быстрый вопрос

Нажмите <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> (или выберите в контекстном меню «Спросить ИИ…»), чтобы открыть небольшую строку чата прямо под абзацем, в котором вы находитесь. Она встраивается в документ и сдвигает текст под собой вниз, а не закрывает его. Если при открытии был выделен текст, выделение передаётся вместе с вопросом. Быстрый вопрос открывается в режиме **Правка**, потому что обычно его вызывают на фрагменте, чтобы этот фрагмент изменить («сократи это»); режимы «Написание» и «Разбор» — в один клик в переключателе режимов.

- **Повторное нажатие**: если строка уже открыта, <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> переводит курсор в её поле ввода; ещё одно нажатие в поле ввода закрывает её. <kbd>Esc</kbd> в любом месте строки тоже закрывает её, и курсор возвращается в документ. Если остались правки без решения, перед закрытием (или новым диалогом) появится вопрос.
- У быстрого вопроса свой короткий диалог, отдельный от диалога на панели и не сохраняемый в историю. Быстрый вопрос можно открыть, даже когда панель открыта. **Продолжить в полном диалоге** (кнопка в его углу) передаёт разговор на панель ИИ, где он продолжается и сохраняется. Включите **Настройки > Textus AI > Дополнительно > Открывать полные диалоги в отдельном окне**, чтобы вместо этого он открывался в отдельном окне.

### 5. Правки в документе

Чат никогда не пишет в документ напрямую. Когда вы просите провайдера, который умеет вызывать инструменты, изменить документ, каждое изменение становится правкой и показывается прямо там, где оно будет внесено: удаляемый текст зачёркнут, новый выделен зелёным. Документ не меняется, пока вы не примете правку, а <kbd>Cmd</kbd>+<kbd>Z</kbd> отменяет принятую правку за один шаг.

- **Принять / Отклонить**: на плавающей панели рядом с правкой, в блоке правки на панели ИИ или с клавиатуры — <kbd>Cmd</kbd>+<kbd>Return</kbd> принимает, <kbd>Cmd</kbd>+<kbd>Delete</kbd>, когда курсор стоит на правке, отклоняет. Несколько правок из одного ответа видны сразу; переходите между ними стрелками ‹› и используйте «Принять все» / «Отклонить все».
- **Причины**: в блоке каждой правки сказано, почему Textus AI её предлагает.
- **Только часть предложений**: если правка переписывает несколько предложений, в её блоке есть кнопка **Выбрать предложения (N)** — отметьте нужные и нажмите **Принять K из N**.
- **У курсора**: если ничего не выделено, Textus AI знает, где стоит курсор, поэтому просьба «напиши здесь переход» вставит текст именно туда.
- **Комментарии вместо правок**: попросите отзыв («где здесь слабые места?»), и Textus AI прикрепит комментарии к фрагментам, не меняя их. В блоке каждого комментария есть кнопка **Показать в документе**, которая выделяет фрагмент, к которому он относится.

## Настройте Textus AI под себя

Textus AI узнаёт о вас и вашей работе из нескольких обычных файлов Markdown, а не из скрытых настроек. У каждого из них одна задача:

| Понятие | Что это | Где находится |
| --- | --- | --- |
| **Папка проекта** | Папка, в которой работает Textus AI и которую он может читать | Папка документа или выбранная вами |
| **Профиль стиля** | Как вы пишете | `.textus/style.md` |
| **Картотека** | Факты о людях, местах и терминах | `.textus/library/` |
| **Инструкции** | Постоянные правила для каждого диалога | `agent.md` — глобальные и для каждого проекта |
| **Запомнил ИИ** | То, что Textus AI запоминает из ваших диалогов | `.textus/memory/` и `memory/` в папке глобальных настроек |
| **Навыки** | Сохранённые инструкции, вызов через `/имя` | `skills/` — глобальные и для каждого проекта |
| **Папка глобальных настроек** | То, что действует во всех документах | Папка настроек приложения |

Ниже «диалоги» — это панель ИИ и быстрый вопрос. Вот как выглядит целый проект:

```
мой-роман/               ← папка проекта
├── глава-1.md           ← документ, который вы редактируете
├── заметки/
│   └── хронология.md    ← материалы, доступные Textus AI
└── .textus/              ← собственные настройки проекта
    ├── style.md         ← профиль стиля
    ├── agent.md         ← инструкции для этого проекта
    ├── library/
    │   ├── Линь Вань.md ← по карточке на персонажа, место или термин
    │   └── Харбор-Сити.md
    └── skills/
        └── polish.md    ← по одному навыку на файл
```

Меню проекта создаёт `.textus/` и файлы в ней, когда вы впервые к ним обращаетесь; вручную добавляются только навыки проекта. Текст внутри комментариев `<!-- -->` в любом из этих файлов — заметка для вас самих, он никогда не отправляется.

### Папка проекта

**Папка проекта — это папка, в которой работает Textus AI.** По умолчанию это папка документа, который вы редактируете, или ближайшая папка над ней, в которой есть папка `.textus/` (так глава из `novel/part-1/` относится к `novel/`): стоит сохранить документ, и его папка станет папкой проекта.

- Textus AI может просматривать, находить по имени, читать и искать файлы в этой папке, чтобы найти более ранние сцены с персонажем, термин или ваши заметки: текстовые файлы (Markdown, обычный текст и похожие форматы) размером до 16 МБ — длинные он читает по частям — и текст файлов PDF, Word, PowerPoint и таблиц. С провайдером, который умеет видеть изображения, он также смотрит изображения PNG, JPEG, GIF и WebP в этой папке, до 6 МБ каждое. Скрытые файлы и папки, то, что исключает файл `.gitignore` или `.ignore` (как в поиске файлов на боковой панели), папки сборки и зависимостей (например, `node_modules`) и отсканированные PDF без текстового слоя пропускаются.
- Если ввести `@` в поле ввода чата, к сообщению можно прикрепить один из её файлов.
- В её папке `.textus/` хранятся профиль стиля, картотека, инструкции и навыки проекта.

Название папки проекта показано в строке под заголовком панели ИИ; нажмите на него, чтобы открыть **меню проекта**. Если справочные материалы лежат не рядом с черновиком, выберите там **Другая папка проекта…** (или откройте **Настройки > Textus AI > Папка проекта**). Выбранная папка используется для всех документов, включая несохранённые черновики, пока вы снова не выберете **Использовать папку документа**.

> [!TIP]
> Черновик лежит в `диссертация/черновики/`, а записи интервью — в `диссертация/материалы/`? Выберите папкой проекта `диссертация/`, и Textus AI сможет читать `материалы/интервью.md`, пока вы работаете над `черновики/глава-2.md`.

Всё, что читает Textus AI, должно находиться внутри папки проекта: `..`, абсолютные пути и ссылки за её пределы отклоняются. У несохранённого черновика нет папки проекта, если вы её не выбрали, а слишком общая папка — домашняя папка или целый диск — не подходит.

### Профиль стиля — «Изучить мой стиль»

**Профиль стиля описывает, как вы пишете** — тон и манеру, ритм предложений, лексику, пунктуацию, то, чего вы никогда не делаете, — чтобы продолжения и правки звучали как ваш собственный текст. Textus AI следует ему в диалогах, а автодополнение — во время набора, во всех документах проекта. Это файл `.textus/style.md`.

Создать его можно двумя способами, оба — в меню проекта:

- **Изучить мой стиль по образцам…** — выберите несколько файлов со своими текстами (до восьми). Textus AI изучит их, составит черновик профиля (тон и манера, предложения и ритм, лексика, пунктуация и оформление, структура, чего вы никогда не делаете, а также несколько коротких цитат-примеров) и откроет его в новой вкладке. Прочитайте, исправьте, дополните: профиль ваш. При повторном изучении прежний профиль сохраняется как `style.previous.md`.
- **Создать профиль стиля** — начните с пустого шаблона и заполните его сами.

Когда профиль есть, его открывает кнопка **Стиль** рядом с названием папки.

```markdown
# Профиль стиля

## Предложения и ритм
- Короткие предложения, редко длиннее 15 слов.
- Абзац начинается с конкретной сцены, затем — мысль.

## Никогда
- Никаких восклицательных знаков. Никаких «вдруг».
```

Конкретные, проверяемые пункты работают лучше прилагательных: «короткие предложения, редко длиннее 15 слов», а не «лаконично». Уложитесь в страницу-две: используются только первые 6000 символов. **Тон автодополнения** из настроек тоже действует — оставьте *Как в документе*, если ваш профиль стиля уже описывает вашу манеру.

### Картотека

**В картотеке хранятся факты, которые должны совпадать во всём тексте**: по одному файлу Markdown на каждого персонажа, место или термин в `.textus/library/`. **Новая карточка…** в меню проекта спрашивает имя и открывает новую карточку; кнопка **Картотека** показывает, сколько их.

```markdown
---
name: Линь Вань
aliases: [Вань, госпожа Линь]
include: detected
---

Главная героиня, 32 года, преподаёт китайский в школе Харбор-Сити.
Левша. Никогда не говорит о своём брате.
```

Прикреплять карточки вручную не нужно. Карточка с `include: detected` (по умолчанию) передаётся Textus AI каждый раз, когда встречается её имя или один из псевдонимов: в вашем сообщении или в документе во время диалога, в тексте у курсора во время автодополнения. `always` отправляет её с каждым запросом, `never` не отправляет никогда. Карточки, которые не упоминаются, никуда не отправляются, поэтому картотека может расти вместе с проектом сколько угодно.

### Инструкции (agent.md)

**Инструкции — это постоянные правила, которые отправляются с каждым диалогом**: о чём проект, на каком языке отвечать, как писать отдельные слова и термины, что Textus AI должен делать всегда или не делать никогда. Они хранятся в файлах `agent.md` на двух уровнях:

- **Глобальные** — для всех документов: **Настройки > Textus AI > Инструкции (agent.md) > Изменить agent.md**.
- **Проектные** — для документов одного проекта: `.textus/agent.md`, открывается пунктом **Изменить инструкции проекта** в меню проекта.

Оба файла открываются во вкладке и начинаются с короткого пояснения в комментариях. Если есть оба, Textus AI получает оба — сначала глобальные инструкции, затем проектные, — а при расхождении приоритет у проектных.

```markdown
Книга — детектив, действие которого происходит в Шанхае 1930-х годов.
Рассказ ведётся от первого лица, от имени Линь Вань.
Всегда отвечай по-русски, хотя сам роман — на английском.
Пиши «Харбор-Сити», а не «Харбор Сити».
```

Инструкции действуют только в диалогах. Автодополнение их не читает: оно следует профилю стиля и картотеке.

### Что запоминает Textus AI

**Textus AI запоминает ваши просьбы и то, как вы пишете**, и вам не нужно ничего записывать в файл. Когда вы говорите ему что-то, что должно действовать дольше одного запроса («всегда пиши „ё“», «никаких длинных тире», правку, которую пришлось вносить дважды), или факт о вашей работе, например кто такой персонаж, он запоминает это и следует этому в следующих диалогах. Каждый раз строка под его ответом сообщает, что он запомнил и где: **Отменить** отменяет это, а **Сделать личным** или **Перенести в проект** переносит запись.

- **Этот проект**: то, что касается этой работы, — в `.textus/memory/`; факты о людях, местах и терминах попадают в картотеку.
- **Для всех проектов**: ваши общие привычки — в `memory/` в папке глобальных настроек. Если папки проекта нет, всё попадает сюда.

На вкладке **Память** панели ИИ всё это собрано в разделе **Запомнил ИИ**, с указанием, когда и в каком диалоге запомнена каждая запись: **Изменить** открывает запись, **Удалить** удаляет её. Если запомненное расходится с вашими собственными инструкциями, побеждают инструкции, а ваш `agent.md` и профиль стиля Textus AI никогда не меняет. Когда записей слишком много, чтобы отправить все, самые старые не отправляются, и вкладка «Память» об этом сообщает. **Настройки > Textus AI > Запоминать автоматически** отключает эту функцию.

**Он учится и на ваших решениях по правкам.** Если вы несколько раз отклоняете правку одного и того же рода — 「」 заменены на “”, одно слово заменено другим, предложения разбиты, добавлена оксфордская запятая, — Textus AI после проверки предлагает запомнить это как требование: **Запомнить** сохраняет его в разделе **Запомнил ИИ**, **Не сейчас** ждёт новых случаев, а **Больше не спрашивать** прекращает вопросы об этом роде правок. Он спрашивает не чаще раза в день, и сохраняется что-либо только по вашему нажатию — даже когда «Запоминать автоматически» выключено. Учитывается лишь короткая запись о том, правки каких родов вы приняли или отклонили; она хранится на этом компьютере рядом с вашими воспоминаниями и никуда не отправляется.

### Навыки (/имя)

**Навык — это набор инструкций с именем, который можно применять снова и снова** («шлифовка», «план», «проверка цитат»). Он хранится в одном файле Markdown: вверху имя и описание в одну строку, ниже — полные инструкции.

```markdown
---
name: polish
description: Отшлифовать выделенный фрагмент, не меняя смысла
---

Отшлифуй текст предложение за предложением: убери лишние слова,
разбей слишком длинные предложения, сохрани исходный смысл и интонацию.
Выведи только готовый текст.
```

Навыком можно воспользоваться двумя способами:

1. **Вызвать его**: введите `/` в поле ввода чата и выберите навык в меню или введите его имя и сразу за ним свой запрос: `/polish посмотри ещё раз на этот абзац`.
2. **Просто попросить** (только у провайдеров, которые умеют вызывать инструменты): Textus AI знает имя и описание каждого навыка и, когда запрос соответствует одному из них, сам загружает полные инструкции и следует им.

Навыки бывают на тех же двух уровнях, что и инструкции: глобальные — в папке `skills/` внутри папки глобальных настроек (**Настройки > Textus AI > Навыки > Импортировать навык…** копирует туда файл навыка), проектные — в `.textus/skills/` (это скрытая папка; в Finder на macOS её показывает <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd>). Навык проекта с тем же именем, что и глобальный, заменяет его.

### Встроенные навыки

В Textus есть 19 навыков для типичных задач письма. В меню `/` они разбиты на группы **Написать** (продолжить историю, описать героя или сцену, отшлифовать диалог, подражать стилю), **Переработать** (расширить, сократить, сменить тон, убрать стиль ИИ, перевести и отшлифовать), **Проверить** (вычитать, проверить нестыковки) и **Форматы** (написать письмо, объявление или официальный документ, протокол встречи, научная редактура, пост для соцсетей, заголовок, кратко изложить, создать тему). Введите `/` и выберите навык или наберите его название на любом из языков приложения: `/proofread`, `/вычитать` и `/校对` вызывают один и тот же навык. Большинство навыков Textus AI выбирает и сам, если запрос им соответствует; **Расширить**, **Сократить**, **Сменить тон** и **Кратко изложить** запускаются только по вашему вызову. **Создать тему** пишет в ответе тему редактора в CSS по вашему описанию: кнопка **Использовать эту тему** под ответом устанавливает и включает её, а можно сохранить её в файл .css и импортировать через **Настройки > Редактор и оформление > Импортировать CSS…**.

В разделе **Настройки > Textus AI > Встроенные навыки** перечислены все навыки. Переключатель отключает навык: он пропадает из меню `/`, и Textus AI перестаёт им пользоваться. **Настроить…** копирует навык в папку `skills/` глобальной папки настроек и открывает копию, чтобы вы могли изменить инструкции; после этого работает ваша копия. **Сбросить** удаляет копию и возвращает встроенную версию. Ваш собственный навык с именем встроенного заменяет встроенный.

### Нормы оформления

**Настройки > Textus AI > Помощь с текстом > Нормы оформления** определяет, каким правилам пунктуации, пробелов и записи чисел следуют Textus AI и проверка грамматики. **Автоматически** — значит по национальной норме, если она у языка есть (для русского — правила русской орфографии и пунктуации, для японского — JTF); в остальных случаях Textus следует тому, как чаще пишут в самом документе, и отмечает только разнобой. Если выбрать профиль, например **GOST** для русского, документы на этом языке будут проверяться по нему.

У проекта может быть свой выбор: добавьте строку `conventions:` между двумя строками `---` в начале профиля стиля (`.textus/style.md`). Для документов этого проекта она важнее настройки.

```markdown
---
conventions: zh-Hans-CN/fiction, en-GB/govuk
---
```

### Папка глобальных настроек

**В папке глобальных настроек хранится то, что действует во всех документах**: ваш глобальный `agent.md` и глобальные навыки. Она принадлежит приложению, а не какому-либо проекту; открыть её можно через **Настройки > Textus AI > Папка глобальных настроек > Показать**.

```
agent/                ← папка глобальных настроек
├── agent.md          ← глобальные инструкции
└── skills/
    └── outline.md    ← глобальный навык
```

Глобального профиля стиля и глобальной картотеки нет: они описывают одно конкретное произведение, поэтому относятся к проекту.

### Что и когда действует

| | Диалоги | Автодополнение | Проверка грамматики |
| --- | :---: | :---: | :---: |
| Файлы проекта (чтение, поиск, `@`) | ✓ | | |
| Профиль стиля | ✓ | ✓ | |
| Упомянутые карточки картотеки | ✓ | ✓ | |
| Инструкции | ✓ | | |
| Что запомнил Textus AI | ✓ | | |
| Навыки | ✓ | | |
| Тон автодополнения (настройки) | | ✓ | |

- **Сначала глобальные, затем проектные.** Отправляются инструкции обоих уровней, проектные — последними, и при противоречии приоритет у них. Навык проекта заменяет глобальный навык с тем же именем.
- **Одна папка проекта за раз.** Учитывается только её `.textus/`: если вы выбрали папку проекта, `.textus/` рядом с документом не читается.
- **Перезапуск не нужен.** Измените любой из этих файлов, и следующий запрос уже использует новую версию (автодополнение — примерно в течение десяти секунд).

### Какой файл для чего?

- Как должен звучать ваш текст → **профиль стиля**.
- Кто есть кто и что есть что → **картотека**.
- Что Textus AI должен знать или всегда делать в диалоге → **инструкции**.
- Задача, о которой вы просите снова и снова → **навык**.
- Заметки, материалы, прежние главы → обычные файлы в **папке проекта**; Textus AI прочитает их, когда это понадобится для запроса.

## О конфиденциальности

Ваш документ, прикреплённые и упомянутые через @ файлы, ваши инструкции, профиль стиля, упомянутые карточки картотеки и все файлы проекта, которые читает Textus AI, отправляются выбранному провайдеру в составе каждого запроса; функция **Изучить мой стиль** отправляет выбранные вами образцы. Поиск в интернете выполняется на серверах этого провайдера. Если вы этого не хотите, отключите нужную функцию в настройках.

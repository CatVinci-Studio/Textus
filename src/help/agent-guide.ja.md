# Textus AI機能ガイド

Textusには執筆専用のAI「Textus AI」が内蔵されています。続き書き、文法チェック、そして文書を読んで書き直す対話です。このガイドでは、サービスの接続方法、AI機能の使い方、そしてプロジェクトフォルダー、文体プロファイル、ライブラリ、執筆の指示とスキルを使ってTextus AIを自分だけの執筆アシスタントにカスタマイズする方法を説明します。

## サービスの接続

1. **設定 > Textus AI** を開き、**接続** の **プロバイダー** で使うサービスを選びます。
2. **ログインと認証** を展開し、そのサービスが対応する方法でアカウントにサインインするか、APIキーを入力します。
3. **カスタムエンドポイント**(OpenAI互換の任意のサーバー:ローカルモデル、中継サービスなど)を使う場合は、ベースURL、必要ならキー、モデル名を入力して保存します。
4. 執筆モデルは **執筆アシスト** で、チャットモデルは **Textus AI チャット** で選びます。

サインインはブラウザで行います。画像、ウェブ検索、文書の編集が使えるかどうかは、選んだサービスとモデルによります。

内蔵のモデル一覧には各プロバイダーの既定モデルだけが入っています(Anthropicの場合、チャットはClaude Sonnet 5.5、補完と文法チェックはClaude Haiku 5.5)。**接続** のモデル一覧の行にある **モデル一覧を取得** を押すと、そのプロバイダーの現在のモデル一覧を読み込んで、その中から選べます。

**Doubao（Volcengine）** を使うときは、[Volcengine Ark のコンソール](https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey)で API キーを作成し、同じコンソールで使いたいモデルを有効にしてください。有効にしていないモデルへのリクエストは Ark に拒否されます。

以下のショートカットはmacOSの表記です。WindowsとLinuxではCmdをCtrl、OptionをAltに読み替えてください。ショートカットを変更した場合は、**設定 > ショートカット** の設定が優先されます。

## AI機能

### 1. 続き書き(補完)

入力中にカーソル位置へ自動的にグレーの続き書き候補が表示され、<kbd>Tab</kbd>で採用します。<kbd>Cmd</kbd>+<kbd>→</kbd> なら次の1語だけを採用し、残りは候補のまま残ります。<kbd>Esc</kbd>で候補を消します。最小文字数の制限はなく、文書の最初の一文からでも動作します。

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> または右クリックメニューで明示的に呼び出すと(カーソルは段落の末尾に置きます)、より長い続き書きが最大3つの候補とともに表示されます —— <kbd>Option</kbd>+<kbd>[</kbd> / <kbd>Option</kbd>+<kbd>]</kbd> で切り替えます。

**設定 > Textus AI > 執筆アシスト** で**補完のトーン**（文書に合わせる / フォーマル / カジュアル / 学術的 / 簡潔）を調整できます。文書が文体プロファイルやライブラリを持つプロジェクトに属している場合(後述の「Textus AIを自分仕様にする」を参照)、補完もそれに従います。

### 2. 文法チェック

問題の可能性がある箇所に下線が引かれます。ホバーするか、カーソルをその中に移すと説明が表示されます。**適用**(またはカーソルがその上にあるときに <kbd>Option</kbd>+<kbd>Enter</kbd>)で修正を取り込み、**無視**で表示を消します。ショートカット <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> で現在の段落を即座にチェックします。

### 3. AIパネル

会話全体はエディタ右側のパネルにあります。ウィンドウバー右端の **Textus AI** ボタン（羽ペンのアイコン）、または <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> で開閉します。

- **文書ごとに1つの会話**:タブごとに会話があり、タブを切り替えるとパネルも切り替わります。パネルのヘッダーの **新しい会話** でやり直せます(未処理の編集があるときは先に確認します)。
- **モード**:入力欄には2つのモードがあります。**執筆** は文書に手を入れます。新しい文章を書き足し(続き、新しい段落や節)、今ある文章も書き換えます(書き直し、翻訳、削る)。選択中のテキストがあれば、それへの変更は選択範囲を置き換え、書き足す文章はその後ろに入ります。**レビュー** は質問に答え、相談に乗り、コメントを付けますが、文書は変えません。執筆の変更はどれも提案で、適用するか却下するかを選べます。パネルの初期モードは **設定 > Textus AI > Textus AI チャット > デフォルトモード** で設定します。
- **@メンション**:入力欄で `@` と入力すると、プロジェクトフォルダー内のテキストファイルを選んでメッセージに添付できます。
- **ファイルの添付**:入力欄左側の **+** をクリックすると、PDF、Word、PowerPoint、表計算、EPUB電子書籍、RTF・HTMLファイル、画像、テキストファイルをそのメッセージに添付できます。画像以外はローカルでテキストに変換されてメッセージに埋め込まれ、画像は視覚に対応したプロバイダーへ本物の画像として送られます(非対応のプロバイダーは黙って捨てるのではなく、その場で知らせます)。長いファイルは一部のみが送られ、その場合は添付タグに「（一部のみ）」と表示されます。
- **モデル**:入力欄のコントロールの中にあるボタンに、次のメッセージを送るモデルの名前が表示されます。クリックすると、**設定 > Textus AI** で設定したどのサービスのモデルにも切り替えられます。モデルが1つしかないときは、その名前が表示されるだけです。
- **ウェブ検索**:入力欄の横の虫めがねボタンで、必要なときにTextus AIがウェブを検索します。詳しくは下の **7. ウェブ検索** を参照してください。
- **じっくり考える**:ウェブ検索の隣のボタン(電球のアイコン)を押すと、モデルは答える前にじっくり考えます。時間も料金もかかるので、難しい質問や大きな書き直しに向いています。もう一度押すまで、文書を切り替えてもオンのままです。考えている間はパネルに「考え中 · 8 秒」と表示され、終わると「12 秒考えました」に変わります。プロバイダーが思考の内容を返す場合は、クリックすると読めます。ボタンはより深く考えられるモデルでだけ表示されます。クイック質問はいつも素早い回答を求めます。
- **履歴**：AIパネル上部の「履歴」ボタン（時計のアイコン）に、過去の会話がフォルダーごとに表示されます。上部の **会話を検索** で、ある言葉が出てきた会話を探せます。クリックすると、その会話の文書とともに開き直して続けられます。以前の会話に触れると、Textus AIもそれらを検索します。
- **エラー時**:リクエストが失敗すると、プロバイダー自身のメッセージの上に、どんな種類の問題で何をすればよいか(キーを確認する、使い切った残高をチャージする、少し待つ、別のモデルを選ぶ)が、お使いの言語で表示されます。チャットだけでなく、続き書きや文法チェックでも同じです。
- **長い文書**:長い文書を章ごとに翻訳したり書き直したりするよう頼むと、Textus AIは各章を自分の手伝い役に任せ、繰り返し出てくる名前や用語の書き方を共通のリストにまとめるので、文書全体を一度に変えられます。

パネルのヘッダーの **別ウィンドウで開く** で、会話を独立したウィンドウに移せます。2台目のモニターで便利です。このウィンドウはあなたに追従します:タブやウィンドウを切り替えると、文書・タイトル・選択範囲がそれに追従し、提案される編集はその時点で編集しているファイルに落ちます。独立ウィンドウはエディタウィンドウごとに1つだけです。ヘッダーの **📌** でエディタより前面に固定できます。

### 4. クイック質問

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>(または右クリック > AIに聞く…)で、いまいる段落のすぐ下に小さな対話バーを開きます。バーは文書の中に置かれ、本文を覆わずに下の内容を押し下げます。開く前にテキストを選択していれば、その選択範囲も渡されます。クイック質問は **執筆** モードで開きます。たいていは書き換えたい箇所で開くからです(「ここを短く」)。レビューにはモード選択からワンクリックで切り替えられます。

- **もう一度ショートカット**:バーが開いているときに <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> を押すと入力欄にカーソルが移り、入力欄でもう一度押すとバーを閉じます。バー内のどこでも <kbd>Esc</kbd> で閉じられ、カーソルは本文に戻ります。未処理の編集があるときは、閉じる前(または新しい会話を始める前)に確認します。
- クイック質問はパネルとは別の短い会話を持ち、履歴には保存されません。パネルを開いていても使えます。右上の **会話パネルで続ける** で、このやり取りを AI パネルに引き継ぎ、そこで続けて履歴に保存できます。**設定 > Textus AI > 詳細設定 > 会話全体を別ウィンドウで開く** を有効にすると、代わりに別ウィンドウで開きます。

### 5. 文書内での編集

対話が文書を直接書き換えることはありません。ツール呼び出しに対応したプロバイダーに文書の変更を依頼すると、変更はそれぞれ提案として変更箇所にその場で表示されます:削除されるテキストには取り消し線、追加されるテキストは緑色で表示されます。適用するまで文書には一切変更が加わらず、<kbd>Cmd</kbd>+<kbd>Z</kbd>で適用済みの変更を一度で取り消せます。

- **適用 / 却下**:編集のそばのフローティングバー、パネル内の提案カード、またはキーボードで操作します —— <kbd>Cmd</kbd>+<kbd>Return</kbd> で適用、カーソルが編集の上にあるときに <kbd>Cmd</kbd>+<kbd>Delete</kbd> で却下。1回の返信に複数の提案がある場合は同時にプレビューされ、‹›で切り替え、すべて適用/すべて却下もできます。
- **理由**:提案カードには、Textus AIがその変更をした理由が表示されます。
- **一部の文だけ**:提案が複数の文を書き換える場合、カードに「N か所の文の変更 · 選んで適用」が表示されます —— 欲しい文にチェックを入れて **選択した変更を適用** を押します。
- **カーソル位置に**:何も選択していないとき、Textus AIはカーソルの位置を把握しているので、「ここにつなぎの文を」と頼めばちょうどそこに挿入されます。
- **編集ではなくコメント**:レビューを頼むと(「ここの弱いところは？」)、Textus AIは本文を変えずに該当箇所へコメントを付けます。コメントカードの **文書内で表示** を押すと、その箇所が選択されます。
- **自分のメモ**:語句を選んで右クリックし、**メモを追加** を選ぶと、Textus AIのコメントと並んで余白にあなたのメモが入り、「自分」と表示されます。メモはMarkdownの中ではなく、Textus自身のデータと一緒に保存されます。
- **変更を記録**(表示メニュー):オンの間は、自分の編集も変更として表示されます。削除した部分には取り消し線が引かれ、追加した部分には印が付きます。それぞれ余白に「自分」と表示されたカードが出て、適用か却下を選べます。

### 6. 画像

**設定 > Textus AI** で **画像モデル** を選ぶと、Textus AI が文書用の画像を作れるようになります。画像は1枚ごとにサービス側で少し費用がかかるため、選ぶまでは **なし** です。サービスとモデルを選んでください：OpenAI、Google Gemini、Doubao（Volcengine）、Alibaba Qwen、Zhipu GLM、SiliconFlow、または OpenAI 互換のエンドポイント。そのサービスをすでにチャットに使っていればそのキーを使い、なければ設定でキーを尋ねます。

- 執筆モードで頼むか（「最初の段落の後に港の絵を入れて」）、段落を右クリックして **この段落に挿絵を付ける** を選びます。
- 画像はほかの挿入と同じく、置かれる場所に提案として表示されます。採用するまで何も保存されません。採用すると、貼り付けた画像と同じく **設定 > 画像** のとおりに保存され、Markdown の画像として挿入されます。却下すれば何も残りません。
- 提案された画像を描き直すには、画像にポインターを合わせて **描き直す…** を選び、変えたい点を伝えます。描き直されるのはその画像だけです。1つの作品の中の画像は、同じ人物と雰囲気を保ちます。再び登場する人物は同じ言葉で描写され、画像モデルが参考画像を受け取れる場合は、その人物の新しい画像は以前の画像をもとに描かれます。
- サービスが説明を断った場合は、その理由がパネルに表示されます。1回の依頼で作る画像は2枚までです。

### 7. ウェブ検索

入力欄の横の **ウェブ検索** ボタンをオンにすると(最初からオンにするには **設定 > Textus AI > Textus AI チャット > ウェブ検索**)、最新の事実や確かでない事実が必要なとき、Textus AIがウェブで調べます。貼り付けたアドレスのページを読むこともできます。

- **誰が検索するか**:自分で検索できるモデル(OpenAI、Claude、Grok、OpenRouter、Groq、Qwen、Zhipu GLM)は、それぞれの検索を使います。それ以外のモデル(DeepSeek、Gemini、Mistral、Kimi、ローカルモデル、カスタムエンドポイント)では、設定の「ウェブ検索」の下にある **検索サービス** でTextusが検索します。**自動** はチャット用に保存済みのDeepSeek、Zhipu、Kimiのキーを使います。Bocha、Tavily、Brave Search、Exaを選んでキーを入力するか、SearXNGを選んで自分のサーバーのアドレスを入力することもできます。この行には検索内容の送り先が表示されます。検索に使えるものがないときは、ボタンに赤い点が付きます。
- **出典**:返信は見つけた内容を [1]、[2] で示し、そのページを下に並べます。クリックするとブラウザで開きます。番号は会話全体で変わりません。
- **出典を脚注として追加**:提案がウェブの内容に基づくとき、提案カードに **出典を脚注として追加** が表示されます。チェックすると、採用時に文書の末尾へ出典のMarkdown脚注を加えます。チェックしなければ、出典なしで本文だけが入ります。カードは前回の選択を覚えています。
- **ページは読むだけで、従わない**:ページに書かれた内容がTextus AIへの指示になることはなく、編集はこれまでどおり提案だけです。Textusが読むのは公開ウェブのページだけで、あなたのコンピューターやローカルネットワーク上のものは読みません。

## Textus AIを自分仕様にする

Textus AIがあなたとあなたの作品について知る手がかりは、隠れた設定ではなく、いくつかの普通のMarkdownファイルです。それぞれの役割は1つだけです：

| 概念 | 何か | 置き場所 |
| --- | --- | --- |
| **プロジェクトフォルダー** | Textus AIが作業し、読み取れるフォルダー | 文書のフォルダー、または自分で選んだフォルダー |
| **文体プロファイル** | あなたの書き方 | `.textus/style.md` |
| **ライブラリ** | 人物・場所・用語の設定 | `.textus/library/` |
| **執筆の指示** | 毎回の会話で守らせる常設のルール | `agent.md`（グローバルとプロジェクトごと） |
| **記憶** | Textus AIが会話から覚えておくこと | `.textus/memory/` と、グローバル設定フォルダーの `memory/` |
| **スキル** | `/名前` で呼び出す再利用できる指示 | `skills/`（グローバルとプロジェクトごと） |
| **グローバル設定フォルダー** | すべての文書に適用されるもの | アプリの設定フォルダー |

以下の「会話」は、AIパネルとクイック質問のことです。プロジェクト全体はおおよそ次のようになります：

```
私の小説/                ← プロジェクトフォルダー
├── 第一章.md            ← 編集中の文書
├── メモ/
│   └── 年表.md          ← Textus AIが参照できる資料
└── .textus/              ← プロジェクト自身の設定
    ├── style.md         ← 文体プロファイル
    ├── agent.md         ← このプロジェクトの執筆の指示
    ├── library/
    │   ├── 林晩.md       ← 人物・場所・用語ごとに1項目
    │   └── 港町.md
    └── skills/
        └── polish.md    ← 1ファイル1スキル
```

`.textus/` とその中のファイルは、プロジェクトメニューから初めて使うときに自動で作られます。手で追加するのはプロジェクトのスキルだけです。どのファイルでも、`<!-- -->` のコメント内に書いたことは自分用のメモで、送信されることはありません。

### プロジェクトフォルダー

**プロジェクトフォルダーは、Textus AIが作業するフォルダーです。** 既定では編集中の文書があるフォルダー、またはその上にある、`.textus/` フォルダーを持ついちばん近いフォルダーです（たとえば `novel/part-1/` にある章は `novel/` に属します）。文書を保存すると、そのフォルダーがプロジェクトフォルダーになります。

- Textus AIはその中のファイルを一覧・名前で検索・読み込み・全文検索でき、登場人物の以前の場面、用語、メモなどを探せます。対象は16 MBまでのテキストファイル（Markdown、テキストなど。長いファイルは少しずつ読みます）と、PDF、Word、PowerPoint、表計算、EPUB、RTFファイルのテキストです。画像を扱えるプロバイダーなら、その中のPNG、JPEG、GIF、WebP画像（1枚6 MBまで）も見られます。隠しファイルと隠しフォルダー、`.gitignore` や `.ignore` で除外されたもの（サイドバーのファイル検索と同じ）、ビルドや依存関係のフォルダー（`node_modules` など）、テキスト層のないスキャンPDFは対象外です。
- 対話の入力欄で `@` と入力すると、その中のファイルをメッセージに添付できます。
- その `.textus/` フォルダーに、このプロジェクトの文体プロファイル、ライブラリ、執筆の指示、スキルが置かれます。

AIパネルのヘッダーの下にあるバーにプロジェクトフォルダーの名前が表示され、クリックすると**プロジェクトメニュー**が開きます。参考資料が草稿と別の場所にあるときは、そこから **プロジェクトフォルダーを選択…** を使います（**設定 > Textus AI > プロジェクトフォルダー** でも選べます）。選んだフォルダーは、**文書のフォルダーを使う** で戻すまで、保存していない草稿も含めてすべての文書で使われます。

> [!TIP]
> 草稿は `論文/草稿/`、インタビューのメモは `論文/資料/` にある？ `論文/` をプロジェクトフォルダーに選べば、`草稿/第二章.md` を書きながら、Textus AIが `資料/インタビュー.md` を読めます。

Textus AIが読むものはすべてプロジェクトフォルダー内に限られ、`..`、絶対パス、外部を指すリンクはいずれも拒否されます。フォルダーを選んでいない場合、保存していない草稿にはプロジェクトフォルダーがありません。範囲が広すぎるフォルダー（ホームフォルダーやドライブ全体）も拒否されます。

### 文体プロファイル ——「文体を学習」

**文体プロファイルは、あなたの書き方の説明です。** 続き書きや編集があなたらしく読めるように、語調、文のリズム、言葉選び、句読点、決して使わない書き方を書きます。プロジェクト内のすべての文書で、Textus AIは会話のときに、補完は入力中に、これに従います。実体は `.textus/style.md` というファイルです。

作り方は2つあり、どちらもプロジェクトメニューにあります：

- **サンプルから文体を学習…** —— 自分で書いたファイルをいくつか（8つまで）選びます。Textus AIがそれを読んでプロファイルを下書きし（語調、文とリズム、言葉選び、句読点と書式、構成、使わない書き方、例として短い引用をいくつか）、新しいタブで開きます。読んで、違うところを直し、足りないところを書き足してください。もうあなたのものです。もう一度学習すると、以前のプロファイルは `style.previous.md` として残ります。
- **文体プロファイルを作成** —— 空の見出しから自分で書きます。

プロファイルができると、フォルダー名の横に**文体**チップが表示され、クリックで開けます。

```markdown
# 文体プロファイル

## 文とリズム
- 一文は短く、40字を超えることはまれ。
- 段落は具体的な場面から始め、それから要点を書く。

## 使わない
- 感嘆符は使わない。「突然」は使わない。
```

形容詞より、確かめられる具体的な項目のほうが効きます。「簡潔」ではなく「一文は短く、40字を超えることはまれ」と書きましょう。分量は1〜2ページまでに。使われるのは最初の6,000文字だけです。設定の**補完のトーン**も同時に適用されます。文体プロファイルで書きぶりを説明済みなら、「文書に合わせる」のままにしておきましょう。

### ライブラリ

**ライブラリには、一貫させたい設定を置きます。** 人物・場所・用語ごとに1つのMarkdownファイルで、`.textus/library/` に入ります。プロジェクトメニューの **ライブラリに項目を追加…** で名前を入力すると、新しい項目が開きます。**ライブラリ**チップに項目の数が表示されます。

```markdown
---
name: 林晩
aliases: [晩ちゃん, 林先生]
include: detected
---

主人公、32歳、港町の中学校で国語を教えている。
左利き。兄のことは決して話さない。
```

項目を自分で添付する必要はありません。`include: detected`（既定）の項目は、名前か別名が出てきたときに自動的にTextus AIへ渡されます。会話ではあなたのメッセージと文書、補完ではカーソル付近のテキストが対象です。`always` は毎回のリクエストに含まれ、`never` は決して含まれません。言及されない項目はコストにならないので、ライブラリはプロジェクトに合わせていくらでも育てられます。

### 執筆の指示（agent.md）

**執筆の指示は、毎回の会話に添えられる常設のルールです。** このプロジェクトが何なのか、どの言語で返信するか、表記や用語、Textus AIが常に守ること・決してしないことを書きます。`agent.md` というファイルに書き、2つの階層があります：

- **グローバル**（すべての文書）：**設定 > Textus AI > 執筆の指示（agent.md）> agent.mdを編集**。
- **プロジェクト**（1つのプロジェクトの文書だけ）：`.textus/agent.md`。プロジェクトメニューの **このプロジェクトの執筆の指示を編集** で開きます。

どちらもタブで開き、冒頭にコメントで短い説明が入っています。両方あるときはTextus AIに両方が渡され（先にグローバル、後にプロジェクト）、食い違う点はプロジェクトの指示が優先されます。

```markdown
1930年代の上海を舞台にしたミステリー。語り手は林晩（一人称）。
常に日本語で返信する。
人物名は「林晩」と書き、「林晚」とは書かない。
```

執筆の指示が使われるのは会話だけです。補完はこれを読まず、文体プロファイルとライブラリに従います。

### Textus AIが覚えること

**Textus AIは、あなたの頼みごとや書き方を覚えます。** ファイルを書く必要はありません。1回の依頼を超えて守ってほしいこと（「常に常体で書く」「ダッシュは使わない」、2度も直す羽目になった修正など）や、登場人物が誰かといった作品についての事実を伝えると、Textus AIはそれを覚えて、以降の会話で従います。そのたびに返信の下に、何をどこに覚えたかを示す1行が出ます。**元に戻す** で取り消し、**全体に移す** や **プロジェクトに移す** で移動できます。

- **このプロジェクト**：この作品に関することは `.textus/memory/` に入ります。人物・場所・用語についての事実はライブラリに入ります。
- **すべてのプロジェクト**：あなたの全般的な習慣は、グローバル設定フォルダーの `memory/` に入ります。プロジェクトフォルダーがないときは、すべてここに入ります。

AIパネルの **プロジェクト** タブには、**記憶** の下にすべてが一覧になり、それぞれいつ、どの会話で覚えたかも表示されます。**編集** で開き、**削除** で消します。Textus AIはときどき記憶を整理し、同じことを言っている記憶をまとめ、より新しいルールに覆されたルールを外します。外したものは **最近忘れたもの** にあり、元に戻せます。自分で書いた執筆の指示と食い違うときは執筆の指示が優先され、Textus AIがあなたの `agent.md` や文体プロファイルを書き換えることはありません。記憶が多すぎて送りきれないときは古いものから省かれ、プロジェクトタブにそのことが表示されます。**設定 > Textus AI > 自動で覚える** でオフにできます。

**修正の採否からも学びます。** 同じ種類の変更――「」を“”にする、ある語を別の語にする、文を分割する、オックスフォード・コンマを加える――を何度も却下すると、レビューが終わったあとで Textus AI がそれを要望として覚えておくかたずねます。**覚えておく**で**記憶**に保存され、**今はしない**ならもう少し様子を見て、**今後たずねない**ならその種類についてはもうたずねません。たずねるのは1日1回までで、保存されるのはクリックしたときだけです（「自動で覚える」をオフにしていても同じです）。数えているのは、どの種類の変更を採用・却下したかの短い記録だけで、このコンピュータの記憶と同じ場所に保存され、送信されることはありません。

### スキル（/名前）

**スキルは、名前の付いた再利用できる指示です。**「推敲」「アウトライン」「引用の確認」などを1つのMarkdownファイルに書きます。先頭に名前と1行の説明、その下に完全な指示を書きます。

```markdown
---
name: polish
description: 選択した段落を、意味を変えずに引き締めて磨き上げる
---

与えられたテキストを一文ずつ磨き上げる：冗長な語を削り、
長い文を短く分割し、元の意味とトーンは変えない。
磨き上げた後のテキストのみを出力する。
```

スキルの使い方は2つあります：

1. **呼び出す**：対話の入力欄に `/` と入力してメニューから選ぶか、名前に続けて依頼を書きます（例：`/polish この段落も見て`）。
2. **ただ頼む**（ツール呼び出しに対応したプロバイダーのみ）：Textus AIは各スキルの名前と説明を把握しており、依頼がいずれかに合うと、自分で完全な指示を読み込んで従います。

頼んだことが自分なりの手順――また使いたくなる一連のステップ――だったときは、Textus AIが返信の下で、それをスキルとして残すかたずねます。すべての文書用にも、このプロジェクト専用にもできます。選ばない限り何も保存されません。

スキルも執筆の指示と同じ2つの階層に置けます。グローバルのスキルはグローバル設定フォルダーの `skills/` に（**設定 > 拡張機能 > スキル > … > スキルをインポート…** でスキルファイルがそこへコピーされます）、プロジェクトのスキルは `.textus/skills/` に置きます（隠しフォルダーです。macOSのFinderでは <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> で表示できます）。同じ名前のスキルがあるときは、プロジェクトのものがグローバルのものに代わって使われます。

### 組み込みスキル

Textus には 4 つのスキルが組み込まれています。レビューモードの**校正**は、文章の言語の規範に沿って、誤字、文法、句読点、数字をチェックします。作成モードの**テーマを作る**、**プラグインを作る**、**スキルを作る**は、説明に合わせてエディターのテーマ、小さなプラグイン、自分用のスキルを作ります。ほかのスキル（膨らませる、簡潔にする、翻訳、要約、設定の整合性チェック、メール、議事録など）は**設定 > 拡張機能 > スキル > さらに入手**にあります。`/` を入力してメニューから選ぶか、アプリのどの言語の名前でも入力できます。`/proofread`、`/校对`、`/校正` はどれも同じスキルを呼び出します。依頼の内容が合えば、Textus AI が自分でスキルを選んで使うこともあります。**テーマを作る**は、テーマの CSS を返信に書きます。返信の下の**このテーマを使う**でインストールするか、.css ファイルに保存して**設定 > 編集と外観 > CSSをインポート…**で読み込みます。

組み込みスキルは **設定 > Textus AI > 組み込みスキル** にあり、常にオンです。**カスタマイズ…** はスキルをグローバル設定フォルダーの `skills/` にコピーしてそのコピーを開くので、指示を書き換えられます。以後はそのコピーが使われます。**リセット** はコピーを削除し、組み込みの版に戻します。**設定 > 拡張機能 > スキル** には追加したスキルが並びます。それぞれ使えるモードが表示され、クリックすると変更できます。横のスイッチで一時的にオフにでき、モードはそのまま残るので、オンに戻せば元どおりです。組み込みスキルと同じ名前の自作スキルがある場合は、自作のものが代わりに使われます。

### 表記ルール

**設定 > Textus AI > 執筆アシスト > 表記ルール** では、Textus AI と文法チェックが従う句読点・スペース・数字の表記ルールを選びます。**自動**では、国や業界の標準がある言語はそれに従い（たとえば日本語は JTF 日本語標準スタイルガイド、簡体字中国語は GB/T）、それ以外は文書の中ですでに多数派になっている書き方に合わせ、ゆれだけを指摘します。ルールを1つ選ぶと（たとえば日本語の**小説**）、その言語の文書はそのルールでチェックされます。

プロジェクトごとに指定することもできます。文体プロファイル（`.textus/style.md`）の先頭にある2本の `---` の間に `conventions:` の行を加えると、そのプロジェクトの文書では設定よりこちらが優先されます。

```markdown
---
conventions: zh-Hans-CN/fiction, en-GB/govuk
---
```

### グローバル設定フォルダー

**グローバル設定フォルダーには、すべての文書に適用されるものを置きます。** グローバルの `agent.md` とグローバルのスキルです。どのプロジェクトにも属さないアプリ自身のフォルダーで、**設定 > Textus AI > グローバル設定フォルダー > 表示** で開けます。

```
agent/                ← グローバル設定フォルダー
├── agent.md          ← グローバルの執筆の指示
└── skills/
    └── outline.md    ← グローバルのスキル
```

文体プロファイルとライブラリにはグローバル版がありません。どちらも1つの作品を説明するものなので、プロジェクトに属します。

### いつ何が使われるか

| | 会話 | 補完 | 文法チェック |
| --- | :---: | :---: | :---: |
| プロジェクトのファイル（読み込み・検索・`@`） | ✓ | | |
| 文体プロファイル | ✓ | ✓ | |
| 言及されたライブラリの項目 | ✓ | ✓ | |
| 執筆の指示 | ✓ | | |
| Textus AIが覚えたこと | ✓ | | |
| スキル | ✓ | | |
| 補完のトーン（設定） | | ✓ | |

- **グローバルが先、プロジェクトが後。** 両方の執筆の指示が送られ、プロジェクトの指示が後に来て、食い違う点では優先されます。同じ名前のスキルは、プロジェクトのものが使われます。
- **プロジェクトフォルダーは常に1つ。** 有効なのはその `.textus/` だけです。プロジェクトフォルダーを選んだ場合、文書の隣にある `.textus/` は読まれません。
- **再起動は不要。** これらのファイルを編集すると、次のリクエストから新しい内容が使われます（補完には10秒ほどで反映されます）。

### 何をどこに書くか

- 文章がどう読めるべきか → **文体プロファイル**
- 誰が誰で、何が何か → **ライブラリ**
- 会話でTextus AIが知っておくべきこと、常に守ること → **執筆の指示**
- 何度も頼む同じ種類の作業 → **スキル**
- メモ、資料、前の章 → **プロジェクトフォルダー**の普通のファイル（必要なときにTextus AIが自分で読みます）

## Textus AI をオフにする

ウィンドウバー右端の **Textus AI** ボタンを右クリックすると、Textus AI を 1 時間停止するか、オフにできます。オフの間は羽ペンに斜線が入り、クリックするとオンに戻せます。一時停止は 1 時間たつと自動で解除されます。**設定 > Textus AI > Textus AI を有効にする**、そして **設定 > ショートカット** で設定できるショートカットでもオン・オフできます。iPhone ではメニューにあります。

オフの間は、Textus を開いた瞬間から、どの AI サービスにも何も送信しません。補完も文法チェックも会話も、記憶することもありません。AI パネル、クイック質問、右クリックメニューの AI の項目は消え、書いている途中の返信は止まります。文書の中にすでに提案された編集はそのまま残り、承認するか却下するかを選べます。各機能はそれぞれの設定を保ち、Textus AI をオンに戻すと、すべて元どおりに働きます。

## プライバシーについて

文書の内容、添付・@メンションしたファイル、執筆の指示、文体プロファイル、言及されたライブラリの項目、Textus AIが読み込んだプロジェクト内のファイルは、選択したプロバイダーへリクエストとともに送信されます。**サンプルから文体を学習** では選んだサンプルが送信されます。ウェブ検索がオンのとき、検索内容は選択したプロバイダー、または設定に表示された検索サービスへ送られ、Textus AIが読むページはこのコンピューターから取得されます。不要な場合は設定で該当機能をオフにしてください。

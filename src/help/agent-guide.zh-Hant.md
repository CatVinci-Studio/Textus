# Textus AI 功能指南

Textus 內建一個專為寫作打造的 AI：Textus AI。它提供續寫、文法檢查，以及能閱讀並修改文件的對話。本指南說明如何連線到 AI 服務、各項 AI 功能，以及如何用專案資料夾、文風檔案、資料庫、寫作指示和技能，把 Textus AI 調整成你自己的寫作助手。

## 連線到 AI 服務

1. 開啟**設定 > Textus AI**，在**連線 > 服務供應商**中選擇要使用的服務。
2. 展開**登入與憑證**，依照該服務支援的方式登入帳號，或輸入 API 金鑰。
3. 使用**自訂端點**（任何相容 OpenAI 的伺服器，例如本機模型或代理服務）時，輸入基礎 URL、需要時再填入金鑰，以及模型名稱，然後儲存。
4. 在**寫作輔助**中選擇寫作用的模型，在**Textus AI 對話**中選擇對話模型。

登入會在瀏覽器中完成。能否使用圖片、網路搜尋和文件修改，取決於你選擇的服務和模型。

內建的模型清單只列出各服務供應商的預設模型（以 Anthropic 為例：對話用 Claude Sonnet 5.5，續寫和文法檢查用 Claude Haiku 5.5）。在**連線**下的「模型清單」那一列按**取得模型清單**，即可載入該服務供應商目前提供的完整清單，並從中任選模型。

使用**豆包（火山引擎）**時，在[火山方舟主控台](https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey)建立 API Key，並在同一主控台的**開通管理**裡開通要用的模型：未開通的模型，方舟會拒絕請求。

以下的快速鍵以 macOS 標示；在 Windows 和 Linux 上，Cmd 換成 Ctrl、Option 換成 Alt。如果改過快速鍵，以**設定 > 快速鍵**中的設定為準。

## AI 功能

### 1. 續寫

打字時，游標處會出現灰色的續寫建議——按 <kbd>Tab</kbd> 接受；按 <kbd>Cmd</kbd>+<kbd>→</kbd> 則只接受下一個詞，其餘部分繼續保留。按 <kbd>Esc</kbd> 可關閉建議。沒有最少字數的限制，從文件的第一句話就能使用。

也可以用 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> 或右鍵選單主動要求續寫（游標必須在段落結尾）：這時會得到較長的續寫，最多附上三個候選版本——用 <kbd>Option</kbd>+<kbd>[</kbd> / <kbd>Option</kbd>+<kbd>]</kbd> 切換。

在**設定 > Textus AI > 寫作輔助**中可以選擇**續寫語氣**（配合文件／正式／輕鬆／學術／簡潔）。如果文件所屬的專案有文風檔案或資料庫（見下方的「**讓 Textus AI 配合你的寫作**」），續寫也會遵循它們。

### 2. 文法檢查

可能有問題的地方會加上底線。將指標移到底線上，或把游標移進去，就能看到說明；按**套用**（或游標在其上時按 <kbd>Option</kbd>+<kbd>Enter</kbd>）即可採用修正，按**忽略**則略過。<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> 會立即檢查目前的段落。

### 3. AI 面板

完整的對話位於編輯器右側的面板中。按視窗標題列右端的 **Textus AI** 按鈕（羽毛筆圖示），或按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>，即可開啟或關閉面板。

- **每份文件一個對話**：每個分頁都有自己的對話，切換分頁時，面板也會跟著切換。面板頂端的**新對話**會重新開始（還有尚未決定的修改時，會先詢問你）。
- **模式**：輸入框提供三種模式。**寫作**在文件中起草新內容（續寫、新的段落或章節），只增加、不改動：選取文字時，寫在選取內容之後。**審閱**回答、討論、留下註解，不改動文件。**修訂**修改既有的文字。寫作和修訂的每處修改都是建議，由你採用或拒絕。面板開啟時的模式，在**設定 > Textus AI > Textus AI 對話 > 預設模式**中設定。
- **@ 提及**：在輸入框中輸入 `@`，即可從專案資料夾挑選一個文字檔，附加到訊息中。
- **附加檔案**：輸入框左側的 **+** 按鈕可以為該則訊息附加 PDF、Word 文件、PowerPoint 簡報、試算表、EPUB 電子書、RTF 或 HTML 檔、圖片或純文字檔。圖片以外的檔案都會先在本機擷取成文字，再隨訊息一起送出；圖片則會以真正的圖片傳給看得懂圖片的服務供應商（不支援的服務會事先說明，而不是默默略過）。很長的檔案只會傳送一部分，這時附件標籤上會註明「（已截斷）」。
- **網路搜尋**：輸入框旁的放大鏡按鈕讓 Textus AI 在需要時上網搜尋，詳見下方的 **7. 網路搜尋**。
- **深度思考**：網路搜尋旁邊的按鈕（燈泡圖示）讓模型先把問題想透再回答——比較慢，也比較貴，適合困難的問題和大段改寫。按下後會一直開著，換文件也不變，再按一次才關閉。模型思考時面板會顯示「思考中 · 8 秒」，結束後變成「已思考 12 秒」；服務供應商提供思考內容時，點一下就能展開閱讀。只有能深入思考的模型才會顯示這個按鈕；快速提問一律要求快速回答。
- **紀錄**：AI 面板頂端的**紀錄**按鈕（時鐘圖示）會依資料夾列出過去的對話。按一下其中一則，即可連同它的文件重新開啟並繼續。
- **錯誤**：要求失敗時，對話中會先說明是哪一類問題、該怎麼處理（檢查金鑰、稍候片刻、改選其他模型），再附上服務供應商的原始訊息。

面板頂端的**在獨立視窗中開啟**會把對話移到獨立的視窗中——適合放在第二個螢幕上。這個視窗會跟著你走：切換分頁或視窗時，它的文件、標題和選取範圍都會跟著改變，提出的修改也會套用在你實際正在編輯的那個檔案上。每個編輯器視窗最多只會有一個這樣的視窗；視窗頂端的 **📌** 可以讓它保持在編輯器上方。

### 4. 快速提問

按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>（或按右鍵 > 詢問 AI…），就會在你所在段落的正下方開啟一個小對話列。它嵌在文件中，會把下方的文字往下推，而不是蓋住文字。開啟時如果有選取文字，會一併附上選取的內容。快速提問會以**修訂**模式開啟，因為通常是針對某段文字要求修改（「把這段縮短」）；需要時，在模式選擇器中按一下就能改成寫作或審閱。

- **再按一次快速鍵**：對話列開啟時按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>，游標會移到它的輸入框；在輸入框中再按一次，就會關閉對話列。在對話列的任何地方按 <kbd>Esc</kbd> 也會關閉它，游標則回到文件中。還有尚未決定的修改時，關閉（或開始新對話）前會先詢問你。
- 快速提問有自己的簡短對話，和面板的對話分開，也不會存進紀錄。即使面板開著，也能開啟快速提問。按角落的**在完整對話中繼續**，這段對話就會交給 AI 面板接手，在那裡繼續並保存下來。開啟**設定 > Textus AI > 進階 > 在獨立視窗中開啟完整對話**後，則會改為交給獨立視窗。

### 5. 文件中的修改

對話絕不會直接改寫你的文件。當你要求支援工具呼叫的服務修改文件時，每一處修改都會以建議的形式，顯示在它將要套用的位置：刪除的文字加上刪除線，新增的文字以綠色顯示。在你接受之前，文件不會有任何變動；已接受的修改可以用 <kbd>Cmd</kbd>+<kbd>Z</kbd> 一步復原。

- **接受／拒絕**：可以用修改旁的浮動列、面板中該建議的卡片，或鍵盤——<kbd>Cmd</kbd>+<kbd>Return</kbd> 接受，游標在修改上時按 <kbd>Cmd</kbd>+<kbd>Delete</kbd> 拒絕。同一則回覆中有多項建議時，會同時預覽；用 ‹› 在各項之間切換，或使用「全部接受」／「全部拒絕」。
- **理由**：每張建議卡片都會說明 Textus AI 為什麼這樣修改。
- **只採用部分句子**：當一項建議改寫了好幾個句子，卡片上會出現「逐句選擇（N）」——勾選想要的句子，再按**接受**；按鈕會顯示採用了幾處，例如「接受 2/3 處」。
- **在游標處**：沒有選取文字時，Textus AI 知道游標在哪裡，所以「在這裡寫一段轉折」會剛好插在那個位置。
- **以註解代替修改**：要求審閱（「這裡哪裡寫得比較弱？」）時，Textus AI 會把註解釘在相關的段落上，而不改動原文。每張註解卡片都有**在文件中顯示**，按下後會選取它所針對的段落。

### 6. 圖片

在 **設定 > Textus AI** 裡選好 **圖片模型** 後，Textus AI 就能為文件產生圖片。預設是 **無**，因為每張圖片都要在服務商那裡花一點錢。選一個服務和模型：OpenAI、Google Gemini、豆包（火山引擎）、阿里通義、智譜 GLM、SiliconFlow，或任何相容 OpenAI 的介面。如果這個服務已經用於對話，會直接用它的 key；否則設定裡會請你填一個。

- 在寫作或修訂模式下提出（「在第一段後面配一張港口的圖」），或者右鍵點一段，選 **為這段配圖**。
- 圖片會作為提議出現在它要放的位置，和其他插入一樣。採納之前什麼都不會儲存；採納後按 **設定 > 圖片** 裡貼上圖片的規則儲存，並插入為 Markdown 圖片。拒絕則什麼都不留下。
- 如果服務商拒絕了這段描述，面板會顯示它給出的原因。每次請求最多產生兩張圖片。

### 7. 網路搜尋

開啟輸入框旁的**網路搜尋**按鈕（或在**設定 > Textus AI > Textus AI 對話 > 網路搜尋**中設為預設開啟），要求需要最新的、或它不確定的事實時，Textus AI 會上網查詢。你貼上一個網址，它也能讀取那個頁面。

- **由誰搜尋**：能自行搜尋的模型（OpenAI、Claude、Grok、OpenRouter、Groq、通義千問和智譜 GLM）使用它們內建的搜尋。其他模型（DeepSeek、Gemini、Mistral、Kimi、本機模型、自訂端點）由 Textus 負責搜尋，使用設定中「網路搜尋」下方的**搜尋服務**：**自動**會用你已經為對話儲存的 DeepSeek、智譜或 Kimi 金鑰；也可以選擇博查、Tavily、Brave Search 或 Exa 並填入它的金鑰，或選擇 SearXNG 並填入你自己伺服器的網址。這一列會寫明搜尋內容傳送給誰。沒有可用的搜尋時，按鈕上會出現一個紅點。
- **來源**：回覆以 [1]、[2] 標出引用的內容，並在下方列出這些頁面；點一下就在瀏覽器中開啟。同一段對話裡，編號始終不變。
- **把來源加為註腳**：建議用到網路上的內容時，建議卡片上會有**把來源加為註腳**。勾選後，採用時會在文件末尾為這些來源加上 Markdown 註腳；不勾選，文字就不帶來源。卡片會記住你上次的選擇。
- **網頁只供閱讀，不聽指揮**：網頁上寫的任何內容都不會成為給 Textus AI 的指示，它仍然只會提出建議。Textus 只讀取公開網路上的頁面，從不讀取你的電腦或區域網路裡的內容。

## 讓 Textus AI 配合你的寫作

Textus AI 透過幾個普通的 Markdown 檔案認識你和你的作品，而不是藏起來的設定。每個檔案各有一項用途：

| 概念 | 是什麼 | 放在哪裡 |
| --- | --- | --- |
| **專案資料夾** | Textus AI 工作、可以讀取的資料夾 | 文件所在的資料夾，或你另外選擇的資料夾 |
| **文風檔案** | 你的寫作方式 | `.textus/style.md` |
| **資料庫** | 人物、地點和術語的資料 | `.textus/library/` |
| **寫作指示** | 每次對話都適用的常駐規則 | `agent.md`——全域一份，每個專案也各有一份 |
| **AI 記住的** | Textus AI 從對話中記下的內容 | `.textus/memory/`，以及全域設定資料夾中的 `memory/` |
| **技能** | 用 `/名稱` 呼叫、可重複使用的指示 | `skills/`——全域一套，每個專案也各有一套 |
| **全域設定資料夾** | 適用於每份文件的內容 | 應用程式的設定資料夾 |

下文的「對話」指的是 AI 面板和快速提問。一個完整的專案大致如下：

```
我的小說/                ← 專案資料夾
├── 第一章.md            ← 你正在編輯的文件
├── 筆記/
│   └── 時間軸.md        ← Textus AI 可以讀取的參考資料
└── .textus/              ← 專案自己的設定
    ├── style.md         ← 文風檔案
    ├── agent.md         ← 本專案的寫作指示
    ├── library/
    │   ├── 林晚.md      ← 每個人物、地點或術語一個條目
    │   └── 港城.md
    └── skills/
        └── polish.md    ← 一個檔案一個技能
```

第一次從專案選單要求使用時，`.textus/` 和其中的檔案就會自動建立；只有專案技能需要你自己手動加入。這些檔案中寫在 `<!-- -->` 註解裡的文字，是寫給自己的備註，永遠不會傳送。

### 專案資料夾

**專案資料夾就是 Textus AI 工作的資料夾。**預設是你正在編輯的文件所在的資料夾——或是它上層最近一個含有 `.textus/` 資料夾的資料夾，因此 `novel/part-1/` 中的一章屬於 `novel/`：儲存文件後，它所在的資料夾就會成為專案資料夾。

- Textus AI 可以列出、按名稱尋找、閱讀和搜尋其中的檔案，用來找出某個角色先前的戲份、某個術語，或你的筆記：不超過 16 MB 的文字檔（Markdown、純文字和類似的格式），長的檔案會分段閱讀；還有 PDF、Word、PowerPoint、試算表、EPUB 和 RTF 檔案裡的文字。所用的服務供應商看得懂圖片時，它也能查看其中的 PNG、JPEG、GIF 和 WebP 圖片，每張不超過 6 MB。隱藏的檔案和資料夾、`.gitignore` 或 `.ignore` 檔案排除的內容（與側邊欄的檔案搜尋相同）、建置與相依套件的資料夾（例如 `node_modules`），以及沒有文字層的掃描版 PDF 都會略過。
- 在對話輸入框中輸入 `@`，可以把其中的檔案附加到訊息中。
- 其中的 `.textus/` 資料夾存放本專案的文風檔案、資料庫、寫作指示和技能。

AI 面板頂端下方的專案列會顯示專案資料夾的名稱；按一下即可開啟**專案選單**。如果參考資料不在草稿旁邊，就使用選單中的**選擇專案資料夾…**（或**設定 > Textus AI > 專案資料夾**）。你選擇的資料夾會用於每一份文件（包括未儲存的草稿），直到你再次選擇**改用文件所在的資料夾**。

> [!TIP]
> 草稿在 `論文/草稿/`，訪談筆記在 `論文/研究/`？把 `論文/` 選為專案資料夾，你在編輯 `草稿/第二章.md` 時，Textus AI 就能讀取 `研究/訪談.md`。

Textus AI 讀取的一切都必須位於專案資料夾內：`..`、絕對路徑和指向外部的連結都會被拒絕。未儲存的草稿除非你另外選擇了資料夾，否則沒有專案資料夾；範圍太大的資料夾（你的個人資料夾或整個磁碟）也會被拒絕。

### 文風檔案——「學習我的文風」

**文風檔案描述你的寫作方式**，讓續寫和修改讀起來像出自你的手：語氣與筆調、句子節奏、用字遣詞、標點，以及你絕不使用的寫法。在專案的每份文件中，Textus AI 對話時會遵循它，續寫也會在你打字時遵循它。它就是 `.textus/style.md` 這個檔案。

建立的方式有兩種，都在專案選單中：

- **從樣本學習我的文風…**——挑選幾份你自己寫的檔案（最多八份）。Textus AI 會研讀這些文字並起草一份檔案——語氣與筆調、句子與節奏、用字遣詞、標點與格式、結構、你絕不使用的寫法，再摘錄幾句原文作為範例——然後在新分頁中開啟。讀一遍、修正、補充：它屬於你。再次學習時，先前的檔案會保留為 `style.previous.md`。
- **建立文風檔案**——從空白的大綱開始，自己動手寫。

有了文風檔案之後，資料夾名稱旁的**文風**標籤就能開啟它。

```markdown
# 文風檔案

## 句子與節奏
- 多用短句，很少超過 25 個字。
- 段落先寫具體的場景，再帶出重點。

## 禁忌
- 不用驚嘆號。不用「突然」。
```

具體、可以檢驗的要點，比形容詞更有用：寫「多用短句，很少超過 25 個字」，而不是「簡潔」。篇幅控制在一兩頁以內；只有前 6,000 個字元會被使用。設定中的**續寫語氣**也會同時生效——如果文風檔案已經描述了你的筆調，就讓它維持在「配合文件」。

### 資料庫

**資料庫用來記下必須前後一致的細節**：每個人物、地點或術語一個 Markdown 檔，放在 `.textus/library/` 中。專案選單中的**新增資料庫條目…**會先詢問名稱，再開啟新條目；**資料庫**標籤會顯示條目的數量。

```markdown
---
name: 林晚
aliases: [晚晚, 林老師]
include: detected
---

女主角，32 歲，在港城一所中學教國文。
左撇子。從不談起她的哥哥。
```

你不需要自己附加條目。設為 `include: detected`（預設值）的條目，只要它的名稱或某個別名出現，就會交給 Textus AI：對話時看你的訊息或文件，續寫時看游標附近的文字。`always` 會在每次要求時附上，`never` 則一律不附上。沒被提到的條目不會增加任何成本，所以資料庫可以隨專案的需要不斷擴充。

### 寫作指示（agent.md）

**寫作指示是每次對話都會附上的常駐規則**：這個專案是什麼、要用哪種語言回覆、用字與用詞，以及 Textus AI 一定要做或絕不能做的事。它們寫在名為 `agent.md` 的檔案中，分成兩個層級：

- **全域**，適用於每份文件：**設定 > Textus AI > 寫作指示（agent.md）> 編輯 agent.md**。
- **專案**，適用於某個專案的文件：`.textus/agent.md`，從專案選單中的**編輯本專案的寫作指示**開啟。

兩者都會在分頁中開啟，開頭附有一段寫在註解中的簡短說明。兩份都存在時，Textus AI 會同時收到——先是全域的，再來是專案的——內容衝突時，以專案的為準。

```markdown
這是一部以 1930 年代上海為背景的推理小說，由林晚以第一人稱敘述。
一律用繁體中文回覆。
人名一律寫作「林晚」，不寫「林婉」。
```

寫作指示只用於對話。續寫不會讀取它，而是遵循文風檔案和資料庫。

### Textus AI 記住了什麼

**Textus AI 會記住你的要求和你的寫作方式**，不需要你自己寫檔案。當你告訴它一件不只適用於這一次的事——「一律使用全形標點」「不要用破折號」、一個你得糾正兩次的地方——或是關於作品的事實，例如某個人物是誰，它就會記下來，並在之後的對話中遵循。每次記下時，它的回覆下方都會有一行說明記住了什麼、記在哪裡：**復原**會收回這一條，**改為個人**或**改為專案**則會把它移過去。

- **本專案**：與這部作品有關的內容，存放在 `.textus/memory/`；關於人物、地點和術語的事實會放進資料庫。
- **所有專案通用**：你的一般習慣，存放在全域設定資料夾中的 `memory/`。沒有專案資料夾時，所有內容都存放在這裡。

AI 面板的**記憶**分頁會在**AI 記住的**下列出全部內容，並註明每一條是何時、在哪段對話中記下的：**編輯**會開啟它，**刪除**會移除它。兩者衝突時，以你自己的寫作指示為準，而且 Textus AI 絕不會修改你的 `agent.md` 或文風檔案。記憶太多、無法全部傳送時，最舊的幾條會被略過，記憶分頁也會註明這一點。**設定 > Textus AI > 自動記住**可以關閉這項功能。

**它也會從你的修訂取捨裡學習。** 當你多次拒絕同一類修改——把「」改成“”、把某個詞換成另一個、拆分句子、加上牛津逗號——審閱結束後，Textus AI 會詢問要不要把它記成一條要求：**記住**會把它存進**AI 記住的**，**暫不**等以後再說，**不再詢問**則不再問這一類。它每天最多問一次，而且只有你點擊才會儲存，關閉「自動記住」時也是這樣。它統計的只是你接受或拒絕了哪幾類修改的簡短紀錄，儲存在這台電腦上、和記憶放在一起，從不傳送。

### 技能（/名稱）

**技能是一套有名稱、可以重複使用的指示**——例如「潤稿」「擬大綱」「核對引文」——存放在一個 Markdown 檔中：開頭是名稱和一行描述，下方是完整的指示。

```markdown
---
name: polish
description: 精簡選取的段落，但不改變原意
---

逐句潤飾提供的文字：刪去多餘的字詞，拆開過長的句子，
並保留原本的意思和語氣。只輸出潤飾後的文字。
```

使用技能有兩種方式：

1. **呼叫它**：在對話輸入框中輸入 `/`，從選單中挑選；或輸入技能名稱，再接上你的要求：`/polish 再幫我看一下這段`。
2. **直接提出要求**（僅限支援工具呼叫的服務供應商）：Textus AI 知道每個技能的名稱和描述，當你的要求符合某個技能時，它會自行載入完整的指示並照著做。

技能和寫作指示一樣分成兩個層級：全域技能放在全域設定資料夾的 `skills/` 中（**設定 > Textus AI > 技能 > 匯入技能…**會把技能檔案複製到那裡），專案技能放在 `.textus/skills/` 中（這是隱藏資料夾——在 macOS 的 Finder 中按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> 即可顯示）。與全域技能同名的專案技能會取代該全域技能。

### 內建技能

Textus 內建 19 個技能，涵蓋常見的寫作工作。`/` 選單把它們分成四組：**寫作**（接著寫、描寫人物或場景、對話潤飾、模仿文風）、**修改**（擴寫、精簡、調整語氣、去 AI 味、翻譯潤飾）、**檢查**（校對、檢查前後一致）和**文體**（寫郵件、公文與通知、會議紀錄、學術潤飾、社群貼文、下標題、摘要、設計主題）。輸入 `/` 後從選單中選擇，或直接輸入它在任一介面語言中的名稱：`/proofread`、`/校對` 和 `/校正` 呼叫的是同一個技能。你的要求與某個技能相符時，Textus AI 大多會自行選用；**擴寫**、**精簡**、**調整語氣**和**摘要**則只在你主動呼叫時執行。**設計主題**依你的描述寫一份編輯器主題 CSS，放在回覆裡：按回覆下方的**使用此主題**即可安裝並啟用，也可以存成 .css 檔，再用**設定 > 編輯器與外觀 > 匯入 CSS…**匯入。

**設定 > Textus AI > 內建技能** 列出所有技能。關掉開關，這個技能就會從 `/` 選單中消失，Textus AI 也不再使用它。**自訂…** 會把技能複製到全域設定資料夾的 `skills/` 中並開啟這份副本，你可以自由修改其中的說明；之後執行的就是你的副本。**還原** 會刪除副本，恢復內建版本。你自己的技能若與內建技能同名，會取代內建技能。

### 寫作規範

**設定 > Textus AI > 寫作輔助 > 寫作規範** 決定 Textus AI 和文法檢查遵循哪一套標點、空格與數字規範。選擇**自動**時，有國家標準的語言就依國家標準處理（例如繁體中文依教育部《重訂標點符號手冊》，日文依 JTF）；其他情況則沿用文件中已占多數的寫法，只指出前後不一致之處。選定一套規範（例如繁體中文的**公文**），該語言的文件就依它來要求。

專案也可以另外指定：在文風檔案（`.textus/style.md`）開頭的兩行 `---` 之間加上一行 `conventions:`。對這個專案的文件，它優先於設定中的選擇。

```markdown
---
conventions: zh-Hans-CN/fiction, en-GB/govuk
---
```

### 全域設定資料夾

**全域設定資料夾存放適用於每份文件的內容**：你的全域 `agent.md` 和全域技能。它屬於應用程式，不屬於任何專案；**設定 > Textus AI > 全域設定資料夾 > 打開**會打開它。

```
agent/                ← 全域設定資料夾
├── agent.md          ← 全域寫作指示
└── skills/
    └── outline.md    ← 一個全域技能
```

文風檔案和資料庫沒有全域版本：它們描述的是一部作品，所以屬於專案。

### 什麼情況下用到什麼

| | 對話 | 續寫 | 文法檢查 |
| --- | :---: | :---: | :---: |
| 專案檔案（讀取、搜尋、`@`） | ✓ | | |
| 文風檔案 | ✓ | ✓ | |
| 被提到的資料庫條目 | ✓ | ✓ | |
| 寫作指示 | ✓ | | |
| Textus AI 記住的內容 | ✓ | | |
| 技能 | ✓ | | |
| 續寫語氣（設定） | | ✓ | |

- **先全域，再專案。**兩個層級的寫作指示都會傳送，專案的排在最後，衝突時以專案的為準。專案技能會取代同名的全域技能。
- **一次只有一個專案資料夾。**只有它的 `.textus/` 有效：選擇了專案資料夾後，文件旁邊的 `.textus/` 就不會被讀取。
- **不需要重新啟動。**修改這些檔案後，下一次要求就會使用新版本（續寫約在十秒內生效）。

### 哪個檔案寫什麼？

- 文字該讀起來是什麼樣子 → **文風檔案**。
- 誰是誰、什麼是什麼 → **資料庫**。
- Textus AI 在對話中該知道或一律要做的事 → **寫作指示**。
- 一再重複要求的工作 → **技能**。
- 筆記、研究資料、先前的章節 → 放在**專案資料夾**中的一般檔案；需要時 Textus AI 會自己讀取。

## 關閉 Textus AI

在視窗列右端的 **Textus AI** 按鈕上按右鍵，可以暫停 Textus AI 1 小時，或者把它關閉。關閉期間，羽毛筆圖示上會有一道斜線，點它可以重新開啟；暫停滿 1 小時後會自動恢復。**檢視 > Textus AI**、**設定 > Textus AI > 啟用 Textus AI**，以及可以在 **設定 > 快速鍵** 裡設定的快速鍵，也能開啟或關閉；iPhone 上它在選單裡。

關閉期間，從打開 Textus 起就不會向任何 AI 服務傳送內容：沒有續寫、沒有語法檢查、沒有對話，也不會記住什麼。AI 面板、快速提問和右鍵選單裡的 AI 項目都會隱藏，正在產生的回覆會停下。文件裡已經提出的修改仍然保留，等你接受或拒絕。每項功能都保留自己的設定，重新開啟 Textus AI 後照常生效。

## 關於隱私權

你的文件、附加和以 @ 提及的檔案、你的寫作指示、文風檔案、被提到的資料庫條目，以及 Textus AI 讀取的任何專案檔案，都會隨每次要求傳送給你選擇的服務供應商；**學習我的文風**會傳送你挑選的樣本。開啟網路搜尋時，搜尋內容會傳送給你選擇的服務供應商，或傳送給設定中顯示的搜尋服務；Textus AI 讀取的網頁則從這台電腦下載。不想這樣時，可以在設定中關閉對應的功能。

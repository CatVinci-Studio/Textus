# Textus AI 功能指南

Textus 提供续写、语法检查，以及围绕文档的对话和修改。本指南介绍连接服务、使用功能，以及用文件夹、文风档案、资料库、写作要求和技能把 Textus AI 调成你自己的写作助手。

## 连接服务

与 AI 有关的设置都在 **设置 › Textus AI** 下，分四页：**模型设置**、**写作辅助**、**Agent 功能**和**外部工具**。

1. 在**模型设置**页的**服务商**列表里选择服务，按它支持的方式**账户登录**或填写 **API Key**。列表里有圆点的，就是已经设置好的服务。
2. 使用**自定义接口**（任何兼容 OpenAI 的服务：本地模型、中转等）时，填写接口地址、所需的密钥和模型名称，再保存配置。
3. 在同一页顶部的**模型选择**里，选择**对话用的服务商**和**对话模型**；续写和语法检查用的是**写作辅助用的服务商**（默认**跟随对话**）和**辅助模型**。

登录会在浏览器中完成。是否支持图片、联网搜索和文档修改，取决于所选服务与模型。

内置的模型列表只包含各服务商的默认模型（Anthropic：对话用 Claude Sonnet 5.5，续写和语法检查用 Claude Haiku 5.5）。在服务商下方的**模型**里点**获取模型列表**，即可载入该服务商当前的全部模型并从中选择。

使用**豆包（火山引擎）**时，在[火山方舟控制台](https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey)创建 API Key，并在同一控制台的**开通管理**里开通要用的模型：未开通的模型，方舟会拒绝请求。

以下快捷键按 macOS 标注；Windows 和 Linux 将 Cmd 换成 Ctrl、Option 换成 Alt。修改过快捷键时，以 **设置 › 快捷键** 中的配置为准。

## AI 功能

### 1. 续写（补全）

输入时自动在光标处给出灰色的续写建议，按 <kbd>Tab</kbd> 采纳；按 <kbd>Cmd</kbd>+<kbd>→</kbd> 只采纳下一个词，其余部分继续保留。<kbd>Esc</kbd> 关闭建议。没有最小字数限制，文档第一句话就能触发。

用 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> 或右键菜单主动请求续写时（光标需在段落末尾），会得到更长的续写，并最多给出三个候选——用 <kbd>Option</kbd>+<kbd>[</kbd> / <kbd>Option</kbd>+<kbd>]</kbd> 切换。

在 **设置 › Textus AI › 写作辅助 › 续写与检查** 里可以开关续写，并调整**续写语气**（跟随文档 / 正式 / 轻松 / 学术 / 简洁）。如果文档所在的文件夹有文风档案或资料库（见下文「让 Textus AI 懂你的写作」），续写也会遵循它们。

### 2. 语法检查

对可能有问题的文字加下划线。鼠标悬停或把光标移进去即可查看说明；点**应用**（或光标在其上时按 <kbd>Option</kbd>+<kbd>Enter</kbd>）采用修改，点**忽略**则不再提示。快捷键 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> 立即检查当前段落。**检查强度**（写作辅助 › 续写与检查）决定提示多少问题。

### 3. 对话

对话以**标签页**的形式打开。点窗口标题栏右端的 **Textus AI** 按钮（星光图标），或按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>，或选**视图 › AI 面板**：AI 会在右侧单独的一个岛里打开。它的标签和别的标签一样，可以拖到文档旁边、拖进另一个岛，或者拖出去成为单独的窗口。

- **按文件夹**：对话属于你所在的文件夹，而不是某一篇文档。每个打开的对话是一个标签；最前面的那个就是你正在对话的，针对的是最前面的文档。关掉的对话仍在历史记录里。
- **新对话**：在 AI 标签的空白处点右键，选**新对话**（还有未处理的修改时会先询问）。**记忆**也在这个菜单里。
- **历史记录**：AI 标签右上角的时钟按钮按文件夹列出过去的对话，顶部的**搜索对话**可以找出说过某些话的对话；点一条即可重新打开。你提到之前的某次对话时，Textus AI 也会去里面找。在 **设置 › 隐私与数据** 里可以不保存对话。
- **模式和模型**：输入框旁的一个按钮同时写着两者，「通用 · 模型名」。**通用**处理文档：起草新内容（续写、新的段落或章节），也修改已有的文字（改写、翻译、删减）。选中文字时，针对它的修改会替换它，新增的内容写在它之后。**审阅**回答、讨论、留下批注，不改动文档。**专业写作**接收一个题目，调研之后成文（见下面的 **8. 专业写作**）。列表里还有你设置过的所有服务的模型，以及你添加的 **Agent**（见 **9. 外部 Agent**）。新对话从审阅开始；之后会记住你上次选的模式。
- **@ 引用**：在输入框中输入 `@`，即可从文件夹里选一个文本文件附到消息中。
- **附加文件**：点输入框左侧的 **+** 可以一次附上一个或多个文件：PDF、Word、PowerPoint、表格、EPUB 电子书、RTF 或 HTML 文件，任何文本或代码文件，zip 压缩包，以及图片（PNG、JPEG、GIF、WebP、BMP、TIFF，Mac 上还有 HEIC 和 AVIF）。每个文件都会复制到这个对话自己的临时文件夹里，不会写进你的文件夹，Textus AI 需要时可以再完整读取。文档会在本地抽成文字随消息发出；文件很长时只发送一部分，附件标签上会注明「已截断」，其余部分 Textus AI 需要时自己去读。zip 压缩包会在那里解压，并列出里面的文件。图片会转成所有服务都能读的格式，太大的会先缩小，再作为真正的图像发给支持视觉的服务（不支持的会直接提示，而不是悄悄丢掉）。
- **联网搜索**：输入框旁的放大镜按钮让 Textus AI 在需要时上网搜索，详见下面的 **7. 联网搜索**。
- **深度思考**：联网搜索旁边的按钮（灯泡图标）让模型先把问题想透再回答——更慢，也更费钱，适合难的问题和大段改写。按下后一直开着，换文档也不变，再按一次才关。模型思考时标签里显示「思考中 · 8 秒」，结束后变成「已思考 12 秒」；服务商提供思考内容时，点一下就能展开阅读。只有能深入思考的模型才显示这个按钮；快速提问总是要求快速回答。
- **出错时**：请求失败时，Textus 会用你的语言先说明是哪类问题、该怎么办（检查密钥、余额用完时去充值、稍后再试、换一个模型），再附上服务商的原始信息。对话、自动补全和语法检查都是这样。
- **长文档**：让 Textus AI 按章节翻译或改写一篇长文档时，它会把每一章交给一个单独的助手同时处理，并共用一份人名和术语的写法清单，整篇文档一次改完。

### 4. 快速提问

按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd>（或右键 > **询问 AI…**）在当前段落下方打开一个小对话条。它嵌在文档中，会把下方内容往下推，不会遮住正文。如果打开前选中了文字，会附上选中内容。快速提问默认使用**通用**模式，因为它通常是针对某段文字发起修改（「缩短这段」）；需要时可在模式选择中一键换成审阅。

- **再按一次快捷键**：对话条已打开时按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> 会把光标移到输入框；在输入框中再按一次则关闭。在对话条任意位置按 <kbd>Esc</kbd> 也会关闭，光标回到正文。还有未处理的修改时，关闭或新建对话会先询问。
- 快速提问有自己的简短对话，和 AI 标签里的对话分开，也不写入对话历史。点右上角的**转到大对话**，这段对话会交给 AI 标签继续，并保存到历史。

### 5. 对文档的修改

**设置 › Textus AI › 写作辅助 › Textus AI 的修改方式** 决定 Textus AI 的修改怎样进入你的文字：

- **修订（逐条审阅）**（默认）：每处修改都以修订的形式显示在它要改的位置，你采纳之前都不算数。
- **直接写入**：修改一到就写进去，但会一直标着，看得出改了哪里，每条回复都能撤销。

专业写作的文章无论哪种方式都会直接写入。<kbd>Cmd</kbd>+<kbd>Z</kbd> 可以一步撤销已采纳的修改。

**修订怎么显示**：**修订显示方式**（在写作辅助里，或审阅栏的眼睛按钮）有三种：
- **只看结果，原文在页边**（默认）；
- **原文在正文，修改在页边**；
- **全部在正文中**：删除的文字加删除线，新增的文字以绿色显示。

新增的文字总是画在正文里。没有页边空间时（窗口窄、侧边栏和 AI 都开着），页边的两种方式会等一等，先全部显示在正文中。

- **审阅栏**：文档底部的一条栏汇总这里所有待处理的内容，修改和批注都在。用 ‹ › 逐条查看（或 <kbd>F7</kbd> / <kbd>Shift</kbd>+<kbd>F7</kbd>），逐条**采纳**或**拒绝**，也可以**全部采纳** / **全部拒绝**。每句改动在正文里还有 ✓ / ✕；只采纳一部分时，栏上会写「采纳 2/5 处」。键盘上，<kbd>Cmd</kbd>+<kbd>Return</kbd> 采纳，光标在修改上时 <kbd>Cmd</kbd>+<kbd>Delete</kbd> 拒绝。
- **修改理由**：对话里每张提议卡片都会说明 Textus AI 为什么这样改。
- **在光标处插入**：没有选中文字时，Textus AI 知道光标的位置，「在这里写一段过渡」会正好插在光标处。
- **批注而非修改**：请 Textus AI 审阅（「这里哪里写得弱？」）时，它会把批注钉在对应段落上，而不改动原文。每张批注卡片都有**在文档中定位**，点击会选中它所针对的段落。
- **你自己的批注**：选中一些文字，点右键选**添加批注**，你的批注会出现在页边，和 Textus AI 的批注放在一起，标着「我」。批注保存在 Textus 自己的数据里，不会写进你的 Markdown。
- **修订模式**（视图菜单）：打开后，你自己的修改也会显示为改动：删掉的文字加删除线，新增的文字加标记，页边各有一张标着「我」的卡片，可以逐条采纳或拒绝。文件里保存的是原文和你已采纳的修改；还没处理的修改和 Textus AI 的一样，保存在旁边的 `.textus` 文件夹里，下次打开时还在。分享时把整个文件夹发出去，修订也会一起带上。

**文件夹里的其他文件**：Textus AI 也能修改你没有打开的文件。

- **修订（逐条审阅）**：这类文件的修改会以修订的形式留在文件里。打开文件时它们会放进正文，按上面的方式采纳或拒绝。文件树和这个文件的标签上会标出来，例如「3 处待审」。
- **它新建的文件**要你决定：**保留**，或者**丢弃**（丢弃的进废纸篓）。
- **直接写入**：修改会立刻写进去，修改前的文字会留着，可以撤销。
- **回复里的卡片**列出它改过的文件，带**撤销**、**应用**、**保留**和**丢弃**。如果文件在这期间被你改过，那处修改会单独留着，标为「之后被改过」；点**忽略**即可放下。

### 6. 图片

Textus AI 可以为文档生成图片。**图片服务**（设置 › Textus AI › 模型设置 › 模型选择）默认跟随聊天服务：用 ChatGPT 登录时，使用订阅自带的画图额度（标为实验性，因为它不是公开的 API）；聊天服务自己能画图时，用它自己的图片模型和同一个 key。聊天服务不能画图时，要先选一个图片服务（OpenAI、Google Gemini、豆包（火山引擎）、阿里通义、智谱 GLM、硅基流动（SiliconFlow），或任何兼容 OpenAI 的接口），再选它的模型。

- 在通用模式下提出（“在第一段后面配一张港口的图”），或者右键点一段，选 **为这段配图**。
- 文字和图片一起生成：文字边写边出现，图片在它的位置先显示一个缓缓流动的框，生成好就换成图片。还没生成完也可以先采纳，图片到了就会保存。
- 采纳之前什么都不会保存；采纳后按 **设置 › 编辑 › 图片** 里粘贴图片的规则保存，并插入为 Markdown 图片。拒绝则什么都不留下。
- 想让一张提议中的图片重画，把鼠标移到它上面，选 **重画…**，再说哪里要改；只有这一张会重画。同一篇里的图片会保持人物和画风一致：反复出现的人物用同样的描述，图片模型支持参考图时，新图会以之前的图为基础来画。
- 想改一张图，右键点它，选 **让 Textus AI 修改这张图…**，再说怎么改。新图会作为提议出现在原来的位置；采纳后会问你要不要把旧图片文件移到废纸篓，你不同意就保留。
- 说要几张，Textus AI 就生成几张，但不超过 **每次最多生成几张图**（在模型选择里，默认两张，可以改）。如果服务商拒绝了某段描述，图片的位置会显示它给出的原因。

### 7. 联网搜索

打开输入框旁的**联网搜索**按钮，请求需要最新的、或它拿不准的事实时，Textus AI 会去网上查。你贴上一个网址，它也能读那个页面。

- **谁来搜索**：能自己搜索的模型（OpenAI、Claude、Grok、OpenRouter、Groq、通义千问和智谱 GLM）用它们自带的搜索。其他模型（DeepSeek、Gemini、Mistral、Kimi、本地模型、自定义接口）由 Textus 来搜索，用的是 **设置 › Textus AI › 写作辅助 › 联网与代理** 里的**搜索服务**：**自动**会用你已经为对话保存的 DeepSeek、智谱或 Kimi 的 Key；也可以选博查、Tavily、Brave Search 或 Exa 并填入它的 Key，或者选 SearXNG 并填入你自己服务器的地址。这一行会写明搜索内容发给谁。没有可用的搜索时，按钮上会出现一个红点。
- **来源**：回复用 [1]、[2] 标出所引用的内容，并在下方列出这些页面；点一下就在浏览器里打开。同一段对话里，编号始终不变。
- **把来源加为脚注**：建议里用到了网上的内容时，建议卡片上会有**把来源加为脚注**。勾选后，采纳时会在文档末尾为这些来源加上 Markdown 脚注；不勾选，文字里就不带来源。卡片会记住你上次的选择。
- **网页只供阅读，不听指挥**：网页上写的任何内容都不会成为给 Textus AI 的指令，它仍然只会提出建议。Textus 只读取公共网络上的页面，从不读取你的电脑或局域网里的内容。

### 8. 专业写作

在模式按钮里选**专业写作**，发送一个题目而不是一个请求：Textus AI 会调研（网上、你的文件夹、你附上的论文），先列提纲，再把文章写进文档。输入 `/` 可以选文章类型（随笔、报告、文献综述等），或者保持**自动判断**。**使用子 Agent 研究**（写作辅助）让它把调研分给几个助手同时做；**引用核对**会在完成前逐句核对引用是否和来源一致。专业写作的文章无论**Textus AI 的修改方式**怎么设，都会直接写进文档。

### 9. 外部 Agent

Claude Code、Codex 等编程 Agent 可以通过插件在 Textus 里工作。添加之后，窗口标题栏的 Textus AI 按钮旁会多一个它的按钮，模式按钮的 **Agent** 一组里也有它：选中后，你的消息会发给它，而不是发给模型。它在改文件之前会在对话里先问你。**设置 › Textus AI › 外部工具** 的 **ACP Agent** 下列出它们（**获取 Agent…** 会打开插件面板），上面是 Textus AI 可以使用其工具的 **MCP 服务器**。

## 让 Textus AI 懂你的写作

Textus AI 了解你和你的作品，靠的是几个普通的 Markdown 文件，而不是藏在某处的设置。每个文件只管一件事：

| 概念 | 是什么 | 放在哪里 |
| --- | --- | --- |
| **文件夹** | Textus AI 工作、可以读取的文件夹 | 你在侧边栏打开的文件夹，或你另选的文件夹 |
| **文风档案** | 你是怎么写的 | `.textus/style.md` |
| **资料库** | 人物、地点、术语的设定 | `.textus/library/` |
| **写作要求** | 每次对话都要遵守的常驻要求 | `agent.md`——全局一份，每个文件夹也可以有一份 |
| **记忆** | Textus AI 从对话中记下的内容 | 全局配置文件夹里的 `memory/`，以及按文件夹分开的 `projects/<文件夹>/memory/` |
| **技能** | 用 `/名称` 调用的可复用指令 | `skills/`——全局一套，每个文件夹也可以有一套 |
| **全局配置文件夹** | 对所有文档生效的那部分 | 应用自己的设置文件夹 |

下文说的「对话」，指 AI 标签和快速提问。一个完整的文件夹大致是这样：

```
我的小说/                ← 文件夹
├── 第一章.md            ← 正在编辑的文档
├── 笔记/
│   └── 时间线.md        ← Textus AI 可以查阅的参考资料
└── .textus/              ← 这个文件夹自己的设置
    ├── style.md         ← 文风档案
    ├── agent.md         ← 这个文件夹的写作要求
    ├── library/
    │   ├── 林晚.md       ← 每个人物、地点或术语一个条目
    │   └── 港城.md
    └── skills/
        └── polish.md    ← 一个文件一个技能
```

`.textus/` 和里面的文件，都会在你第一次从文件夹菜单里用到时自动创建；只有文件夹技能需要你手动添加。这些文件里写在 `<!-- -->` 注释中的内容是写给自己的备注，永远不会发送。

### 文件夹

**文件夹就是 Textus AI 工作的文件夹。** 它是你在侧边栏打开的文件夹（**文件 > 打开文件夹…**），或你另选的文件夹；都没有时，是文档上方最近的、带有 `.textus/` 文件夹的那个文件夹，所以 `novel/part-1/` 里的一章属于 `novel/`。单独打开的一篇文档没有文件夹：这时 Textus AI 只读这篇文档和你附上的文件，下载或桌面里的一个文件不会让整个文件夹都向它敞开。

- Textus AI 可以列出、按名称查找、阅读和搜索其中的文件，用来查找某个角色之前的戏份、某个术语，或你的笔记：不超过 16 MB 的文本文件（Markdown、纯文本等格式），长文件会分段阅读；还有 PDF、Word、PowerPoint、表格、EPUB 和 RTF 文件里的文字。所用的服务能看图片时，它还能查看其中的 PNG、JPEG、GIF 和 WebP 图片，每张不超过 6 MB。隐藏文件和文件夹、`.gitignore` 或 `.ignore` 文件排除的内容（与侧边栏的文件搜索相同）、构建与依赖目录（如 `node_modules`），以及没有文字层的扫描版 PDF 都会跳过。
- 在对话输入框中输入 `@`，可以把其中的某个文件附到消息里。
- 它的 `.textus/` 文件夹存放这个文件夹的文风档案、资料库、写作要求和技能。

在 AI 标签的空白处点右键选**记忆**：最上面一行显示文件夹的名字，点一下就是**文件夹菜单**。参考资料不和草稿放在一起时，用其中的**选择文件夹…**（也可以在 **设置 › Textus AI › Agent 功能 › 文件夹** 中选择）。选好的文件夹会用于所有文档——包括未保存的草稿——直到你点**不使用文件夹**。

> [!TIP]
> 草稿在 `论文/草稿/`，访谈笔记在 `论文/资料/`？把 `论文/` 选为文件夹，编辑 `草稿/第二章.md` 时，Textus AI 就能读到 `资料/访谈.md`。

Textus AI 读取的一切都必须在文件夹之内：`..`、绝对路径和指向外部的链接都会被拒绝。没有打开或选择文件夹时就没有文件夹；范围太大的文件夹（主目录或整个磁盘）也会被拒绝。Textus AI 工作中产生的东西（调研笔记、写到一半的稿子）放在 Textus 自己的文件夹或系统临时文件夹里，不会写进你的文件夹。

### 文风档案——「学习我的文风」

**文风档案描述你怎么写**，让续写和修改读起来像你写的：语气、句子节奏、用词、标点、你从不使用的写法。在文件夹内的每篇文档里，Textus AI 对话时会遵循它，续写在你打字时也会遵循它。它就是 `.textus/style.md` 这个文件。

有两种方式建立，都在文件夹菜单里：

- **从样本学习我的文风…**——选几篇你自己写的文件（最多八篇）。Textus AI 会读完这些文字，起草一份档案：语气、句子与节奏、用词、标点与格式、结构、从不使用的写法，再摘几句原文作为例子；然后在新标签页中打开。读一遍，改掉不对的，补上没写到的——它归你所有。再次学习时，旧档案会保留为 `style.previous.md`。
- **新建文风档案**——从一份空白提纲开始，自己写。

有了档案后，文件夹菜单里的**打开文风档案**（以及记忆里的文风一行）可以打开它。

```markdown
# 文风档案

## 句子与节奏
- 多用短句，很少超过 25 个字。
- 段落先写一个具体场景，再说观点。

## 从不
- 不用感叹号，不用「突然」。
```

写具体、可以检验的要点，比写形容词有用得多：写「多用短句，很少超过 25 个字」，而不是「简洁」。篇幅控制在一两页以内，只有前 6,000 个字符会被使用。设置里的**续写语气**也同时生效——文风档案已经写清你的笔调时，把它留在「跟随文档」即可。

### 资料库

**资料库存放需要前后一致的设定**：每个人物、地点或术语一个 Markdown 文件，放在 `.textus/library/` 里。文件夹菜单中的**新建资料库条目…**会先问名称，再打开新条目；记忆里会列出全部条目。

```markdown
---
name: 林晚
aliases: [晚晚, 林老师]
include: detected
---

女主角，32 岁，在港城一所中学教语文。
左撇子。从不提起她的哥哥。
```

条目不需要你手动附加。`include: detected`（默认值）的条目，只要它的名字或某个别名出现，就会自动交给 Textus AI：对话时看你的消息和文档，续写时看光标附近的文字。`always` 每次请求都带上，`never` 则永远不带。没被提到的条目不产生任何开销，资料库可以随文件夹一起慢慢长大。

### 写作要求（agent.md）

**写作要求是每次对话都会附上的常驻要求**：这个文件夹是什么、用哪种语言回复、某些词怎么写、Textus AI 始终要做或绝不能做的事。它们写在名为 `agent.md` 的文件里，分两级：

- **全局**，对所有文档生效：**设置 › Textus AI › Agent 功能 › 写作要求（agent.md）› 编辑 agent.md**。
- **文件夹**，只对一个文件夹里的文档生效：`.textus/agent.md`，用文件夹菜单中的**编辑这个文件夹的写作要求**打开。

两者都会在新标签页中打开，开头附有一段写在注释里的简短说明。两份都存在时，Textus AI 两份都会收到——先全局，后文件夹——有冲突时以文件夹的为准。

```markdown
这是一部以 1930 年代上海为背景的悬疑小说，第一人称，叙述者是林晚。
始终用中文回复。
人物名统一写作「林晚」，不要写成「林婉」。
```

写作要求只用于对话。续写不读它，而是遵循文风档案和资料库。

### Textus AI 记住了什么

**Textus AI 会记住你的要求和你的写法**，不用你自己写文件。当你告诉它一件不只适用于这一次的事——「始终用全角标点」「不要用破折号」、一处你纠正了两次的地方——或者关于作品的事实，比如某个人物是谁，它就会记下来，并在以后的对话中遵循。每次记下时，它的回复下方都有一行说明记住了什么、记在哪里：**撤销**收回这条，**改为全局**或**改为这个文件夹专用**把它移过去。

- **这个文件夹**：与这部作品有关的内容，存在全局配置文件夹里的 `projects/<文件夹>/memory/`（Textus 自己保存，不写进你的文件夹）；关于人物、地点和术语的事实会放进资料库。
- **所有文件夹通用**：你的一般习惯，存在全局配置文件夹里的 `memory/`。没有文件夹时，所有内容都存在这里。

**记忆**（在 AI 标签的空白处点右键 › 记忆）会列出全部内容，并注明每条是何时、在哪次对话中记下的：**编辑**打开它，**删除**移除它。Textus AI 会不时整理记忆：合并说同一件事的几条，去掉已被新规则推翻的旧规则；去掉的内容放在**最近忘记的**里，可以找回。两者冲突时以你自己写的写作要求为准，Textus AI 也从不修改你的 `agent.md` 或文风档案。记忆太多、无法全部发送时，最早的几条会被略去，记忆里会注明这一点。**开启记忆功能**（设置 › Textus AI › Agent 功能）可以关闭它。

**它也会从你的修订取舍里学习。** 当你多次拒绝同一类修改——把「」改成“”、把某个词换成另一个、拆分句子、加上牛津逗号——审阅结束后，Textus AI 会询问要不要把它记成一条要求：**记住**会把它存进**记忆**，**暂不**等以后再说，**不再询问**则不再问这一类。它每天最多问一次，而且只有你点击才会保存，关闭“自动记住”时也是这样。它统计的只是你接受或拒绝了哪几类修改的简短记录，保存在这台电脑上、和记忆放在一起，从不发送。

### 技能（/名称）

**技能是一套有名字、可以反复使用的指令**——「润色」「列提纲」「核对引文」——保存在一个 Markdown 文件里：开头是名称和一句话描述，下面是完整的指令。

```markdown
---
name: polish
description: 润色选中的段落，保持原意，收紧句子
---

对给出的文字逐句润色：删掉冗余的词，把长句拆短，
保持原本的意思和语气不变。只输出润色后的文字。
```

使用技能有两种方式：

1. **直接调用**：在对话输入框中输入 `/`，从菜单里选；或者输入技能名再接上你的要求，比如 `/polish 再帮我看看这段`。
2. **直接提要求**（仅限支持工具调用的服务）：Textus AI 知道每个技能的名称和描述，当你的请求和某个技能对得上时，它会自己加载完整指令并照做。

如果你让它做的是一套你自己的流程，以后还会用到，Textus AI 会在回复下方提议把它存成技能，可以存给所有文档，也可以只存给这个文件夹。你不选，就什么都不会保存。

技能和写作要求一样分两级：全局技能放在全局配置文件夹的 `skills/` 里（**设置 › Textus AI › Agent 功能** 里「技能」顶部的**导入技能…**会把技能文件复制过去），文件夹技能放在 `.textus/skills/` 里（这是隐藏文件夹——在 macOS 的访达中按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> 可以显示）。文件夹技能和全局技能同名时，以文件夹的为准。

### 内置技能

Textus 自带四个技能。审阅模式下的**校对**按文本所用语言的规范检查错别字、语法、标点和数字。**设计主题**、**做插件**和**生成技能**按你的描述做一份编辑器主题、一个小插件或一个你自己的技能，在单独的标签里进行：**制作你的主题**在外观页的主题商店里，**制作你的插件**在插件面板的 **⋯** 菜单里。更多技能——扩写、精简、翻译、总结、检查前后一致、写邮件、会议纪要等——在 **设置 › Textus AI › Agent 功能** 里「技能」末尾的**可安装**中。输入 `/` 后从菜单中选择，或者直接输入它在任一界面语言中的名称：`/proofread`、`/校对` 和 `/校正` 调用的是同一个技能。你的请求与某个技能相符时，Textus AI 也会自行选用。**设计主题**把主题的 CSS 放在回复里：点回复下方的**使用此主题**即可安装，也可以存成 .css 文件，再用 **设置 › 外观** 里的**从 CSS 文件添加主题**添加。

内置技能排在 **设置 › Textus AI › Agent 功能** 的「技能」最前面，始终开启。**自定义…** 会把技能复制到全局配置文件夹的 `skills/` 中并打开这份副本，你可以修改其中的说明；此后运行的就是你的副本。**还原** 会删除副本，恢复内置版本。下面是你添加的技能：每个都标出它适用的模式，点一下即可更改；旁边的开关可以暂时关掉它，适用的模式会保留，再打开就恢复。你自己的技能如果与内置技能同名，会取代内置技能。

### 写作规范

**写作规范**（设置 › Textus AI › 写作辅助 › 续写与检查）决定 Textus AI 和语法检查遵循哪套标点、空格和数字规范。选择**自动**时，有国家标准的语言按国家标准处理（例如简体中文按 GB/T，日语按 JTF）；其他情况则沿用文档里已经占多数的写法，只指出前后不一致的地方。选定一套规范（例如简体中文的**小说**），这种语言的文档就按它来要求。

文件夹也可以单独指定：在文风档案（`.textus/style.md`）开头的两行 `---` 之间加一行 `conventions:`。对这个文件夹的文档，它优先于设置里的选择。

```markdown
---
conventions: zh-Hans-CN/fiction, en-GB/govuk
---
```

### 全局配置文件夹

**全局配置文件夹存放对所有文档生效的内容**：全局的 `agent.md` 和全局技能。它属于应用本身，不属于任何文件夹；**设置 › Textus AI › Agent 功能 › 全局配置文件夹 › 打开** 可以打开它。

```
agent/                ← 全局配置文件夹
├── agent.md          ← 全局写作要求
└── skills/
    └── outline.md    ← 一个全局技能
```

文风档案和资料库没有全局版本：它们描述的是某一部作品，所以属于文件夹。

### 什么时候用到什么

| | 对话 | 续写 | 语法检查 |
| --- | :---: | :---: | :---: |
| 文件夹里的文件（阅读、搜索、`@`） | ✓ | | |
| 文风档案 | ✓ | ✓ | |
| 被提到的资料库条目 | ✓ | ✓ | |
| 写作要求 | ✓ | | |
| Textus AI 记住的内容 | ✓ | | |
| 技能 | ✓ | | |
| 续写语气（设置） | | ✓ | |

- **先全局，后文件夹。** 两级的写作要求都会发送，文件夹的排在后面，冲突时以文件夹的为准；文件夹技能会替换同名的全局技能。
- **同一时间只有一个文件夹。** 只有它的 `.textus/` 有效：另选了文件夹后，文档旁边的 `.textus/` 不会被读取。
- **改完即生效。** 修改这些文件后，下一次请求就会用上新内容，无需重启（续写约十秒内生效）。

### 什么内容写在哪里？

- 文字应该读起来是什么样 → **文风档案**。
- 谁是谁、什么是什么 → **资料库**。
- 对话中 Textus AI 应该知道或始终遵守的事 → **写作要求**。
- 反复要做的同一类任务 → **技能**。
- 笔记、资料、前面的章节 → 放在**文件夹**里的普通文件，需要时 Textus AI 会自己去读。

## 关闭 Textus AI

在窗口栏右端的 **Textus AI** 按钮上点右键，可以暂停 Textus AI 1 小时，或者把它关闭。关闭期间，星光图标上会有一道斜线，点它可以重新开启；暂停满 1 小时后会自动恢复。命令面板里的**开启或关闭 Textus AI**，以及可以在 **设置 › 快捷键** 里设定的快捷键，也能开启或关闭；iPhone 上它在菜单里。

关闭期间，从打开 Textus 起就不会向任何 AI 服务发送内容：没有续写、没有语法检查、没有对话，也不会记住什么。AI 标签、快速提问和右键菜单里的 AI 菜单项都会隐藏，正在生成的回复会停下。文档里已经提出的修改仍然保留，等你采纳或拒绝。每项功能都保留自己的设置，重新开启 Textus AI 后照常生效。

## 隐私说明

文档内容、附加和 @ 引用的文件、你的写作要求、文风档案、被提到的资料库条目，以及 Textus AI 读取的文件夹里的文件，会随请求发送给你所选的服务；**从样本学习我的文风**会发送你选中的样本。打开联网搜索时，搜索内容会发给你所选的服务，或发给设置里显示的搜索服务；Textus AI 读取的网页从这台电脑下载。不需要时在设置里关掉对应功能即可。

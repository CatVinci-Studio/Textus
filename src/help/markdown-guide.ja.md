# Textus Markdown ガイド

ようこそ！これはTextusが対応するMarkdownレンダリング機能を紹介する、内蔵のデモ文書です。これは保存されていない草稿なので、自由に編集して試してかまいません —— 閉じるときに保存しなければそれで大丈夫です。

> [!TIP]
> `Cmd+/` でWYSIWYGとソースコードモードを切り替えられます。どの例も元の書き方を見比べてみてください。

## 見出しと引用

行頭に `#` とスペースを入力するとレベル1、`##` とスペースならレベル2の見出しになります。上の見出しが実際の表示例です。

引用ブロック：

> 引用文の中には **太字** や `コード` など他の記法もネストできます。

GitHub形式のアラートブロック:

> これは補足説明に適したノートです。

## インラインスタイル

**太字**、*斜体*、***太字斜体***、~~取り消し線~~、==ハイライト==、そして `インラインコード`。

リンクの書き方：[Textus リポジトリ](https://github.com/CatVinci-Studio/Textus)。Ctrl/⌘ を押しながらクリックするとリンク先へ移動します。Web のリンクはブラウザで、別の Markdown ファイルへのリンクはタブで開き、`#見出し` へのリンクはその見出しまでスクロールします。インラインHTMLも描画されます。例えばキーボードキー <kbd>Cmd</kbd> + <kbd>S</kbd>。`<details>` の折りたたみ、HTML の表、一部のインラインスタイル（色、背景色、サイズ、太さ、配置、下線、取り消し線）、インラインの `<svg>`（画像として表示）も描画されます。スクリプトなどそれ以外の HTML はソースのまま表示されます。

インライン数式：質量とエネルギーの関係式 $E = mc^2$、オイラーの等式 $e^{i\pi} + 1 = 0$。

## 表

| 機能 | 記法 | 結果 |
| --- | --- | --- |
| 太字 | `**テキスト**` | **テキスト** |
| ハイライト | `==テキスト==` | ==テキスト== |
| インライン数式 | `$x^2$` | $x^2$ |

表の上にマウスを乗せると行・列の追加や削除ができます。`| 名前 | 年齢 |` と入力して Enter を押すと表になります。表の中で Enter を押すと次の行へ移り、最終行では行が追加され、空のままの新しい行でもう一度 Enter を押すと表から出ます。Ctrl/⌘+Enter ならいつでも出られます。

## コードブロック

シンタックスハイライト付きのフェンスコードブロック(右上で言語を切り替え可能)。末尾の空行で Enter を押すとブロックから出ます。Ctrl/⌘+Enter ならいつでも出られ、引用でも同じです。

```python
def fib(n: int) -> int:
    """お馴染みのフィボナッチ数列。"""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

```rust
fn main() {
    let greeting = "こんにちは、Textus!";
    println!("{greeting}");
}
```

## 数式ブロック

`$$` で囲んだブロック数式はKaTeXによって描画されます:

$$
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$

`mermaid` コードブロックはリアルタイムで図表に描画されます。フローチャート:

```mermaid

    B -- はい --> C[Mermaidを描く]
    B -- いいえ --> D[書き続ける]
    C --> D
```

## 画像

クリップボードから画像を直接貼り付けると、Textusは画像を保存して参照を挿入します。保存先は**設定 → 編集と外観 → 画像**で決めます。**このコンピューター**なら、ドキュメントのフォルダー内の**サブフォルダー**（既定は `assets/`、名前は変更できます）か、**ドキュメントと同じフォルダー**を選べます。貼り付けた画像に付くリンクは設定画面に表示されます。**画像ホストにアップロード**なら、PicGo / PicList、SM.MS、Imgur、または自分のエンドポイント(**カスタム**)へ送ります。

カスタムのエンドポイントは `multipart/form-data` の `file` フィールドで画像を受信し、公開 URL をプレーンテキストまたは設定可能な JSON フィールドで返します。ファイル名は自動変更、元の名前の保持、アップロード前の毎回確認から選べます。保存先を切り替えても既存の画像参照は変更されません。

参照を手書きすることもできます:

```markdown
![説明文](assets/screenshot.png)
```

Obsidian の埋め込み（`![[image.png]]` や `![[attachments/image.png|300]]`）も画像として表示されます。Textus は文書が属する Obsidian の保管庫からファイルを探し、埋め込みは書いたとおりに保存します。

## 表示とモード

WYSIWYGエディタとソースコードモード(`Cmd+/`)のほかに、Textusには3つの書き方があります(WindowsとLinuxでは `Cmd` を `Ctrl` に読み替えてください。ショートカットを変更した場合は 設定 → ショートカット の設定が優先されます):

- **分割表示**(`Cmd+Shift+E`):左にMarkdownソース、右にレンダリング結果のプレビューを表示し、スクロールも連動します。
- **タイプライターモード**(設定 → 編集と外観 → テーマ):入力中の行を常にウィンドウ中央に保ちます。エディター、ソースモード、分割表示で有効です。
- **禅モード**(`Cmd+Shift+J`):本文以外をすべて隠して全画面にし、書いている段落以外を薄く表示します。`Esc` で終了します。

3つとも **表示**(View)メニューからも使えます。

## クイックメモ

**ファイル → 新規クイックメモ**で、思いついたことを書き留める小さなウインドウが開きます。`Esc`（または `Cmd+Enter`、`Cmd+S`、`Cmd+W`）を押すとメモが保存され、ウインドウが閉じます。何も書いていなければそのまま閉じます。**Textus で開く**を押すと、保存してからタブで開きます。

メモは「書類」フォルダの `Textus/クイックメモ` に 1 件 1 ファイルで保存され、1 行目がファイル名になります。**設定 → 一般 → クイックメモ**で、保存先の変更、**1 日 1 ファイル**への切り替え、どのアプリからでもクイックメモを開ける**グローバルショートカット**の有効化ができます（Mac は `Control+Option+N`、Linux は `Ctrl+Alt+N`、Windows は `Win+Alt+N`）。数分以内にもう一度開くと、前のメモの続きになります。Wayland では、そこに表示される `textus --quick-note` コマンドをデスクトップの設定でキーに割り当ててください。

ウインドウを開いていないときも Textus をすぐ使えるようにするには、**設定 → 一般 → バックグラウンド → バックグラウンドで実行し続ける**をオンにします。最後のウインドウを閉じても Textus は実行を続け、通知領域（Windows）、システムトレイ（Linux）、メニューバー（Mac）にアイコンを表示します。そのメニューから新規クイックメモ、書類、クイックメモのフォルダ、設定を開けます。完全に終了するのはそこで**Textusを終了**を選んだときです。**ログイン時に開く**をオンにすると、ログイン時にこの状態で起動します。GNOME では AppIndicator 拡張機能がないとトレイアイコンは表示されません。

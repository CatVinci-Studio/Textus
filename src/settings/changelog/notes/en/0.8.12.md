## What's new

- Text width can be chosen in Settings: the default "Adaptive" widens the text on wide screens and makes the font slightly larger; you can also pick "Standard" or "Full Width".
- Zooming keeps the point under the mouse in place, so the text no longer jumps up and down.
- No extra empty line appears after a picture. A handle on a picture's right edge lets you drag it to a new width.
- PDF export: all three platforms write the PDF file directly, without the system print dialog. Text, formulas and tables are no longer cut off at the page edges. On macOS and Windows, dark themes and themes with a background colour fill the whole page, with no white border. Local pictures show in exported PDF and HTML, and the # before headings and the code block language picker no longer appear in the export.
- AI chat panel: clear rules for opening and closing. Plain question-and-answer replies open in full; replies that change the document stay compact. The shortcut first focuses the input box, and pressing it again closes the panel. Esc closes the panel from anywhere in it. If there are changes you haven't dealt with, you're asked before it closes. When the chat is popped out into its own window, the shortcut switches to that window.
- AI replies show full Markdown, including maths, tables, headings and task lists. On wide screens the panel has a maximum width and is centred.
- OpenAI models are updated to the GPT-6 series (gpt-6-astra, gpt-6.1-sol, gpt-6-luna). Completion and the grammar check use lower reasoning effort, so they respond faster.
- All kinds of blocks in the text share the same spacing and corner radii. The code block language picker moves to the top-right corner, and line spacing in code blocks is back to normal. Mermaid diagrams refresh promptly when edited in place, and Gantt chart text is readable again.
- Typing and moving the caret are much smoother in long documents with many formulas.
- Switching between source mode and editing mode keeps the caret position and scroll position.
- A `max-width` set on `#write` by an imported theme now takes effect. New "Custom CSS" lets you adjust the current theme locally (first-line indent, line spacing, fonts and so on), and you can export the current theme as a CSS file.
- Linux: the window uses the same combined title bar as on Windows, the menus follow the interface language, the title no longer takes its own row when there is a single window, and F11 toggles full screen.

Installers for macOS, Windows and Linux are built by the release workflow. On Linux, exported PDFs use ordinary page margins, and with a dark theme the top and bottom margins may be white.

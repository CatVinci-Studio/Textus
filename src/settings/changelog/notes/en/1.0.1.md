## What's new

Textus 1.0.1: fixes the problems you reported after 1.0.0.

### Input methods and lists

- Typing with a Chinese input method in a new list or to-do item no longer adds empty items or splits the pinyin apart, and a to-do's checked state is kept. The same is fixed in table cells.
- New ways to make a to-do directly: `- 【】`, `-【】`, `- []`, `-[]`, or `【】` typed in a list item; write `【x】` or `[x]` for a done item. When you type `- [ ] `, the trailing space is no longer left at the start of the to-do.
- Enter on a table's last row starts the new row in its first cell.
- A table's height no longer changes when the mouse moves over a column divider.

### Pasting

- A pasted screenshot is saved to the `assets/` folder beside the document and inserted with a relative path, so the picture is still there when you reopen the document (for a new, unsaved document, it moves there on the first save).
- Pasting a picture file copied in the file manager inserts the picture instead of a link to the file.
- Pasting a URL makes a clickable link, saved as `[URL](URL)`. A link with no text, `[](URL)`, shows the URL itself and is saved as it is.

### PDF export

- On Linux with a non-English system, PDF export no longer spins forever without finishing.
- When an export fails, the error shows instead of being hidden behind the progress message.
- On Linux, a PDF exported with a theme that has a background colour has that colour over the whole last page.

### Headings and source mode

- Level 5 and 6 headings are the same size as body text instead of smaller; level 4 headings are slightly larger than body text, and level 6 headings are a little lighter in colour.
- Text in source mode is the same size as body text and stays sharp while you edit.

### Other improvements

- Closing the right-click menu with Esc keeps the grey completion suggestion.
- After you create a library entry, the AI panel stays on the "Memory" page.
- After undoing an accepted change, the card's change count shows both the additions and the deletions correctly.
- In narrow windows and on phones, comment numbers match the comment cards in the AI chat one to one.
- HTML comments in a document show as faint hint text; move the caret into one to edit the source.
- macOS 26: the window buttons line up with the title, and an empty document no longer scrolls for no reason.
- Scrolling with the mouse over a table scrolls the whole document.
- The screen reader name of the mode picker is now "Mode".

Installers for macOS, Windows and Linux are built by the release workflow.

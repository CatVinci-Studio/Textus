## What's new

- Arch Linux: a new signed pacman repository, [`[catvinci]`](https://github.com/CatVinci-Studio/arch-repo), provides the `levis-bin` package. Set it up once as described in the README's "Installation" section, and `sudo pacman -Syu` upgrades Levis for you.
- Levis installed through a package manager still tells you about new versions, but no longer downloads and installs them itself. It asks you to update with the package manager instead, so it doesn't conflict with files pacman manages.
- The GitHub Release adds `Levis_0.8.13_linux_x86_64.tar.gz`, for Linux packages.

Installers for macOS, Windows and Linux are built by the release workflow.

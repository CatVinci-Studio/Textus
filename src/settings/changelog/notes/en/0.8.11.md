## What's new

- Settings, menus, dialogs, the tutorial and the AI panel share the same colours, corner radii and control styles. Small windows lay out better, and keyboard use is improved.
- After you import a CSS theme, the interface takes on the theme's colours. Built-in themes have more contrast for text and links, and the source view background is fixed.
- The Chinese, English and Japanese tutorials are shorter, and the Chinese help text is updated. Restoring tutorial progress and the tutorial's state after quitting are fixed.
- On macOS, Cmd+arrow navigation and selection work again, and no longer clash with code block and table shortcuts.
- Fixes the draft autosave timer, state carried across documents, and edge cases in Find and Replace. Shortcut conflicts now show a warning.
- Diagram rendering, HTML cleaning and build dependencies are updated, closing known dependency vulnerabilities.

Installers for macOS, Windows and Linux are built by the release workflow. Dragging between windows still works on macOS only. Special layouts and remote styles in third-party themes still depend on how each theme is written.

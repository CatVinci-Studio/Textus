## What's new

### Editing

- Enter behaves the same way in every kind of block:
  - In a table, Enter moves to the next row; on the last row it adds a row, and Enter again on an empty new row leaves the table. Ctrl/⌘+Enter leaves it at any time.
  - Type `| Name | Age |` and press Enter to make a table.
  - Enter on an empty last line of a code block or maths block leaves the block, not only at the end of the document.
  - Ctrl/⌘+Enter also leaves a quote.
- "Select Row" and "Select Column" in the table's right-click menu highlight the selected cells, and table commands act on the cell you right-clicked.

### Themes

- Exported theme CSS includes decorations such as the underline under level 2 headings, the bar beside level 3 headings and the quote background, so they are no longer lost when you edit the theme and import it again.
- Table headers in the built-in themes have the same background colour as quotes and code blocks.

### Other

- Milkdown is updated to 7.22.3.

Installers for macOS, Windows and Linux are built by the release workflow.

## What's new

This is the last version of Levis. Levis has become Textus: a new name, a new icon, and it keeps being updated.

### Levis has become Textus

- After updating, you see a message about Textus once, with a link straight to the download page; later you can find it in Settings › General.
- Your documents stay where they are. On first launch, Textus offers to import Levis's settings, history, themes and keys. It only copies them, and changes nothing in Levis.

### Levis AI, redesigned

- Take or leave revisions sentence by sentence in the text: the original sentence is marked in the text, and the new sentence with ✓ / ✕ sits in the margin. The review bar at the bottom of the editor jumps from change to change and accepts or rejects them all. In a narrow window or on a phone, they show in the text itself.
- Review comments sit in the margin beside the text they refer to; you can ask a follow-up or mark them as resolved.
- Grammar check cards name the kind of problem and show "original → fix", and the button shows the fix and Alt+Enter.
- The AI panel adds a "Memory" page that brings the style profile, library, writing instructions and skills together in one place.
- Buttons are rounded pills and follow the colours of the current theme (imported Typora themes included).
- How revisions are shown can be switched, as in Word's markup views: everything in the text; the original in the text and changes in the margin; changes in the text and the original in the margin; or only the result. Choose it from the eye icon on the review bar or in Settings.

### Editing

- The table's right-click menu scrolls with the mouse wheel or scroll bar instead of closing as soon as you scroll, so "Delete Row" and "Delete Column" at the bottom can be clicked.
- When the last line of a code block or diagram block holds only indentation, Enter leaves the code block too.
- Clicking a Mermaid diagram opens its own source, instead of jumping to another diagram above it.
- With a pinyin input method, pressing Shift (to switch between Chinese and English) together with Enter now counts as a plain Enter and starts a new paragraph, instead of a line break inside the paragraph.
- When a paragraph ends with a line break, Shift+Enter in the middle of a line no longer swallows the character before it.
- GitHub callout markers (such as `> [!NOTE]`) are saved as they are, instead of being escaped.

### Export

- PDF and HTML no longer show the metadata box at the top of the document, and footnote numbers sit on the same line as the text.
- HTML keeps the look it had when exported, instead of a reader's dark mode clashing with light diagrams.
- Word, OpenDocument, EPUB and RTF: diagrams are exported as pictures, highlights stay highlights, pictures use the width you set, callout titles follow the interface language, and the file name no longer appears as a second title above the document's title.

### Chinese, Japanese and Korean

- In the Chinese and Japanese interfaces, quotation marks, ellipses and dashes are drawn with the Chinese font: "……" no longer shows as six dots on the baseline, and "——" no longer breaks apart.
- Korean text breaks lines between words, no longer splitting a word across two lines (except in table cells).
- In Chinese and Japanese, the word count counts characters, and the unit shows as "字".
- Callout titles (Note, Tip, Important, Warning, Caution) follow the interface language.
- In the Japanese interface, "承認" is now "適用".

Installers for macOS, Windows and Linux are built by the release workflow.

## What's new

### Fixed

- Saving could lose content: after typing a long passage and saving at once, the last part typed might not reach the file, and if the window's focus changed while saving, unwritten content could be thrown away. Closing a window, switching to source mode and dragging a tab now also take the editor's latest content first.
- Pressing Enter in a numbered list and then typing Chinese with an input method no longer adds extra empty lines, repeats text or garbles it.
- On Linux, a new line no longer takes two presses of Enter after picking a word in an input method.
- On Linux, Chinese text can be made bold.
- Saving no longer turns a tight bullet list into one with an empty line between items.
- A code block's language label no longer covers the first line of code ([#16](https://github.com/CatVinci-Studio/Levis/issues/16)).
- Tables with many columns no longer run past the text; they scroll sideways within the text width ([#15](https://github.com/CatVinci-Studio/Levis/issues/15)).

### Themes

- Imported Typora themes now fully control the styles of quotes, tables, code blocks and so on, instead of being overridden by Levis's own styles. With an imported theme, Levis's own heading decorations and quote background are turned off, so the result is closer to Typora ([#13](https://github.com/CatVinci-Studio/Levis/issues/13)).

### Linux windows

- Windows have a thin border, and you can drag the edges and corners to resize; the resize cursor shows when the mouse reaches an edge ([#11](https://github.com/CatVinci-Studio/Levis/issues/11)).
- Remembers the window size from the last time it was closed ([#11](https://github.com/CatVinci-Studio/Levis/issues/11)).
- Under Wayland (tiling window managers such as niri), the floating AI chat window floats as a child of the editing window, instead of taking a new column.

### Performance

- Editing no longer re-renders every open tab, and moving the caret no longer scans the whole document again and again, so long documents edit more smoothly.

Installers for macOS, Windows and Linux are built by the release workflow.

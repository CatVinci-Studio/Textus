## What's new

Textus 1.0.3: improvements to copying, pasting and signing in.

### Copy and paste

- Copying into apps that only take plain text, such as WeChat, gives readable text: links are written as "text (URL)", without Markdown marks. Pasting into Word, mail or Textus still keeps the formatting. When you need the Markdown source, switch it in "Settings › Editor & Appearance › Markdown › When copying to other apps".
- "Copy" in the right-click menu gives the same result as the copy shortcut: both formatted and plain text.
- Pasting a URL in the middle of a link's text no longer splits the link; pasting a URL over selected text turns that text into a link to the URL.

### Intel Mac

- Adds installers for Macs with Intel chips (file names ending in `_x64.dmg`); the Apple silicon one is still `_aarch64.dmg`. Both update automatically, and Homebrew picks the right one for your Mac's chip.

### Signing in

- When signing in with a ChatGPT or Claude account, if the browser doesn't open by itself, Settings shows the sign-in link and a "Copy link" button; open the link in a browser on this computer to finish signing in.

Installers for macOS, Windows and Linux are built by the release workflow.

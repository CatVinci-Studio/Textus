## What's new

Textus 1.0.0: the next-generation Markdown editor. You write; the AI grinds the ink.

### New name, new icon

- Levis is renamed Textus, with a new quill icon; the AI assistant is renamed Textus AI to match.
- The app identifier is now `com.catvinci.textus`, so it doesn't interfere with Levis, and both can be installed at once.

### Textus AI, redesigned

- Take or leave revisions sentence by sentence in the text: each change's original sentence is marked in the text, and the new sentence with ✓ / ✕ sits in the margin, with a thin line to the original. The review bar at the bottom of the editor jumps from change to change and accepts or rejects them all. Once the last sentence is decided, the change takes effect. In a narrow window or on a phone, the new sentence and ✓ / ✕ show in the text itself.
- Review comments sit in the margin beside the text they refer to. Hovering highlights the text and the comment together, and you can ask a follow-up or mark a comment as resolved. Without room in the margin, a number follows the text; click it to see the comment.
- Grammar check cards name the kind of problem (typo, grammar, punctuation, writing conventions) and show "original → fix", and the button shows the fix and Alt+Enter. When a paragraph has several problems, you can step through them one by one.
- The AI panel adds a "Memory" page: the style profile, the library (marking the entries this document uses), writing instructions and skills are together in one place, and each opens for editing with a click.
- The top of the panel is a single row, and revision and comment cards are leaner.
- On a phone, the AI panel folds away when revisions arrive, the text scrolls to the first change, and the review bar at the bottom takes you back to the chat at any time. Comments and grammar suggestions open as cards from the bottom.

### A new look

- Buttons are rounded pills, and primary buttons use the current theme's colour: built-in themes and imported Typora themes change the AI panel, the review bar and the cards together, inverted for dark themes.

### Improvements and fixes

- The interface adds Traditional Chinese, Japanese, Korean, Spanish, French, German, Russian and Portuguese, for 10 languages in all; grammar check explanations follow the interface language.
- Export: PDFs have margins of about 20 mm all round. Footnotes, highlights, picture widths, callouts and Mermaid diagrams export to Word, ODT, EPUB and RTF as they look on the page. HTML export keeps the current light or dark look. Formulas, diagrams and callouts are no longer cut across page breaks.
- Saving: Windows line endings and the BOM are kept as they are. A read-only file shows that it can't be saved, instead of failing silently. A symbolic link writes back to the file it points to, and file permissions are kept.
- Undoing an accepted AI change puts the proposal back to pending, so you can accept or reject it again.
- Asking the AI to rewrite a paragraph selected with a triple-click no longer joins that paragraph to the next one when you accept.
- Completion in tables: the suggestion is kept to one line so it doesn't break the table; right-clicking a paragraph outside a table shows the paragraph's menu; after starting completion from the right-click menu, Tab accepts it straight away.
- The mode you chose in the AI panel carries over to new chats and separate windows, and accepting a completion no longer asks for the next suggestion right away.
- With the AI panel open, the text's scroll bar shows only while scrolling.
- The shortcut for a new window is ⌘⇧N / Ctrl+Shift+N everywhere.

### Importing from Levis

- On first launch, if this computer has Levis data, Textus offers to import it: settings, AI chat and clipboard history, themes, writing instructions, skills, recent files, open documents and unsaved drafts. API keys and ChatGPT and Claude sign-ins are asked about separately.
- Importing only copies, and changes nothing in Levis. You can import again later from Settings › General › Import from Levis.
- Project folders use `.textus/`. A `.levis/` left by Levis can still be read; when one of its files needs changing, Textus first copies it to `.textus/` and leaves the original as it is.

### Installing and updating

- Homebrew: `brew install --cask catvinci-studio/tap/textus`. If you installed Levis with Homebrew, `brew upgrade` switches it to Textus.
- Arch Linux: `textus-bin` replaces `levis-bin`, and `sudo pacman -Syu` swaps it in.
- Automatic updates use a new update manifest, so Textus and Levis updates don't affect each other.

Installers for macOS, Windows and Linux are built by the release workflow.

## What's new

### Fixed

- "Split View" and "Zen Mode" in the View menu respond when clicked again (their menu shortcuts work again too).
- Menu commands are no longer sometimes run more than once, for example "New File" opening several tabs.
- In a quote, Backspace at the start of a line moves that line out of the quote.
- After you change the interface language, the placeholder text in an empty document changes with it.
- The minimum height of input boxes works again.

### Interface

- In the app menu on Windows and Linux, toggles such as Sidebar, Source Mode, Typewriter Mode and Zen Mode show a check mark when on.
- Risky commands such as "Delete" in right-click menus are shown in red.
- In a narrow window, the category tabs at the top of Settings scroll sideways in one row instead of wrapping.

Installers for macOS, Windows and Linux are built by the release workflow.

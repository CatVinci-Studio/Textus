## What's new

0.9 is an AI update centred on writing: the AI understands your project and your style, changes can be taken sentence by sentence, and the editor adds split view, typewriter mode and zen mode.

### AI panel

- The AI chat shows to the right of the editor by default and follows the document you switch to. The chat button in the window's top bar or Ctrl/⌘+Shift+L turns it on and off, and it can still open as its own window.
- Quick Ask (which pops up after you select text) starts in "Edit" by default, and one click moves it to the right-hand panel to carry on.
- Every suggested change comes with a reason. You can tick a change sentence by sentence and accept only the parts you want (the same "Accept" button then reads "Accept 1 of 2").
- The change cards and Quick Ask are laid out again: one change has one pair of Accept/Reject buttons, and buttons you rarely need only appear when they apply.
- The AI can insert text at the caret, or leave only a comment without changing the text; comments can be located in the document.
- Error messages are clearer: not set up, invalid key, too many requests, model unavailable, and server or network problems each give their cause and what to do.

### Projects and writing material

- The folder holding a saved document is its project. The AI can browse, read and search the text files in it; type @ in the input box to refer to a file. Folders that are too large, such as your home folder or the root folder, aren't treated as projects.
- `.levis/style.md`: a style profile. "Learn style" can create it from samples you pick, and completion and edits follow the way you write.
- `.levis/library/`: a library. Entries for people, terms, settings and so on are matched by name and alias, and the relevant ones are sent to the AI with each request.

### Completion and grammar

- Completion fits the context better: it takes the title, the current section and the style profile into account, and avoids common AI clichés.
- Ctrl/⌘+→ accepts a completion word by word, Alt+[ / Alt+] switch between candidates, and Esc cancels.
- Grammar check: rest the caret on a problem to see the suggestion, press Alt+Enter to accept it, or choose to ignore it.

### Editor

- Split view: source on the left, live preview on the right, with synced scrolling (Ctrl/⌘+Shift+E).
- Typewriter mode: the line you're typing stays in the middle of the window (Settings › Editor & Appearance).
- Zen mode: hides the interface, goes full screen and highlights only the current paragraph (Ctrl/⌘+Shift+J, Esc to leave).
- The window title shows the current document's name, so windows are easier to tell apart in the taskbar and window switcher.
- Buttons, corner radii and pop-up menus look and behave the same everywhere: buttons of the same kind are the same size, and every menu closes when you click outside it or press Esc.
- The welcome page shows the proper app icon.
- The first-run tutorial adds an introduction to the sidebar.

### Models

- The built-in model list keeps only each service's default models (Anthropic: Claude Sonnet 5.5 for the Agent, Claude Haiku 5.5 for completion), and model information is synced weekly from models.dev.
- In Settings you can fetch every model a provider currently offers and pick one yourself.
- Anthropic requests use prompt caching, so long chats are faster and cost less.

### Windows and Linux

- On Windows and Linux, opening a file from the file manager hands it to the Levis that is already open, instead of starting another process.
- Closing an editing window also closes its separate chat window.
- File dialogs show as children of the editing window, and saving adds the .md extension for you.
- Better display compatibility with NVIDIA graphics on Linux.
- The sign-in credentials file can be read only by the current user.

### Fixed

- The number of deleted lines in AI change cards no longer shows as garbled text (`−`).
- Pop-ups no longer stay where they were when you scroll, and the right-click menu no longer opens by mistake.
- Esc closes the find bar again while the AI panel is open (and always, on Windows).
- Quick Ask no longer jumps to the end of the document after receiving a change, hiding the Accept button.
- Code blocks in the split view preview have their background and border.

Installers for macOS, Windows and Linux are built by the release workflow.

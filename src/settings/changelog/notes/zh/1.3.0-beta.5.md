## 更新内容

Textus 1.3.0-beta.5 新增复制路径、图片查看器、帮助 › 报告问题，以及在所有系统上可用的 `textus` 命令；重做了插件按钮，用你的语言显示错误信息，并带来 1.2.6 的修复。

### 新增

- 文件菜单、标签页右键菜单和文件树菜单中新增复制路径，可复制文档的完整路径，所有系统均可用。
- 点击图片角落的按钮或双击图片，即可在图表所用的可缩放查看器中打开：滚动或双指捏合缩放，拖动移动。(#428)
- 帮助 › 报告问题：描述遇到的问题，Textus 会附上版本、系统、插件和最近的错误，发送前全部展示给你。提交会打开已填好的 GitHub 错误报告表单；复制会把全部内容放到剪贴板，方便在聊天或邮件中发送。(#427)
- `textus` 终端命令现在也支持 Windows 和 Linux AppImage：`textus notes.md` 会在 Textus 中打开文件，终端立即回到提示符。设置 › 通用 在所有系统上都会显示它已安装。

### 改进

- 每个插件只有一个按钮，旁边带一个菜单，在获取更多和已安装插件中保持一致：安装；安装后有更新时显示更新，否则显示停用或启用，卸载放在菜单中。有更新时直接显示在按钮上，返回按钮也更容易找到。(#431)
- 错误信息现在用你的语言说明发生了什么：没有文件或文件夹的权限、文件已不存在、磁盘已满或只读、文件被其他程序占用、无网络连接或超时、文件过大无法打开、名称不可用、插件过大无法安装，以及 AI 无法生成图片。系统自带的信息如有补充，仍会显示在下方。

### 修复

- 从访达、文件资源管理器或 Linux 文件管理器拖入的文件可以再次打开，此前拖放没有被识别。拖入文件夹会像打开文件夹一样在侧边栏中打开。(#429)
- 右键图片选择复制会复制图片本身，复制的图片粘贴到其他应用时就是图片，粘贴到 Markdown 应用时则带有其 Markdown。(#428)
- 把标签页拖到另一个窗格的标签栏上（沿标签栏拖动或先向下拉出）时，会在松手的位置加入该窗格；在 Windows 上，从标签栏拉出的标签页不再卡在屏幕上。(#426)
- 新标签页和新打开的文档会保持你上次切换到的视图（源码模式或源码与预览），不再每次都回到富文本编辑器。(#424)
- 写在粗体或斜体内的 HTML 标签（如 `**<u>words</u>**`）会显示其样式，而不是原始标签。(#423)
- 获取更多中显示每个插件的图标，而不是名称的首字母。(#431)
- AI 服务的余额或额度用尽时，Textus 会用你的语言如实说明，并告诉你去哪里充值或切换服务，不再误报为速率限制。

## 更新内容

Textus 1.3.8 修复了光标离开链接时链接消失的问题，打开链接的本地文件前会先询问，源码模式下可以粘贴图片，Word 导出也可以使用你自己的模板。

### 新增

- 源码模式和分屏视图中也能粘贴图片：按 设置 › 图片 中的方式存储，并在光标处写入 `![](...)`。(#196)
- **设置 › 编辑与外观 › 导出 › Word 模板**：导出的 Word 文件沿用你所选 Word 文件的样式、字体和页边距（即 Pandoc 的参考文档）。(#196)

### 改进

- Ctrl/Cmd+点击指向本地文件（PDF、Word 文档、图片）的链接时，会先询问，然后用系统默认的应用打开，而不是只在文件夹中显示它。程序或脚本仍然只在文件夹中显示。(#561)
- 在 Windows 上，窗口最小化时会让 WebView2 减少内存占用，窗口回到屏幕上后再恢复。

### 修复

- 同一个链接在另一个标签页中以 Markdown 形式显示过后，光标离开该链接时链接不再消失；此前保存时，这一段会把链接丢掉。(#561)
- 在 Windows 上，在新窗口中打开另一篇文档（文档设为在独立窗口中打开时使用 文件 › 打开…、在侧边栏中 Ctrl+点击，或 移到新窗口）可能导致应用卡死，通过远程桌面使用时尤其常见。
- 使用 **视图 › 放大** 后，快速预览卡片会出现在链接正下方，而不是链接未缩放时所在的位置。
- 读取 Word、Excel 等基于 zip 的文件时使用了更新后的库，修复了两个已报告的安全问题（RUSTSEC-2026-0429、RUSTSEC-2026-0433）。(#533)

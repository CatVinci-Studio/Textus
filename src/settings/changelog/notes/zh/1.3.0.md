## 更新内容

Textus 1.3.0 向插件开放，并登陆 iPhone 和 iPad。**设置 › 扩展** 里的统一商店汇集了插件、主题和技能：思维导图、Vim 和 Emacs 键位、Marp 幻灯片、Zotero 引用、笔记关系图谱、类 Notion 的页面和数据库、图表等等；插件在 iPhone 和 iPad 上的运行方式与电脑上相同。窗口可以随意分出任意多个窗格，命令面板让你输入文字即可执行一切操作，修订模式像对待 Textus AI 的修改一样保留你自己的编辑供审阅，整个应用采用统一的外观，主题可以为所有界面重新着色。

### 新增

- 在 Textus 内安装插件：**设置 › 扩展** 先列出你已有的插件、主题和技能，再列出可以添加的，一个搜索框就能搜遍全部。每个插件都有自己的页面，安装前可以看到截图、使用指南和它申请的权限；一个按钮即可安装、更新、关闭或开启；还有它自己的设置，可以对所有文档生效，也可以只对当前打开的文件夹生效。卸载时，插件保存的数据会移到废纸篓。
- 首批官方插件：
  - **写作：** Vim 和 Emacs 键位、快速插入（`/` 插入标题、列表、表格、公式、提示框和表情）、模板、Markdown Lint、中英文间距、标题编号、写作统计、LaTeX 补全、自然语言日期和 WakaTime。
  - **笔记：** 页面（页面中嵌套页面）、数据库（把文件夹中的文档显示为表格、看板、日历或画廊，支持从 Notion 导入）、图谱视图、反向链接、标签、任务、书签、日历与每日笔记、快速笔记、快速预览、提醒和版本历史。
  - **绘图：** 思维导图（Markmap）、ECharts、Chart.js、PlantUML、时间线、ABC 记谱法乐谱、WaveDrom 和 Function Plot，绘制在代码块下方，导出时以图片形式保留。
  - **阅读与研究：** Marp 幻灯片、Zotero 引用、链接卡片，以及在标签页中打开的 PDF、Word、图片和网页查看器。
- iPhone 和 iPad：Textus 上架 App Store，是同一个应用，只是布局更窄——插件、主题、技能、Textus AI 和修订都包含在内。文档保存在“文件”App 中；按住标签页即可拖动或分屏。
- 同时打开两篇以上的文档：**视图 › 向右分屏**（`Ctrl/⌘ + Alt + S`）和 **向下分屏** 可以对当前窗格反复分割；把标签页或文件拖到边缘即可在那里打开，拖出窗口则独占一个新窗口。每个窗格都有自己的标签页，每个窗口重新打开时都会恢复原来的标签页和窗格。
- **视图 › 命令面板…**（`Ctrl/⌘ + Shift + P`）可以查找并执行菜单中的所有操作和每个插件命令，也支持拼音（输入 `bs` 能找到“背诵”）。
- 修订模式，位于视图菜单：你的编辑会显示为修订——删除的内容加删除线，新增的内容加标记，中文和日文按字标记——可以在审阅条上逐条或全部采纳、拒绝，并提供与 Textus AI 的修改相同的三种视图。文件中保存原文和已采纳的修改；尚未决定的修订保存在旁边的 `.textus` 文件夹中，再次打开文档时会恢复。
- 在页边写下自己的批注：选中文字，右键 › **添加批注**，批注会出现在文字旁边，标为“我”，与 Textus AI 的批注并列。
- **视图 › 只读**，或标签页菜单中的只读，可以防止文档被修改；标题旁的小锁图标表示只读状态。
- 后退和前进（`Ctrl + -` 和 `Ctrl + Shift + -`，Windows 和 Linux 上为 `Alt + ←/→`，或使用鼠标侧键）可以在点击链接、跳转标题或切换标签页后回到原来的位置。
- `Alt/⌥ + ↑/↓` 可以上下移动段落、列表项或选中的块。
- 右键点击图片可以向左或向右旋转 90 度，或在可缩放的查看器中打开；双击图片也能打开查看器。
- **文件 › 重新打开关闭的标签页**（`Ctrl/⌘ + Shift + T`）、**复制路径**，以及标签页菜单中的关闭其他标签页、关闭左侧标签页和关闭右侧标签页；鼠标中键点击可以关闭标签页。
- **帮助 › 报告问题** 可以在 Textus 内直接发送问题报告，发送前会展示你的版本、系统和插件信息——无需 GitHub 账号。
- `textus` 终端命令现在也支持 Windows 和 Linux AppImage。
- Textus AI：可以在消息框中切换对话模型、搜索历史对话、把值得重复的请求保存为技能、把插件的工具提供给 Textus AI，并按你自己的描述重画某一张提议的图片。
- 面向插件作者，插件 API 1.0 的类型定义在 `docs/dev/textus.d.ts` 中，`textus-plugin.json` 附有 JSON Schema；插件可以绘制代码块、标记文本、添加 `/` 菜单项和 AI 工具、使用自己的存储、通过通知提醒你，并在后台定时运行。manifest 会注明插件可在哪些平台运行，第三方插件也可以上架商店。

### 改进

- 整个应用采用统一的外观：所有面板、卡片和对话框使用相同的圆角，按钮和开关都是胶囊样式，文字大小遵循同一套层级。主题会为整个窗口重新着色——侧边栏、设置、菜单和 AI 面板——侧边栏一直延伸到标题栏后面。
- 复制时，剪贴板的纯文本中放入 Markdown，因此 GitHub、Obsidian 和聊天应用能保留格式，而 Word 和 Notion 仍粘贴为带格式的内容；**编辑 › 复制为纯文本** 和 **粘贴为纯文本**（`Ctrl/⌘ + Shift + V`）只处理文字本身。还可以在 **设置 › 编辑与外观** 中把纯文本复制和粘贴加到右键菜单里。
- 右键菜单把你点击的内容相关的项放在最前，剪切、复制和粘贴固定在顶部——没有选中内容时剪切和复制显示为灰色——并新增 **格式**：粗体、斜体、标题、列表、引用、代码块和表格。指针移向子菜单时，子菜单保持打开。
- 每次粘贴、剪切、拖放和替换都是单独的一步撤销，与 Word 一致；查找会从你选中的文字开始。
- 打开文件遵循同一条规则：已打开的文件会切换到前面，未改动的空白文档会让出位置，其余情况都在新的标签页中打开。
- 文档被其他应用修改后，只要它所在的窗口可见，Textus 会很快更新；你未保存的编辑绝不会被覆盖。(#468)
- 源码模式、源码与预览、禅模式和打字机模式对所有标签页和窗口统一生效。分屏视图现更名为 **源码与预览**。
- 页边的修订和批注卡片在任何缩放比例下、侧边栏打开时都紧贴正文，不会遮挡文字或闪烁；没有空间时，由审阅条接管。在正文中显示原文的视图里，仅有新增文字的修订也放在卡片中，并用一条细线标出插入位置。
- [[Wikilinks]] 显示为笔记名，只有光标停在上面时才显示方括号。
- 错误信息用你的界面语言说明发生了什么——文件不存在、没有权限、磁盘已满、没有网络、余额用完——不再显示系统的原始文字。
- 设置更清爽了：常改的选项排在前面，其余放在“高级设置”中；通用 › 帮助 里有新手导览、使用指南、报告问题和社区。
- **设置 › 编辑与外观** 可以让图片靠左；在 Mac 上，还可以在深色模式下写作的同时用浅色导出 PDF。修订模式和只读也和其他视图开关放在一起。
- Textus 自带四个技能——校对、设计主题、制作插件和制作技能；扩写、精简、翻译、总结和连贯性检查在商店中一键即可添加，你自己的技能也可以暂时关闭。
- 长文档按章节同时翻译或改写，人名和术语全文保持一致；Textus AI 的记忆会自动整理。
- 窗口打开更快：分屏视图、导出、新手导览和插件宿主在第一次使用时才加载。

### 修复

- Backspace、Delete、回车和粘贴会保持代码块、公式块、引用、列表和表格的结构：不会再把块倒进旁边的行，缩进代码保留其中的空行，粘贴的表格会填入落点处的单元格。
- 在 macOS 上，撤销和重做能撤回粘贴、剪切和格式修改，不再只限于输入；在文本框或对话窗口中撤销，也不会影响到后面的文档。
- 从访达、文件资源管理器或 Linux 文件管理器拖入的文件又能打开了，拖入的文件夹会在侧边栏中打开。(#429)
- 点击正文旁的空白页边，光标会落在最近的一行。
- 在 Windows 和 Linux 上，设置和其他菜单命令在你使用它们的窗口中打开。

### 平台说明

- **iPhone 和 iPad：** 需要在后台运行或依赖电脑上程序的插件——快速笔记、提醒、Zotero 和网页视图——仅在电脑上可用。
- **Windows 和 Linux：** **设置 › 编辑与外观 › 显示菜单栏** 会把文件、编辑、视图等菜单放在标题栏上，不再收在 ☰ 后面。

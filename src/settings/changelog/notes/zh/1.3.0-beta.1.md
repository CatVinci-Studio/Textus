## 更新内容

Textus 1.3.0-beta.1 是 1.3 的第一个测试版，为它打下基础：在 Textus 内安装的插件，拥有自己的设置和存储，以及更完整的开发 API；插件、主题和技能的统一市场；输入公式时的 LaTeX 命令补全；你自己的批注和修订与 Textus AI 的并列在页边；启动更轻快。它也包含 1.2.1 的全部内容。测试版可能还有不完善之处，欢迎在 GitHub 或 Discord 告诉我们。

### 新增

- 插件、主题和技能的统一市场：设置 › 扩展 › 获取更多 列出这三类内容，一个搜索框即可搜索，每类各有一个标签页，技能一键即可安装；设置 › 扩展 › 插件 列出你已安装的插件，每个都可以打开自己的页面。
- 插件的设置可以只属于某个项目：打开文件夹后，插件在 设置 › 扩展 中的页面会出现 **适用于**——所有文档，或此项目——项目的设置值保存在项目的 `.textus/settings.json` 中，随文件夹一起走，并优先于通用设置；**改用通用的值** 可以恢复某一项。
- 插件把自己的数据存放在两个地方：一处对所有文档通用，位于 Textus 的配置文件夹中，与你的全局 agent.md 放在一起；另一处随项目走，位于项目的 `.textus/plugins/` 中——后者仅限你授权过的插件。每个插件只能访问自己的数据，每处最多 50 MB。
- 经你允许后，插件可以为 Textus AI 提供工具——统计字数、在文献管理器中查找、转换格式等；每次调用都会显示在对话中，与 MCP 服务器的调用一样。
- 输入公式时的 LaTeX 命令补全，需安装 LaTeX 补全插件（设置 › 扩展 › 获取更多）：输入反斜杠和命令开头——`\fr`、`\alp`——即列出以此开头的命令，并显示各自的效果；按回车或 Tab 写入命令，光标停在花括号内。(#358)
- 每个插件都会说明用法：无论从获取更多还是从文件安装，插件的使用指南都会以你的界面语言在标签页中打开；在设置中的插件页面点击 **使用说明** 可以再次打开。
- 安装网页视图插件后，按住 Ctrl 点击网页链接（Mac 上为 ⌘+点击）会在笔记旁的标签页中打开，不再跳转到浏览器；网页上方的栏只有细细一行，还可以收起为一个小把手。
- 安装 Vim 和 Emacs 插件后，编辑器支持 Vim 和 Emacs 键位：Vim 的模式、移动、操作符、寄存器和 flash 跳转；Emacs 的移动、标记和 kill ring。**插件 › 开启或关闭 Vim 键位**（Emacs 同理）用于切换。
- 安装分屏插件后，可以同时查看两篇文档：向右分屏（Ctrl+Alt+S，Mac 上为 ⌘⌥S）把当前文档与另一个标签页并排显示，向下分屏则上下排列。
- 安装快速预览插件后，可以快速查看链接指向的内容：把指针停在指向另一篇文档的链接上——Markdown 链接或 [[wikilink]]——旁边的卡片中就会显示它的开头；安装 Zotero 插件后，把指针停在 [@darwin1859] 这样的引用上，会显示它引用的文献。
- 你自己的批注：选中文字，右键 › 添加批注，批注会出现在页边，与 Textus AI 的并列，标为“我”；批注保存在 Textus 自己的数据旁，不写入你的 Markdown。
- 修订模式（编辑菜单）：开启后，你的编辑会显示为修订——删除的内容加删除线，新增的内容加标记——每处修订在页边都有一张标为“我”的卡片，可以采纳或拒绝。
- 可以在消息框中切换对话模型：其他控件旁的按钮显示下一条消息将发给哪个模型，可从你在 **设置 › Textus AI** 中配置的服务商中选择；只配置了一个模型时，这个按钮不会出现。
- 搜索对话：AI 面板的历史记录新增搜索框，可以找到说过某些话的对话；当你提到之前的对话时，Textus AI 也会在这里查找。
- 值得重复的任务可以变成技能：当你的请求是一套自己的流程时，Textus AI 会在回复下方提议把它保存为技能，可用于所有文档或仅此项目；只有你选择保存时才会保存。
- 按你自己的描述重画提议的图片：指向图片并选择重画…，只重画这一张。
- 开启 **设置 › 隐私 › 关闭时保留未保存的修改，不再询问** 后，关闭窗口时会直接保留未保存的修改，不再询问；默认关闭，并且需要开启草稿恢复。
- 面向插件作者，完整的插件 API 类型定义在 `docs/dev/textus.d.ts` 中，`textus-plugin.json` 附有 JSON Schema，编辑器可以在你输入时进行校验。
- 插件 API 新增：安装后显示的 `USAGE.md` 使用指南、`contributes.links`（按住 Ctrl/Cmd 点击时由插件打开的网页链接）、`textus.storage.global` 和 `textus.storage.project`、按项目的设置、`textus.ai.registerTool` 配合 `contributes.aiTools`、`textus.workspace.readDocuments()` 和 `search(query)`、`textus.window.openFile(path, { asDocument: true })`（取代 `textus.openAsDocument` 命令）、`textus.window.splitEditor`、`textus.editor.registerCompletionProvider` 配合 `contributes.completions`（输入时在光标下方显示建议）、`textus.editor.registerHoverProvider` 配合 `onHover` 激活事件、`textus.motion` 和 `textus.l10n.t`。

### 改进

- 启动时加载的内容更少：分屏视图、编辑器菜单、首次运行导览和运行插件的代码在第一次使用时才加载，窗口的启动代码从 1.32 MB 降到 1.02 MB。
- 侧边栏的文件树不再显示隐藏文件——以点开头的文件，以及 Windows 上标记为隐藏或系统的文件，如 desktop.ini——**排序** 菜单中的 **显示隐藏文件** 可以让它们显示出来。(#357)
- 设置中的插件页面会显示插件存储了多少数据——对所有文档通用的部分，以及当前打开的项目中的部分——**清空** 会在确认后清除这些数据。
- 设置 › 扩展 中的插件、主题、Skill 和 MCP 采用同一种布局：一行说明该标签页的内容，**获取更多** 和用于其他操作（从文件安装、导入 CSS、手动添加服务器）的 **⋯** 菜单，你已安装的内容，以及折叠起来的高级设置。尚未安装的内容——主题库、你关闭的内置技能、大多数人会添加的 MCP 服务器——都在获取更多中。
- 长文档按章节同时修改：让 Textus AI 按章节翻译或改写长文档时，它会把每一章交给单独的助手处理，并共享一份反复出现的人名和术语的写法清单。
- Textus AI 的记忆会自动整理：它会不时合并内容相同的记忆，并删除已被新规则推翻的旧规则；被删除的内容在记忆页的“最近忘记的”中，可以找回。
- 同一作品中的图片保持人物和风格一致：再次出现的人物会用相同的文字描述；如果图像模型支持参考图，会以之前的图片为参考绘制该人物的新图片。
- 标签页中的网页（网页视图插件）在 macOS 和 Windows 上可以打开任何网站，使用系统自带的网页视图及其 Cookie；在 Linux 上，网页暂时仍以 frame 方式显示。
- 获取插件时会先立即显示上次的列表，同时获取最新列表；离线时也会继续显示。
- 开发插件更快了：从文件夹加载的插件（设置 › 扩展 › 插件 › 加载插件文件夹…）在你保存修改后会自动重新加载，其页面会列出最近出现的错误。
- 插件 `engines` 范围中指定测试版时，如 `>=1.3.0-beta.1`，会与包括测试版号在内的完整版本号进行比较。

### 修复

- 官方插件支持 Textus 的全部十种语言——繁体中文不再显示为简体，其他语言也不再显示为英文。
- 官方插件更加稳定：任务插件能列出使用 Windows 换行符的文件中的任务；版本历史能保留位于深层或非拉丁字符文件夹中的文档版本，并在存储空间满时腾出空间；新建的看板不会再覆盖另一个仅大小写不同的同名看板；网页视图会打开所选链接本身的地址；快速笔记会保留按下按钮前最后输入的文字；图谱视图不再显示上次保存之前的图谱；每日笔记不会覆盖当天已有的笔记；PDF 查看器能显示 PDF 未内嵌字体的中文、日文和韩文文字；图片查看器在文件无法打开时会给出提示，不再显示空白标签页。
- 在审阅模式中，让 Textus AI 标出难词或所有不够有力的句子时，会全部标出，而不只是第一个。

### 平台说明

- **Windows 和 Linux：** 设置 › 编辑与外观 › 显示菜单栏 会把文件、编辑、视图等菜单放在标题栏上，不再收在 ☰ 后面——默认关闭。

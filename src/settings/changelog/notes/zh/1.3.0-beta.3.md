## 更新内容

Textus 1.3.0-beta.3 让分屏后的每个窗格都有自己的标签页，打开文件统一为一条规则，插件商店里每个插件都有自己的页面，新增只读文档，并修复了大量编辑问题。测试版可能还有不完善之处，欢迎在 GitHub 或 Discord 告诉我们。

### 新增

- 在 Mac 上，**设置 › 编辑与外观 › 导出 PDF 时使用浅色** 可以在深色模式下写作的同时，用主题的浅色导出白底 PDF。Windows 和 Linux 本来就以白底打印。
- **设置 › 编辑与外观 › 独占一行的图片** 可以改为靠左，不再居中，编辑器和 HTML、PDF 导出中都生效。Markdown 文件本身不会改动。(#367)
- 所有桌面平台上，标签页的右键菜单都有 **移到新窗口**。
- 在 Windows 上，把标签页拖出窗口即可让它独占一个窗口，拖到另一个窗口的标签栏上则移到那个窗口，和 Mac 上一样。
- 在 Linux 上，把标签页拖到窗口外松开，即可在新窗口中打开。
- textus.catvinci.com/playground/ 上的网页版编辑器可以在浏览器里保存多篇文档：点栏上的文档名即可切换、新建和删除。**打开…** 可以打开电脑上的 Markdown 文件，**保存**（`Ctrl/⌘ + S`）会写回该文件。浏览器不支持写回时，保存会询问保存位置或直接下载文件。
- 编辑 › 粘贴为纯文本（Cmd/Ctrl+Shift+V）按原样粘贴剪贴板里的文字，不解析其中的 Markdown。
- 鼠标中键点击可以关闭标签页；标签页菜单新增关闭其他标签页、关闭左侧标签页和关闭右侧标签页。有未保存修改的标签页不会被关闭。
- 大纲的菜单（右键打开）新增全部展开和全部折叠；按住 Option（Alt）点击标题旁的箭头，可一次折叠或展开所有标题。
- 视图 › 只读，或标签页菜单里的只读，可以防止文档被修改：输入、粘贴、拖放、撤销、AI 修改和插件都无法改动。标题旁的小锁图标表示只读状态，点击即可关闭。保持只读的文件再次打开时仍是只读。
- 文件 › 重新打开关闭的标签页（Cmd/Ctrl+Shift+T）按从近到远的顺序找回在该窗口中关闭的文档。

### 改进

- 编辑器的右键菜单更短了。你点击的内容相关的项排在最前：在表格里，先是在下方插入行、在右侧插入列，其余操作在 **行 ›** 和 **列 ›** 中。**插入 ›** 和 **Textus AI ›** 在菜单旁展开。全选和查找留在编辑菜单和对应的快捷键里。
- 像 VS Code 一样，分屏后的每个窗格都有自己的标签页。打开的文档进入当前所在的窗格，拖到另一个窗格的标签页会移过去，窗格的标签页在各自的标签栏里排序。关闭窗格的最后一个标签页即结束分屏。
- 代码块的语言、**复制** 和新增的 **全选** 按钮一起放在右上角。
- 代码块的语言改用应用自己的菜单选择，可以输入文字搜索，不再使用系统菜单。
- 使用 Claude 账号登录标为实验性功能：这并不是 Anthropic 向其他应用开放的登录方式。使用 API 密钥更可靠。
- 复制时，剪贴板的纯文本中放入 Markdown 源码，因此粘贴到 GitHub、Obsidian、VS Code、聊天应用和 AI 对话中能以 Markdown 保留格式，而 Word、Pages、邮件和 Notion 仍粘贴为带格式的内容。在代码块内复制的代码只包含代码本身。编辑 › 复制为纯文本只复制文字、不带标记，适用于微信等应用。
- **获取更多** 像应用商店一样列出插件：每个都有图标、功能介绍、作者和安装人数，默认按安装数排序（也可以按最新或名称排序）。
- 安装前，插件会先打开自己的页面，展示截图、README 和它将申请的权限。安装后，在设置中的插件页面可以查看 README。
- 安装插件不再打开使用指南并关闭设置：**安装** 原地变为 **已安装**，可以连续安装多个插件。
- 获取更多中不再有插件合集，改为安装最多的插件排在最前。
- 已安装插件上方新增搜索框，可按名称、描述或作者查找。列表中的“自己制作”已移除：如需插件，请在创造模式下让 Textus AI 来做。
- 插件可以删除字符而不复制它们（`deleteChars` 配合 `copy: false`），因此 `inoremap jj <Esc>` 这样的 Vim 映射不再在剪贴板里留下一个“j”。
- 标签页快捷键与浏览器一致：Cmd/Ctrl+T 在当前窗口新建标签页，不受设置中文件打开方式的影响；Cmd/Ctrl+N 新建窗口（原为 Cmd/Ctrl+Shift+N）。文件 › 新建文件现改为新建标签页。
- 插件可以打开命令面板，把自己的命令排在最前，并取回输入的内容（`textus.ui.pick` 配合 `commands`），因此 Vim 的 `:` 会打开命令面板。
- Vim 的 flash 跳转在输入一个字母后就标出位置，不再需要两个。
- 获取更多中的插件更新：PDF 查看器围绕指针平滑缩放，Zotero 支持 Zotero 10，图谱视图新增简洁的筛选和颜色分组面板。
- 在 Mac 上，当插件把每个按键都当作命令时（如 Vim 的普通模式），窗口改用英文键盘输入，拼音等输入法不会截获按键；回到输入文字时，恢复你自己的输入法。
- Vim 的块状光标从一开始就显示，之后打开的标签页中也是如此，不再要等第一次切换模式后才出现。
- [[Wikilinks]] 像在 Obsidian 中一样显示为笔记名，光标停在上面时才显示方括号。`[[Note|text]]` 显示其中的文字。
- 使用了 [[wikilinks]] 的文档会推荐一次反向链接插件，在提示中即可安装。
- Textus 现在自带四个技能：校对、设计主题、制作插件和制作技能。扩写、精简、翻译、总结和连贯性检查在 设置 › 扩展 › Skill › 获取更多 中；原先有这些技能的配置会从那里自动安装一次。
- 在窗口中打开文件遵循同一条规则：已打开的文件会切换到前面，未改动的空白文档会让出位置，其余情况都在新的标签页中打开。点击侧边栏或 文件 > 打开… 不再替换你正在阅读的文档。“打开文档方式”设置现在只决定从 Textus 外部打开的文件放在哪里。

### 修复

- 在 Windows 和 Linux 上，设置和其他菜单命令在你使用它们的窗口中打开，不再总是出现在第一个打开的窗口里。
- 在 Windows 上，在文档中输入时按 **Ctrl+,** 也能打开设置。
- 插件添加到侧边栏文件右键菜单、标签页右键菜单或侧边栏视图顶部的菜单项现在都能显示。之前只有编辑器自身的菜单会显示它们。
- 窗口栏显示“1 word”而不是“1 words”。
- 侧边栏中插件列表的筛选框（如任务插件的）只有一行高，不再沿侧边栏向下拉伸。
- 在以 [[wikilink]] 结尾的行末点击，光标会落在链接之后：接下来输入的内容和回车不再进入链接里。
- 侧边栏顶部一行、每个窗格的标签栏和 AI 面板的标题栏底部对齐；标签页过多放不下时，下方不再出现滚动条。
- 只读关闭时，标签页右键菜单中只读前面不再留出空隙。
- 网页加载失败时，标签页中会说明，并提供重新载入和在浏览器中打开，不再一片空白。
- 网页不可见超过五分钟会被释放，最多同时保留三个已加载的网页：每个网页都占用一个独立的 WebKit 进程。重新显示时，会加载它最后的地址。
- Mac 上的网页以 Safari 的身份标识自己，哔哩哔哩等网站不再把它当作旧浏览器拒之门外。
- 插件的页面改为通过 URL 加载文件，不再内联：一个绘制 PlantUML 代码块的窗口原先占用近 3 GB 内存，现在不到 200 MB。图表、PDF 和 Word 文档打开时占用的内存也少得多。
- 设置 › 扩展 › Skill 中你自己的技能与内置技能显示方式一致，名称在上，命令和描述在下，写作、审阅和创造改为小开关，不再是一排复选框。
- **导出以发布…** 在重命名插件 id 的同时也重命名插件自己的命令和视图，导出的插件可以在 Textus 中加载。之前它们保留旧名称，Textus 会拒绝加载该插件。
- 文档放大或缩小时，代码块的行号与对应的行保持对齐。
- 粘贴的代码保留原有的行：带中文注释或长行的代码不再有部分行被连在一起。
- 选好代码块的语言后立即应用新的高亮颜色，不再等到下一次编辑。
- 在代码块中输入时不再弹出 AI 补全。
- 语法检查不再检查代码：代码块不做检查，行内代码也不再让周围的文字出现建议。
- 在引用中后面一行的开头按 Backspace，会把它并入上一行，不再把它移出引用、把引用拆成两段。
- 在代码块、公式块或表格开头按 Backspace，或在它们前面按 Delete，光标会移入其中，不再把整个块当作纯文本倒进旁边的行，也不再选中整个表格导致下一个按键把它替换掉。front matter 下方的一行不再并入 front matter，两个代码块之间的空行也可以删除了。
- 选区从普通文本开始、在代码块中结束（或反过来）时，输入覆盖或删除选区都会保留代码块，不再把它剩下的行变成段落。
- 在引用或列表前一行的末尾按 Delete，会像 Backspace 一样合并文字，不再把引用或列表的第一行移出来；在提示框前则移入提示框的文字中，保留提示框。
- 在列表中的代码块或公式块末尾按回车，会在块中新增一行，不再开始新的列表项。
- 在只有缩进的代码行上按回车会留在块内：该行保持空白，缩进延续下去，因此缩进代码（如 Python 函数）中的空行不再结束代码块。在空行上按回车，或在任何位置按 Cmd/Ctrl+Enter，仍会离开代码块。
- 粘贴的引用、代码块或公式块无论落在哪里都保持原样：以列表开头的引用（`> - item`）不再只粘贴出列表；粘贴到空列表项或一行文字中的代码不再被压成那一行，该行的其余部分也不会混进代码里。
- 在新行上粘贴的表格占据该行，不再在上方留下空行；粘贴到表格的单元格中时，从该单元格开始依次填入，超出边界时自动添加行和列，不再把表格拆成两半。
- 在列表项的行上输入三个反引号或 `$$` 后按回车，会在该项中开始代码块或公式块，不再把围栏留作文字并开始新的列表项。
- macOS：在代码块第一行按 Cmd+Backspace 会删除到行首，不再毫无反应并吞掉之后输入的按键。
- 光标停在 AI 建议上时，即使在引用或代码块中，Cmd/Ctrl+Enter 和 Cmd/Ctrl+Backspace 也能采纳或拒绝建议，不再被编辑器自身对这些键的用法抢先。
- 右键菜单中的粘贴与 Cmd/Ctrl+V 效果一致：支持图片、其他应用的带格式文本、保留的换行和表格单元格，以前只能粘贴文字。在 macOS 上，不再需要再点一次“粘贴”按钮。
- 紧接在链接后按 Backspace，或紧挨在链接前按 Delete，会像对待粗体或代码一样删除其 Markdown 源码中的一个字符，不再一次删掉整个链接及其文字和地址。wikilink、嵌入和行内 HTML 同样如此。
- 输入 `---` 或 `___` 后按回车会生成分隔线，光标位于其下一行，与 `***` 一致，不再多留一个空行；`---` 后面还有其他文字时仍保留为文字。
- 拖到 PDF 或其他插件视图上的文件或标签页可以在那里放下，并像拖到文档上一样分割窗口。

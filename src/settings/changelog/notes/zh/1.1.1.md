## 更新内容

Textus 1.1.1 打磨了 Textus AI 修订的显示效果，并修复了输入链接和图片、粗体后的光标位置，以及在空窗口中使用“最近打开”的问题。

### 改进

- 鼠标指向的修订，或在审阅条中跳转到的修订，会像审阅批注一样加深颜色：正文和页边卡片中，新文字显示为更深的绿色，原文显示为更深的红色，不再加外框。(#207)
- 无法加载的图片会显示为一张卡片，列出文件名和原因（该路径下没有文件、无法连接网络主机、Textus 无法显示的文件），悬停时显示完整路径，并提供 **重新选择图片…** 以指向其他文件，以及 **在文件夹中显示**，不再显示浏览器的破图图标。Obsidian `![[...]]` 嵌入也使用同样的卡片。(#212)
- 图片的右键菜单在宽度选项旁新增 **在文件夹中显示** 和 **复制图片路径**：前者在访达、资源管理器或文件管理器中打开并选中该图片，后者复制其完整路径，网络图片则复制其地址。Obsidian `![[...]]` 嵌入同样支持这两项，文件会在仓库中查找。(#224)
- 图片宽度以 HTML 保存为 `<img src="…" width="50%">`，GitHub、Typora、Obsidian 和 VS Code 都会按该尺寸显示；不再在标题中写入 `{textus-width=50%}` 标注，其他应用会忽略它并把它显示为提示文字。**图片宽度：自动** 会重新保存为 `![]()`。带宽度的 `<img>`（来自 Typora 或其他地方）现在会作为图片打开，并带有宽度菜单；旧版本保存的文件会按其宽度打开，并在你修改之前保持原样。(#227)

### 修复

- **设置 › 编辑与外观 › 正文宽度** 为 **自适应** 时，窗口宽度从约 1100px（原为 1214px）起正文就随之变宽，因此在 1280–1440px 的窗口上会比标准宽度更宽而不是更窄；在较小窗口中与侧边栏或 AI 面板并排时，宽度保持不变，修订的页边视图也仍在原来可用的情况下可用。(#211)
- 当前窗口是新建的空窗口时，从 **文件 › 最近打开** 中选择的文件会在当前窗口中打开，不再在旁边另开一个窗口。(#201)
- 删除粗体或斜体后面的文字时，光标保持在收尾的 `**` 或 `*` 之后，接下来输入的文字不再变成粗体或斜体。(#199)
- 输入收尾的 `)` 时，`![alt](url)` 会变成图片，就像 `[text](url)` 已经会变成链接一样，不再保持为文字，保存时被加上反斜杠而不再显示为图片。(#189)
- 为没有标题的图片设置宽度后，再从右键菜单或手机键盘工具栏中选择 **图片宽度：自动**，会恢复为自动宽度；此前该选项不起作用。(#223)
- 在 **打字机模式** 下用鼠标点击、拖动或轻点时，页面保持不动，点击会把光标放在点击处，拖动会选中经过的内容，不再页面跳动、光标或选区落到别处；按下一个键时，仍会像以前一样把当前行居中。(#217)
- 用 LaTeX 的 `\(...\)` 和 `\[...\]` 写的公式保存时保持原样，不再在打开文件时改写为 `$...$`；单独成行的 `\[...\]` 显示为行间公式而非行内公式；`\[1\]` 这样的引用以及代码中的内容保持不变。Textus AI 回复中和粘贴进来的公式仍会转换为 `$...$`。(#228)
- 保存或从代码块菜单中选择其他语言时，保留代码块首行语言之后的其余内容，例如 `js` 后面的 `title="a.js"`，不再丢弃。(#228)
- `> [!note]`、`> [!Tip]` 以及 Obsidian 的可折叠写法 `> [!tip]-` 和 `> [!tip]+` 都显示为提示框，并按原样保存，不再保存为 `> \[!note]`；Obsidian 的其他提示框类型（如 `> [!question]`）也会按原样保存。(#228)
- 输入的网址或邮箱地址，如 `https://x.org`、`www.x.org` 或 `a@b.com`，保存时不再加反斜杠，因此在 GitHub 等地方仍是链接，而不是 `https\://x.org`。(#228)
- 单波浪线 `~x~`（Pandoc 的下标写法，如 `H~2~O`）保存时保持单个波浪线，不再变成 `~~x~~` 删除线。(#228)
- 用 `$$x$$` 写的行内公式保存时保持两个美元符号，不再变成 `$x$`。(#228)

### 平台说明

- **macOS：** 可通过 Homebrew 官方 cask 用 `brew install --cask textus` 安装；从 `catvinci-studio/tap` tap 安装的 Textus 会在下次 `brew update` 时迁移过去。
- **Windows：** 安装程序的侧边图和页眉图换成了 Textus 的羽毛笔和名称，此前仍显示旧的 Levis 图片。

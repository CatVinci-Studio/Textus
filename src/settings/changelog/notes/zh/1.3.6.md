## 更新内容

Textus 1.3.6 让插件可以在你的写作区域上方悬浮一个小视图（首先是桌宠：Moyu 或你所用模型的 LLM-chan 陪着你），可以在 HTML 表格显示的位置直接编辑文字，像 GitHub 一样显示 README，标题栏也可以变成毛玻璃。

### 新增

- **Desk Pet**（桌宠）插件，可在 设置 › 扩展 中获取：Textus 的吉祥物 Moyu，或 Textus AI 当前所用模型的 LLM-chan，待在窗口一角或你的桌面上。你打字时她写字，停下时她打盹，保存时她欢呼，戳她或摸摸她都会回应，并且始终面朝中间；右键点击她可以切换角色。
- 插件可以显示悬浮视图：一个小小的透明页面，悬浮在桌面上、所有窗口上方或 Textus 窗口内，比如桌宠、计时器。它最初出现在窗口内；可以拖到任何地方，从顶角调整大小，右键点击可以放到桌面上、收成一个圆点或关闭；在桌面上时，它的菜单还能打开 Textus 或 Textus AI。再次打开时，它会出现在你上次放的位置。插件还能得知你戳了、摸了或移动了它的视图，你在打字或保存，以及 Textus AI 正在做什么、用的是哪个模型，但绝不会得到你文档或对话中的任何文字。插件可以在视图的右键菜单中添加自己的菜单项（`menus` `floating/context`），比如切换桌宠的角色。详见插件参考中的 `contributes.floatingViews`、`layout.openFloating`、`app.onDidActivity` 和 `ai.onDidChangeState`。
- HTML 表格或块中的文字可以在显示的位置直接编辑：点击单元格或某一行后输入，按 Enter（或点击别处）会把新文字写回源码中原来的标签之间；按 Escape 则恢复原样。和以前一样，Option 加点击会显示源码。
- 标题栏可以像 macOS 工具栏一样变成毛玻璃，在 **设置 › 编辑与外观 › 主题** 中开启：文档滚动到标题栏下方时透出颜色和形状，顶部最模糊，越往边缘越清晰，玻璃结束处没有分界线。

### 改进

- README 的显示效果与 GitHub 一致：`<div align="center">`、`<p align>` 或 `<center>` 中的 Markdown 会按对齐方式显示，标签所在的行在光标移到上面之前都会隐藏；包含浅色和深色两个 logo 的 `<picture>` 会跟随 Textus 的主题；定义列表、带说明文字的图片、`<abbr>`、`<q>`、`<ruby>`、`<kbd>` 之类的标签，以及 GitHub 允许的其他小型行内标签都能正常显示。
- 桌面版启动稍快：手机版专用的部分不再随每个窗口一起加载。

### 修复

- AI 面板打开和关闭时，文档标题随面板平滑移动，而不是一下子跳到页面的新中心。
- 一排 README 徽章无论是否带链接都能对齐，缩放按钮和调整大小的手柄也不再挡住徽章上的文字。

## 更新内容

Textus 1.3.0-beta.2 把双文档并排内置进 Textus，新增命令面板，并推出插件 API 1.0：可以在代码块中绘制图表和图片、在文字上做标记，首批图表与写作插件也基于它构建。测试版可能仍有不完善之处，欢迎在 GitHub 或 Discord 告诉我们。

### 新增

- 内置双文档同屏：使用 **视图 › 向右分屏**（`Ctrl/⌘ + Alt + S`）或 **向下分屏**，在标签页右键菜单中选择 **在旁边打开**，或者像 VS Code 那样把标签页（或侧边栏中的文件）拖到编辑器边缘松开。把标签页拖出窗口，它会获得独立窗口。右键分隔线可以旋转、交换或均分窗格；重新打开窗口时分屏依旧保留。
- **视图 › 命令面板…**（`Ctrl/⌘ + Shift + P`）：菜单里的所有操作和插件添加的每条命令，输入即可找到。
- 文档中的图表：在 **设置 › 扩展 › 获取更多** 中安装新的图表插件，包括由大纲生成的思维导图（markmap）、ECharts、PlantUML（在本机绘制，也可选择由 plantuml.com 绘制）、Chart.js、时间线、ABC 记谱法乐谱、WaveDrom 时序图和函数图像。用插件对应的语言写一个代码块，图表就会画在下方；在语言名后加 `height=400` 可设置高度。
- 写作工具插件：Markdown Lint 为违反常见规范的 Markdown 加下划线，并可一键修正；CJK Spacing 通过命令或在每次保存时，在中文或日文与拉丁字母之间加空格；Heading Numbers 在写作时为标题编号，导出时同样生效；Templates 为新文档和片段填充内容；Bookmarks 在侧边栏中保存需要回看的段落。
- **获取更多 › 插件** 中新增合集：写作、图表和研究合集可一次安装搭配使用的插件。
- **设置 › 扩展 › 插件** 中新增 **自己制作**：描述插件要做什么，Textus AI 的创作模式就会把它写出来。
- 脚本：单个 `.js` 文件即可成为插件，名称和权限写在顶部注释中；放进 **安装插件 › 打开脚本文件夹** 打开的文件夹即可。
- 插件的命令显示在 **设置 › 快捷键** 的「插件」分组下，可以为它们设置自己的快捷键或清除。
- `textus://command/<command>` 链接经你同意后，可以从其他应用或网页运行命令。
- 对自己制作的插件使用 **导出以发布**，会以你的名义把它整理成独立仓库，包含 README、许可证和发布工作流。
- 面向插件作者，插件 API 升级为 1.0：`docs/dev/textus.d.ts` 是它的全部内容，`docs/dev/plugin-reference.md` 由它生成。
- 插件 API 新增：`views.registerCodeBlock`（在你的语言的代码块下显示页面，围栏上的文字作为 `block.meta`，通过页面的 `onExport` 为导出提供图片）、`editor.registerDecorations`（高亮、下划线、文字前后的徽标）、`files.onWillSave`、`export.onWillExport`（为 HTML 或 PDF 导出提供 CSS 或 HTML）、`ctx.storage.document(path)`（插件为单个文档保存的数据，文档重命名时随之迁移）、用于 `textus://<plugin>/` 链接的 `uri.registerHandler`，以及用于 `/` 菜单的 `menus["editor/slash"]`。
- 第三方插件可以上架到获取更多：textus-plugins 中的 LISTING.md 说明了方法，每次上架合并前都会由工作流审核。

### 改进

- 导出会带上插件绘制的内容：代码块中的图表以图片形式导出到 HTML、PDF、Word 和 EPUB；插件无法生成图片的代码块保留源码。
- 插件设置支持颜色、列表和按钮，可以按标题分组，也可以仅在另一项设置开启时显示。
- 在 beta.1 中安装的官方插件会自动升级到新版本，并保留原有权限；分屏插件让位于 Textus 内置的分屏。
- 卸载插件时，它为各个文档保存的数据会移到废纸篓，而不是直接删除。

### 修复

- 插件在文字上绘制的高亮、下划线或徽标不再被复制到导出内容中。

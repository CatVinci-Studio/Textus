## 更新内容

Textus 1.3.0-beta.6 支持把窗口拆分成任意多个窗格，重新打开时每个窗口都会恢复各自的标签页和窗格；新增后退与前进、用 Alt+↑/↓ 移动段落、旋转图片和拼音搜索；可以直接在 Textus 内发送问题报告；整理了设置，并带来 1.2.7 和 1.2.8 的修复。

### 新增

- 同时打开两个以上的文档：向右分屏和向下分屏会再次拆分当前窗格，左右或上下排列，次数不限。把标签页拖到窗格边缘，会在那一侧的新窗格中打开；窗格之间的每条分隔线可调整两侧窗格的大小；重新打开窗口时整个布局都会恢复。把标签页拖到最外侧边缘，会在所有窗格旁打开：在上下两个窗格的右边缘松开，它会从上到下占满右侧。(#432)
- 右键图片可以向左或向右旋转 90 度，或放大查看。旋转角度保存在图片标题中，Markdown 仍保持标准写法。感谢 @jzzzzh。(#458)
- Alt+↑ 和 Alt+↓（Mac 上为 Option）可以把所在的段落或列表项，或选中的所有块，移到相邻块的上方或下方。
- 后退与前进：点击链接、在大纲中点击标题或切换标签页后，Ctrl+-（Windows 和 Linux 上为 Alt+←）返回原来的位置，Ctrl+Shift+-（Alt+→）再前进。鼠标的后退和前进键也有同样效果。
- 文件搜索和命令面板支持用拼音全拼或首字母查找中文名称：输入 `beisong`、`bs` 或 `beis` 都能找到「背诵」。也可以省略重音符号：`cafe` 能找到 café。

### 改进

- 设置 › 通用 的帮助分组中也加入了报告问题，并会在报告中附上你的设置，但不含任何隐私信息：只有开关、数值和选项，绝不包括文件夹、地址、服务器、自定义 CSS 或你写的文字。它会询问报告类型、涉及 Textus 的哪个部分，如果是错误还会询问严重程度；如果你愿意接受进一步询问，可以留下邮箱或微信。**发送** 会直接替你在 GitHub 上提交 issue，无需 GitHub 账号，并告诉你编号；**在 GitHub 提交** 则会打开 GitHub 的表单。你留下的联系方式只发给团队，绝不会出现在公开的 issue 中。
- 源码模式、源码与预览、禅模式和打字机模式成为全局设置：在任一窗口中切换（通过视图菜单、快捷键或设置），所有窗口的所有标签页都会一起切换，之后打开的文档也会使用该模式，下次启动 Textus 时依然保持。
- 设置更加整洁。通用 › 帮助 有五行：欢迎与入门教程（重新开始引导）、使用指南、报告问题、加入社区和关于 Textus（在这里查看更新）。编辑与外观和 Textus AI 把常用设置放在前面，其余收进高级设置；Textus AI 生成图片的设置单独成组。
- 菜单、设置和快捷键中，同一事物只用一个名称：分屏视图现在叫 **源码与预览**，以免与向右分屏和向下分屏混淆；图片上传设置改称 **图床**。
- 在 Mac 上，**Textus › 检查更新…** 会打开关于页面并立即检查。
- 命令面板可以切换外观（浅色、深色或跟随系统）、编辑器主题，以及开启或关闭 Textus AI。
- 获取更多中的主题可以自带深色版本，随外观在浅色和深色之间切换。

### 修复

- 重新打开 Textus 时，每个窗口都会恢复各自的标签页，分屏也会恢复其窗格，而不是把上次会话的每个文档都单独开一个窗口。
- 插件按钮和旁边的菜单箭头重新合为一个按钮，不再是并排的两个形状。
- 在图片和图表查看器中，双指捏合或按住 Ctrl 滚动只缩放图片，不会缩放后面的文档；更深的背景让查看器与页面区分开来。
- 复制的图片粘贴到微信等聊天应用时是图片本身，而不是它的 Markdown 文本。
- 在源码模式和代码中，`fi` 等字母不再连写成一个字形，光标可以停在它们之间。(#438)
- 代码中含有 `<!--` 和 `<script>` 的插件（打包的 Markdown 解析器两者都有）可以再次运行，不会在添加命令之前就停止。
- 使用微软拼音等输入法时，在已以 `*` 结尾的文字前输入 `*`，会像不用输入法时一样变为斜体。
- 在 Windows 上，导出 PDF 时跨页的编号列表会在下一页继续编号，而不是从头开始。
- 插件重命名文件并更新指向它的链接时，行内代码和代码块中的链接示例保持不变。感谢 @Ciao1019。(#457)

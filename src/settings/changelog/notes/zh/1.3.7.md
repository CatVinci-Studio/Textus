## 更新内容

Textus 1.3.7 让拖动选择无论从哪里开始都能正常工作，新增 格式 › 高亮，并在就地编辑表格单元格时保持 `<ruby>` 完整。

### 新增

- 通过 **格式 › 高亮**、右键菜单中的“格式”或 Cmd/Ctrl+Shift+H 高亮文字，与 Typora 一致；再按一次即可取消高亮。(#554)

### 修复

- 拖动选择文字无论从哪里开始都能正常工作：从加粗、高亮或删除线文字、标题、行内 HTML 或双链上开始拖动时，以前常常什么都选不中；从文字旁边的空白页边开始拖动时，以前只会放置光标。点击处的 `**` 或 `#` 会在松开鼠标后才显示，而不是在拖动途中出现在指针下方。(#554)
- 就地编辑 HTML 表格的某个单元格时，不再把另一个单元格中 `<ruby>` 的注音复制到它的基础文字中，按 Escape 也不再丢掉该注音。(#564)

## 更新内容

Textus 1.0.4 带来可调整宽度的侧边栏和 PDF 页码，修复了 Windows 和 Linux 上的 PDF 导出，并缩小了安装包。

### 新增

- 拖动侧边栏的边缘即可调宽或调窄，宽度会被记住。(#77)
- 打开 **设置 › 编辑与外观 › Markdown › 导出时显示页码**（默认关闭）后，导出的 PDF 会带上页码。(#68)
- 新增 **设置 › 通用 › 关于 Textus**，包含版本号、检查更新以及 GitHub 和社区的链接。
- **帮助 › 加入社区** 会以你的语言打开社区页面，包含 Discord 以及中文 QQ 群和微信群。

### 改进

- 安装包更小：Linux 版不到原来的一半。(#115)
- 更新了编辑器的依赖，其中两个有安全公告。

### 修复

- 在 Windows 和 Linux 上，导出的 PDF 使用白色背景和合适的页边距，页面底部也不再丢行。(#68)
- 在 Windows 上按 `Ctrl + P` 会导出 PDF，而不是打印窗口。(#68)
- 在 Linux 上用源码模式编辑时，文字保持清晰。(#61)

### 平台说明

- **Windows：** 可以打开拖到窗口上的文件，**文件 › 打开…** 也可以选择任意文件。(#78)

## 编辑器

- 加粗、斜体、删除线、高亮、行内代码和公式现在是真正的节点，并像 Typora 一样显示分隔符：方向键一次跨过一个阶段，Backspace/Delete 编辑分隔符本身，重新输入删掉的分隔符会恢复节点。
- 修复了 WKWebView 特有的光标问题：离开带样式的文字后光标画在行首，以及快速按或按住方向键时跨越边界出错。
- ` ``` `（可带语言）加 Enter 创建代码块；`$$` 加 Enter 创建公式块，它像普通的围栏代码块一样编辑，源码单独占一行。
- 右键菜单中的复制、剪切和粘贴支持 Markdown：复制时保留语法，粘贴 Markdown 时渲染它。
- 右键点击不再移动光标，也不再自动选中指针下的单词（这是 macOS WebKit 的行为，现在会在显示之前撤销）。

## AI

- 新增 **询问 AI** 行内对话（通过右键菜单或快捷键）：回答关于文档的问题，每条回复都提供需确认的应用操作：替换选中内容、在光标处插入或替换整篇文档。在你点击之前不会改动文档，每次应用都可以撤销。
- 智能体现在可以 **提出修改**：引用原文和替换内容，以差异卡片显示，并附带“应用”按钮。
- 段落中含有带样式的文字时，语法检查的下划线现在位置正确；补全的长度和上下文有了明确上限。
- 每个 AI 功能（补全、语法检查、询问 AI）在设置中都有各自的开关，控制对应的菜单项和快捷键。

## 界面

- 弹出窗口（对话、语法修正、公式预览）不会超出窗口范围。
- 设置简化：通用部分只保留语言，导入主题 CSS 只需一步。

## 更新内容

Textus 1.2.4 让代码块、编辑按键和复制粘贴的表现符合预期，并为标签页配上与浏览器相同的快捷键。

### 新增

- 编辑 › 粘贴为纯文本（Cmd/Ctrl+Shift+V）按原样粘贴剪贴板中的文字，不解析其中的 Markdown。
- 文件 › 重新打开关闭的标签页（Cmd/Ctrl+Shift+T）恢复本窗口中关闭的文档，最近关闭的最先恢复。

### 改进

- 代码块的语言、**复制** 和新增的 **全选** 按钮一起放在右上角。语言从应用自带的菜单中选择，可以输入文字搜索，不再使用系统菜单。
- 使用 Claude 账号登录被标为实验性功能：这并不是 Anthropic 向其他应用提供的登录方式。API 密钥才是可靠的方式。
- 复制时，剪贴板的纯文本中放的是 Markdown 源码，因此 GitHub、Obsidian、VS Code、聊天应用和 AI 对话拿到的是 Markdown 格式，而 Word、Pages、邮件和 Notion 粘贴时仍带格式。从代码块内部复制的代码只包含代码本身。编辑 › 复制为纯文本 则只复制文字、不带标记，适合微信等应用。
- 标签页快捷键与浏览器一致：Cmd/Ctrl+T 在本窗口中新建标签页，无论设置中文件以何种方式打开；Cmd/Ctrl+N 新建窗口（原为 Cmd/Ctrl+Shift+N）。文件 › 新建文件 现改为 新建标签页。

### 修复

- 文档放大或缩小时，代码块的行号始终在对应行旁边。
- 粘贴的代码保留分行：带中文注释或长行的代码不再有几行挤在一起。
- 选择代码块的语言后立即应用新的配色，不再要等下一次编辑。
- 在代码块中输入时不再弹出 AI 补全。
- 语法检查不再碰代码：不检查代码块，行内代码也不再让周围的文字出现建议。
- 在引用中后面某一行的开头按 Backspace，会把它并入上一行，不再把它移出引用、把引用一分为二。
- 在代码块、数学块或表格开头按 Backspace，或在它们紧前方按 Delete，会把光标移进去，不再把整个块当作纯文本倒进旁边那一行，也不再选中整个表格导致下一次按键替换掉它。前置元数据下方的一行不再并入前置元数据，两个代码块之间的空行也可以删除了。
- 选区从普通文字开始、在代码块中结束（或反过来）时，输入覆盖或删除选区会保留代码块，不再把其余的代码行变成段落。
- 在引用或列表前一行的末尾按 Delete，会像 Backspace 一样把文字合并，不再把引用或列表的第一行移出来；在提示框前则移到提示框的文字中，并保留提示框。
- 在列表中的代码块或数学块末尾按 Enter，会在块中添加一行，不再新建列表项。
- 在只有缩进的代码行上按 Enter 会留在代码块中：该行留空，缩进延续，因此缩进代码（如 Python 函数）中的空行不再结束代码块。在空行上按 Enter，或在任意位置按 Cmd/Ctrl+Enter，仍会离开代码块。
- 粘贴的引用、代码块或数学块无论落在哪里都保持原样：以列表开头的引用（`> - item`）不再变成单纯的列表；粘贴到空列表项或一行文字中的代码不再被压成那一行；该行其余文字也不会被卷进代码里。
- 在新行上粘贴的表格占用这一行，不再在上方留下空行；粘贴到表格单元格中时，从该单元格开始填充表格，超出边缘时增加行和列，不再把表格断成两半。
- 在列表项所在行输入三个反引号或 `$$` 后按 Enter，会在该项中开始代码块或数学块，不再把围栏留作文字并新建列表项。
- macOS：在代码块第一行按 Cmd+Backspace 会删除到行首，不再毫无反应并吞掉接下来输入的按键。
- 光标在 AI 建议上时，即使在引用或代码块中，Cmd/Ctrl+Enter 和 Cmd/Ctrl+Backspace 也能采纳或拒绝建议，不再被编辑器对这些按键的原有用法抢先。
- 右键菜单中的粘贴与 Cmd/Ctrl+V 效果相同：支持图片、来自其他应用的带格式文字、保留的换行和表格单元格，此前只能粘贴文字。在 macOS 上不再需要再点一次“粘贴”按钮。
- 紧跟在链接后按 Backspace，或紧挨在链接前按 Delete，会像粗体或代码一样删除其 Markdown 源码中的一个字符，不再一下子删掉整个链接及其文字和地址。Wiki 链接、嵌入和内联 HTML 也一样。
- 在单独一行输入三个反引号后，输入语言期间它们显示为纯文本，中间那个不再看起来像行内代码。
- 文档以代码块开头或结尾时，全选会高亮整篇文档；此前其实已全部选中，只是没有显示出来。代码块的按钮也不再随文字一起被选中。
- `---` 或 `___` 加 Enter 会生成分隔线，并把光标放在它下面一行，与 `***` 一致，不再多留一个空行；`---` 后面还有其他文字时仍保持为文字。

## 更新內容

Textus 1.3.0-beta.3 讓分割後的每個窗格都有自己的標籤頁，開啟檔案統一為一條規則，外掛商店裡每個外掛都有自己的頁面，新增唯讀文件，並修復了大量編輯問題。測試版可能還有不完善之處，歡迎在 GitHub 或 Discord 告訴我們。

### 新增

- 在 Mac 上，**設定 › 編輯與外觀 › 匯出 PDF 時使用淺色** 可以在深色模式下寫作的同時，用主題的淺色匯出白底 PDF。Windows 和 Linux 本來就以白底列印。
- **設定 › 編輯與外觀 › 獨佔一行的圖片** 可以改為靠左，不再居中，編輯器和 HTML、PDF 匯出中都生效。Markdown 檔案本身不會改動。(#367)
- 所有桌面平台上，標籤頁的右鍵選單都有 **移到新視窗**。
- 在 Windows 上，把標籤頁拖出視窗即可讓它獨佔一個視窗，拖到另一個視窗的標籤欄上則移到那個視窗，和 Mac 上一樣。
- 在 Linux 上，把標籤頁拖到視窗外鬆開，即可在新視窗中開啟。
- textus.catvinci.com/playground/ 上的網頁版編輯器可以在瀏覽器裡儲存多篇文件：點欄上的文件名即可切換、新建和刪除。**開啟…** 可以開啟電腦上的 Markdown 檔案，**儲存**（`Ctrl/⌘ + S`）會寫回該檔案。瀏覽器不支援寫回時，儲存會詢問儲存位置或直接下載檔案。
- 編輯 › 貼上為純文字（Cmd/Ctrl+Shift+V）按原樣貼上剪貼簿裡的文字，不解析其中的 Markdown。
- 滑鼠中鍵點選可以關閉標籤頁；標籤頁選單新增關閉其他標籤頁、關閉左側標籤頁和關閉右側標籤頁。有未儲存修改的標籤頁不會被關閉。
- 大綱的選單（右鍵開啟）新增全部展開和全部摺疊；按住 Option（Alt）點選標題旁的箭頭，可一次摺疊或展開所有標題。
- 檢視 › 唯讀，或標籤頁選單裡的唯讀，可以防止文件被修改：輸入、貼上、拖放、撤銷、AI 修改和外掛都無法改動。標題旁的小鎖圖示表示唯讀狀態，點選即可關閉。保持唯讀的檔案再次開啟時仍是唯讀。
- 檔案 › 重新開啟關閉的標籤頁（Cmd/Ctrl+Shift+T）按從近到遠的順序找回在該視窗中關閉的文件。

### 改進

- 編輯器的右鍵選單更短了。你點選的內容相關的項排在最前：在表格裡，先是在下方插入行、在右側插入列，其餘操作在 **行 ›** 和 **列 ›** 中。**插入 ›** 和 **Textus AI ›** 在選單旁展開。全選和查詢留在編輯選單和對應的快捷鍵裡。
- 像 VS Code 一樣，分割後的每個窗格都有自己的標籤頁。開啟的文件進入當前所在的窗格，拖到另一個窗格的標籤頁會移過去，窗格的標籤頁在各自的標籤欄裡排序。關閉窗格的最後一個標籤頁即結束分割。
- 程式碼塊的語言、**複製** 和新增的 **全選** 按鈕一起放在右上角。
- 程式碼塊的語言改用應用自己的選單選擇，可以輸入文字搜尋，不再使用系統選單。
- 使用 Claude 賬號登入標為實驗性功能：這並不是 Anthropic 向其他應用開放的登入方式。使用 API 金鑰更可靠。
- 複製時，剪貼簿的純文字中放入 Markdown 原始碼，因此貼上到 GitHub、Obsidian、VS Code、聊天應用和 AI 對話中能以 Markdown 保留格式，而 Word、Pages、郵件和 Notion 仍貼上為帶格式的內容。在程式碼塊內複製的程式碼只包含程式碼本身。編輯 › 複製為純文字只複製文字、不帶標記，適用於微信等應用。
- **獲取更多** 像應用商店一樣列出外掛：每個都有圖示、功能介紹、作者和安裝人數，預設按安裝數排序（也可以按最新或名稱排序）。
- 安裝前，外掛會先開啟自己的頁面，展示截圖、README 和它將申請的許可權。安裝後，在設定中的外掛頁面可以檢視 README。
- 安裝外掛不再開啟使用指南並關閉設定：**安裝** 原地變為 **已安裝**，可以連續安裝多個外掛。
- 獲取更多中不再有外掛合集，改為安裝最多的外掛排在最前。
- 已安裝外掛上方新增搜尋框，可按名稱、描述或作者查詢。列表中的“自己製作”已移除：如需外掛，請在創造模式下讓 Textus AI 來做。
- 外掛可以刪除字元而不復制它們（`deleteChars` 配合 `copy: false`），因此 `inoremap jj <Esc>` 這樣的 Vim 對映不再在剪貼簿裡留下一個“j”。
- 標籤頁快捷鍵與瀏覽器一致：Cmd/Ctrl+T 在當前視窗新建標籤頁，不受設定中檔案開啟方式的影響；Cmd/Ctrl+N 新建視窗（原為 Cmd/Ctrl+Shift+N）。檔案 › 新建檔案現改為新建標籤頁。
- 外掛可以開啟命令面板，把自己的命令排在最前，並取回輸入的內容（`textus.ui.pick` 配合 `commands`），因此 Vim 的 `:` 會開啟命令面板。
- Vim 的 flash 跳轉在輸入一個字母后就標出位置，不再需要兩個。
- 獲取更多中的外掛更新：PDF 檢視器圍繞指標平滑縮放，Zotero 支援 Zotero 10，圖譜檢視新增簡潔的篩選和顏色分組面板。
- 在 Mac 上，當外掛把每個按鍵都當作命令時（如 Vim 的普通模式），視窗改用英文鍵盤輸入，拼音等輸入法不會截獲按鍵；回到輸入文字時，恢復你自己的輸入法。
- Vim 的塊狀游標從一開始就顯示，之後開啟的標籤頁中也是如此，不再要等第一次切換模式後才出現。
- [[Wikilinks]] 像在 Obsidian 中一樣顯示為筆記名，游標停在上面時才顯示方括號。`[[Note|text]]` 顯示其中的文字。
- 使用了 [[wikilinks]] 的文件會推薦一次反向連結外掛，在提示中即可安裝。
- Textus 現在自帶四個技能：校對、設計主題、製作外掛和製作技能。擴寫、精簡、翻譯、總結和連貫性檢查在 設定 › 擴充套件 › Skill › 獲取更多 中；原先有這些技能的配置會從那裡自動安裝一次。
- 在視窗中開啟檔案遵循同一條規則：已開啟的檔案會切換到前面，未改動的空白文件會讓出位置，其餘情況都在新的標籤頁中開啟。點選側邊欄或 檔案 > 開啟… 不再替換你正在閱讀的文件。“開啟文件方式”設定現在只決定從 Textus 外部開啟的檔案放在哪裡。

### 修復

- 在 Windows 和 Linux 上，設定和其他選單命令在你使用它們的視窗中開啟，不再總是出現在第一個開啟的視窗裡。
- 在 Windows 上，在文件中輸入時按 **Ctrl+,** 也能開啟設定。
- 外掛新增到側邊欄檔案右鍵選單、標籤頁右鍵選單或側邊欄檢視頂部的選單項現在都能顯示。之前只有編輯器自身的選單會顯示它們。
- 視窗欄顯示“1 word”而不是“1 words”。
- 側邊欄中外掛列表的篩選框（如任務外掛的）只有一行高，不再沿側邊欄向下拉伸。
- 在以 [[wikilink]] 結尾的行末點選，游標會落在連結之後：接下來輸入的內容和回車不再進入連結裡。
- 側邊欄頂部一行、每個窗格的標籤欄和 AI 面板的標題欄底部對齊；標籤頁過多放不下時，下方不再出現捲軸。
- 唯讀關閉時，標籤頁右鍵選單中唯讀前面不再留出空隙。
- 網頁載入失敗時，標籤頁中會說明，並提供重新載入和在瀏覽器中開啟，不再一片空白。
- 網頁不可見超過五分鐘會被釋放，最多同時保留三個已載入的網頁：每個網頁都佔用一個獨立的 WebKit 程序。重新顯示時，會載入它最後的地址。
- Mac 上的網頁以 Safari 的身份標識自己，嗶哩嗶哩等網站不再把它當作舊瀏覽器拒之門外。
- 外掛的頁面改為透過 URL 載入檔案，不再內聯：一個繪製 PlantUML 程式碼塊的視窗原先佔用近 3 GB 記憶體，現在不到 200 MB。圖表、PDF 和 Word 文件開啟時佔用的記憶體也少得多。
- 設定 › 擴充套件 › Skill 中你自己的技能與內建技能顯示方式一致，名稱在上，命令和描述在下，寫作、審閱和創造改為小開關，不再是一排核取方塊。
- **匯出以釋出…** 在重新命名外掛 id 的同時也重新命名外掛自己的命令和檢視，匯出的外掛可以在 Textus 中載入。之前它們保留舊名稱，Textus 會拒絕載入該外掛。
- 文件放大或縮小時，程式碼塊的行號與對應的行保持對齊。
- 貼上的程式碼保留原有的行：帶中文註釋或長行的程式碼不再有部分行被連在一起。
- 選好程式碼塊的語言後立即應用新的高亮顏色，不再等到下一次編輯。
- 在程式碼塊中輸入時不再彈出 AI 補全。
- 語法檢查不再檢查程式碼：程式碼塊不做檢查，行內程式碼也不再讓周圍的文字出現建議。
- 在引用中後面一行的開頭按 Backspace，會把它併入上一行，不再把它移出引用、把引用拆成兩段。
- 在程式碼塊、公式塊或表格開頭按 Backspace，或在它們前面按 Delete，游標會移入其中，不再把整個塊當作純文字倒進旁邊的行，也不再選中整個表格導致下一個按鍵把它替換掉。front matter 下方的一行不再併入 front matter，兩個程式碼塊之間的空行也可以刪除了。
- 選區從普通文字開始、在程式碼塊中結束（或反過來）時，輸入覆蓋或刪除選區都會保留程式碼塊，不再把它剩下的行變成段落。
- 在引用或列表前一行的末尾按 Delete，會像 Backspace 一樣合併文字，不再把引用或列表的第一行移出來；在提示框前則移入提示框的文字中，保留提示框。
- 在列表中的程式碼塊或公式塊末尾按回車，會在塊中新增一行，不再開始新的列表項。
- 在只有縮排的程式碼行上按回車會留在塊內：該行保持空白，縮排延續下去，因此縮排程式碼（如 Python 函式）中的空行不再結束程式碼塊。在空行上按回車，或在任何位置按 Cmd/Ctrl+Enter，仍會離開程式碼塊。
- 貼上的引用、程式碼塊或公式塊無論落在哪裡都保持原樣：以列表開頭的引用（`> - item`）不再只貼上出列表；貼上到空列表項或一行文字中的程式碼不再被壓成那一行，該行的其餘部分也不會混進程式碼裡。
- 在新行上貼上的表格佔據該行，不再在上方留下空行；貼上到表格的單元格中時，從該單元格開始依次填入，超出邊界時自動新增行和列，不再把表格拆成兩半。
- 在列表項的行上輸入三個反引號或 `$$` 後按回車，會在該項中開始程式碼塊或公式塊，不再把圍欄留作文字並開始新的列表項。
- macOS：在程式碼塊第一行按 Cmd+Backspace 會刪除到行首，不再毫無反應併吞掉之後輸入的按鍵。
- 游標停在 AI 建議上時，即使在引用或程式碼塊中，Cmd/Ctrl+Enter 和 Cmd/Ctrl+Backspace 也能採納或拒絕建議，不再被編輯器自身對這些鍵的用法搶先。
- 右鍵選單中的貼上與 Cmd/Ctrl+V 效果一致：支援圖片、其他應用的帶格式文字、保留的換行和表格單元格，以前只能貼上文字。在 macOS 上，不再需要再點一次“貼上”按鈕。
- 緊接在連結後按 Backspace，或緊挨在連結前按 Delete，會像對待粗體或程式碼一樣刪除其 Markdown 原始碼中的一個字元，不再一次刪掉整個連結及其文字和地址。wikilink、嵌入和行內 HTML 同樣如此。
- 輸入 `---` 或 `___` 後按回車會生成分隔線，游標位於其下一行，與 `***` 一致，不再多留一個空行；`---` 後面還有其他文字時仍保留為文字。
- 拖到 PDF 或其他外掛檢視上的檔案或標籤頁可以在那裡放下，並像拖到文件上一樣分割視窗。

## 更新內容

Textus 1.3.7 讓拖動選擇無論從哪裡開始都能正常工作，新增 格式 › 高亮，並在就地編輯表格單元格時保持 `<ruby>` 完整。

### 新增

- 透過 **格式 › 高亮**、右鍵選單中的“格式”或 Cmd/Ctrl+Shift+H 高亮文字，與 Typora 一致；再按一次即可取消高亮。(#554)

### 修復

- 拖動選擇文字無論從哪裡開始都能正常工作：從加粗、高亮或刪除線文字、標題、行內 HTML 或雙鏈上開始拖動時，以前常常什麼都選不中；從文字旁邊的空白頁邊開始拖動時，以前只會放置游標。點選處的 `**` 或 `#` 會在鬆開滑鼠後才顯示，而不是在拖動途中出現在指標下方。(#554)
- 就地編輯 HTML 表格的某個單元格時，不再把另一個單元格中 `<ruby>` 的注音複製到它的基礎文字中，按 Escape 也不再丟掉該注音。(#564)

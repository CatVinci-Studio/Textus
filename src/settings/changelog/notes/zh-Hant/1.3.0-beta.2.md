## 更新內容

Textus 1.3.0-beta.2 把雙文件並排內建進 Textus，新增命令面板，並推出外掛 API 1.0：可以在程式碼塊中繪製圖表和圖片、在文字上做標記，首批圖表與寫作外掛也基於它構建。測試版可能仍有不完善之處，歡迎在 GitHub 或 Discord 告訴我們。

### 新增

- 內建雙文件同屏：使用 **檢視 › 向右分割**（`Ctrl/⌘ + Alt + S`）或 **向下分割**，在標籤頁右鍵選單中選擇 **在旁邊開啟**，或者像 VS Code 那樣把標籤頁（或側邊欄中的檔案）拖到編輯器邊緣鬆開。把標籤頁拖出視窗，它會獲得獨立視窗。右鍵分隔線可以旋轉、交換或均分窗格；重新開啟視窗時分割依舊保留。
- **檢視 › 命令面板…**（`Ctrl/⌘ + Shift + P`）：選單裡的所有操作和外掛新增的每條命令，輸入即可找到。
- 文件中的圖表：在 **設定 › 擴充套件 › 獲取更多** 中安裝新的圖表外掛，包括由大綱生成的思維導圖（markmap）、ECharts、PlantUML（在本機繪製，也可選擇由 plantuml.com 繪製）、Chart.js、時間線、ABC 記譜法樂譜、WaveDrom 時序圖和函式影象。用外掛對應的語言寫一個程式碼塊，圖表就會畫在下方；在語言名後加 `height=400` 可設定高度。
- 寫作工具外掛：Markdown Lint 為違反常見規範的 Markdown 加下劃線，並可一鍵修正；CJK Spacing 透過命令或在每次儲存時，在中文或日文與拉丁字母之間加空格；Heading Numbers 在寫作時為標題編號，匯出時同樣生效；Templates 為新文件和片段填充內容；Bookmarks 在側邊欄中儲存需要回看的段落。
- **獲取更多 › 外掛** 中新增合集：寫作、圖表和研究合集可一次安裝搭配使用的外掛。
- **設定 › 擴充套件 › 外掛** 中新增 **自己製作**：描述外掛要做什麼，Textus AI 的創作模式就會把它寫出來。
- 指令碼：單個 `.js` 檔案即可成為外掛，名稱和許可權寫在頂部註釋中；放進 **安裝外掛 › 開啟指令碼資料夾** 開啟的資料夾即可。
- 外掛的命令顯示在 **設定 › 快捷鍵** 的「外掛」分組下，可以為它們設定自己的快捷鍵或清除。
- `textus://command/<command>` 連結經你同意後，可以從其他應用或網頁執行命令。
- 對自己製作的外掛使用 **匯出以釋出**，會以你的名義把它整理成獨立倉庫，包含 README、許可證和釋出工作流。
- 面向外掛作者，外掛 API 升級為 1.0：`docs/dev/textus.d.ts` 是它的全部內容，`docs/dev/plugin-reference.md` 由它生成。
- 外掛 API 新增：`views.registerCodeBlock`（在你的語言的程式碼塊下顯示頁面，圍欄上的文字作為 `block.meta`，透過頁面的 `onExport` 為匯出提供圖片）、`editor.registerDecorations`（高亮、下劃線、文字前後的徽標）、`files.onWillSave`、`export.onWillExport`（為 HTML 或 PDF 匯出提供 CSS 或 HTML）、`ctx.storage.document(path)`（外掛為單個文件儲存的資料，文件重新命名時隨之遷移）、用於 `textus://<plugin>/` 連結的 `uri.registerHandler`，以及用於 `/` 選單的 `menus["editor/slash"]`。
- 第三方外掛可以上架到獲取更多：textus-plugins 中的 LISTING.md 說明了方法，每次上架合併前都會由工作流稽核。

### 改進

- 匯出會帶上外掛繪製的內容：程式碼塊中的圖表以圖片形式匯出到 HTML、PDF、Word 和 EPUB；外掛無法生成圖片的程式碼塊保留原始碼。
- 外掛設定支援顏色、列表和按鈕，可以按標題分組，也可以僅在另一項設定開啟時顯示。
- 在 beta.1 中安裝的官方外掛會自動升級到新版本，並保留原有許可權；分割外掛讓位於 Textus 內建的分割。
- 解除安裝外掛時，它為各個文件儲存的資料會移到廢紙簍，而不是直接刪除。

### 修復

- 外掛在文字上繪製的高亮、下劃線或徽標不再被複制到匯出內容中。

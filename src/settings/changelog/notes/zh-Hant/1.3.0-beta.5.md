## 更新內容

Textus 1.3.0-beta.5 新增複製路徑、圖片檢視器、幫助 › 報告問題，以及在所有系統上可用的 `textus` 命令；重做了外掛按鈕，用你的語言顯示錯誤資訊，並帶來 1.2.6 的修復。

### 新增

- 檔案選單、標籤頁右鍵選單和檔案樹選單中新增複製路徑，可複製文件的完整路徑，所有系統均可用。
- 點選圖片角落的按鈕或雙擊圖片，即可在圖表所用的可縮放檢視器中開啟：滾動或雙指捏合縮放，拖動移動。(#428)
- 幫助 › 報告問題：描述遇到的問題，Textus 會附上版本、系統、外掛和最近的錯誤，傳送前全部展示給你。提交會開啟已填好的 GitHub 錯誤報告表單；複製會把全部內容放到剪貼簿，方便在聊天或郵件中傳送。(#427)
- `textus` 終端命令現在也支援 Windows 和 Linux AppImage：`textus notes.md` 會在 Textus 中開啟檔案，終端立即回到提示符。設定 › 通用 在所有系統上都會顯示它已安裝。

### 改進

- 每個外掛只有一個按鈕，旁邊帶一個選單，在獲取更多和已安裝外掛中保持一致：安裝；安裝後有更新時顯示更新，否則顯示停用或啟用，解除安裝放在選單中。有更新時直接顯示在按鈕上，返回按鈕也更容易找到。(#431)
- 錯誤資訊現在用你的語言說明發生了什麼：沒有檔案或資料夾的許可權、檔案已不存在、磁碟已滿或唯讀、檔案被其他程式佔用、無網路連線或超時、檔案過大無法開啟、名稱不可用、外掛過大無法安裝，以及 AI 無法生成圖片。系統自帶的資訊如有補充，仍會顯示在下方。

### 修復

- 從訪達、檔案資源管理器或 Linux 檔案管理器拖入的檔案可以再次開啟，此前拖放沒有被識別。拖入資料夾會像開啟資料夾一樣在側邊欄中開啟。(#429)
- 右鍵圖片選擇複製會複製圖片本身，複製的圖片貼上到其他應用時就是圖片，貼上到 Markdown 應用時則帶有其 Markdown。(#428)
- 把標籤頁拖到另一個窗格的標籤欄上（沿標籤欄拖動或先向下拉出）時，會在鬆手的位置加入該窗格；在 Windows 上，從標籤欄拉出的標籤頁不再卡在螢幕上。(#426)
- 新標籤頁和新開啟的文件會保持你上次切換到的檢視（原始碼模式或原始碼與預覽），不再每次都回到富文字編輯器。(#424)
- 寫在粗體或斜體內的 HTML 標籤（如 `**<u>words</u>**`）會顯示其樣式，而不是原始標籤。(#423)
- 獲取更多中顯示每個外掛的圖示，而不是名稱的首字母。(#431)
- AI 服務的餘額或額度用盡時，Textus 會用你的語言如實說明，並告訴你去哪裡充值或切換服務，不再誤報為速率限制。

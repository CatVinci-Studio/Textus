## 更新內容

Textus 1.0.1：修復 1.0.0 釋出後大家反饋的問題。

### 輸入法與列表

- 用中文輸入法在新建的列表或待辦項裡打字，不再多出空項，也不會把拼音拆開；待辦的勾選狀態保持不變。表格單元格里同樣修復。
- 新寫法直接生成待辦：`- 【】`、`-【】`、`- []`、`-[]`，在列表項裡輸入 `【】` 也可以；寫成 `【x】` 或 `[x]` 即為已完成。輸入 `- [ ] ` 時，結尾的空格不會留在待辦開頭。
- 在表格最後一行按回車，新的一行從第一個單元格開始。
- 滑鼠移到表格的列分隔線上時，表格高度不再變化。

### 貼上

- 貼上截圖會儲存到文件旁的 `assets/` 目錄並插入相對路徑，重新開啟文件後圖片仍在（未儲存的新文件會在第一次儲存時一起移過去）。
- 從檔案管理器複製圖片檔案後貼上，插入的是圖片而不是檔案連結。
- 貼上網址生成可點選的連結，儲存為 `[網址](網址)`；文字為空的連結 `[](網址)` 顯示網址本身，儲存時保持原樣。

### 匯出 PDF

- 修復 Linux 上非英文系統匯出 PDF 一直轉圈、無法完成的問題。
- 匯出失敗時顯示錯誤資訊，不再被進度提示擋住。
- Linux 上帶底色的主題匯出 PDF，最後一頁整頁都有底色。

### 標題與原始碼模式

- 五級、六級標題與正文同樣大小，不再比正文小；四級標題略大於正文，六級標題顏色稍淡。
- 原始碼模式的文字與正文同樣大小，編輯時文字保持清晰。

### 其他改進

- 按 Esc 關閉右鍵選單時，灰色的續寫建議保留。
- 新建資料庫條目後，AI 面板停留在“記憶”頁。
- 撤銷已採納的修改後，卡片上的改動數正確顯示增刪兩部分。
- 窄視窗和手機上，批註編號與 AI 對話中的批註卡片一一對應。
- 文件裡的 HTML 註釋顯示為淡色的提示文字，游標移入後可以編輯原文。
- macOS 26：視窗按鈕與標題對齊，空文件不再出現多餘的滾動。
- 滑鼠在表格上滾動時，滾動的是整篇文件。
- 模式選擇框的讀屏名稱改為“模式”。

macOS、Windows 和 Linux 安裝包由釋出流程構建。

## 更新內容

Textus 1.3.0 向外掛開放，並登陸 iPhone 和 iPad。**設定 › 擴充套件** 裡的統一商店彙集了外掛、主題和技能：思維導圖、Vim 和 Emacs 鍵位、Marp 幻燈片、Zotero 引用、筆記關係圖譜、類 Notion 的頁面和資料庫、圖表等等；外掛在 iPhone 和 iPad 上的執行方式與電腦上相同。視窗可以隨意分出任意多個窗格，命令面板讓你輸入文字即可執行一切操作，修訂模式像對待 Textus AI 的修改一樣保留你自己的編輯供審閱，整個應用採用統一的外觀，主題可以為所有介面重新著色。

### 新增

- 在 Textus 內安裝外掛：**設定 › 擴充套件** 先列出你已有的外掛、主題和技能，再列出可以新增的，一個搜尋框就能搜遍全部。每個外掛都有自己的頁面，安裝前可以看到截圖、使用指南和它申請的許可權；一個按鈕即可安裝、更新、關閉或開啟；還有它自己的設定，可以對所有文件生效，也可以只對當前開啟的資料夾生效。解除安裝時，外掛儲存的資料會移到廢紙簍。
- 首批官方外掛：
  - **寫作：** Vim 和 Emacs 鍵位、快速插入（`/` 插入標題、列表、表格、公式、提示框和表情）、範本、Markdown Lint、中英文間距、標題編號、寫作統計、LaTeX 補全、自然語言日期和 WakaTime。
  - **筆記：** 頁面（頁面中巢狀頁面）、資料庫（把資料夾中的文件顯示為表格、看板、日曆或畫廊，支援從 Notion 匯入）、圖譜檢視、反向連結、標籤、任務、書籤、日曆與每日筆記、快速筆記、快速預覽、提醒和版本歷史。
  - **繪圖：** 思維導圖（Markmap）、ECharts、Chart.js、PlantUML、時間線、ABC 記譜法樂譜、WaveDrom 和 Function Plot，繪製在程式碼塊下方，匯出時以圖片形式保留。
  - **閱讀與研究：** Marp 幻燈片、Zotero 引用、連結卡片，以及在標籤頁中開啟的 PDF、Word、圖片和網頁檢視器。
- iPhone 和 iPad：Textus 上架 App Store，是同一個應用，只是佈局更窄——外掛、主題、技能、Textus AI 和修訂都包含在內。文件儲存在“檔案”App 中；按住標籤頁即可拖動或分割。
- 同時開啟兩篇以上的文件：**檢視 › 向右分割**（`Ctrl/⌘ + Alt + S`）和 **向下分割** 可以對當前窗格反覆分割；把標籤頁或檔案拖到邊緣即可在那裡開啟，拖出視窗則獨佔一個新視窗。每個窗格都有自己的標籤頁，每個視窗重新開啟時都會恢復原來的標籤頁和窗格。
- **檢視 › 命令面板…**（`Ctrl/⌘ + Shift + P`）可以查詢並執行選單中的所有操作和每個外掛命令，也支援拼音（輸入 `bs` 能找到“背誦”）。
- 修訂模式，位於檢視選單：你的編輯會顯示為修訂——刪除的內容加刪除線，新增的內容加標記，中文和日文按字標記——可以在審閱條上逐條或全部採納、拒絕，並提供與 Textus AI 的修改相同的三種檢視。檔案中儲存原文和已採納的修改；尚未決定的修訂儲存在旁邊的 `.textus` 資料夾中，再次開啟文件時會恢復。
- 在頁邊寫下自己的批註：選中文字，右鍵 › **新增批註**，批註會出現在文字旁邊，標為“我”，與 Textus AI 的批註並列。
- **檢視 › 唯讀**，或標籤頁選單中的唯讀，可以防止文件被修改；標題旁的小鎖圖示表示唯讀狀態。
- 後退和前進（`Ctrl + -` 和 `Ctrl + Shift + -`，Windows 和 Linux 上為 `Alt + ←/→`，或使用滑鼠側鍵）可以在點選連結、跳轉標題或切換標籤頁後回到原來的位置。
- `Alt/⌥ + ↑/↓` 可以上下移動段落、列表項或選中的塊。
- 右鍵點選圖片可以向左或向右旋轉 90 度，或在可縮放的檢視器中開啟；雙擊圖片也能開啟檢視器。
- **檔案 › 重新開啟關閉的標籤頁**（`Ctrl/⌘ + Shift + T`）、**複製路徑**，以及標籤頁選單中的關閉其他標籤頁、關閉左側標籤頁和關閉右側標籤頁；滑鼠中鍵點選可以關閉標籤頁。
- **幫助 › 報告問題** 可以在 Textus 內直接傳送問題報告，傳送前會展示你的版本、系統和外掛資訊——無需 GitHub 賬號。
- `textus` 終端命令現在也支援 Windows 和 Linux AppImage。
- Textus AI：可以在訊息框中切換對話模型、搜尋歷史對話、把值得重複的請求儲存為技能、把外掛的工具提供給 Textus AI，並按你自己的描述重畫某一張提議的圖片。
- 面向外掛作者，外掛 API 1.0 的型別定義在 `docs/dev/textus.d.ts` 中，`textus-plugin.json` 附有 JSON Schema；外掛可以繪製程式碼塊、標記文字、新增 `/` 選單項和 AI 工具、使用自己的儲存、透過通知提醒你，並在背景定時執行。manifest 會註明外掛可在哪些平台執行，第三方外掛也可以上架商店。

### 改進

- 整個應用採用統一的外觀：所有面板、卡片和對話方塊使用相同的圓角，按鈕和開關都是膠囊樣式，文字大小遵循同一套層級。主題會為整個視窗重新著色——側邊欄、設定、選單和 AI 面板——側邊欄一直延伸到標題欄後面。
- 複製時，剪貼簿的純文字中放入 Markdown，因此 GitHub、Obsidian 和聊天應用能保留格式，而 Word 和 Notion 仍貼上為帶格式的內容；**編輯 › 複製為純文字** 和 **貼上為純文字**（`Ctrl/⌘ + Shift + V`）只處理文字本身。還可以在 **設定 › 編輯與外觀** 中把純文字複製和貼上加到右鍵選單裡。
- 右鍵選單把你點選的內容相關的項放在最前，剪下、複製和貼上固定在頂部——沒有選中內容時剪下和複製顯示為灰色——並新增 **格式**：粗體、斜體、標題、列表、引用、程式碼塊和表格。指標移向子選單時，子選單保持開啟。
- 每次貼上、剪下、拖放和替換都是單獨的一步撤銷，與 Word 一致；查詢會從你選中的文字開始。
- 開啟檔案遵循同一條規則：已開啟的檔案會切換到前面，未改動的空白文件會讓出位置，其餘情況都在新的標籤頁中開啟。
- 文件被其他應用修改後，只要它所在的視窗可見，Textus 會很快更新；你未儲存的編輯絕不會被覆蓋。(#468)
- 原始碼模式、原始碼與預覽、禪模式和打字機模式對所有標籤頁和視窗統一生效。分割檢視現更名為 **原始碼與預覽**。
- 頁邊的修訂和批註卡片在任何縮放比例下、側邊欄開啟時都緊貼正文，不會遮擋文字或閃爍；沒有空間時，由審閱條接管。在正文中顯示原文的檢視裡，僅有新增文字的修訂也放在卡片中，並用一條細線標出插入位置。
- [[Wikilinks]] 顯示為筆記名，只有游標停在上面時才顯示方括號。
- 錯誤資訊用你的介面語言說明發生了什麼——檔案不存在、沒有許可權、磁碟已滿、沒有網路、餘額用完——不再顯示系統的原始文字。
- 設定更清爽了：常改的選項排在前面，其餘放在“高階設定”中；通用 › 幫助 裡有新手導覽、使用指南、報告問題和社群。
- **設定 › 編輯與外觀** 可以讓圖片靠左；在 Mac 上，還可以在深色模式下寫作的同時用淺色匯出 PDF。修訂模式和唯讀也和其他檢視開關放在一起。
- Textus 自帶四個技能——校對、設計主題、製作外掛和製作技能；擴寫、精簡、翻譯、總結和連貫性檢查在商店中一鍵即可新增，你自己的技能也可以暫時關閉。
- 長文件按章節同時翻譯或改寫，人名和術語全文保持一致；Textus AI 的記憶會自動整理。
- 視窗開啟更快：分割檢視、匯出、新手導覽和外掛宿主在第一次使用時才載入。

### 修復

- Backspace、Delete、回車和貼上會保持程式碼塊、公式塊、引用、列表和表格的結構：不會再把塊倒進旁邊的行，縮排程式碼保留其中的空行，貼上的表格會填入落點處的單元格。
- 在 macOS 上，撤銷和重做能撤回貼上、剪下和格式修改，不再只限於輸入；在文字框或對話視窗中撤銷，也不會影響到後面的文件。
- 從訪達、檔案資源管理器或 Linux 檔案管理器拖入的檔案又能開啟了，拖入的資料夾會在側邊欄中開啟。(#429)
- 點選正文旁的空白頁邊，游標會落在最近的一行。
- 在 Windows 和 Linux 上，設定和其他選單命令在你使用它們的視窗中開啟。

### 平台說明

- **iPhone 和 iPad：** 需要在背景執行或依賴電腦上程式的外掛——快速筆記、提醒、Zotero 和網頁檢視——僅在電腦上可用。
- **Windows 和 Linux：** **設定 › 編輯與外觀 › 顯示選單欄** 會把檔案、編輯、檢視等選單放在標題欄上，不再收在 ☰ 後面。

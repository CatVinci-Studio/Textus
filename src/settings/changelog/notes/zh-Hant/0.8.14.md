## 更新內容

### 問題修復

- 修復儲存時可能丟失內容的問題：連續輸入一大段後立即儲存，最後輸入的部分可能沒有寫入檔案；儲存過程中視窗焦點變化時，未寫入的內容還可能被丟棄。關閉視窗、切換原始碼模式、拖動標籤頁時同樣會先取得編輯器中的最新內容。
- 修復在數字列表中按回車後，用輸入法輸入中文時出現多餘空行、文字重複或亂碼的問題。
- 修復 Linux 上輸入法選詞後需要按兩次回車才能換行的問題。
- 修復 Linux 上中文無法加粗的問題。
- 修復儲存時緊湊的無序列表被改成每項之間空一行的問題。
- 程式碼塊的語言標籤不再遮擋第一行程式碼 ([#16](https://github.com/CatVinci-Studio/Levis/issues/16))。
- 列數較多的表格不再超出正文範圍，改為在正文寬度內橫向滾動 ([#15](https://github.com/CatVinci-Studio/Levis/issues/15))。

### 主題

- 匯入的 Typora 主題現在可以完整控制引用塊、表格、程式碼塊等樣式，不再被 Levis 自帶的樣式覆蓋；使用匯入主題時，Levis 自帶的標題裝飾和引用塊底色會自動關閉，效果更接近 Typora ([#13](https://github.com/CatVinci-Studio/Levis/issues/13))。

### Linux 視窗

- 視窗四周新增細邊框，邊緣和四角可以直接拖動調整大小，滑鼠移到邊緣即顯示縮放游標 ([#11](https://github.com/CatVinci-Studio/Levis/issues/11))。
- 記住上次關閉時的視窗大小 ([#11](https://github.com/CatVinci-Studio/Levis/issues/11))。
- 在 Wayland（niri 等平鋪式視窗管理器）下，AI 浮動對話視窗會作為編輯視窗的子視窗浮動顯示，而不是佔用新的一列。

### 效能

- 編輯時不再重新渲染所有已開啟的標籤頁；移動游標時不再反覆掃描整篇文件，長文件編輯更流暢。

macOS、Windows 和 Linux 安裝包由釋出流程構建。

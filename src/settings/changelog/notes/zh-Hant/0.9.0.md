## 更新內容

0.9 是一次以寫作為中心的 AI 更新：AI 讀得懂你的專案和文風，改動逐句可選，編輯器新增分割、打字機和禪模式。

### AI 面板

- AI 對話預設顯示在編輯器右側，隨文件切換；視窗頂欄的對話按鈕或 Ctrl/⌘+Shift+L 開關，仍可展開為獨立視窗。
- 快速提問（選中文字後彈出）預設進入“編輯”，可一鍵展開到右側面板繼續。
- 每條修改建議都附帶理由；一段改動可以逐句勾選，只採納需要的部分（同一個“採納”按鈕會顯示“採納 1/2 處”）。
- 修改卡片和快速提問的介面重新整理：一處修改只有一組採納/拒絕，不常用的按鈕只在需要時出現。
- AI 可以在游標處插入內容，也可以只留批註而不改原文，批註可在文件中定位。
- 錯誤提示更清楚：未配置、金鑰無效、請求過於頻繁、模型不可用、服務端或網路問題等分別給出原因和處理辦法。

### 專案與寫作資料

- 儲存過的文件所在的資料夾即為專案，AI 可以瀏覽、閱讀和搜尋其中的文字檔案；在輸入框中用 @ 引用檔案。主目錄、根目錄等過大的資料夾不會被當作專案。
- `.levis/style.md`：文風檔案。可從你挑選的範文中“學習文風”自動生成，續寫和修改都會貼近你的寫法。
- `.levis/library/`：資料庫。人物、術語、設定等條目按名稱和別名自動匹配，相關條目會隨請求一起提供給 AI。

### 續寫與語法

- 續寫更貼合上下文：參考標題、所在章節和文風檔案，避免常見的 AI 套話。
- Ctrl/⌘+→ 逐詞采納續寫，Alt+[ / Alt+] 切換候選，Esc 取消。
- 語法檢查：游標停在問題上即顯示建議，Alt+Enter 直接採納，可選擇忽略。

### 編輯器

- 分割模式：左側原始碼、右側實時預覽，滾動同步（Ctrl/⌘+Shift+E）。
- 打字機模式：正在輸入的一行始終保持在視窗中間（設定 → 編輯與外觀）。
- 禪模式：隱藏介面、全屏，只突出當前段落（Ctrl/⌘+Shift+J，Esc 退出）。
- 視窗標題顯示當前文件名，工作列和視窗切換時更容易區分。
- 按鈕、圓角和彈出選單的樣式與互動統一：同類按鈕大小一致，選單都可以點外面或按 Esc 關閉。
- 歡迎頁顯示正式的應用圖示。
- 首次使用的教程新增側邊欄介紹。

### 模型

- 內建模型列表只保留各服務的預設模型（Anthropic：Agent 使用 Claude Sonnet 5.5，續寫使用 Claude Haiku 5.5），模型資訊每週從 models.dev 同步。
- 可在設定中拉取服務商當前提供的全部模型自行選擇。
- Anthropic 請求啟用提示快取，長對話更快、更省。

### Windows 與 Linux

- Windows、Linux 上從檔案管理器開啟檔案時，會交給已經開啟的 Levis，不再另起一個程序。
- 關閉編輯視窗時，它的獨立對話視窗一起關閉。
- 檔案對話方塊作為編輯視窗的子視窗顯示；儲存時自動補全 .md 副檔名。
- Linux 上改進 NVIDIA 顯示卡的顯示相容性。
- 登入憑據檔案僅當前使用者可讀。

### 問題修復

- 修復 AI 修改卡片中刪除行數顯示為亂碼（`−`）的問題。
- 修復滾動時彈出層停留在原位、右鍵選單誤觸發等問題。
- 修復 AI 面板開啟時（以及 Windows 上始終）按 Esc 無法關閉查詢欄等問題。
- 修復快速提問在收到修改後跳到文件末尾、看不到採納按鈕的問題。
- 修復分割預覽中的程式碼塊沒有背景和邊框的問題。

macOS、Windows 和 Linux 安裝包由釋出流程構建。

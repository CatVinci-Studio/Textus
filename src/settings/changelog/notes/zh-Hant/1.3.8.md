## 更新內容

Textus 1.3.8 修復了游標離開連結時連結消失的問題，開啟連結的本地檔案前會先詢問，原始碼模式下可以貼上圖片，Word 匯出也可以使用你自己的範本。

### 新增

- 原始碼模式和分割檢視中也能貼上圖片：按 設定 › 圖片 中的方式儲存，並在游標處寫入 `![](...)`。(#196)
- **設定 › 編輯與外觀 › 匯出 › Word 範本**：匯出的 Word 檔案沿用你所選 Word 檔案的樣式、字型和頁邊距（即 Pandoc 的參考文件）。(#196)

### 改進

- Ctrl/Cmd+點選指向本地檔案（PDF、Word 文件、圖片）的連結時，會先詢問，然後用系統預設的應用開啟，而不是只在資料夾中顯示它。程式或指令碼仍然只在資料夾中顯示。(#561)
- 在 Windows 上，視窗最小化時會讓 WebView2 減少記憶體佔用，視窗回到螢幕上後再恢復。

### 修復

- 同一個連結在另一個標籤頁中以 Markdown 形式顯示過後，游標離開該連結時連結不再消失；此前儲存時，這一段會把連結丟掉。(#561)
- 在 Windows 上，在新視窗中開啟另一篇文件（文件設為在獨立視窗中開啟時使用 檔案 › 開啟…、在側邊欄中 Ctrl+點選，或 移到新視窗）可能導致應用卡死，透過遠端桌面使用時尤其常見。
- 使用 **檢視 › 放大** 後，快速預覽卡片會出現在連結正下方，而不是連結未縮放時所在的位置。
- 讀取 Word、Excel 等基於 zip 的檔案時使用了更新後的庫，修復了兩個已報告的安全問題（RUSTSEC-2026-0429、RUSTSEC-2026-0433）。(#533)

## 更新內容

Textus 1.1.1 打磨了 Textus AI 修訂的顯示效果，並修復了輸入連結和圖片、粗體後的游標位置，以及在空視窗中使用“最近開啟”的問題。

### 改進

- 滑鼠指向的修訂，或在審閱條中跳轉到的修訂，會像審閱批註一樣加深顏色：正文和頁邊卡片中，新文字顯示為更深的綠色，原文顯示為更深的紅色，不再加外框。(#207)
- 無法載入的圖片會顯示為一張卡片，列出檔名和原因（該路徑下沒有檔案、無法連線網路主機、Textus 無法顯示的檔案），懸停時顯示完整路徑，並提供 **重新選擇圖片…** 以指向其他檔案，以及 **在資料夾中顯示**，不再顯示瀏覽器的破圖圖示。Obsidian `![[...]]` 嵌入也使用同樣的卡片。(#212)
- 圖片的右鍵選單在寬度選項旁新增 **在資料夾中顯示** 和 **複製圖片路徑**：前者在訪達、資源管理器或檔案管理器中開啟並選中該圖片，後者複製其完整路徑，網路圖片則複製其地址。Obsidian `![[...]]` 嵌入同樣支援這兩項，檔案會在倉庫中查詢。(#224)
- 圖片寬度以 HTML 儲存為 `<img src="…" width="50%">`，GitHub、Typora、Obsidian 和 VS Code 都會按該尺寸顯示；不再在標題中寫入 `{textus-width=50%}` 標註，其他應用會忽略它並把它顯示為提示文字。**圖片寬度：自動** 會重新儲存為 `![]()`。頻寬度的 `<img>`（來自 Typora 或其他地方）現在會作為圖片開啟，並帶有寬度選單；舊版本儲存的檔案會按其寬度開啟，並在你修改之前保持原樣。(#227)

### 修復

- **設定 › 編輯與外觀 › 正文寬度** 為 **自適應** 時，視窗寬度從約 1100px（原為 1214px）起正文就隨之變寬，因此在 1280–1440px 的視窗上會比標準寬度更寬而不是更窄；在較小視窗中與側邊欄或 AI 面板並排時，寬度保持不變，修訂的頁邊檢視也仍在原來可用的情況下可用。(#211)
- 當前視窗是新建的空視窗時，從 **檔案 › 最近開啟** 中選擇的檔案會在當前視窗中開啟，不再在旁邊另開一個視窗。(#201)
- 刪除粗體或斜體後面的文字時，游標保持在收尾的 `**` 或 `*` 之後，接下來輸入的文字不再變成粗體或斜體。(#199)
- 輸入收尾的 `)` 時，`![alt](url)` 會變成圖片，就像 `[text](url)` 已經會變成連結一樣，不再保持為文字，儲存時被加上反斜槓而不再顯示為圖片。(#189)
- 為沒有標題的圖片設定寬度後，再從右鍵選單或手機鍵盤工具欄中選擇 **圖片寬度：自動**，會恢復為自動寬度；此前該選項不起作用。(#223)
- 在 **打字機模式** 下用滑鼠點選、拖動或輕點時，頁面保持不動，點選會把游標放在點選處，拖動會選中經過的內容，不再頁面跳動、游標或選區落到別處；按下一個鍵時，仍會像以前一樣把當前行居中。(#217)
- 用 LaTeX 的 `\(...\)` 和 `\[...\]` 寫的公式儲存時保持原樣，不再在開啟檔案時改寫為 `$...$`；單獨成行的 `\[...\]` 顯示為行間公式而非行內公式；`\[1\]` 這樣的引用以及程式碼中的內容保持不變。Textus AI 回覆中和貼上進來的公式仍會轉換為 `$...$`。(#228)
- 儲存或從程式碼塊選單中選擇其他語言時，保留程式碼塊首行語言之後的其餘內容，例如 `js` 後面的 `title="a.js"`，不再丟棄。(#228)
- `> [!note]`、`> [!Tip]` 以及 Obsidian 的可摺疊寫法 `> [!tip]-` 和 `> [!tip]+` 都顯示為提示框，並按原樣儲存，不再儲存為 `> \[!note]`；Obsidian 的其他提示框型別（如 `> [!question]`）也會按原樣儲存。(#228)
- 輸入的網址或郵箱地址，如 `https://x.org`、`www.x.org` 或 `a@b.com`，儲存時不再加反斜槓，因此在 GitHub 等地方仍是連結，而不是 `https\://x.org`。(#228)
- 單波浪線 `~x~`（Pandoc 的下標寫法，如 `H~2~O`）儲存時保持單個波浪線，不再變成 `~~x~~` 刪除線。(#228)
- 用 `$$x$$` 寫的行內公式儲存時保持兩個美元符號，不再變成 `$x$`。(#228)

### 平台說明

- **macOS：** 可透過 Homebrew 官方 cask 用 `brew install --cask textus` 安裝；從 `catvinci-studio/tap` tap 安裝的 Textus 會在下次 `brew update` 時遷移過去。
- **Windows：** 安裝程式的側邊圖和頁首圖換成了 Textus 的羽毛筆和名稱，此前仍顯示舊的 Levis 圖片。

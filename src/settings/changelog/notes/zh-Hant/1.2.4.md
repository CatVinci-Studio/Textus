## 更新內容

Textus 1.2.4 讓程式碼塊、編輯按鍵和複製貼上的表現符合預期，併為標籤頁配上與瀏覽器相同的快捷鍵。

### 新增

- 編輯 › 貼上為純文字（Cmd/Ctrl+Shift+V）按原樣貼上剪貼簿中的文字，不解析其中的 Markdown。
- 檔案 › 重新開啟關閉的標籤頁（Cmd/Ctrl+Shift+T）恢復本視窗中關閉的文件，最近關閉的最先恢復。

### 改進

- 程式碼塊的語言、**複製** 和新增的 **全選** 按鈕一起放在右上角。語言從應用自帶的選單中選擇，可以輸入文字搜尋，不再使用系統選單。
- 使用 Claude 賬號登入被標為實驗性功能：這並不是 Anthropic 向其他應用提供的登入方式。API 金鑰才是可靠的方式。
- 複製時，剪貼簿的純文字中放的是 Markdown 原始碼，因此 GitHub、Obsidian、VS Code、聊天應用和 AI 對話拿到的是 Markdown 格式，而 Word、Pages、郵件和 Notion 貼上時仍帶格式。從程式碼塊內部複製的程式碼只包含程式碼本身。編輯 › 複製為純文字 則只複製文字、不帶標記，適合微信等應用。
- 標籤頁快捷鍵與瀏覽器一致：Cmd/Ctrl+T 在本視窗中新建標籤頁，無論設定中檔案以何種方式開啟；Cmd/Ctrl+N 新建視窗（原為 Cmd/Ctrl+Shift+N）。檔案 › 新建檔案 現改為 新建標籤頁。

### 修復

- 文件放大或縮小時，程式碼塊的行號始終在對應行旁邊。
- 貼上的程式碼保留分行：帶中文註釋或長行的程式碼不再有幾行擠在一起。
- 選擇程式碼塊的語言後立即應用新的配色，不再要等下一次編輯。
- 在程式碼塊中輸入時不再彈出 AI 補全。
- 語法檢查不再碰程式碼：不檢查程式碼塊，行內程式碼也不再讓周圍的文字出現建議。
- 在引用中後面某一行的開頭按 Backspace，會把它併入上一行，不再把它移出引用、把引用一分為二。
- 在程式碼塊、數學塊或表格開頭按 Backspace，或在它們緊前方按 Delete，會把游標移進去，不再把整個塊當作純文字倒進旁邊那一行，也不再選中整個表格導致下一次按鍵替換掉它。前置後設資料下方的一行不再併入前置後設資料，兩個程式碼塊之間的空行也可以刪除了。
- 選區從普通文字開始、在程式碼塊中結束（或反過來）時，輸入覆蓋或刪除選區會保留程式碼塊，不再把其餘的程式碼行變成段落。
- 在引用或列表前一行的末尾按 Delete，會像 Backspace 一樣把文字合併，不再把引用或列表的第一行移出來；在提示框前則移到提示框的文字中，並保留提示框。
- 在列表中的程式碼塊或數學塊末尾按 Enter，會在塊中新增一行，不再新建列表項。
- 在只有縮排的程式碼行上按 Enter 會留在程式碼塊中：該行留空，縮排延續，因此縮排程式碼（如 Python 函式）中的空行不再結束程式碼塊。在空行上按 Enter，或在任意位置按 Cmd/Ctrl+Enter，仍會離開程式碼塊。
- 貼上的引用、程式碼塊或數學塊無論落在哪裡都保持原樣：以列表開頭的引用（`> - item`）不再變成單純的列表；貼上到空列表項或一行文字中的程式碼不再被壓成那一行；該行其餘文字也不會被捲進程式碼裡。
- 在新行上貼上的表格佔用這一行，不再在上方留下空行；貼上到表格單元格中時，從該單元格開始填充表格，超出邊緣時增加行和列，不再把表格斷成兩半。
- 在列表項所在行輸入三個反引號或 `$$` 後按 Enter，會在該項中開始程式碼塊或數學塊，不再把圍欄留作文字並新建列表項。
- macOS：在程式碼塊第一行按 Cmd+Backspace 會刪除到行首，不再毫無反應併吞掉接下來輸入的按鍵。
- 游標在 AI 建議上時，即使在引用或程式碼塊中，Cmd/Ctrl+Enter 和 Cmd/Ctrl+Backspace 也能採納或拒絕建議，不再被編輯器對這些按鍵的原有用法搶先。
- 右鍵選單中的貼上與 Cmd/Ctrl+V 效果相同：支援圖片、來自其他應用的帶格式文字、保留的換行和表格單元格，此前只能貼上文字。在 macOS 上不再需要再點一次“貼上”按鈕。
- 緊跟在連結後按 Backspace，或緊挨在連結前按 Delete，會像粗體或程式碼一樣刪除其 Markdown 原始碼中的一個字元，不再一下子刪掉整個連結及其文字和地址。Wiki 連結、嵌入和內聯 HTML 也一樣。
- 在單獨一行輸入三個反引號後，輸入語言期間它們顯示為純文字，中間那個不再看起來像行內程式碼。
- 文件以程式碼塊開頭或結尾時，全選會高亮整篇文件；此前其實已全部選中，只是沒有顯示出來。程式碼塊的按鈕也不再隨文字一起被選中。
- `---` 或 `___` 加 Enter 會生成分隔線，並把游標放在它下面一行，與 `***` 一致，不再多留一個空行；`---` 後面還有其他文字時仍保持為文字。

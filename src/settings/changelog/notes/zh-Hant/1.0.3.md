## 更新內容

Textus 1.0.3：複製、貼上和登入的改進。

### 複製與貼上

- 複製到微信等只接收純文字的 App 時，得到的是可讀文字：連結寫成“文字 (網址)”，不再帶 Markdown 符號。貼上到 Word、郵件或 Textus 時仍然保留格式。需要 Markdown 原文時，可以在“設定 › 編輯與外觀 › Markdown › 複製到其他 App 時”裡切換。
- 右鍵選單的“複製”和快捷鍵複製的結果一致，同時帶格式和純文字。
- 在連結文字中間貼上網址，不會再把連結拆開；選中一段文字後貼上網址，這段文字會變成指向該網址的連結。

### Intel Mac

- 新增 Intel 晶片 Mac 的安裝包（檔名以 `_x64.dmg` 結尾），Apple 晶片的仍是 `_aarch64.dmg`。兩種都能自動更新，Homebrew 會按電腦的晶片自動選擇。

### 登入

- 使用 ChatGPT 或 Claude 賬號登入時，如果瀏覽器沒有自動開啟，設定裡會顯示登入連結和“複製連結”按鈕，在這台電腦的瀏覽器裡開啟即可完成登入。

macOS、Windows 和 Linux 安裝包由釋出流程構建。

## 更新內容

- Arch Linux：新增簽名的 pacman 軟體源 [`[catvinci]`](https://github.com/CatVinci-Studio/arch-repo)，提供 `levis-bin` 包。按 README「安裝」一節配置一次後，`sudo pacman -Syu` 會自動升級 Levis。
- 透過軟體包管理器安裝的 Levis 仍會提示新版本，但不再自行下載安裝，而是提示用包管理器更新，避免與 pacman 管理的檔案衝突。
- GitHub Release 新增 `Levis_0.8.13_linux_x86_64.tar.gz`，供 Linux 軟體包使用。

macOS、Windows 和 Linux 安裝包由釋出流程構建。

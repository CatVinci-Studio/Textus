## 更新內容

Textus 1.3.0-beta.1 是 1.3 的第一個測試版，為它打下基礎：在 Textus 內安裝的外掛，擁有自己的設定和儲存，以及更完整的開發 API；外掛、主題和技能的統一市場；輸入公式時的 LaTeX 命令補全；你自己的批註和修訂與 Textus AI 的並列在頁邊；啟動更輕快。它也包含 1.2.1 的全部內容。測試版可能還有不完善之處，歡迎在 GitHub 或 Discord 告訴我們。

### 新增

- 外掛、主題和技能的統一市場：設定 › 擴充套件 › 獲取更多 列出這三類內容，一個搜尋框即可搜尋，每類各有一個標籤頁，技能一鍵即可安裝；設定 › 擴充套件 › 外掛 列出你已安裝的外掛，每個都可以開啟自己的頁面。
- 外掛的設定可以只屬於某個專案：開啟資料夾後，外掛在 設定 › 擴充套件 中的頁面會出現 **適用於**——所有文件，或此專案——專案的設定值儲存在專案的 `.textus/settings.json` 中，隨資料夾一起走，並優先於通用設定；**改用通用的值** 可以恢復某一項。
- 外掛把自己的資料存放在兩個地方：一處對所有文件通用，位於 Textus 的配置資料夾中，與你的全域性 agent.md 放在一起；另一處隨專案走，位於專案的 `.textus/plugins/` 中——後者僅限你授權過的外掛。每個外掛只能訪問自己的資料，每處最多 50 MB。
- 經你允許後，外掛可以為 Textus AI 提供工具——統計字數、在文獻管理器中查詢、轉換格式等；每次呼叫都會顯示在對話中，與 MCP 伺服器的呼叫一樣。
- 輸入公式時的 LaTeX 命令補全，需安裝 LaTeX 補全外掛（設定 › 擴充套件 › 獲取更多）：輸入反斜槓和命令開頭——`\fr`、`\alp`——即列出以此開頭的命令，並顯示各自的效果；按回車或 Tab 寫入命令，游標停在花括號內。(#358)
- 每個外掛都會說明用法：無論從獲取更多還是從檔案安裝，外掛的使用指南都會以你的介面語言在標籤頁中開啟；在設定中的外掛頁面點選 **使用說明** 可以再次開啟。
- 安裝網頁檢視外掛後，按住 Ctrl 點選網頁連結（Mac 上為 ⌘+點選）會在筆記旁的標籤頁中開啟，不再跳轉到瀏覽器；網頁上方的欄只有細細一行，還可以收起為一個小把手。
- 安裝 Vim 和 Emacs 外掛後，編輯器支援 Vim 和 Emacs 鍵位：Vim 的模式、移動、運算子、暫存器和 flash 跳轉；Emacs 的移動、標記和 kill ring。**外掛 › 開啟或關閉 Vim 鍵位**（Emacs 同理）用於切換。
- 安裝分割外掛後，可以同時檢視兩篇文件：向右分割（Ctrl+Alt+S，Mac 上為 ⌘⌥S）把當前文件與另一個標籤頁並排顯示，向下分割則上下排列。
- 安裝快速預覽外掛後，可以快速檢視連結指向的內容：把指標停在指向另一篇文件的連結上——Markdown 連結或 [[wikilink]]——旁邊的卡片中就會顯示它的開頭；安裝 Zotero 外掛後，把指標停在 [@darwin1859] 這樣的引用上，會顯示它引用的文獻。
- 你自己的批註：選中文字，右鍵 › 新增批註，批註會出現在頁邊，與 Textus AI 的並列，標為“我”；批註儲存在 Textus 自己的資料旁，不寫入你的 Markdown。
- 修訂模式（編輯選單）：開啟後，你的編輯會顯示為修訂——刪除的內容加刪除線，新增的內容加標記——每處修訂在頁邊都有一張標為“我”的卡片，可以採納或拒絕。
- 可以在訊息框中切換對話模型：其他控制元件旁的按鈕顯示下一條訊息將發給哪個模型，可從你在 **設定 › Textus AI** 中配置的服務商中選擇；只配置了一個模型時，這個按鈕不會出現。
- 搜尋對話：AI 面板的歷史記錄新增搜尋框，可以找到說過某些話的對話；當你提到之前的對話時，Textus AI 也會在這裡查詢。
- 值得重複的任務可以變成技能：當你的請求是一套自己的流程時，Textus AI 會在回覆下方提議把它儲存為技能，可用於所有文件或僅此專案；只有你選擇儲存時才會儲存。
- 按你自己的描述重畫提議的圖片：指向圖片並選擇重畫…，只重畫這一張。
- 開啟 **設定 › 隱私 › 關閉時保留未儲存的修改，不再詢問** 後，關閉視窗時會直接保留未儲存的修改，不再詢問；預設關閉，並且需要開啟草稿恢復。
- 面向外掛作者，完整的外掛 API 型別定義在 `docs/dev/textus.d.ts` 中，`textus-plugin.json` 附有 JSON Schema，編輯器可以在你輸入時進行校驗。
- 外掛 API 新增：安裝後顯示的 `USAGE.md` 使用指南、`contributes.links`（按住 Ctrl/Cmd 點選時由外掛開啟的網頁連結）、`textus.storage.global` 和 `textus.storage.project`、按專案的設定、`textus.ai.registerTool` 配合 `contributes.aiTools`、`textus.workspace.readDocuments()` 和 `search(query)`、`textus.window.openFile(path, { asDocument: true })`（取代 `textus.openAsDocument` 命令）、`textus.window.splitEditor`、`textus.editor.registerCompletionProvider` 配合 `contributes.completions`（輸入時在游標下方顯示建議）、`textus.editor.registerHoverProvider` 配合 `onHover` 啟用事件、`textus.motion` 和 `textus.l10n.t`。

### 改進

- 啟動時載入的內容更少：分割檢視、編輯器選單、首次執行導覽和執行外掛的程式碼在第一次使用時才載入，視窗的啟動程式碼從 1.32 MB 降到 1.02 MB。
- 側邊欄的檔案樹不再顯示隱藏檔案——以點開頭的檔案，以及 Windows 上標記為隱藏或系統的檔案，如 desktop.ini——**排序** 選單中的 **顯示隱藏檔案** 可以讓它們顯示出來。(#357)
- 設定中的外掛頁面會顯示外掛儲存了多少資料——對所有文件通用的部分，以及當前開啟的專案中的部分——**清空** 會在確認後清除這些資料。
- 設定 › 擴充套件 中的外掛、主題、Skill 和 MCP 採用同一種佈局：一行說明該標籤頁的內容，**獲取更多** 和用於其他操作（從檔案安裝、匯入 CSS、手動新增伺服器）的 **⋯** 選單，你已安裝的內容，以及摺疊起來的高階設定。尚未安裝的內容——主題庫、你關閉的內建技能、大多數人會新增的 MCP 伺服器——都在獲取更多中。
- 長文件按章節同時修改：讓 Textus AI 按章節翻譯或改寫長文件時，它會把每一章交給單獨的助手處理，並共享一份反覆出現的人名和術語的寫法清單。
- Textus AI 的記憶會自動整理：它會不時合併內容相同的記憶，並刪除已被新規則推翻的舊規則；被刪除的內容在記憶頁的“最近忘記的”中，可以找回。
- 同一作品中的圖片保持人物和風格一致：再次出現的人物會用相同的文字描述；如果影象模型支援參考圖，會以之前的圖片為參考繪製該人物的新圖片。
- 標籤頁中的網頁（網頁檢視外掛）在 macOS 和 Windows 上可以開啟任何網站，使用系統自帶的網頁檢視及其 Cookie；在 Linux 上，網頁暫時仍以 frame 方式顯示。
- 獲取外掛時會先立即顯示上次的列表，同時獲取最新列表；離線時也會繼續顯示。
- 開發外掛更快了：從資料夾載入的外掛（設定 › 擴充套件 › 外掛 › 載入外掛資料夾…）在你儲存修改後會自動重新載入，其頁面會列出最近出現的錯誤。
- 外掛 `engines` 範圍中指定測試版時，如 `>=1.3.0-beta.1`，會與包括測試版號在內的完整版本號進行比較。

### 修復

- 官方外掛支援 Textus 的全部十種語言——繁體中文不再顯示為簡體，其他語言也不再顯示為英文。
- 官方外掛更加穩定：任務外掛能列出使用 Windows 換行符的檔案中的任務；版本歷史能保留位於深層或非拉丁字元資料夾中的文件版本，並在儲存空間滿時騰出空間；新建的看板不會再覆蓋另一個僅大小寫不同的同名看板；網頁檢視會開啟所選連結本身的地址；快速筆記會保留按下按鈕前最後輸入的文字；圖譜檢視不再顯示上次儲存之前的圖譜；每日筆記不會覆蓋當天已有的筆記；PDF 檢視器能顯示 PDF 未內嵌字型的中文、日文和韓文文字；圖片檢視器在檔案無法開啟時會給出提示，不再顯示空白標籤頁。
- 在審閱模式中，讓 Textus AI 標出難詞或所有不夠有力的句子時，會全部標出，而不只是第一個。

### 平台說明

- **Windows 和 Linux：** 設定 › 編輯與外觀 › 顯示選單欄 會把檔案、編輯、檢視等選單放在標題欄上，不再收在 ☰ 後面——預設關閉。

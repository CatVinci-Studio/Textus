## 更新內容

Textus 1.3.6 讓外掛可以在你的寫作區域上方懸浮一個小檢視（首先是桌寵：Moyu 或你所用模型的 LLM-chan 陪著你），可以在 HTML 表格顯示的位置直接編輯文字，像 GitHub 一樣顯示 README，標題欄也可以變成毛玻璃。

### 新增

- **Desk Pet**（桌寵）外掛，可在 設定 › 擴充套件 中獲取：Textus 的吉祥物 Moyu，或 Textus AI 當前所用模型的 LLM-chan，待在視窗一角或你的桌面上。你打字時她寫字，停下時她打盹，儲存時她歡呼，戳她或摸摸她都會回應，並且始終面朝中間；右鍵點選她可以切換角色。
- 外掛可以顯示懸浮檢視：一個小小的透明頁面，懸浮在桌面上、所有視窗上方或 Textus 視窗內，比如桌寵、計時器。它最初出現在視窗內；可以拖到任何地方，從頂角調整大小，右鍵點選可以放到桌面上、收成一個圓點或關閉；在桌面上時，它的選單還能開啟 Textus 或 Textus AI。再次開啟時，它會出現在你上次放的位置。外掛還能得知你戳了、摸了或移動了它的檢視，你在打字或儲存，以及 Textus AI 正在做什麼、用的是哪個模型，但絕不會得到你文件或對話中的任何文字。外掛可以在檢視的右鍵選單中新增自己的選單項（`menus` `floating/context`），比如切換桌寵的角色。詳見外掛參考中的 `contributes.floatingViews`、`layout.openFloating`、`app.onDidActivity` 和 `ai.onDidChangeState`。
- HTML 表格或塊中的文字可以在顯示的位置直接編輯：點選單元格或某一行後輸入，按 Enter（或點選別處）會把新文字寫回原始碼中原來的標籤之間；按 Escape 則恢復原樣。和以前一樣，Option 加點選會顯示原始碼。
- 標題欄可以像 macOS 工具欄一樣變成毛玻璃，在 **設定 › 編輯與外觀 › 主題** 中開啟：文件滾動到標題欄下方時透出顏色和形狀，頂部最模糊，越往邊緣越清晰，玻璃結束處沒有分界線。

### 改進

- README 的顯示效果與 GitHub 一致：`<div align="center">`、`<p align>` 或 `<center>` 中的 Markdown 會按對齊方式顯示，標籤所在的行在游標移到上面之前都會隱藏；包含淺色和深色兩個 logo 的 `<picture>` 會跟隨 Textus 的主題；定義列表、帶說明文字的圖片、`<abbr>`、`<q>`、`<ruby>`、`<kbd>` 之類的標籤，以及 GitHub 允許的其他小型行內標籤都能正常顯示。
- 桌面版啟動稍快：手機版專用的部分不再隨每個視窗一起載入。

### 修復

- AI 面板開啟和關閉時，文件標題隨面板平滑移動，而不是一下子跳到頁面的新中心。
- 一排 README 徽章無論是否帶連結都能對齊，縮放按鈕和調整大小的手柄也不再擋住徽章上的文字。

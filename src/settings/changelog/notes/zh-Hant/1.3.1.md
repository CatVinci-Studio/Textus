## 更新內容

Textus 1.3.1 讓開啟外掛時的大資料夾和長文件依然流暢，把引導教程縮短為八步，並新支援三種 Typora 或 GitHub 中的 Markdown 寫法：`[TOC]`、上下標和 `:emoji:` 短程式碼。

### 新增

- 單獨一行的 `[TOC]` 會像 Typora 一樣顯示由文件標題組成的目錄：它隨你的寫作同步更新，點選即可跳轉到對應標題。輸入 `[TOC]` 後按 Enter 即可插入；儲存時保留原樣。
- 與 Typora 和 Pandoc 一致的下標和上標：`H~2~O` 顯示為 H₂O，`x^2^` 顯示為 x²，輸入閉合的 `~` 或 `^` 時即生效。單個波浪號只在緊跟字母或數字時才是下標；其他位置的 `~text~` 仍像 GitHub 一樣顯示為刪除線，`~~text~~` 則始終是刪除線。中間有空格的文字（如 `2^10 and 3^4`）保持原樣。
- 與 GitHub 一致的 emoji 短程式碼（如 `:tada:` 和 `:rocket:`）會像 Typora 一樣顯示為對應的 emoji。檔案中保留短程式碼，游標移到上面時會顯示短程式碼以便編輯。程式碼和連結中的內容保持不變。

### 改進

- 引導教程從十七步縮短為八個簡短步驟：輸入 Markdown、命令面板、**設定 › 擴充套件** 中的外掛、主題和技能、連線 AI，以及用 Textus AI 撰寫和續寫筆記。表格、公式、主題、審閱等內容請看 **幫助 › 影片教程**。
- 在配備 120 Hz 顯示器的 Mac 上，輸入和動畫以顯示器的全重新整理率繪製，而不是約每秒 60 幀。

### 修復

- 在一百萬字元及以上的文件中輸入也能跟上：按鍵顯示所需時間約減半，貼上或修改一行所需時間大幅縮短。
- 外掛在側邊欄中顯示數千項的列表（如大資料夾的任務）時，不再拖慢輸入和切換文件：每次只繪製一頁的行，也不會在每次按鍵時重新繪製。
- 在包含數千篇筆記的資料夾中，跟蹤連結的外掛（反向連結、關係圖等）讀取資料夾時不再讓視窗卡住數秒：每個連結都按名稱查詢，而不是與所有檔案逐一比對。
- 列出資料夾中筆記、標籤或任務的外掛（頁面、標籤、任務、反向連結等）在 Textus 啟動後才開啟資料夾時也能跟上編輯，並會在切換到其他資料夾時隨之更新。
- 當文件所在位置沒有 Obsidian 倉庫時，`[[Wikilinks]]` 和 `![[embeds]]` 可以在側邊欄開啟的資料夾中的任何位置找到筆記和圖片，而不只是文件旁邊。
- 外掛在開啟的資料夾中新增、移動或刪除的檔案會立即顯示在側邊欄中，無需點選重新整理。
- 外掛的設定頁面在 **設定 › 擴充套件** 中完整顯示，不再被截斷在一個小框裡。
- 多行設定（外掛的設定或 MCP 伺服器的環境變數）顯示為圓角柔和的輸入框，而不是被拉伸的膠囊形狀。
- 長列表的預覽卡片會把專案符號保留在卡片內，不再畫到卡片下方。
- 列表項中開始的程式碼塊（如 `2. ```）之後的所有標題都會顯示在大綱中。
- 公式中矩陣的各行像 Typora 一樣留有間距，分式行不再擠在一起。
- 沒有英文字串的外掛，在 Textus 使用其不支援的語言時，會顯示外掛自身的語言（名稱、命令和麵板），而不是 `name` 這樣的原始鍵名。

## 更新內容

Textus 1.3.0-beta.6 支援把視窗拆分成任意多個窗格，重新開啟時每個視窗都會恢復各自的標籤頁和窗格；新增後退與前進、用 Alt+↑/↓ 移動段落、旋轉圖片和拼音搜尋；可以直接在 Textus 內傳送問題報告；整理了設定，並帶來 1.2.7 和 1.2.8 的修復。

### 新增

- 同時開啟兩個以上的文件：向右分割和向下分割會再次拆分當前窗格，左右或上下排列，次數不限。把標籤頁拖到窗格邊緣，會在那一側的新窗格中開啟；窗格之間的每條分隔線可調整兩側窗格的大小；重新開啟視窗時整個佈局都會恢復。把標籤頁拖到最外側邊緣，會在所有窗格旁開啟：在上下兩個窗格的右邊緣鬆開，它會從上到下佔滿右側。(#432)
- 右鍵圖片可以向左或向右旋轉 90 度，或放大檢視。旋轉角度儲存在圖片標題中，Markdown 仍保持標準寫法。感謝 @jzzzzh。(#458)
- Alt+↑ 和 Alt+↓（Mac 上為 Option）可以把所在的段落或列表項，或選中的所有塊，移到相鄰塊的上方或下方。
- 後退與前進：點選連結、在大綱中點選標題或切換標籤頁後，Ctrl+-（Windows 和 Linux 上為 Alt+←）返回原來的位置，Ctrl+Shift+-（Alt+→）再前進。滑鼠的後退和前進鍵也有同樣效果。
- 檔案搜尋和命令面板支援用拼音全拼或首字母查詢中文名稱：輸入 `beisong`、`bs` 或 `beis` 都能找到「背誦」。也可以省略重音符號：`cafe` 能找到 café。

### 改進

- 設定 › 通用 的幫助分組中也加入了報告問題，並會在報告中附上你的設定，但不含任何隱私資訊：只有開關、數值和選項，絕不包括資料夾、地址、伺服器、自定義 CSS 或你寫的文字。它會詢問報告型別、涉及 Textus 的哪個部分，如果是錯誤還會詢問嚴重程度；如果你願意接受進一步詢問，可以留下郵箱或微信。**傳送** 會直接替你在 GitHub 上提交 issue，無需 GitHub 賬號，並告訴你編號；**在 GitHub 提交** 則會開啟 GitHub 的表單。你留下的聯絡方式只發給團隊，絕不會出現在公開的 issue 中。
- 原始碼模式、原始碼與預覽、禪模式和打字機模式成為全域性設定：在任一視窗中切換（透過檢視選單、快捷鍵或設定），所有視窗的所有標籤頁都會一起切換，之後開啟的文件也會使用該模式，下次啟動 Textus 時依然保持。
- 設定更加整潔。通用 › 幫助 有五行：歡迎與入門教程（重新開始引導）、使用指南、報告問題、加入社群和關於 Textus（在這裡檢視更新）。編輯與外觀和 Textus AI 把常用設定放在前面，其餘收進高階設定；Textus AI 生成圖片的設定單獨成組。
- 選單、設定和快捷鍵中，同一事物只用一個名稱：分割檢視現在叫 **原始碼與預覽**，以免與向右分割和向下分割混淆；圖片上傳設定改稱 **圖床**。
- 在 Mac 上，**Textus › 檢查更新…** 會開啟關於頁面並立即檢查。
- 命令面板可以切換外觀（淺色、深色或跟隨系統）、編輯器主題，以及開啟或關閉 Textus AI。
- 獲取更多中的主題可以自帶深色版本，隨外觀在淺色和深色之間切換。

### 修復

- 重新開啟 Textus 時，每個視窗都會恢復各自的標籤頁，分割也會恢復其窗格，而不是把上次會話的每個文件都單獨開一個視窗。
- 外掛按鈕和旁邊的選單箭頭重新合為一個按鈕，不再是並排的兩個形狀。
- 在圖片和圖表檢視器中，雙指捏合或按住 Ctrl 滾動只縮放圖片，不會縮放後面的文件；更深的背景讓檢視器與頁面區分開來。
- 複製的圖片貼上到微信等聊天應用時是圖片本身，而不是它的 Markdown 文字。
- 在原始碼模式和程式碼中，`fi` 等字母不再連寫成一個字形，游標可以停在它們之間。(#438)
- 程式碼中含有 `<!--` 和 `<script>` 的外掛（打包的 Markdown 解析器兩者都有）可以再次執行，不會在新增命令之前就停止。
- 使用微軟拼音等輸入法時，在已以 `*` 結尾的文字前輸入 `*`，會像不用輸入法時一樣變為斜體。
- 在 Windows 上，匯出 PDF 時跨頁的編號列表會在下一頁繼續編號，而不是從頭開始。
- 外掛重新命名檔案並更新指向它的連結時，行內程式碼和程式碼塊中的連結示例保持不變。感謝 @Ciao1019。(#457)

## 編輯器

- 加粗、斜體、刪除線、高亮、行內程式碼和公式現在是真正的節點，並像 Typora 一樣顯示分隔符：方向鍵一次跨過一個階段，Backspace/Delete 編輯分隔符本身，重新輸入刪掉的分隔符會恢復節點。
- 修復了 WKWebView 特有的游標問題：離開帶樣式的文字後游標畫在行首，以及快速按或按住方向鍵時跨越邊界出錯。
- ` ``` `（可帶語言）加 Enter 建立程式碼塊；`$$` 加 Enter 建立公式塊，它像普通的圍欄程式碼塊一樣編輯，原始碼單獨佔一行。
- 右鍵選單中的複製、剪下和貼上支援 Markdown：複製時保留語法，貼上 Markdown 時渲染它。
- 右鍵點選不再移動游標，也不再自動選中指標下的單詞（這是 macOS WebKit 的行為，現在會在顯示之前撤銷）。

## AI

- 新增 **詢問 AI** 行內對話（透過右鍵選單或快捷鍵）：回答關於文件的問題，每條回覆都提供需確認的應用操作：替換選中內容、在游標處插入或替換整篇文件。在你點選之前不會改動文件，每次應用都可以撤銷。
- 智慧體現在可以 **提出修改**：引用原文和替換內容，以差異卡片顯示，並附帶“應用”按鈕。
- 段落中含有帶樣式的文字時，語法檢查的下劃線現在位置正確；補全的長度和上下文有了明確上限。
- 每個 AI 功能（補全、語法檢查、詢問 AI）在設定中都有各自的開關，控制對應的選單項和快捷鍵。

## 介面

- 彈出視窗（對話、語法修正、公式預覽）不會超出視窗範圍。
- 設定簡化：通用部分只保留語言，匯入主題 CSS 只需一步。

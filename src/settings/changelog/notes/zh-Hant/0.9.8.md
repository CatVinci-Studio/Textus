## 更新內容

這是 Levis 的最後一個版本。Levis 已升級為 Textus：新名字、新圖示，並繼續更新。

### Levis 已升級為 Textus

- 更新後會提示一次 Textus 的訊息，可以直接開啟下載頁面；之後在 設定 → 通用 中也能找到。
- 文件都留在原處。Textus 首次啟動時會提示匯入 Levis 的設定、歷史記錄、主題和金鑰，只複製，不改動 Levis 裡的任何內容。

### 重新設計的 Levis AI

- 修訂在正文裡逐句取捨：原句標在正文中，新句子和 ✓ / ✕ 放在頁邊；編輯器底部的審閱條可以逐處跳轉、整體採納或拒絕。視窗較窄或在手機上時直接顯示在正文裡。
- 審閱批註貼在原文旁邊的頁邊，可以追問或標記為已處理。
- 語法檢查卡片標出問題型別，以“原文 → 改法”顯示，按鈕上寫著改法和 Alt+Enter。
- AI 面板新增“記憶”頁，文風檔案、資料庫、寫作要求和技能集中在一處。
- 按鈕統一為圓角膠囊樣式，並跟隨當前主題（包括匯入的 Typora 主題）的顏色。
- 修訂的顯示方式可以像 Word 的標記檢視一樣切換：全部顯示在正文裡、原文在正文改動在頁邊、改動在正文原文在頁邊，或只看結果。在審閱條的眼睛圖示或設定裡選擇。

### 編輯

- 表格右鍵選單可以用滑鼠滾輪或捲軸滾動，不再一滾動就關閉，選單底部的“刪除行”“刪除列”都能點到。
- 程式碼塊和圖表塊的末行只剩縮排空格時，按回車同樣可以離開程式碼塊。
- 點選 Mermaid 圖表會進入它自己的原始碼，不再跳到上方的另一個圖表。
- 用拼音輸入法時，切換中英文的 Shift 和回車同時按下，現在按普通回車處理，另起一段，不再變成段內換行。
- 段落以換行結尾時，在行中間按 Shift+回車不再吞掉前一個字。
- GitHub 提示框的標記（如 `> [!NOTE]`）儲存時保持原樣，不再被轉義。

### 匯出

- PDF 和 HTML 不再顯示文件開頭的後設資料框；腳註編號與正文在同一行。
- HTML 保留匯出時的外觀，不會被閱讀器的深色模式改得和淺色圖表不協調。
- Word、OpenDocument、EPUB 和 RTF：圖表以圖片匯出，高亮保留為高亮，圖片按設定的寬度，提示框標題跟隨介面語言，檔名不再作為第二個標題出現在正文標題上方。

### 中文、日文和韓文

- 中文和日文介面中，引號、省略號和破折號由中文字型繪製：“……”不再顯示成貼近底線的六個點，“——”也不會斷開。
- 韓文正文按詞斷行，不再把一個詞拆到兩行（表格單元格除外）。
- 中文和日文的字數統計按字計算，單位顯示為“字”。
- 提示框（備註、提示、重要、警告、注意）的標題跟隨介面語言。
- 日文介面中“承認”改為“適用”。

macOS、Windows 和 Linux 安裝包由釋出流程構建。

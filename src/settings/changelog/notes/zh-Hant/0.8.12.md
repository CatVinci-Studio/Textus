## 更新內容

- 正文寬度可在設定中選擇：預設「自適應」會在寬屏上加寬正文，字號隨之略微放大；也可選「標準」或「鋪滿」。
- 縮放時以滑鼠位置為錨點，正文不再上下跳動。
- 圖片後不再多出空行；圖片右側新增拖動手柄，可直接調整寬度。
- PDF 匯出：三個平台都直接生成 PDF 檔案，不再經過系統列印對話方塊。頁面邊緣不再裁切文字、公式和表格；macOS 和 Windows 上深色及帶底色的主題也能鋪滿整頁，沒有白邊。匯出的 PDF 和 HTML 中本地圖片可以正常顯示，標題前的 # 和程式碼塊的語言選擇框不再出現在匯出結果中。
- AI 對話面板：明確了展開與關閉的規則。純問答回覆自動展開，修改文件的回覆保持緊湊；快捷鍵先聚焦輸入框，再按一次關閉；Esc 在面板任意位置都可關閉；有未處理的修改時，關閉前會先確認。對話彈出到獨立視窗後，快捷鍵會切換到該視窗。
- AI 回覆支援完整的 Markdown 顯示，包括數學公式、表格、標題和任務列表；面板在寬屏上限制寬度並居中。
- OpenAI 模型更新為 GPT-6 系列（gpt-6-astra、gpt-6.1-sol、gpt-6-luna）；自動補全和語法檢查使用較低推理強度，響應更快。
- 統一正文各類塊的間距與圓角；程式碼塊的語言選擇移到右上角，行距恢復正常；Mermaid 圖表在原位置修改後會及時重新整理，甘特圖文字恢復可讀。
- 公式較多的長文件中，輸入和游標移動明顯更流暢。
- 切換原始碼模式和編輯模式時保留游標位置和滾動位置。
- 匯入的主題透過 `#write` 設定的 `max-width` 現在會生效；新增「自定義 CSS」，可在當前主題上做首行縮排、行距、字型等區域性調整，並可將當前主題匯出為 CSS 檔案。
- Linux：視窗改為與 Windows 相同的一體化標題欄，選單跟隨介面語言，單視窗時標題不再單獨佔一行，F11 可切換全屏。

macOS、Windows 和 Linux 安裝包由釋出流程構建。Linux 上匯出的 PDF 使用普通頁邊距，深色主題的上下邊距可能為白色。

## 更新內容

Textus 1.0.4 帶來可調整寬度的側邊欄和 PDF 頁碼，修復了 Windows 和 Linux 上的 PDF 匯出，並縮小了安裝包。

### 新增

- 拖動側邊欄的邊緣即可調寬或調窄，寬度會被記住。(#77)
- 開啟 **設定 › 編輯與外觀 › Markdown › 匯出時顯示頁碼**（預設關閉）後，匯出的 PDF 會帶上頁碼。(#68)
- 新增 **設定 › 通用 › 關於 Textus**，包含版本號、檢查更新以及 GitHub 和社群的連結。
- **幫助 › 加入社群** 會以你的語言開啟社群頁面，包含 Discord 以及中文 QQ 群和微信群。

### 改進

- 安裝包更小：Linux 版不到原來的一半。(#115)
- 更新了編輯器的依賴，其中兩個有安全公告。

### 修復

- 在 Windows 和 Linux 上，匯出的 PDF 使用白色背景和合適的頁邊距，頁面底部也不再丟行。(#68)
- 在 Windows 上按 `Ctrl + P` 會匯出 PDF，而不是列印視窗。(#68)
- 在 Linux 上用原始碼模式編輯時，文字保持清晰。(#61)

### 平台說明

- **Windows：** 可以開啟拖到視窗上的檔案，**檔案 › 開啟…** 也可以選擇任意檔案。(#78)

## What's new

Textus 1.3.0-beta.3 gives each split pane its own tabs, one rule for opening files, a plugin store with a page for every plugin, read-only documents and many editing fixes. A beta may still have rough edges - tell us on GitHub or Discord.

### New

- On a Mac, **Settings › Editor & Appearance › Export PDFs in light colors** exports a PDF on white in your theme's light colors while you keep writing in dark mode. Windows and Linux already print on white.
- **Settings › Editor & Appearance › Images on their own line** can sit them on the left instead of centered, in the editor and in HTML and PDF exports. The Markdown file is not changed. (#367)
- A tab's right-click has **Move to New Window**, on every desktop.
- On Windows, drag a tab out of the window to give it a window of its own, or onto another window's tabs to move it there, as on a Mac.
- On Linux, let a tab go outside the window to open it in a new window.
- The web editor at textus.catvinci.com/playground/ keeps several documents in your browser: switch, create and delete them from the document's name in the bar. **Open…** opens Markdown files from your computer, and **Save** (`Ctrl/⌘ + S`) writes back into the file. In a browser that can't, Save asks where or downloads the file.
- Edit › Paste as Plain Text (Cmd/Ctrl+Shift+V) pastes the clipboard's text as it is, without reading Markdown in it.
- A middle click closes a tab, and a tab's menu has Close Others, Close Tabs to the Left and Close Tabs to the Right. Tabs with unsaved changes stay open.
- The outline's menu (right-click it) has Expand All and Collapse All, and Option-click (Alt-click) on a heading's arrow folds or unfolds every heading at once.
- View › Read Only, or Read Only in a tab's menu, keeps a document from being changed: typing, paste, a drop, undo, AI edits and plugins alike. A small padlock beside the title shows it and turns it off. A file left read-only opens read-only again.
- File › Reopen Closed Tab (Cmd/Ctrl+Shift+T) brings back the documents closed in the window, the latest first.

### Improved

- The editor's right-click menu is shorter. What you clicked on comes first: in a table, Insert Row Below, Insert Column Right, then **Row ›** and **Column ›** for the rest. **Insert ›** and **Textus AI ›** open beside the menu. Select All and Find stay in the Edit menu and on their shortcuts.
- Split panes each have their own tabs, as in VS Code. A document opened goes into the pane you are in, a tab dragged onto the other pane moves there, and a pane's tabs reorder in its own bar. Closing a pane's last tab ends the split.
- A code block's language, **Copy** and a new **Select All** button sit together in its top-right corner.
- A code block's language is picked from the app's own menu, which you can search by typing, instead of the system's.
- Signing in with a Claude account is marked experimental: it isn't a sign-in Anthropic offers other apps. An API key is the dependable way.
- Copy puts the Markdown source in the clipboard's plain text, so GitHub, Obsidian, VS Code, chat apps and AI chats get the formatting as Markdown, while Word, Pages, mail and Notion still paste it formatted. Code copied from inside a code block is the code alone. Edit › Copy as Plain Text gives the words without the marks, for apps such as WeChat.
- **Get more** lists plugins as an app store does: each with its icon, what it does, who made it and how many people installed it, the most installed first (or the latest, or by name).
- A plugin opens a page of its own before you install it, with its pictures, its README and the permissions it will ask for. Its page in Settings shows the README once it is installed.
- Installing a plugin no longer opens its guide and closes Settings: **Install** turns into **Installed** where it is, so you can install several in a row.
- Plugin packs are gone from Get more; the most installed plugins come first instead.
- A search box above your installed plugins finds one by name, description or author. Make your own is gone from the list: ask Textus AI in Create mode for a plugin instead.
- Plugins can delete characters without copying them (`deleteChars` with `copy: false`), so a Vim mapping like `inoremap jj <Esc>` no longer leaves a "j" on the clipboard.
- The tab keys work as in a browser: Cmd/Ctrl+T opens a new tab in the window, whatever Settings says files open in, and Cmd/Ctrl+N a new window (it was Cmd/Ctrl+Shift+N). File › New File is now New Tab.
- Plugins can open the command palette with their own commands first and get back what was typed (`textus.ui.pick` with `commands`), so Vim's `:` opens the palette.
- Vim's flash labels the places after one letter instead of two.
- Plugin updates in Get more: the PDF Viewer zooms smoothly around the pointer, Zotero works with Zotero 10, and Graph View has a lean panel of filters and colour groups.
- On a Mac, while a plugin takes every key as a command (Vim's normal mode), the window types with a Roman keyboard, so an input method such as Pinyin doesn't catch the keys; your own input source comes back for typing.
- Vim's block cursor shows from the start, and in a tab opened later, not only after the first change of mode.
- [[Wikilinks]] read as the note's name, as in Obsidian; the brackets show while the caret is on one. `[[Note|text]]` shows its text.
- A document written with [[wikilinks]] suggests the Backlinks plugin once, in a note you can install it from.
- Four skills come with Textus now: Proofread, and Design a theme, Make a plugin and Make a skill. Expand, Tighten, Translate, Summarize and Check continuity are in Settings › Extensions › Skills › Get more; a profile that had them gets them installed from there once.
- Opening a file in a window follows one rule: a file already open comes to the front, an untouched blank document gives way to it, and anything else opens in a tab of its own. A click in the sidebar or File > Open no longer replaces the document you were reading. The "Open documents in" setting now only decides where files opened from outside Textus go.

### Fixed

- On Windows and Linux, Settings and the other menu commands open in the window you used them in, instead of in the first window you opened.
- On Windows, **Ctrl+,** opens Settings while you are typing in a document.
- Items a plugin adds to a file's right-click menu in the sidebar, a tab's right-click menu, or the top of its sidebar view now show up. Before, only the editor's own menu showed them.
- The window bar says "1 word" instead of "1 words".
- A plugin list's filter box in the sidebar, such as Tasks', is one line high instead of stretching down the sidebar.
- A click at the end of a line that ends in a [[wikilink]] puts the caret after the link: what you type next, and Enter, no longer go into it.
- The sidebar's top row, each pane's tab bar and the AI panel's header end on one line, and a row of tabs too long to fit no longer grows a scrollbar under it.
- A tab's right-click menu no longer leaves a gap before Read Only while it is off.
- A web page that doesn't load says so in its tab, with Reload and Open in Browser, instead of staying blank.
- A web page out of sight for five minutes is let go, and no more than three stay loaded: each takes a WebKit process of its own. Shown again, it loads its last address.
- Web pages on a Mac name themselves as Safari does, so sites such as Bilibili no longer turn them away as an old browser.
- A plugin's pages load its files by URL instead of inlining them: a window drawing a PlantUML block took close to 3 GB, and now takes under 200 MB. Charts, PDFs and Word documents open with far less memory too.
- Your own skills in Settings › Extensions › Skills read as the built-in ones do, name over command and description, with Write, Review and Create as small switches instead of a row of checkboxes.
- **Export for Publishing** renames the plugin's own commands and views along with its id, so the exported plugin loads in Textus. Before, they kept the old name and Textus refused the plugin.
- Line numbers in code blocks stay beside their lines when the document is zoomed in or out.
- Pasted code keeps its lines: code with Chinese comments or long lines no longer has some of its lines run together.
- A code block takes its new colours as soon as you pick its language, instead of after the next edit.
- AI completion no longer pops up while you type in a code block.
- The grammar check leaves code alone: code blocks aren't checked, and inline code no longer draws suggestions in the text around it.
- Backspace at the start of a later line in a quote joins it to the line above, instead of taking it out of the quote and splitting the quote in two.
- Backspace at the start of a code block, maths block or table, or Delete just before one, moves the caret there instead of pouring the block into the line beside it as plain text, or selecting the whole table so the next key replaced it. The line below the front matter no longer joins the front matter, and an empty line between two code blocks can be removed.
- Typing over, or deleting, a selection that starts in ordinary text and ends in a code block (or the other way round) keeps the code block, instead of turning its remaining lines into a paragraph.
- Delete at the end of a line before a quote or list joins their text, as Backspace does, instead of taking the quote's or list's first line out of it; before a callout it moves to the callout's text, keeping the callout.
- Enter at the end of a code or maths block inside a list adds a line to the block, instead of starting a new list item.
- Enter on a code line holding only indentation keeps you in the block: the line is left empty and the indentation carries on, so blank lines inside indented code (a Python function) no longer end the block. Enter on an empty line, or Cmd/Ctrl+Enter anywhere, still leaves it.
- A pasted quote, code block or maths block keeps its shape wherever it lands: a quote that starts with a list (`> - item`) no longer comes in as the bare list, code pasted on an empty list item or into a line of text is no longer flattened into that line, and the rest of the line stays out of the code.
- A table pasted on a new line takes that line, instead of leaving an empty line above it; pasted into a table's cell, its cells fill the table from that cell on, adding rows and columns where it runs past the edge, instead of breaking the table in two.
- Three backticks or `$$` typed on a list item's line, then Enter, start a code block or maths block in that item, instead of leaving the fence as text and starting a new item.
- macOS: Cmd+Backspace on a code block's first line deletes back to the line's start, instead of doing nothing and losing the next keys typed.
- With the caret on an AI suggestion, Cmd/Ctrl+Enter and Cmd/Ctrl+Backspace accept or reject it even in a quote or a code block, where the editor's own use of those keys came first.
- The right-click menu's Paste works as Cmd/Ctrl+V does: images, formatted text from other apps, kept line breaks and table cells, where it used to read only the text. On macOS it no longer asks for a second click on a "Paste" button.
- Backspace right after a link, or Delete right before one, takes one character of its Markdown source, as for bold or code, instead of deleting the whole link, its text and address, at once. The same for wikilinks, embeds and inline HTML.
- `---` or `___` and Enter make a rule with the caret on the line below it, as `***` does, instead of leaving an extra empty line; `---` followed by more text stays text.
- A file or tab dragged over a PDF or another plugin's view can be dropped there, and splits the window as it does over a document.

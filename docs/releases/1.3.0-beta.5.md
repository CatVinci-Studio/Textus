## What's new

Textus 1.3.0-beta.5 adds Copy Path, a picture viewer, Help › Report a Problem and the `textus` command on every system, reworks the plugin buttons, says errors in your language, and brings 1.2.6's fixes.

### New

- Copy Path in the File menu, a tab's right-click menu and the file tree's menu copies a document's full path, on every system.
- A picture opens in the zoomable viewer diagrams use, from the button in its corner or a double click: scroll or pinch to zoom, drag to move. (#428)
- Help › Report a Problem: say what went wrong, and Textus adds its version, your system, your plugins and recent errors, shown before anything is sent. Submit opens GitHub's bug form already filled in; Copy puts it all on the clipboard for a chat or an email. (#427)
- The `textus` terminal command now works on Windows and in the Linux AppImage too: `textus notes.md` opens the file in Textus, and the terminal gets its prompt back at once. Settings › General shows it as installed on every system.

### Improved

- Each plugin has one button with a menu beside it, the same in Get more and in your installed plugins: Install; once installed, Update when there is one, or Turn Off and Turn On, with Uninstall in the menu. An update shows on the button itself, and the back button is easier to find. (#431)
- Error messages now say what happened in your language: no permission for a file or folder, a file that's gone, a full or read-only disk, a file another program is using, no connection or a timeout, a file too large to open, a name that can't be used, a plugin too large to install, and pictures the AI couldn't make. The system's own message stays below when it adds something.

### Fixed

- Files dragged in from Finder, File Explorer or a Linux file manager open again; the drop went unnoticed. A dropped folder opens in the sidebar, as Open Folder does. (#429)
- Copy on a right-clicked picture copies it, and a copied picture pastes into other apps as the picture itself, with its Markdown for Markdown apps. (#428)
- A tab dragged onto the other pane's tab bar, along the bars or pulled down first, joins that pane where you let it go, and a tab pulled out of the bar no longer stays stuck on screen on Windows. (#426)
- New tabs and documents you open stay in the view you last switched to - source mode or split view - instead of going back to the rich editor each time. (#424)
- HTML tags written inside bold or italic, such as `**<u>words</u>**`, show their style instead of the raw tags. (#423)
- Get more shows each plugin's icon instead of its first letter. (#431)
- When an AI service's balance or quota runs out, Textus says so in your language and tells you where to top up or switch services, instead of calling it a rate limit.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

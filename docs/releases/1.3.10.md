## What's new

Textus 1.3.10 brings preview tabs, one View › Mode menu, the same scrolling in every mode and dragging that works everywhere; databases become Obsidian Bases, and plugins gain Canvas, Link Cards and Pomodoro.

### New

- **Preview tabs.** A click on a file in the sidebar opens it in a preview tab, its title in italics; the next file clicked takes its place, so looking through files no longer piles up tabs. Writing in it, double-clicking its tab or double-clicking the file keeps it.
- File icons for the common kinds - databases (`.base`), canvases, PDF, Word, spreadsheets, slides, audio, video, archives, code, data files, LaTeX, e-books and fonts - from the open-source Lucide set.
- Official plugins with it: **Workspace** keeps databases as Obsidian Bases (`.base` files and ` ```base ` blocks) with table, board, cards, list and calendar views, and **Notion Import** brings a Notion export over, page icons included; new **Canvas** (Obsidian canvases and Excalidraw drawings), **Link Cards** and **Pomodoro**; Tasks, Templates, Daily Notes (now weekly and monthly too), Quick Notes (kept in a file), Zotero (literature notes), Bookmarks and Graph follow an Obsidian vault's own files.
- What Textus AI made for you in Create shows a "Made with Textus AI" tag in Settings › Extensions, among your plugins, themes and skills.
- Your own skills can be deleted from Settings › Extensions › Skills; their files go to the Trash.
- Research can hand a narrower part of a question (a case, a data set, a dispute) to a helper of its own. Off unless turned on in Settings › Textus AI: it is more thorough, but slower and makes more model calls.
- The Files tab has New Document and New Folder buttons beside its name, and you name the new item right in the list. Double-click the empty space below the files for a new Markdown document; right-click › New Document and New Folder name in place too.
- Settings › Textus AI › Research: check each cited sentence. Before Research revises its draft, every cited sentence is compared with its sources' notes and one that overstates them is rewritten. Off by default: it adds one model call per section. (#596)
- Plugins can claim Markdown documents by their front matter (`customEditors[].frontMatter`): a board saved as a plain `.md` with `kanban-plugin: board` opens as a board, as Obsidian's Kanban files do.
- **Settings › Editor › Embedded notes**: show `![[note]]` embeds in full, as before, or as a card each that opens on a click.

### Improved

- A plugin version that needs a newer Textus is never installed by an update: the version you have keeps working, and the store shows **Needs Textus X.Y.Z** instead of Install until Textus is updated.
- Themes, Custom CSS and a document's HTML can no longer load scripts or reach the web by themselves. Web fonts in a theme or in Custom CSS still show: Textus fetches them and keeps them with the theme, so they also work offline afterwards. Copy Picture on a web picture now copies the picture from any site.
- Source and split views colour their Markdown: headings, emphasis, links, quotes and fenced code read the way they do in the rendered document, instead of one flat grey.
- Icons, the title bar, the tabs and the sidebar's tabs grow with Settings › Interface Text Size, and in a straight line with the window's width (up to 1.35× on a wide or full-screen window), instead of staying small on a large screen.
- Clipboard History is now an official plugin (Settings › Extensions) instead of part of Textus itself. If you used it, Textus offers the plugin once; the old list stays behind.
- Research checks its notes against what the sources said: a quote that isn't in the page is refused, a figure the source doesn't give is sent back (1,200 and 1200, 3,5 % and 3.5 %, 1.2万 and 12,000 count as the same), and a note resting on an address that was never read is written as someone's claim, not as fact. A section's cited figures must come from its notes. Thanks to @jzzzzh. (#596)
- Settings › Extensions › Plugins has **Update All** beside the installed plugins' title when two or more have updates; one that can't be updated is named afterwards, the rest still update.
- Source mode edits as plain text again, now with colours: Enter still continues a list or quote, as in the rendered view, but HTML tags aren't closed as typed, a pasted URL isn't made a link, Tab moves the focus instead of indenting, and there are no line or word highlights, extra carets or code-editor shortcuts.
- In Source and Preview, the preview draws what plugins draw (charts, mind maps, databases) as the rendered view does, instead of their source.
- A block a plugin draws (a database, a chart) no longer opens its source underneath when the caret passes: the arrow keys step over it, and its source shows only from the block's </> button, until the caret leaves.
- A database or another plugin's block inside an embedded note shows as one line with the plugin's name; click it to draw it.
- Scrolling is the same in every mode: source mode and the preview of Source and Preview give at either end on a Mac, as the rendered view does, and every mode leaves room under the last line so it can come up to the middle.
- **View › Mode** holds the four ways to see a document - Default, Source, Source and Preview, and Reading Mode (Read Only before) - one at a time, with Track My Changes, Zen and Typewriter beside them to add on. Their keys work as before: pressing one again goes back to Default.
- The **Plugins** menu puts a plugin's commands in a submenu of its name when it has several.
- The sidebar's tabs can be **dragged** into the order you like.
- **Settings › Extensions › Create**: Textus AI checks a plugin it wrote before handing it to you - its manifest, the permissions its code needs, what it declares but never sets up, the Textus it needs - and fixes what it finds.

### Fixed

- In Source and Preview, the preview follows what you type in the source again; since 1.3.9 it only caught up after switching modes. Thanks to @new-Beginner for the report (#561).
- Get Plugins and plugin installs try once more when the connection drops or times out halfway, and say so plainly instead of "error decoding response body" (#580).
- A plugin drawn in a document (a database, a chart, a mind map) follows the document's zoom: sharp, as wide as the column, without its toolbar wrapping or its right side cut off on the Mac. A pinch or ⌘-scroll over it zooms the document as anywhere else.
- Source mode scrolls like the rendered view: its scrollbar at the pane's edge, not beside the column, and zoomed text sits where the rendered text does instead of off to one side.
- A read-only document asks Textus AI for no completions.
- In source mode and split view, Esc in the file search puts the keyboard back in the source editor, not nowhere or the preview.
- A plugin's menu - a database column's, its filter - opens where it was clicked in a zoomed document, not scaled off to the side.
- The start page and **File › Open Recent** leave out folders and files that have been deleted; one on a drive that isn't plugged in comes back when it is.
- A fast flick into either end of a document no longer stops before it bounces, and pulling again while a document springs back no longer makes it jump.
- Dragging to reorder works in the app: the sidebar's tabs, the pages tree, and the lists and cards of Task Board and database boards. The others make way as an item passes, and it stays where it is let go. (The window's own file drop used to take these drags: a copy cursor and nothing moved.)
- Plugin pages no longer open the system's right-click menu (text fields keep it).
- Menus put the check at the end of a row, so every label starts in the same place.
- Names sort by number value - Week 2 before Week 10 - in plugin menus, Settings › Plugins, the store and the skill picker.
- The web page's handle, with its address bar hidden, sits at the right where the hide button was.
- A plugin list's scrollbar in the sidebar shows only under the pointer, like the sidebar's own.

### Platform notes

- Plugin API 1.3: `textus.env.onDidCopy` tells a plugin with the `clipboard` permission what the user copies or cuts in a document, as Markdown.
- Plugins: `layout.showSidebarTab(id)` opens the sidebar on a tab, and a list's provider can take `onMove(item, target)` for rows dragged onto one another (docs/dev/plugins/reference.md).
- Plugins: `layout.panels()` and `layout.onDidChangePanels` tell which of the window's panels are open - the sidebar (and its tab) and Textus AI's - read only.
- Plugin pages can drag with pointer events and Textus's `tx-drag-ghost` / `tx-drag-source` styles; HTML drag and drop inside a page is taken by the window's file drop.
- Plugins: `textus.dates` (Moment-style `format` and `parse`) and `textus.templates.fill` (Obsidian's `{{date}}`/`{{title}}` templates and Templater's common tags, in the folder's formats) - no permission, nothing leaves the plugin. `files.appSettings("obsidian", file)` reads the nearest vault's own settings files, also above the open folder. The folder's conventions name its Templates date and time formats and its weekly and monthly notes, and an Obsidian vault with no daily notes settings keeps them at its top, as Obsidian does. The plugin API is 1.4.
- Plugins: writing files includes reading them; Textus names, before installing a plugin, a completion without `editor.read` and a menu condition it never sets. The plugin documentation is in `docs/dev/plugins/`, with a skill an AI coding assistant can load.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

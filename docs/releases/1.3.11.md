## What's new

Textus 1.3.11 writes new links as standard Markdown links that open in any app, and fixes preview tabs, which took no clicks in 1.3.10.

### Improved

- New links are standard Markdown links by default, by the path from the note - `[Nov 8](Week45/Nov%208.md)` - which open in any app: a page or database made from the pages tree, a note picked after `[[`. A folder that chose `[[wiki links]]` (Two-way Links › New Links), an Obsidian vault, and a note that already links that way keep them, so a page never mixes the two; a `[[link]]` that needs a path to find its note shows the note's name, not the path.

### Fixed

- A preview tab, its title in italics, can be clicked and closed again; since 1.3.10 it took no clicks, so it could neither be brought back to the front nor closed.
- A click in the middle of a tab with a short name opens it instead of closing it: the close button sits at the tab's end.
- Typing `-[]`, `-[x]` or `-【】` at the start of a line that already has words in it makes the line a task, its words the task's text, as `[]` does at the start of a list item; before, only an empty line became one.
- Clicking into a link no longer draws the caret a character off for a moment while the link's source appears around it.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

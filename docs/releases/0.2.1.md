## Auto-update

Levis now updates itself. The app checks GitHub Releases at startup (and every 4 hours while running); when a newer version exists, a small notice appears with an **Update & Restart** button. Downloads are signature-verified before installing, and nothing installs without your click.

This is the first release carrying the updater, so 0.2.0 and earlier still need a manual download - every release from here on arrives automatically.

## What's new

Textus 1.2.0 is about working across many files without disturbing the ones you open: it saves only the parts of a file you edited, opens whole folders with a search for their file names, follows Obsidian wikilinks and links to headings in other files, and reopens documents where you left off. It also adds Quick Notes - a small window for writing something down from any app, saved as a Markdown file the moment you close it - with an optional background mode and tray icon, Revise rewrites that appear sentence by sentence as Textus AI writes them, shortcuts for switching tabs and setting headings, a size for the interface text, a copy button and line numbers for code blocks, colour swatches beside colour codes, and a choice of diagram engine.

### New

- Opens a Quick Note window with **File › New Quick Note**, with a global shortcut you turn on in **Settings › General › Quick Notes** (`⌃⌥N` on macOS, `Ctrl + Alt + N` on Linux, `Win + Alt + N` on Windows; off by default, changeable, and listening for that one combination only), or with `textus --quick-note`. `Esc`, `Ctrl/⌘ + Enter`, `Ctrl/⌘ + S`, `Ctrl/⌘ + W`, the close button and quitting all save the note and close the window; an empty note closes without writing anything, and **Discard** asks before throwing one away. (#193)
- Saves each quick note as its own file in `Textus/Quick Notes` in your Documents folder, named after its first line (or the time, when that is empty), or with **One file per day** adds it to that day's `YYYY-MM-DD.md` under a `## HH:MM` heading; the folder can be changed. (#193)
- Continues the last quick note when you open one again within a few minutes of saving - five by default, adjustable, or never - so a thought you forgot to finish goes into the same file. (#193)
- Keeps what you type in a quick note as a draft while you write, and brings it back with a notice if the window closed before it could save. (#193)
- Saves the quick note and opens it as a tab with **Open in Textus**, and opens the Quick Notes folder in the sidebar with **File › Open Quick Notes Folder** (**Settings › General › Quick Notes** still shows it in the file manager). (#193, #152)
- Keeps Textus running after you close its last window, with an icon in the notification area, the system tray or the menu bar, once you turn on **Settings › General › Background › Keep running in the background** (off by default). The icon's menu has **New Quick Note**, **Open Textus** (which brings back the documents you had open), **Open Quick Notes Folder**, **Settings…** and **Quit Textus**; turning the setting off removes the icon at once. With no window open, Textus keeps no page loaded and runs nothing in the background. (#244)
- Starts Textus in the background when you log in, without a window, once you turn on **Settings › General › Background › Open at login** (off by default, and only with background mode on). (#244)
- Opens a whole folder in the sidebar with **File › Open Folder…**: the file tree stays rooted there while you open documents inside it, the folder comes back with your session and appears under **File › Open Recent**, and **File › Close Folder** returns the tree to following the document. (#152, #79)
- Searches file names across the opened folder from a box at the top of the sidebar's **Files** tab - documents listed first, then other files, or documents only with the filter beside the box - skipping what `.gitignore` leaves out and folders such as `node_modules`: type to filter, `↑`/`↓` to move, `Enter` to open, `Esc` to clear; `Ctrl/⌘ + Shift + O` jumps there (changeable in **Settings › Shortcuts**). (#196)
- Reads Obsidian wikilinks - `[[Note]]`, `[[Note|text]]` and `[[Note#Heading]]` - as links: `Ctrl/⌘ + click` opens the note (at the heading, if one is named) from the same folder or anywhere in the vault, and they, like `#tags` at the start of a line, are saved as written instead of as `\[\[Note]]` and `\#tag`. (#234)
- Opens a link to a heading in another file, `[see](./notes.md#heading)`, at that heading when you `Ctrl/⌘ + click` it - in a new tab, or the tab the file is already open in - instead of at the top of the file. (#233)
- Reopens a document with the caret where you left it, and scrolled there, when Textus restores your last session or you pick it from **File › Open Recent**, as long as the file hasn't changed since; with **Settings › General › Restore previous session on startup** off, documents open at the top as before. (#218)
- Adds **Next tab** and **Previous tab** shortcuts, `Ctrl + Tab` and `Ctrl + Shift + Tab` on every platform (and `⌘ + Shift + ]` / `⌘ + Shift + [` on a Mac), and shortcuts for **Heading 1** to **Heading 6** and **Paragraph**, which start unbound and can be set in **Settings › Shortcuts**, for example to `Ctrl/⌘ + 1` to `6` as in Typora; the same page now lists the shortcuts that can't be changed, such as save, zoom, bold and italic. (#214)
- Adds **Settings › Editor & Appearance › Interface text size** - 90%, 100%, 110% or 125% - which enlarges or shrinks the text of the sidebar, the outline, the tabs, the AI panel and its window, menus and Settings, while the document keeps its own zoom. (#150)
- Adds a **Copy** button beside a code block's language picker, which copies the block's code, and line numbers for code blocks, turned on in **Settings › Editor & Appearance › Line numbers in code blocks**; with them on, long lines scroll sideways instead of wrapping, so each number stays beside its line. Neither the button nor the numbers appear in a PDF, an export or a printout. (#233)
- Shows a small square of the colour before inline code that is a colour, such as `#ff8800`, `rgb(0 128 255)` or `hsl(120 50% 50%)`, once you turn on **Settings › Editor & Appearance › Colour swatches in inline code**; colour names like `red` stay plain, and the swatches stay out of exports and printouts. (#146)
- Adds **Settings › Editor & Appearance › Diagram engine**: Mermaid, as before and by default, or [Pele](https://pele.run), which draws the same ` ```mermaid ` blocks faster, from a much smaller download, and follows a switch of appearance or theme without redrawing, but lays diagrams out its own way and leaves out a few features, such as HTML in labels. A diagram Pele can't draw is drawn by Mermaid, and the editor, split view and every export use the engine you chose. (#242)

### Improved

- Saves only the blocks you edited: every other paragraph, heading, list and table is written back exactly as it was in the file, so a file you also keep in Git or edit in another app shows a small diff instead of being reformatted throughout. (#234)
- Shows a Revise rewrite sentence by sentence while Textus AI is still writing it: each sentence appears in its place as it is written, the original it replaces struck beside it and the sentences it keeps left as they are, instead of the whole passage struck with the new text streaming after it and the sentences laid out only at the end; nothing moves when it is done, and **Stop** keeps the sentences it finished and leaves the rest of the passage as it was. (#243)
- Makes the revision animations calmer and alike: new text, strikes and the ✓ / ✕ fade in with one timing, in quick succession rather than one by one, without blur or bounce, and accepted text fades from green where it now stands instead of switching at once. (#243)
- Updates a document open in a window when a quick note is saved into it: a tab without unsaved changes shows the new text at once, one with unsaved changes takes in a note added to the end of the day's file, and otherwise **Save** says that a quick note would be overwritten before it lets you. (#193)
- Uses a folder you open as Textus AI's project folder, unless you already chose one for the AI. (#152)
- Sorts the file tree and the search results the way your file manager does: numbers by value (`file2` before `file10`, `第2章` before `第10章`) and names in the order of the interface language. (#230)

### Fixed

- Keeps reference links, `[text][ref]`, and their `[ref]: url` definitions, which the first save after an edit turned into inline links and deleted. (#234)
- Reads the lists and quotes in a file that opens with a `---` rule as lists and quotes, instead of as plain text that an edit then saved with escapes. (#245)
- Keeps brackets in a link's text, as in `[Tech [Episodes]](…)`, when you edit its paragraph, instead of saving them in a form that read back as maths. (#245)
- Keeps a link around bold or italic text as one link when you edit its paragraph or make a word in it bold, instead of saving it as three links. (#245)
- Saves bold and italic text as it reads after you delete or format words in it: deleting its last word no longer leaves stray `**` or `*` in the file, and a word made bold next to bold text, or two code spans or formulas left side by side, no longer run together. (#245)
- Saves a line of text that starts with `# `, `- ` or `1. ` as text, instead of as a heading or a list item once the word after it is deleted or made bold. (#245)
- Keeps a paragraph whole when you delete the only word on one of its lines or a `<br>` ends a line, and no longer saves a line break at the end of a paragraph as a stray backslash. (#245)
- Keeps the `<br>` tags in your file as you wrote them when you edit elsewhere in the document. (#245)
- Keeps the rest of a list item in the item when you delete its first line, a rule inside a list item a rule, and the `#` that ends a heading such as `## Item #`. (#245)
- Keeps the file tree where it was, with its folders still expanded, when you open a document from one of its subfolders - it used to jump into that subfolder. (#152)
- Tints only the text of a proposal that runs over several lines, not the line breaks in it: hard breaks and the blank line between two paragraphs no longer get a stub of green at the line end or on the empty line, under the pointer neither, and a rewrite after a hard break no longer strikes one character too many or is shown as one block. (#243)

### Platform notes

- **macOS:** The Quick Note window opens on the Space you are on, over a full-screen app too, and closing it takes you back to the app you were in. Textus keeps running after its last window closes, so the shortcut works until you quit. Background mode adds a Textus icon to the menu bar, drawn in the menu bar's own colour; clicking it opens its menu. (#193, #244)
- **Windows:** The default Quick Note shortcut is `Win + Alt + N`, not `Ctrl + Alt + N`, because Windows reads `Ctrl + Alt` as AltGr, which types letters on many keyboard layouts; if OneNote or another app holds the combination, Settings says so and you can choose another. In background mode, clicking the icon in the notification area opens a quick note, and right-clicking it opens its menu. An update, and an installer run by hand, close a Textus that runs in the background before they install. (#193, #244)
- **Linux:** On Wayland no app may register a global shortcut; Settings shows the exact `--quick-note` command to bind to a key in your desktop's settings, which also opens a quick note while Textus isn't running. The tray icon needs libayatana-appindicator, which the `.deb` now installs and the AppImage carries; without it Textus still keeps running in the background, and Settings says the icon can't be shown. GNOME shows tray icons only with the AppIndicator extension. The `.deb` and `.rpm` now describe Textus in `apt show` and `rpm -qi`, and the `.rpm` names its MIT license. (#193, #244, #239)
- **iPhone and iPad:** Quick Notes, background mode, Open Folder and the file-name search are on the desktop only; the sidebar works as before.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

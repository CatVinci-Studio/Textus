## What's new

Textus 1.2.0 makes Textus AI do more and the editor feel better. Textus AI can search the web with every provider and cite its sources, think harder at the press of a button, make images, read long files, PDFs, Word, slides, spreadsheets and pictures in your folder, learn from the edits you turn down, and be switched off entirely in one click; Doubao joins the providers. The editor opens whole folders, saves only what you edited, follows wikilinks and links to headings, opens Word documents as Markdown, reveals links for editing in place, closes brackets and quotes for you, and stays quick in very long documents. Settings gained a search box, and Textus works with screen readers, the keyboard alone and high contrast, and on older Windows machines.

### New

- Keeps Textus running after you close its last window, with an icon in the notification area, the system tray or the menu bar, once you turn on **Settings › General › Application › Keep running in the background** (off by default). The icon's menu has **Open Textus**, which brings back the documents you had open, and **Quit Textus**; turning the setting off removes the icon at once. With no window open, Textus keeps no page loaded and runs nothing in the background. (#244)
- Opens a whole folder in the sidebar with **File › Open Folder…**: the file tree stays rooted there while you open documents inside it, the folder comes back with your session and appears under **File › Open Recent**, and **File › Close Folder** returns the tree to following the document. (#152, #79)
- Opens a Word document (`.docx`) - picked in **File › Open…**, dropped on the window or handed over by your file manager - as a new Markdown document of the same name, not yet saved: headings, lists with their numbers, tables, bold, italic, links, footnotes and pictures come along, and text that only looks like Markdown, such as `*`, `#` or `$5`, stays text. A quiet notice says some formatting may look different. The first **Save** suggests a `.md` file next to the Word file and moves the pictures into the image folder of **Settings › Images**, as it does for pasted ones; the Word file itself is never changed. (#296)
- Searches file names across the opened folder from a box at the top of the sidebar's **Files** tab - documents listed first, then other files, or documents only with the filter beside the box - skipping what `.gitignore` leaves out and folders such as `node_modules`: type to filter, `↑`/`↓` to move, `Enter` to open, `Esc` to clear; `Ctrl/⌘ + Shift + O` jumps there (changeable in **Settings › Shortcuts**). (#196)
- Reads Obsidian wikilinks - `[[Note]]`, `[[Note|text]]` and `[[Note#Heading]]` - as links: `Ctrl/⌘ + click` opens the note (at the heading, if one is named) from the same folder or anywhere in the vault, and they, like `#tags` at the start of a line, are saved as written instead of as `\[\[Note]]` and `\#tag`. (#234)
- Opens a link to a heading in another file, `[see](./notes.md#heading)`, at that heading when you `Ctrl/⌘ + click` it - in a new tab, or the tab the file is already open in - instead of at the top of the file. (#233)
- Reopens a document with the caret where you left it, and scrolled there, when Textus restores your last session or you pick it from **File › Open Recent**, as long as the file hasn't changed since; with **Settings › General › Restore previous session on startup** off, documents open at the top as before. (#218)
- Adds **Next tab** and **Previous tab** shortcuts, `Ctrl + Tab` and `Ctrl + Shift + Tab` on every platform (and `⌘ + Shift + ]` / `⌘ + Shift + [` on a Mac), and shortcuts for **Heading 1** to **Heading 6**, `Ctrl/⌘ + 1` to `6` as in Typora, shown beside them in the **Format** menu, and for **Paragraph**, which starts unbound. All of them can be changed in **Settings › Shortcuts**, where **Reset** puts a changed one back; the same page now lists the shortcuts that can't be changed, such as save, zoom, bold and italic. An action already using one of these keys keeps it, and that heading level starts unbound instead. (#214)
- Adds **Settings › Editor & Appearance › Interface text size** - 90%, 100%, 110% or 125% - which enlarges or shrinks the text of the sidebar, the outline, the tabs, the AI panel and its window, menus and Settings, while the document keeps its own zoom. (#150)
- Adds a **Copy** button beside a code block's language picker, which copies the block's code, and line numbers for code blocks, turned on in **Settings › Editor & Appearance › Line numbers in code blocks**; with them on, long lines scroll sideways instead of wrapping, so each number stays beside its line. Neither the button nor the numbers appear in a PDF, an export or a printout. (#233)
- Shows a small square of the colour before a colour code, as you choose in **Settings › Editor & Appearance › Swatches before colour codes** (off by default): **In code only** draws it in inline code that is a colour, such as `#0af` or `rgb(0 128 255)`, and before the colour literals in code blocks; **Everywhere** also before a six- or eight-digit hex code or a colour function written anywhere in the text of a paragraph, heading, list, quote or table, such as `#ff8800`, `hsl(120 50% 50%)` or `oklch(70% 0.1 150)`. Short codes in the text, tags like `#cafe`, issue numbers like `#234`, colour names like `red` and links stay plain; the swatches are never part of the text, so they aren't saved, copied or printed, and stay out of exports. (#146)
- Adds **Settings › Editor & Appearance › Diagram engine**: Mermaid, as before and by default, or [Pele](https://pele.run), which draws the same ` ```mermaid ` blocks faster, from a much smaller download, and follows a switch of appearance or theme without redrawing, but lays diagrams out its own way and leaves out a few features, such as HTML in labels. A diagram Pele can't draw is drawn by Mermaid, and the editor, split view and every export use the engine you chose. (#242)
- Adds a **Deep thinking** button, the light bulb beside web search in the AI panel and its window, which asks the model to think a request through before it answers - slower and costlier, for hard questions and long rewrites. It stays on, across conversations and documents, until you press it again, and appears only for models that can think harder; Quick Ask asks for a quick answer instead.
- Shows "Thinking · 8 seconds" above a reply while the model thinks, then "Thought for 12 seconds", which opens to the reasoning where the provider shares it; the reasoning is never kept with the conversation. Which thinking settings each model takes now comes from [models.dev](https://models.dev), and a provider that refuses them gets the request again without.
- Lets Textus AI read the PDF, Word, PowerPoint and spreadsheet files in its project folder and search their text, and, with a provider that can see images, look at the PNG, JPEG, GIF and WebP images there, up to 6 MB each. (#261)
- Adds **Doubao (Volcengine)** - 豆包（火山引擎）in Chinese - to the providers in **Settings › Textus AI**, served by Volcengine Ark: Doubao Seed 2.1 Pro for chat, which reads attached images and can edit the document, and Seed 2.1 Turbo, with its thinking turned off, for completion and grammar. Create the API key in the Volcengine Ark console and enable the models there. (#263)
- Learns from your revision choices: when you turn down the same kind of change several times across proposals - 「」 made “”, one word swapped for another, sentences split, an Oxford comma added - Textus AI offers, once the review is done, to remember it as a requirement, with **Remember**, **Not now** and **Never ask for this**. Remember saves it under **AI remembered** in the Memory tab, where you can delete it; Textus AI asks at most once a day and saves nothing without your click. Only the kinds of change you accepted or rejected are noted, on this computer, and they are never sent.
- Lets Textus AI make pictures for a document once you choose an **Image model** in **Settings › Textus AI** - OpenAI, Google Gemini, Doubao (Volcengine), Alibaba Qwen, Zhipu GLM, SiliconFlow or an OpenAI-compatible endpoint; it is **None** by default, and a service you already use for chat needs no second key. Ask for one in Write or Revise mode, or right-click a paragraph and choose **Illustrate this paragraph**: the picture appears in place as a proposal, is saved only when you accept it, into the image folder or up to the image host as **Settings › Images** says, and leaves nothing behind when you reject it; when the service turns a description down, the AI panel shows its reason. (#194, with ideas from #221)
- Searches the web with every AI provider: models that search by themselves (OpenAI, Claude, Grok, OpenRouter, Groq, Qwen, Zhipu GLM) use their own search, and for the rest - DeepSeek, Gemini, Mistral, Kimi, local models and custom endpoints - Textus searches on the **Search service** under **Settings › Textus AI › Textus AI Chat › Web search**: **Automatic** uses a DeepSeek, Zhipu or Kimi key you already have, or pick Bocha, Tavily, Brave Search or Exa with a key of their own, or your own SearXNG server. Textus AI can also read a web page or PDF whose address you give it - from the public web only, never from your computer or local network - and the Web search button shows a red dot when there is nothing to search with. (#278)
- Lists the pages a reply cites under it, numbered [1], [2] the same way for every provider and for the whole conversation; click one to open it in your browser. A proposal that draws on the web has **Add sources as footnotes** on its card, which adds them as Markdown footnotes at the end of the document when you accept it. (#278)
- Adds a search box to Settings, above its categories: type a word and every page's matching settings are listed by page - names, group titles, More themes and About Textus, the shortcut list, and the explanations behind the **?** - ignoring case, accents and full-width letters. `↑`/`↓` move, `Enter` or a click opens the setting's page with the setting picked out for a moment, and `Esc` clears; `Ctrl/⌘ + F` reaches the box while Settings is open.
- Turns all of Textus AI off from its button at the right end of the window bar, the app icon's quill as a silhouette, instead of the robot: right-click it to pause Textus AI for an hour or to turn it off, and while it is off the quill is struck through and a click offers to turn it back on; a pause ends by itself. **Settings › Textus AI › Enable Textus AI** (on by default), a shortcut you can set in **Settings › Shortcuts** and the iPhone's menu turn it on or off too. While it is off, nothing is sent to any AI service, from the moment Textus opens: no completion, grammar check, conversation or memory; the AI panel, Quick Ask and the AI items of the right-click menu go away, and a reply still being written stops. Edits already proposed stay to accept or reject, and each feature keeps its own setting for when Textus AI is back on. (#196)
- Brackets and quotes close themselves, as in Typora: typing `(`, `[`, `{`, a quote, or `（`, `【`, `「`, `“` from a Chinese or Japanese input method puts the closing partner in after the caret. Typing the closer steps over it, Backspace right after the opener removes both, and with text selected the pair goes around it. Nothing is added inside code, maths or a web address, before a word, or for an apostrophe as in "don't". Turn it off in **Settings › Editor & Appearance › Close (), [] and “”**.
- Shows a link as its Markdown while the caret is on it, as Typora does: click a link, or move onto it with the arrow keys, and `[text](url)` - or `[text](url "title")`, `[text][ref]`, `<https://…>`, a bare URL - is there to edit, text and address alike; move the caret away and it is a link again, with what you changed, or plain text if it is no longer a link. `Ctrl/⌘ + click` still opens it, a link you only looked at is saved exactly as it was, and an edited one as you typed it.

### Improved

- Lets **Academic polish** (`/academic`, 学术润色) work on grant proposals as well as papers and theses: besides formal wording, units and citation formats, it now cuts boilerplate openers, hype, empty intensifiers and over-claiming verbs, keeps each claim no stronger than its evidence and the hedges the evidence calls for, checks a proposal's aims against what makes them feasible (NSF, NIH, 国自然), and leaves every number, equation, citation and cite key as written. Each change comes as a proposal, with a short report of what changed in the reply; it improves the writing and is not a way around an AI-use disclosure. Adapted from [academic-humanizer](https://github.com/AIScientists-Dev/academic-humanizer) (MIT), which builds on [humanizer](https://github.com/blader/humanizer).
- Saves only the blocks you edited: every other paragraph, heading, list and table is written back exactly as it was in the file, so a file you also keep in Git or edit in another app shows a small diff instead of being reformatted throughout. (#234)
- Shows a Revise rewrite sentence by sentence while Textus AI is still writing it: each sentence appears in its place as it is written, the original it replaces struck beside it and the sentences it keeps left as they are, instead of the whole passage struck with the new text streaming after it and the sentences laid out only at the end; nothing moves when it is done, and **Stop** keeps the sentences it finished and leaves the rest of the passage as it was. (#243)
- Makes the revision animations calmer and alike: new text, strikes and the ✓ / ✕ fade in with one timing, in quick succession rather than one by one, without blur or bounce, and accepted text fades from green where it now stands instead of switching at once. (#243)
- Counts and shows a Revise rewrite's changes while Textus AI is still writing it: the review bar is there from the start, its count growing one change at a time, each change gets its margin card the moment it is complete, and ‹ › and the view menu already work; **Accept** and **Reject** wait until the rewrite is in, or until you press **Stop**. (#258)
- Keeps up with the pointer while you drag the edge of the sidebar or the AI panel, and opens and closes the AI panel with less work: neither recalculates the style of every element in the window on each step any more. (#284)
- Slides the text aside in one movement when the margin cards need room, instead of laying the whole document out again on every frame; cards glide to their new places when the stack moves them, a note's buttons take their room at once and fade in instead of growing the card a frame at a time, and a card is drawn again only when what it shows changes, not each time a streaming rewrite changes the text. (#284)
- Uses a folder you open as Textus AI's project folder, unless you already chose one for the AI. (#152)
- Gives Textus AI a Word, PowerPoint or spreadsheet file, attached or in its project folder, with its structure - headings, numbered and bulleted lists, tables, bold, italic, links and footnotes, one section per slide with its speaker notes, and dates in a sheet as dates - instead of as flat text, and reads EPUB e-books and RTF files there too, and HTML files as attachments. (#271)
- Looks through Textus AI's project folder the way the sidebar's file search does - skipping what `.gitignore` leaves out, and seeing a large folder whole instead of its first 2,000 files - and lets it find a file by name instead of listing every file.
- Lets Textus AI read a long file in its project folder, such as a whole manuscript of up to 16 MB, a part at a time, starting where a search found what it needs, instead of refusing every file over 100 KB. (#261)
- Keeps Textus AI from spending a whole request checking its own work: it measures a draft against a length you asked for, or checks its conventions, only a few times, is told when it is down to its last steps so it proposes and replies in time, and asks again on its own when a provider's reply arrives with broken characters (�) instead of showing them or putting them into your document. (#264, with ideas from #221)
- Sorts the file tree and the search results the way your file manager does: numbers by value (`file2` before `file10`, `第2章` before `第10章`) and names in the order of the interface language. (#230)
- Names each row in Settings by what it does, such as **Show page numbers in exports**, and drops the grey lines that used to sit under the rows; the few explanations a label can't carry, such as the diagram engine's trade-off and the image host fields, sit behind a small **?** beside the label, which shows them on hover, a click or a tap. What is live - a missing tray, no room for the margin - still shows under its row.
- Keeps the theme rows of **Settings › Editor & Appearance** to choosing - the appearance and the editor theme - and gathers the rest on one page, **More themes**: **Browse themes**, **Add a theme from a CSS file** and **Custom CSS** with **Export as CSS…**, each in one place instead of mixed in among the choices.
- Explains the icon-only buttons - in the AI panel's message box, the window bar, the sidebar, the tabs, the AI panel's header, the review bar and the find bar - with a tooltip in the app's own style, shown when the pointer rests on one or the keyboard moves to it, instead of the system's, which on Linux came late or not at all. **Deep thinking** now says what it does, and, like **Web search**, says when it is on.

The **When copied to other apps** setting is gone; **Edit › Copy as Markdown**, also in the editor's right-click menu, copies the Markdown source, for anyone who had that setting on Markdown source.
- Loads the maths renderer only for a document or reply that has a formula, so Textus opens with about 260 KB less to load; a document with maths still opens with its formulas drawn, and the split view, exports and AI replies draw them as before. (from #221)
- Works with a screen reader: the editor is a text box named **Document**, the window has landmarks for the sidebar, the document and the AI panel, and Textus AI says when it starts and finishes writing, how many changes it proposes, which one the review bar points at and how many you accepted or rejected. A proposed change reads as a deletion and an insertion, a margin card says what it replaces, the sidebar's file search is a list you move through with `↑`/`↓`, and the buttons drawn only as an icon - a tab's close button, **+**, the unsaved dot, a code block's language - are named in every interface language.

- The sidebar opens on the tab you left it on - Files, Outline or Clipboard - instead of going back to Files on every launch and in every new window. (#196)
- Keeps a long document quick to work in: typing, Enter and Textus AI's reads of it no longer go over the whole document each time, formulas, diagrams and pictures far from the screen are drawn as you scroll towards them, and autocomplete, grammar check and live diagrams stay on in documents of up to about a million and a half characters instead of turning off at a hundred thousand. In a document of 5,000 paragraphs, Enter went from over half a second to a few hundredths and opening takes about half as long. (#274, #277, #283, #285, #295, #307, #309)
- `_italic_` typed with underscores becomes italic and is saved as `_italic_`, instead of staying text saved as `\_italic\_`; `snake_case` and other underscores inside a word stay as they are.
- Tab and Shift+Tab in a table put the caret at the end of the next or previous cell's text, instead of selecting the whole cell, which the next key typed replaced.
- Shift+Enter in a table cell starts a new line in the cell, saved as `<br>` and shown as a line break again when the file is reopened. It used to do nothing.

### Platform notes

- **macOS:** Background mode adds a Textus icon to the menu bar, drawn in the menu bar's own colour; clicking it opens its menu. (#244)
- **Windows:** In background mode, clicking the icon in the notification area opens Textus, and right-clicking it opens its menu. An update, and an installer run by hand, close a Textus that runs in the background before they install. (#244)
- **Windows:** Textus works with WebView2 from version 105 (2022) on, so a computer whose WebView2 doesn't update, such as in a school lab, still gets the whole interface. (#260)
- **Linux:** The tray icon needs libayatana-appindicator, which the `.deb` now installs and the AppImage carries; without it Textus still keeps running in the background, and Settings says the icon can't be shown. GNOME shows tray icons only with the AppIndicator extension. The `.deb` and `.rpm` now describe Textus in `apt show` and `rpm -qi`, and the `.rpm` names its MIT license. (#244, #239)
- **iPhone and iPad:** Background mode, Open Folder and the file-name search are on the desktop only; the sidebar works as before.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

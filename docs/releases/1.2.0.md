## What's new

Textus 1.2.0 adds links to headings in other files, reopening documents where you left off, a copy button and line numbers for code blocks, and colour swatches beside colour codes.

### New

- Opens a link to a heading in another file, `[see](./notes.md#heading)`, at that heading when you `Ctrl` + click it (`⌘` + click on a Mac) - in a new tab, or the tab the file is already open in - instead of at the top of the file. (#228)
- Reopens a document with the caret where you left it, and scrolled there, when Textus restores your last session or you pick it from **File › Open Recent**, as long as the file hasn't changed since; with **Settings › General › Restore Previous Session on Startup** off, documents open at the top as before. (#218)
- Adds a **Copy** button beside a code block's language picker, which copies the block's code, and line numbers for code blocks, turned on in **Settings › Editor & Appearance › Line numbers in code blocks**; with them on, long lines scroll sideways instead of wrapping, so each number stays beside its line. Neither the button nor the numbers appear in a PDF, an export or a printout. (#228)

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

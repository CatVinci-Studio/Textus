## What's new

Textus 1.3.0-beta.2 brings two documents side by side into Textus itself, a command palette, and version 1.0 of the plugin API - charts and pictures drawn in your code blocks, marks on your text, and a first set of chart and writing plugins built on it. A beta may still have rough edges - tell us on GitHub or Discord.

### New

- Two documents at once, built into Textus: **View › Split Right** (`Ctrl/⌘ + Alt + S`) or **Split Down**, a tab's right-click **Open to the Side**, or drag a tab - or a file from the sidebar - to an edge of the editor and let go, as in VS Code. Drag a tab out of the window to give it a window of its own. Right-click the divider to turn, swap or even the panes; the split is there again when you reopen the window.
- **View › Command Palette…** (`Ctrl/⌘ + Shift + P`): everything the menus do and every command a plugin adds, found by typing.
- Charts in your documents, with the new chart plugins in **Settings › Extensions › Get more**: mind maps from an outline (markmap), ECharts, PlantUML - drawn on your computer, or by plantuml.com if you choose - Chart.js, timelines, sheet music in ABC notation, WaveDrom timing diagrams and function plots. Write a code block in the plugin's language and it is drawn below; `height=400` after the language sets its height.
- Writing tools as plugins: Markdown Lint underlines Markdown that breaks common style rules and fixes it in one go; CJK Spacing puts a space between Chinese or Japanese and Latin letters, by command or on every save; Heading Numbers numbers headings as you write, and in exports; Templates fills in new documents and snippets; Bookmarks keeps passages to come back to from the sidebar.
- Packs on **Get more › Plugins**: Writing, Charts and Research install the plugins that go together in one go.
- **Make your own** on **Settings › Extensions › Plugins**: describe what a plugin should do and Textus AI's Create mode writes it.
- Scripts: a plugin in a single `.js` file, its name and permissions in a comment at the top - put it in the folder **Install a plugin › Open Scripts Folder** opens.
- Plugins' commands are in **Settings › Shortcuts**, under Plugins, to give them keys of your own or clear them.
- `textus://command/<command>` links run a command from another app or a web page, once you say so.
- **Export for Publishing** on a plugin you made lays it out as a repository of its own - README, licence and a release workflow - under your name.
- For plugin authors, the plugin API is 1.0: `docs/dev/textus.d.ts` is the whole of it, and `docs/dev/plugin-reference.md` is made from it.
- New in the plugin API: `views.registerCodeBlock` (a page under a block in your language, its fence's words as `block.meta`, a picture for exports with the page's `onExport`), `editor.registerDecorations` (highlights, underlines, badges before or after the words), `files.onWillSave`, `export.onWillExport` (CSS or HTML for an HTML or PDF export), `ctx.storage.document(path)` (what a plugin keeps for one document, following it when it is renamed), `uri.registerHandler` for `textus://<plugin>/` links and `menus["editor/slash"]` for the `/` menu.
- Third-party plugins can be listed on Get more: LISTING.md in textus-plugins says how, and a workflow reviews each listing before it is merged.

### Improved

- Exports carry what plugins draw: a chart in a code block goes into HTML, PDF, Word and EPUB as a picture, and a block a plugin can't picture keeps its source.
- A plugin's settings can be colours, lists and buttons, grouped under headings and shown only when another setting is on.
- Official plugins installed in beta.1 move to their new versions by themselves, with the permissions they had; the Split Panes plugin gives way to the split built into Textus.
- Uninstalling a plugin moves what it kept for every document to the Trash rather than deleting it.

### Fixed

- A highlight, underline or badge a plugin drew on the text is no longer copied into an export.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself on the beta channel.

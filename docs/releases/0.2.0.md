## Editor

- Bold / italic / strikethrough / highlight / inline code / math are now real nodes with Typora-style revealed delimiters: arrow keys cross them one phase at a time, Backspace/Delete edit the delimiters themselves, and retyping a deleted delimiter re-forms the node.
- Fixed WKWebView-specific cursor bugs: the caret painting at line start after exiting a styled span, and boundary crossings misfiring on fast/held arrow keys.
- ` ``` ` (optionally with a language) + Enter opens a code block; `$$` + Enter opens a math block that edits as a proper fenced block with the source on its own line.
- Context-menu copy/cut/paste are markdown-aware: copying keeps the syntax, pasting markdown renders it.
- Right-click no longer moves the caret or auto-selects the word under the pointer (macOS WebKit behavior, now undone before it's visible).

## AI

- New **Ask AI** inline chat (context menu or shortcut): answers about the document, and every reply offers confirm-to-apply actions - replace selection, insert at cursor, or replace the whole document. Nothing touches the document until you click, and every apply is undoable.
- The agent can now **propose edits**: it quotes the exact text and its replacement, shown as a diff card with an Apply button.
- Grammar-check underlines now land correctly in paragraphs containing styled text; completion length/context are explicitly bounded.
- Each AI feature (completion, grammar check, Ask AI) has its own Settings toggle that gates the menu items and shortcuts.

## UI

- Popups (chat, grammar fixes, math preview) stay inside the window.
- Settings simplified: language-only general section, one-step theme CSS import.

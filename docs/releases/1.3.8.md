## What's new

Textus 1.3.8 keeps a link from disappearing when the caret leaves it, opens linked local files after asking, pastes pictures in source mode, and lets Word exports use your own template.

### New

- Pastes pictures in source mode and split view, too: stored as Settings › Images says, and written as `![](...)` at the caret. (#196)
- **Settings › Editor & Appearance › Export › Word template**: Word exports take the styles, fonts and margins of a Word file you choose (Pandoc's reference document). (#196)

### Improved

- Ctrl/Cmd+click on a link to a local file (a PDF, a Word document, a picture) asks, then opens it in the app your system uses for it, instead of only showing it in its folder. A program or script is still only shown in its folder. (#561)
- On Windows, a minimized window asks WebView2 to use less memory, and gives it back once the window is on screen again.

### Fixed

- A link no longer disappears when the caret leaves it after the same link was shown as Markdown in another tab; before, saving then wrote the paragraph without it. (#561)
- On Windows, opening another document in a new window (File › Open with documents opening in their own window, Ctrl+click in the sidebar, or Move to New Window) could freeze the app, most often over Remote Desktop.
- The Quick Preview card opens right under the link after **View › Zoom In**, instead of where the link would be unzoomed.
- Reading Word, Excel and other zip-based files uses updated libraries that close two reported security issues (RUSTSEC-2026-0429, RUSTSEC-2026-0433). (#533)

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

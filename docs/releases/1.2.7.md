## What's new

Textus 1.2.7 makes a copied picture paste into chat apps as the picture, and stops `fi` and similar letters from being drawn joined in source mode and code.

### Fixed

- In source mode and in code, letters such as `fi` are no longer drawn joined as one glyph, so the cursor can stop between them. A coding font's ligatures such as `=>` stay. (#438)
- A copied picture pastes into WeChat and other chat apps as the picture, not as its Markdown text.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

## What's new

Textus 1.1.2 fixes six ways saving an edited file could change what it says, and how the Linux packages describe Textus.

### Fixed

- Reads the lists and quotes in a file that opens with a `---` rule as lists and quotes, instead of as plain text that a save then wrote with escapes. (#247)
- Keeps a link around bold or italic text, as in `[a **b** c](…)`, as one link when you save, instead of writing it as three. (#247)
- Saves nothing in place of bold, italic or code whose only word you deleted, instead of a stray `**` or two backticks, and keeps italic text italic when you delete its last word. (#247)
- Saves a line that starts with `# `, `- ` or `1. ` in a paragraph as text, instead of as a heading or a list item after the text before it was edited. (#247)
- Keeps square brackets in a link's text, as in `[Tech [Episodes]](…)`, as brackets when you save, instead of writing them in a form that read back as maths. (#247)
- Keeps a `<br>` on a line of its own or at the end of a paragraph, which a save used to delete or turn into a stray backslash, and no longer splits a paragraph at a `<br>` that ends a line. (#247)

### Platform notes

- **Linux:** Describes Textus in the `.deb` and `.rpm` packages, so `apt show textus` and `dnf info textus` show what it is instead of "(none)", and gives the `.rpm` its MIT license instead of "Unspecified".

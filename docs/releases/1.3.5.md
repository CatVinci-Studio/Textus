## What's new

Textus 1.3.5 lets Textus AI take almost any file you attach, keeps its work out of your folders, gives your documents the font and spacing you choose, and turns the `textus` terminal command into a way to work on your notes without opening a window.

### New

- Attaches several files at once with the **+** button, and many more kinds: any text or code file, zip archives (unpacked so Textus AI reads each file inside), and BMP, TIFF and - on a Mac - HEIC and AVIF pictures, converted for every service. Very large pictures are made smaller instead of refused. Each file is copied into the conversation's own temporary folder, and Textus AI reads the whole of a long one when it needs it.
- Lets you choose the font of your documents' text from the fonts on your computer, and set character spacing the way Word does - normal, expanded or condensed by a number of points. Text size now goes from 12 to 28 px in single steps. Font, size, character spacing and line spacing sit under one **Body text** row in **Settings › Editor & Appearance › Text & Layout**, which says whether you changed any. (#540)
- The `textus` terminal command does more than open files: `textus help` lists its commands, and `list`, `read`, `search`, `new` and `move` work on your notes without opening a window. With Textus running, it also lists and runs palette commands, plugins' tools, themes, plugins and skills, and exports a document (`textus export notes.md --to pdf`). Where Textus can't update the command it installed before on its own, Settings › General shows "An older version" with an Update button.
- The settings file can carry your AI records too: exporting asks whether to include every conversation and memory, and importing adds them beside yours - a conversation only when it is new here or newer, a memory only when none of its name is here. It has moved to **Settings › Privacy**.

### Improved

- Opens only the folder you open in the sidebar or choose to Textus AI. A document opened on its own no longer gives it the whole folder it sits in, such as Downloads or the Desktop: it reads that document and the files you attach.
- Keeps what Textus AI makes for a project - its memories, research papers and changes you haven't decided on yet - in Textus's own folders instead of your project folder. What earlier versions left in a project's `.textus/` folder moves there by itself.
- A gallery theme opens its own page, like a plugin's: its whole description, both previews at full width, and Install or Use. The gallery shows each theme as it looks in your appearance, light or dark, an enlarged preview pages to the other with ← and →, and our themes' descriptions are now in Chinese too.
- Starts **Save As** for a new document in the folder open in the sidebar, or else in the folder you last saved a document into, instead of wherever the system's dialog was last.
- Opening Extensions › Create no longer flashes a blank panel first.

### Fixed

- Shows an API key you saved as connected even when a sign-in file for the same service can't be read, instead of asking you to set the service up again.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

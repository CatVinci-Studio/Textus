## What's new

Textus 1.2.8 fixes italics typed with Microsoft Pinyin and list numbering in PDFs exported on Windows.

### Fixed

- With an input method such as Microsoft Pinyin, a `*` typed in front of text that already ends in `*` makes it italic, as it does without one.
- On Windows, a numbered list that runs onto the next page of an exported PDF goes on counting there instead of starting again.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

## What's new

Textus 1.4.3 brings table tools with row and column grips, the Git plugin and commits in Version History, .mdx files, agents that ask first, and many fixes for phones and tablets.

### New

- View › Format Bar puts the format bar at the top, the left, the right, or hides it; the same choice is in Settings › Editor.
- Settings › Shortcuts has keys for the sidebar's own tabs (Files, Outline, Search): a key shows its tab, and again puts the sidebar away. (#687)
- Note links (`[[Note]]`) get Open Link and Copy Link in the right-click menu.
- Plugin API 1.7: a page kit and page tools for plugin pages, consistent names and version rules, and page logs. Plugin pages can use the editor tables' grip and lift (`tx-table-grip`, `tx-cell-lifted`, `tx-making-room`).
- Built-in AI tools for the folder's tasks, backlinks and tags.
- `textus.git`: a plugin reads the folder's Git status, a file's history and its text at a commit, and commits the files the user picks (`git.commit` permission, desktop). New official Git plugin: changed files marked in the sidebar, the branch in the status bar, a Commit command, and AI tools for the changes and history. Version History lists a document's commits beside its versions.
- `documentTypes`: a plugin opens other text file types as documents in the editor, keeping the syntax it names exactly as written.
- Tables have tools at their top right while the cursor is in them: alignment, rows and columns, Copy and Delete. A small grid sets the number of rows and columns.
- Rows and columns have a grip on the table's edge: press it to pick the whole row or column, pull it to move it. Alt+↑/↓ moves the caret's row too, and Backspace takes out picked rows or columns.
- A table's tools show where the pointer is: its row and column grips by the row and column under it, the + under the table by the last row, the + beside it by the last column, and the tools at its top right by the head row - not all at once. On a touch screen they show while the cursor is in the table.

### Improved

- Agents (Claude Code, Codex, Gemini CLI and the others) start in their ask-first mode, named by their plugin, and sign in the way their plugin says. A permission prompt shows the command or the file the step is about.
- Changes an agent writes to disk itself are marked in the document, as Textus AI's are, one undo away.
- For agents without modes of their own, Textus offers Ask first / Allow all.
- Textus AI takes a long document whole with cloud models (up to about 120,000 characters); local models read it in parts, and the attachment says so.
- A split made into a narrow window first folds the side panels, then puts the sidebar away, so the documents keep their room; when even that isn't enough, the window says so instead of doing nothing.
- The built-in theme Aurora is now called Prism; if you used it, pick Prism again in Settings › Appearance.
- The Paper theme uses each system's own serif with even-height figures, so numbers no longer rise and fall in a line.
- Source mode takes the same keys as the rendered editor: highlight, strikethrough, inline code, link, headings and lists, code fences, indent, moving lines and a new line below. A heading key at a line's start leaves the cursor after the new `#`.
- A to-do copied whole pastes back as a to-do, and Backspace at a to-do's start turns it into plain text.
- Closing the tab in use goes back to the tab you used before it.
- Phones and tablets: a long press on a file or folder in the sidebar opens its full menu, headed by its name; files can be shared from it.
- Phones and tablets: lists and colour settings open Textus's own menus and cards instead of the system pickers.
- Phones: the tab row scrolls with a swipe, All Tabs names drafts by their first line and marks the open one, and the ⋯ sheet offers the link the cursor is in.
- Phones and tablets: notices step aside while the keyboard is up, and the cursor stays above the format bar.
- iPhone and iPad: open documents, the tab order and the AI's folder come back after the app is reinstalled or updated.
- The plugin store installs the newest version of a plugin that this Textus can run.
- Copying from a table gives other apps what they expect: a head row, lines and no stray paragraphs; Copy Table writes HTML too, and copied rows paste back in as new rows, whether they come as HTML, tab-separated text or Markdown.
- A table's one row under its head row can be deleted, leaving the head alone as Markdown allows.

### Fixed

- A document's first line starts below the format bar with Typewriter Mode on, and a short document no longer scrolls its first line under the bar.
- Windows: exporting a PDF and dragging a tab between windows no longer pass the focus through a hidden window, one way Chinese input could stop working until a restart.
- Windows: windows open in the theme's own background, dark or light, with no white flash at launch, on maximize or when coming back. (#690)
- Linux: windows have GNOME's shadow and can be resized from just outside their edge, and open at the size they had. (#664)
- The welcome tour's card narrows beside the sidebar instead of covering it.
- A heading key pressed while an input method is still composing no longer doubles the text.
- A PDF or zip file that happens to read as text no longer opens in the text editor, where saving would damage it.
- In an unsaved draft, a link to a note by its relative path opens the note.
- On iPhone and iPad, typing right after a link whose path has spaces keeps it a link.
- On iPhone and iPad, Return at the end of a line right before a table starts a new line instead of moving into the table.
- iPhone: the app sometimes started under the status bar and the home indicator until it was turned.
- Touch screens: a tap below or between tables puts the cursor where you tapped, instead of in the table's last cell or on a word iOS then replaced.
- Touch screens: the open tab's name is no longer cut short by its ×.
- Android: the back key, rotation, folding, system font size and dark mode keep your tabs and drafts.
- On iPad, the document that was in front when you left is in front again when you come back, not another one in the split.
- On Android tablets, a tab dragged with a finger drops where you lift it.
- A file changed by another app updates whole blocks when the change spans several lines, so a table is never split in two.
- A table pasted into a table undoes in one step, and rows copied as plain text (tab-separated) paste in as rows.
- A table pasted into a narrower table fills it from the cursor's cell and adds the columns it needs, instead of jumbling its cells.
- On iPhone and iPad, a pasted table undoes in one step, and a copied or cut row with empty cells at its end pastes in as a row.
- A table's row and column grips sit at the middle of their row and column when the document is zoomed or the table scrolled sideways.
- On iPhone and iPad, a long press at the left of a table's first column shows Paste instead of moving the cursor out of the table.
- Phones and tablets: New Document, New Folder, Rename and Delete in the file tree work; a phone deletes documents, after asking.
- Android: a folder opened without "All files" access tells plugins, and you once, why they can't read it.
- A tab dropped at the window's edge where a split has no room joins the island there, and the window says why.
- Words with digits count in the word count on iPhone and iPad.
- Moving a row or column, and dragging a column's edge, follow the pointer at any document zoom, and a row or column dragged with the cursor elsewhere lands where it was let go.
- A table's tools over a narrow table fit it: tighter, then without Copy and the alignments (both stay in the right-click menu), instead of running past the island.
- In a table wider than the page, the + beside it sits after its real last column instead of over the cut-off one.
- An island no longer runs past the window's right edge when the AI joins it beside the open sidebar.
- On a phone, a document brought to the front no longer raises the keyboard on its own, however long it takes to open; a tap in the text does.
- A long document goes whole only to OpenAI, Anthropic, Google, DeepSeek, xAI and MiniMax; through OpenRouter, Groq and other providers with small-window models it goes as an outline and excerpts again, so those requests no longer fail on length.
- A table pasted from a web page or Word with merged cells comes in as plain cells, which Markdown can save and the table tools count right.
- On a touch screen, the row grip follows the cursor's row after a row is put in above it.
- Dragging a column's edge is one undo step however long it is held, and a press on the edge that doesn't drag changes nothing.
- In a read-only document, Backspace, Delete and Enter do nothing but say it is read-only.
- A find bar left open in a tab is there again with its search when you come back to the tab, the page where you were reading.
- A document in source mode let go to save memory comes back with its undo history, cursor and place.
- Plugin pages and source views side by side in a split no longer make the ones out of sight reload at every switch.
- A web page tab under an open menu or dialog is no longer let go as if out of sight, and a web tab keeps the address it was last at when it reloads, the window is restored or the tab moves.
- Plugin pages are told when they go out of sight (`onDidChangeVisibility`), so they can keep their place before Textus lets them go to save memory.
- Windows and Linux: Textus counts memory as short by how much is free (under 1 GB), and on Linux by the system's own memory pressure, instead of a share of the machine; it eases off only after a calm minute. A large machine no longer acts short with gigabytes free, and a busy small one no longer lets go of everything out of sight all day.
- A burst of plugin notes no longer pushes an error or an Undo offer off the screen before it can be read.
- When a conversation with Textus AI grows so long that its first messages no longer go to the model, a note says so once.
- Block handles: point at a block and ＋ and ⋮⋮ show in the margin beside it. Pull ⋮⋮ to move the block (a list item takes its own list along); click it to turn the block into another kind, duplicate, copy or delete it; ＋ adds a block below. Settings › Editor › Block handles turns them off.
- The Format and right-click menus offer Text and Callout among the blocks, from the same list as the handles and plugins' / menus.
- Markdown files opened with Textus show their own document icon (cream paper and a quill) on macOS and Windows, instead of the app's icon.
- A Settings name too long for its row (Japanese has no spaces to break at) wraps instead of running past the edge.
- Selected text can be dragged to another place in the document; hold Option (Ctrl on Windows and Linux) when letting go to copy it instead.
- On desktop Textus draws the caret itself: one height through a paragraph, so bold, code or Chinese beside it no longer make it jump in size. Settings › Editor › Smooth caret makes it glide as it moves.
- A heading clicked in the Outline puts the caret at its end, so typing goes on there.
- The format bar no longer covers the top of the document's scrollbar: the page and its scrollbar start below the bar.
- Windows: a window brought back soon after being minimized shows a long document at once; its memory is trimmed only after ten minutes minimized.

### Platform notes

- The updated agent plugins (Claude Code, Codex, Gemini CLI, Qwen Code, Copilot CLI, OpenCode, DeepSeek Harness) and Database need Textus 1.4.3.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

## What's new

Textus 1.3.12 fixes a Windows bug that could empty your user `Path`, makes the whole interface grow with a large window and Interface Text Size, and gives every menu, drag and plugin page Textus's own look.

### New

- Plugins › Install from File takes several packages at once; one that fails doesn't stop the others.
- A drawn plugin block (a database, a board) has Edit Source and Delete Block in its right-click menu; Done Editing, at the end of the block's tools, or Esc closes an opened source.

### Improved

- The whole interface grows with Interface Text Size and with a wide window: controls, icons, padding, corners, Settings, plugin pages and floating views (the desk pet, the pomodoro) together, not only the text.
- The sidebar and the AI panel keep their width in proportion as the interface grows, and narrow in a small window so the document always keeps room.
- The sidebar's, the tab bar's and the AI panel's header rows end on one line, and the panels' edges run up to the window's top.
- A plugin block in a document (a database, a board) is at most 70% of the window's height and scrolls inside, so the note around it stays in view.
- A link's path shows `%20` as a space, in the document, in source mode and in hover cards; the file keeps the standard `%20`, a run of escapes moves and deletes as one character, and a space you type in a link's path is saved as `%20`.
- Every right-click on a text field - in a dialog, a panel or a plugin's page - opens Textus's own menu (undo, cut, copy, paste, select all), never the system's.
- Dragging works one way across the app: a tab, a sidebar icon or a view tab slides along its row, a file or tab taken somewhere else follows the pointer as one centred copy, and everything dragged lifts the same way.
- A plugin block in a column too narrow for it starts folded to its line, and stays open once you open it.
- A plugin page in a document (a database table) is drawn at the document's text size.
- A long document title is cut short with an ellipsis instead of running under the word count; the file tree's parent folder keeps its name readable beside a long folder name.
- Plugins and Skills in Settings › Extensions say when nothing is installed and point to Available.
- Settings' About, the start page, the welcome and the tutorial use the interface's text sizes.

### Fixed

- **Windows:** starting Textus 1.3.10 or 1.3.11 could replace the user `Path` environment variable with only Textus's folder. Textus now changes `Path` only when it read the whole value, keeps the old value in `PATH-before-textus.txt` beside the `textus` command, reads the result back and restores it if anything differs, and no longer touches `Path` at startup. If your user `Path` lost its entries, see the recovery steps below.
- Opening a recent project from the start page brings back the tabs you left it with; a project you haven't worked in opens its last document or its README, and otherwise shows its files and asks you to pick one, instead of looking untouched.
- In source mode, an undo pressed right after an edit (a pasted picture, say) is no longer undone again a moment later.
- In a small window the AI panel narrows so the document keeps its room, and can still be dragged; its edge now starts under the title bar instead of cutting through the word count and window buttons.
- Plugin pages' own styles grow with the interface too, without any change to the plugins.
- The Plugins menu has each plugin's Settings…, opening its page in Settings.
- A setting's row no longer changes when you click its words or its description, only its switch; a plugin's name on its page no longer turns it off.
- Embedded notes and plugin blocks (a database) fold the same way: a caret in the margin on their left, on hover, folds them to one line with their name. An embed shows its content alone beside a quiet rule, its source opened from ↗ at its top right; nothing shows its name or a fold arrow twice.
- A plugin block shows its source or its drawing, as a diagram does, not both at once.
- A file dragged from the file tree onto a document no longer selects the document's text on the way (macOS).
- A plugin's settings page (Cloud Sync's) is no longer drawn larger than the rest of Settings.
- Vim: `v` starts visual mode again.
- Two quick clicks on a folder's arrow in the file tree fold and unfold it instead of going into the folder; the tree no longer shows a folder's children twice.
- A plugin list's row is lit only under the pointer or the keyboard, not after the pointer leaves.
- A page a plugin moves (a page made a folder for its sub-pages) keeps its unsaved words, and its tab follows it.
- A link whose path has spaces beside parentheses shows and opens as a link.
- A plugin page that fits its frame passes the mouse wheel on to the document; a taller one scrolls itself.

### Platform notes

- **Windows:** if your user `Path` was emptied by 1.3.10 or 1.3.11, open Start › "Edit environment variables for your account", select `Path`, and add back the folders you need. If you made a System Restore point earlier, restoring it also brings the old value back. Windows doesn't keep a copy, so we can't restore it for you; Textus 1.3.12 changes `Path` only when you add the `textus` command in Settings, and then only as described above.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

## What's new

Textus 1.2.3 makes Settings and the other menu commands open in the window you used them in, on Windows and Linux.

### Fixed

- On Windows and Linux, Settings and the other menu commands open in the window you used them in, instead of in the first window you opened.
- On Windows, **Ctrl+,** opens Settings while you are typing in a document.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

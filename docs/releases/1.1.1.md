## What's new

Textus 1.1.1 polishes how Textus AI's revisions look and fixes typed links and images, the caret after bold text, and Open Recent in an empty window.

### Improved

- Darkens the revision you point at, or step to in the review bar, the way a review note does - a darker green for the new text and a darker red for the original, in the text and in its margin card - instead of outlining it. (#207)
- Shows a card in place of an image that can't be loaded - its file name, why (no file at that path, a web host that couldn't be reached, a file Textus can't show) and the full path on hover - with **Choose image…** to point it at another file and **Show in folder**, instead of the browser's broken-image icon. Obsidian `![[...]]` embeds get the same card. (#212)
- Adds **Show in folder** and **Copy image path** to an image's right-click menu, beside the width items: the first opens Finder, Explorer or the file manager with the image selected, the second copies its full path, or the address of a web image. Obsidian `![[...]]` embeds get both, with the file found in the vault. (#224)
- Saves an image's width as HTML, `<img src="…" width="50%">`, which GitHub, Typora, Obsidian and VS Code all show at that size, instead of a `{textus-width=50%}` note in its title that other apps ignored and showed as the tooltip. **Image width: Auto** saves it as `![]()` again. An `<img>` with a width, from Typora or anywhere else, now opens as an image with the width menu, and files saved by older versions open at their width and stay as written until you change it. (#227)

### Fixed

- Widens the text with the window from about 1100px instead of 1214px when **Settings › Editor & Appearance › Text Width** is **Adaptive**, so on a 1280-1440px window it is wider than Standard rather than narrower; beside the sidebar or the AI panel on a smaller window it keeps the width it had, and the margin views of a revision stay available where they were. (#211)
- Opens a file chosen from **File › Open Recent** in the current window when that window is new and empty, instead of in a second window beside it. (#201)
- Keeps the caret after the closing `**` or `*` when you delete the text that follows bold or italic text, so what you type next is no longer bold or italic. (#199)
- Turns `![alt](url)` into an image as you type the closing `)`, as `[text](url)` already becomes a link, instead of leaving it as text that was saved with backslashes and no longer showed as an image. (#189)
- Returns an image without a caption to its automatic width when you choose **Image width: Auto**, from the right-click menu or the phone's keyboard toolbar, after giving it a width; the choice did nothing before. (#223)
- Keeps the page still in **Typewriter Mode** while you click or drag with the mouse or tap, so a click puts the caret where you clicked and a drag selects what it passes over, instead of the page jumping and the caret or selection landing elsewhere; the next key you press centres the line as before. (#217)
- Keeps maths written with LaTeX's `\(...\)` and `\[...\]` as written when you save, instead of rewriting it to `$...$` when the file opens; a `\[...\]` on lines of its own shows as display maths rather than inline, and citations such as `\[1\]` and anything in code stay as they are. Maths in Textus AI's replies and in pastes is still turned into `$...$`. (#228)
- Keeps the rest of a code block's first line after the language, such as `title="a.js"` after `js`, when you save or pick another language from the block's menu, instead of dropping it. (#228)
- Shows `> [!note]`, `> [!Tip]` and Obsidian's folding `> [!tip]-` and `> [!tip]+` as alerts, and saves them as written instead of as `> \[!note]`; Obsidian's other callout types, such as `> [!question]`, are saved as written too. (#228)
- Saves a web address or email address you type, such as `https://x.org`, `www.x.org` or `a@b.com`, without backslashes, so it is a link on GitHub and elsewhere instead of `https\://x.org`. (#228)
- Keeps a single-tilde `~x~`, Pandoc's subscript as in `H~2~O`, as one tilde when you save, instead of turning it into `~~x~~` strikethrough. (#228)
- Keeps inline maths written as `$$x$$` in two dollars when you save, instead of `$x$`. (#228)

### Platform notes

- **macOS:** Installs with `brew install --cask textus` from Homebrew's official casks; a Textus installed from the `catvinci-studio/tap` tap moves there on the next `brew update`.
- **Windows:** Shows the Textus quill and name in the installer's side and header pictures, which still showed the old Levis ones.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

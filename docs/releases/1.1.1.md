## What's new

Textus 1.1.1 polishes how Textus AI's revisions look and fixes typed links and images, the caret after bold text, and Open Recent in an empty window.

### Improved

- Darkens the revision you point at, or step to in the review bar, the way a review note does - a darker green for the new text and a darker red for the original, in the text and in its margin card - instead of outlining it. (#207)
- Shows a card in place of an image that can't be loaded - its file name, why (no file at that path, a web host that couldn't be reached, a file Textus can't show) and the full path on hover - with **Choose image…** to point it at another file and **Show in folder**, instead of the browser's broken-image icon. Obsidian `![[...]]` embeds get the same card. (#212)

### Fixed

- Widens the text with the window from about 1100px instead of 1214px when **Settings › Editor & Appearance › Text Width** is **Adaptive**, so on a 1280-1440px window it is wider than Standard rather than narrower; beside the sidebar or the AI panel on a smaller window it keeps the width it had, and the margin views of a revision stay available where they were. (#211)
- Opens a file chosen from **File › Open Recent** in the current window when that window is new and empty, instead of in a second window beside it. (#201)
- Keeps the caret after the closing `**` or `*` when you delete the text that follows bold or italic text, so what you type next is no longer bold or italic. (#199)
- Turns `![alt](url)` into an image as you type the closing `)`, as `[text](url)` already becomes a link, instead of leaving it as text that was saved with backslashes and no longer showed as an image. (#189)

### Platform notes

- **macOS:** Installs with `brew install --cask textus` from Homebrew's official casks; a Textus installed from the `catvinci-studio/tap` tap moves there on the next `brew update`.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

## What's new

Textus 1.3.0-beta.1 is the first beta of 1.3 and lays its foundations: plugins you install from inside Textus, with their own settings and storage and a fuller API to build them with, one market for plugins, themes and skills, your own notes and tracked changes in the margin beside Textus AI's, and a lighter start. It has everything in 1.2.1 too. A beta may still have rough edges - tell us on GitHub or Discord.

### New

- One market for plugins, themes and skills: Settings › Extensions › Get more lists all three, with one search and a tab for each kind, and installs a skill in a click; Settings › Extensions › Plugins lists the plugins you installed, each opening its own page.
- A plugin's settings can be a project's own: with a folder open, its page in Settings › Extensions has **Applies to** - every document, or this project - and a project's values, kept in its `.textus/settings.json`, go with the folder and stand over the general ones; **Use the general value** takes one back.
- Plugins keep their own data in two places: one for every document, in Textus's config folder beside your global agent.md, and one that travels with a project, in its `.textus/plugins/` - the second only for a plugin you allowed to. A plugin reaches only its own, and each holds up to 50 MB.
- Plugins can give Textus AI tools of its own to use - a word count, a look-up in your reference manager, a conversion - once you allow it; each call shows in the conversation, as an MCP server's do.
- Two documents at once, with the Split Panes plugin: Split Right (Ctrl+Alt+S, ⌘⌥S on a Mac) shows the document in front beside another tab, and Split Down puts one above the other.
- Quick looks at what a link points to, with the Quick Preview plugin: rest the pointer on a link to another document - a Markdown link or a [[wikilink]] - and its opening shows in a card beside it; with the Zotero plugin, resting on a citation such as [@darwin1859] shows what it cites.
- Your own notes: select some words, right-click › Add Note, and your note goes into the margin beside Textus AI's, marked Me; notes are kept beside Textus's own data, not in your Markdown.
- Track My Changes (Edit menu): with it on, your edits show as changes - what you deleted struck through, what you added marked - each with a card in the margin, marked Me, to accept or reject.
- Switches the chat's model from the message box: the button beside the other controls names the model your next message goes to, from the providers you have set up in **Settings › Textus AI**.
- Search your conversations: the AI panel's history has a search field that finds the conversations where words were said, and Textus AI looks there too when you refer to an earlier conversation.
- A task worth doing again becomes a skill: when what you asked for was a procedure of your own, Textus AI offers to keep it as a skill under its reply, for every document or for this project; nothing is saved unless you choose to.
- Redraws a proposed picture from your own description: point at the picture and choose Redraw…, and that picture alone is drawn again.
- Keeps unsaved changes when you close a window, without asking, once you turn on **Settings › Privacy › Keep unsaved changes when closing**; off by default, and it needs Draft Recovery on.

### Improved

- Starts with less to load: Split View, the editor's menu, the first-run tour and the code that runs plugins load the first time they are used, so the window's startup code went from 1.32 MB to 1.02 MB.
- The sidebar's file tree leaves out hidden files - names starting with a dot, and on Windows files marked hidden or system, such as desktop.ini - and its **Sort** menu has **Show Hidden Files** to see them. (#357)
- A plugin's page in Settings says how much it keeps - for every document, and in the open project - and **Clear** empties it, after asking.
- Themes have one place: Settings › Extensions › Themes holds adding a theme from a CSS file, your own CSS and the theme gallery, while Editor & Appearance keeps picking a theme.
- Long documents change chapter by chapter at once: asked to translate or rewrite a long document in chapters, Textus AI hands each chapter to a helper of its own, with a shared list of how recurring names and terms are written.
- Textus AI's memory keeps itself tidy: now and then it merges memories that say the same thing and drops a rule a newer one overturned; what it drops is in the Memory tab's Recently forgotten, to bring back.
- Pictures in one piece keep the same people and look: someone who comes back is described in the same words, and where the image model takes a picture to work from, a new picture of them is drawn from an earlier one.
- Web pages in a tab (the Web View plugin) open every site on macOS and Windows, in the system's own web view with its own cookies; on Linux the page stays a frame for now.
- Get plugins shows the list from last time at once while it fetches a newer one, and keeps showing it when you're offline.

### Fixed

- The official plugins speak all ten of Textus's languages - Traditional Chinese no longer shows Simplified, nor the other languages English.
- In Review, asking Textus AI to mark the hard words, or every weak sentence, marks all of them, not just the first.

### For plugin authors

- The whole plugin API is typed in `docs/dev/textus.d.ts`, and `textus-plugin.json` has a JSON Schema for your editor to check it as you type.
- New in the API: `textus.storage.global` and `textus.storage.project`, settings per project, `textus.ai.registerTool` with `contributes.aiTools`, `textus.workspace.readDocuments()` and `search(query)`, `textus.window.openFile(path, { asDocument: true })` (in place of the `textus.openAsDocument` command), `textus.window.splitEditor`, `textus.editor.registerHoverProvider` with the `onHover` activation event, `textus.motion` and `textus.l10n.t`.
- A plugin loaded from its folder (Settings › Extensions › Plugins › Load a plugin folder…) loads again by itself when you save a change, and its page lists what went wrong in it lately.
- An `engines` range naming a beta, such as `>=1.3.0-beta.1`, is compared with the full version, beta number included.

### Platform notes

- **Windows and Linux:** Settings › Editor & Appearance › Show the menu bar puts File, Edit, View and the rest along the title bar instead of behind ☰ - off by default.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

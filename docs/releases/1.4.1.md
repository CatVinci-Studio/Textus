## What's new

Textus 1.4.1 refines the 1.4 window: three interface sizes, an optional title row, agents you can set from the chat, lighter long sessions, a clearer plugin page and many fixes.

### New

- Appearance › Show the title bar on its own row puts the document's name in a row of its own across the top, with the tabs in the row under it, as VS Code does; with the menu bar shown, the name sits in the middle of the menu's row. A window with one document then shows it as one rounded sheet just under its name, the tabs coming back with a second. Off by default.

### Improved

- The format bar's heading button opens a list of levels, Body text and Heading 1 to 6, with the current one ticked, instead of stepping through them one press at a time.
- Claude Code, Codex, OpenCode and other agents can be set from their menu in the chat: their mode, model and effort, as each offers them, remembered per agent. They still start in the mode that asks before each change, where the agent has one; a mode chosen that doesn't ask, such as Bypass permissions, is shown by name beside the agent while it is on. OpenCode has no such mode and starts in its own build mode. Typing `/` lists the agent's own commands.
- An agent's steps read at a glance: an icon for each kind (reading, searching, running a command, editing), its output a click on the step itself, paths inside the folder shortened, several reads and searches in a row folded into one line, and its plan shown as a checklist while it works.
- A long Claude Code, Codex or Textus AI session uses far less memory and work as it runs: replies reach the window in batches instead of a message a word, an agent's steps come without the whole files and outputs the chat never shows, only the reply being written redraws as it comes in, and a very long conversation draws its newest part, with the earlier ones a click away.
- Textus keeps as much loaded as the computer's memory allows: on a machine with little memory, or when the system runs short, pages out of sight are let go sooner and caches are given back at once.
- The file tree stays quick in a big folder: coming back to the window, or Textus AI writing a file, redraws only the rows that changed.
- Plugins that read the folder's notes (Two-way Links, Tasks, Tags, Graph, databases) get only what changed since they last asked, instead of every note at each save.
- Pictures in a document load as they come near the screen, and switching between long documents does less work.
- A plugin's block in a document can draw at the interface's size (Settings › Appearance › Interface size), so a wider column shows more of it: Wiki bases and task queries now do, rather than growing with the document's text and zoom.
- Switching back to a long document you edited is quicker: its undo history comes back without drawing the whole document again.
- Only the tab in front keeps a source or split view: tabs behind it let theirs go after a while, as plugin pages do.
- In a narrow Plugins list, a plugin with an update keeps its row on one line.
- `Ctrl/⌘ + N`, File › New and the sidebar open a document beside Textus AI and Settings, never among their tabs.
- A Textus AI tab is named for who answers in it (Claude Code, Codex or Textus AI), and each conversation gets a short title from Textus AI after its first exchange, shown in History and on its tab's hover.
- A long command Claude Code or Codex asks to run says how many commands it holds, its text in code type and cut to a few lines until you open it; long steps in a reply show two lines.
- Opening a web page file (`.html`) offers HTML View, which shows it as a page; declined, it opens as text as before.
- Interface Size comes in three presets, Small, Medium and Large, each laid out on whole, even pixels as Chrome and macOS set theirs: the window bar is 36, 40 or 48 points tall, with room above its tabs, and the interface's text, controls and spacing step with it. Medium is the size the interface had before; a size chosen before moves to the nearest preset, and widths you dragged the sidebar and panels to are kept.
- A sidebar panel's search box has room round it, its sides level with the panel's name.
- The sidebar's Plugins list shows each plugin's name and what it is for on one line, with a small Install or Update button at the end; who made it is on its page.
- However many tabs are open, the window bar keeps some bare room before its buttons to move the window by.
- Documents lift off the window the same way in light and dark: a faint rim and a soft two-layer shadow, the dark window a step deeper, instead of a grey outline.
- The network proxy takes a username and password, for a proxy that asks for them: requests then identify themselves with Basic auth. Like the proxy's address, they stay in Textus's own settings on this computer and are left out of an exported settings file and out of problem reports.
- Plugins: a file menu item can leave out folders with `"when": "!resourceIsFolder"`.
- Settings › Plugins › a plugin: Source and Edit with AI sit beside the version, the README shows its first lines until you ask for all of it, and the permissions are a group of their own in small type. The "Adds" row and the About group are gone.

### Fixed

- The + in a Textus AI tab row starts a new conversation instead of opening a blank document; where only one conversation can be kept, the document it opens goes beside the AI rather than among its tabs.
- Bold and Italic in the format bar, the right-click menu and the Format menu now apply to the selected text, as Cmd+B and Cmd+I do, instead of sometimes adding empty markers at the caret.
- Windows: Textus's icon is sharp again on the desktop, in Explorer and on the taskbar; 1.4.0's was blurred at every size.
- A formula's preview while you edit it is as wide as the column, so a long or multi-line formula fits inside it instead of spilling past its border, and it no longer pops in; on Windows it could be left behind at the top of the window after switching tabs.
- Updating and relaunching Textus writes its windows, tabs, settings and AI chats first, so nothing from the last moments before the update is lost.
- A picture embedded the Obsidian way (`![[image.png]]`) stays on show when clicked, as any picture does: its corner button or a double click enlarges it, and right-click offers View Image and Copy. The source comes up as the caret reaches it. (#659)
- Reopening Textus brings its documents back as they were, the one in front first, without flicking through each tab.
- Codex starts in Read-only, its mode that asks before changes, rather than Workspace access.
- `Tab` in source mode indents instead of leaving the document, and `Shift + Tab` takes an indent back; press `Esc` first to move on with `Tab`. (#652)
- A draft recovered after a crash asks before it is saved over a file that changed since its edits began, and a draft whose file can't be found comes back untitled instead of being dropped.
- Updating Textus closes its windows as Quit does, asking about unsaved documents or keeping them as drafts, before the new version starts.
- A tab dragged into another window no longer leaves an old copy to come back as a recovered draft.
- A web page opened in a tab can't read files on your computer, and Textus AI's replies load no pictures from the web as they show.
- A rewrite Textus AI is typing into a document finishes even when you switch to another AI tab; closing an AI tab mid-reply keeps what it wrote and marks the files it changed.
- Reopening another document's conversation from History, with no folder open, shows that conversation.
- Stop ends Claude Code or Codex while it is still starting or signing in.
- After Ctrl+Tab, closing a tab or opening a new one, typing goes to the tab in front.
- A file or folder moved to the Trash in the sidebar or by a plugin lets its tabs go: an unchanged one closes, an edited one stays as an unsaved draft.
- A picture pasted or dropped into a document shows in the file tree at once.
- A grammar card left open after an edit fixes only its own underline.
- `Ctrl/⌘ + F` with the Settings tab in front searches Settings, and Escape or Enter while an input method is composing a word stays the input method's in Find and Settings.
- A settings file brings along a built-in theme in use, and an imported theme whose dark look didn't come with it keeps one look.
- An imported theme shows at once, its web fonts following when they load, also after starting offline.
- An imported theme that uses older variable names no longer flashes its colours in at every start.
- Remembering a rule Textus AI already knows no longer says it failed.
- Plugin pages for Traditional Chinese read English where a plugin has no Traditional Chinese, never Simplified; German speaks with du and French with vous throughout.
- A diagram inside a quote or list no longer moves the pictures of the diagrams after it in a Word, OpenDocument or EPUB export.
- An HTML page saved beside its document shows pictures named from the folder's root (`/assets/x.png`), and links `[[#Heading]]` to its heading.
- A search hit or a plugin's link to a line opens at that line in a document with front matter, lists or extra blank lines.
- Plain-text `.txt` notes are searched too.
- Cut, Copy and Paste in a plugin's own right-click menu (Quick Notes, a Wiki base's cell) work, and Cut never removes text it couldn't copy.
- Ticking a nested row in a plugin's list shows at once.
- `textus open ./notes.md` and `textus export ./notes.md` use the tab already open for that file.
- Signing out while Textus AI refreshes a sign-in keeps you signed out, and signing in again keeps the new account.
- Starting an MCP server or external agent for the first time no longer holds up other work.
- A file moved, renamed or put in the Trash in one window shows in every other window too, and their tabs follow it.
- Heading numbers show in a document open beside another, not only in the one you are typing in.
- A long reply streaming in no longer holds up the window: it is drawn block by block, only its growing end anew, so the conversation scrolls freely while Textus AI writes.
- With Claude Code or Codex answering, Textus AI's own button no longer lights up beside theirs; pressed, it switches back to Textus AI.
- A reply streaming in no longer shows a list's next bullet, a quote's bar or code's ground ahead of the words before it.
- The sidebar's top row, where it reaches the top of the window, moves the window like the rest of the bar.
- The open tab's outline joins its sheet's edge again: the sheet's top edge no longer goes missing under the window bar, which on some screens left the tab's curves hanging apart.
- Jumping back to the top of a document, or switching back to it, no longer leaves its first lines under the format bar.
- A model or service on this computer (localhost, 127.0.0.1 and every other loopback address) is always reached directly: a proxy in the environment of the terminal that started Textus, or the app's own proxy setting, can no longer hijack the request. With the proxy set to None, Textus no longer picks up a proxy from that environment (`HTTPS_PROXY`) either: set one in Settings › Writing assist › Web and proxy if requests need it. The update check follows the same setting.
- Opening or importing an RTF file keeps its list numbers (`3.`, `(3)`, `c)`, `iii.`, `三、`) instead of numbering every item 1, and a link to a place in the same RTF document is no longer broken. A PowerPoint numbered list keeps its start number and counts on.
- A Word picture with an empty description takes its title as alt text, and HTML inline code holding a double backtick keeps its text.
- Export finds Pandoc installed through Nix, conda or another login-shell PATH when Textus was opened from the Dock.
- Headings with the same name get distinct link targets even next to one named like a numbered copy (`Intro`, `Intro`, `Intro-1`). Headings, numbered headings and the suggested file name skip `<!-- -->` comments, as the editor does.
- A project's `.textus/settings.json` with comments or trailing commas can be changed from Textus.
- MCP: two tools whose names collide after the 64-character limit no longer get a name the model's API refuses (every request used to fail), and several servers still starting are waited for once, not one after another.
- Textus AI: a Claude reply cut off by the connection in the middle of an edit says the connection ended instead of sending an empty edit. A picture whose link spells spaces as `%20` is found, and library entries' `aliases:` written as a YAML list are read.
- `textus <plugin-tool> --json '{…}'` passes the JSON to the plugin's tool.

### Platform notes

- **macOS:** the traffic lights sit on the window bar's middle line at every interface size.
- **macOS:** closing a web page tab lets the page finish drawing first, which avoids a rare crash.
- **Windows:** Claude Code, Codex and MCP servers started with `npx` start; a name with `:` (`Meeting 10:30`) is refused instead of making a hidden stream; Textus AI's edits keep a file's Windows line endings; Export no longer flashes a console window and finds Pandoc where its installer puts it; F5, `Ctrl + R` and `Ctrl + P` no longer reload or print the window from Find or a new name in the sidebar; the menu bar's Undo, Redo and Select All act where you were typing.
- **Windows:** pinching on a trackpad zooms the document again, also right after scrolling.
- **Linux:** menus, Settings and dialogs no longer flash as they open (#640), web pages use less memory, and a web page tab out of sight is let go after a while.
- **Obsidian vaults:** Vim reads `.obsidian.vimrc` and WakaTime reads `.wakatime-project` and the Git branch again; Zotero puts literature notes in the folder, and makes them from the template, that the vault's Zotero Integration or Citations plugin is set to.
- **Windows and Linux:** the window bar is as tall as on macOS, at every interface size.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

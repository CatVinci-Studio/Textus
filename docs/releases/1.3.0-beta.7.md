## What's new

Textus 1.3.0-beta.7 makes Undo and Redo on macOS take back every edit, brings Find, Select All and pasting in line with other editors, and adds the command palette to the tour.

### New

- The welcome tour has a lesson on the command palette: press Ctrl+Shift+P (⌘⇧P on a Mac), type a few letters and run any command.

### Improved

- Find takes the words you've selected as what to look for. Pressing Find again while the bar is open goes back to its box with the text selected, ready to type over, instead of closing it. After stepping through the matches, Escape leaves the current one selected.
- In a code or formula block, the first Select All selects its code; the second selects the whole document.
- Each paste, cut, drop and replacement is an undo step of its own, as in Word or Pages. Two quick pastes, or a paste and the typing right after it, are no longer taken back together, and one undo takes back a whole Replace All.

### Fixed

- On macOS, Cmd+Z, Cmd+Shift+Z and Edit › Undo / Redo take back pastes, cuts, formatting, headings and moved paragraphs, not just some typing. In a text field, a plugin's panel, a web page tab or the chat window, they undo there, never in the document behind it.
- Cmd+B and Cmd+I format text across several paragraphs or after Select All; pressing them again takes the formatting off.
- Select All in the chat window selects the chat's text, not the document behind it.
- With all plugins turned off, the plugin list is dimmed as a whole instead of showing a red note on every card.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

## What's new

Textus 1.3.0-beta.8 brings Notion's pages, databases and `/` menu to plain Markdown as new plugins, lets plugins remind you and work in the background, and puts what you can add to Textus on the same page as what you have.

### New

- New official plugins, each installed on its own from Settings › Extensions › Plugins:
  - **Quick Insert**: `/` puts in headings, lists, to-dos, tables, formulas, callouts, dividers and today's date; **Turn into…** changes the paragraph you're in; `:` and a word puts in an emoji.
  - **Pages**: pages inside pages - a sub-page is a document in the folder beside its page, made and linked with `/page`; a tree of pages in the sidebar, page icons, and the pages above the one you're in.
  - **Database**: a folder's documents as a table, a board, a calendar or a gallery, their front matter the columns, edited in place. It imports Notion databases, and Textus AI can make one for you.
  - **Link Cards**: a link as a card with its page's title, description and picture; a YouTube or Bilibili video plays in place.
  - **Reminders**: `(@2026-11-02 09:00)` in a line reminds you of it then, with a notification that opens the line.
- Plugins can remind you on a schedule: a system notification at a time, every day or every so often, which opens the note it is about when you click it - on macOS and Windows also after Textus has quit, on Linux while it runs. Reminders due while Textus was closed come once when it starts again. A plugin asks for the new Notifications permission first.
- Plugins can also work on a schedule in the background - syncing, say - for at most 30 seconds at a time, with no access to the editor. With Keep running in the background on, this goes on with every window closed. A plugin asks for the new Run in the background permission first.
- Plugins can put in the Format menu's blocks - headings, lists, task lists, quotes, code, formulas, dividers and tables - and a plugin's `/` items are found by their English name in any language and, for Chinese ones, by pinyin.

### Improved

- Settings › Extensions has no separate Get more page: each tab lists what you have installed, then what you can add, with one search for both. The list of what you can add folds away and grows as you scroll. A Plugin features switch heads the plugins, and a theme's picture opens large with a click.
- The store's install numbers count how many people installed each plugin, theme and skill - not every download of every version, as before - with the last 30 days' beside them. Themes and skills have them too.
- WakaTime 0.2 counts only your own writing while Textus is in front - time in the background, and files changed elsewhere, don't count - keeps heartbeats while you're offline, and tells you today's writing time.
- Export loads the first time you export, so windows open a little faster.

### Fixed

- Text a plugin or Textus AI puts in mid-sentence keeps a wiki link or bold words it starts with, instead of turning them into plain text.
- Brings 1.2.10's fixes.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

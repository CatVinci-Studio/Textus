## What's new

Textus 1.2.6 makes dragging files in from your file manager work again, and fixes copying pictures, styled HTML inside bold text and a few smaller things.

### Fixed

- Files dragged in from Finder, File Explorer or a Linux file manager open again; the drop went unnoticed. A dropped folder opens in the sidebar, as Open Folder does. (#429)
- Copy on a right-clicked picture copies it, and a copied picture pastes into other apps as the picture itself, with its Markdown for Markdown apps. (#428)
- New tabs and documents you open stay in the view you last switched to - source mode or split view - instead of going back to the rich editor each time. (#424)
- HTML tags written inside bold or italic, such as `**<u>words</u>**`, show their style instead of the raw tags. (#423)
- When an AI service's balance or quota runs out (DeepSeek's "Insufficient Balance", OpenAI's "exceeded your current quota", Anthropic's "credit balance is too low" and the like), Textus now says so in your language and tells you where to top up or switch services, instead of only showing the raw message or calling it a rate limit. Errors from AI completion and grammar checks get the same explanation as the chat.
- Settings › General no longer offers to install the `textus` terminal command on Windows and Linux, where it could only fail. On Linux the .deb and .rpm already provide `textus`.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.

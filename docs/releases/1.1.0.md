## What's new

Textus 1.1.0 brings a new first-run tour, more HTML in your documents, and a beta update channel.

### New

- Starts new users with a rebuilt tour: connect your AI first, then the main features one step at a time, each with a short animation to watch; skip the AI and its lessons show you instead. (#90)
- Shows collapsible `<details>` blocks, HTML tables, a few inline styles (colour, size, weight, alignment) and inline `<svg>` drawings as they look, while you write, in split view and in HTML and PDF exports. Scripts in a document never run.
- Lets you choose **Settings › General › About Textus › Update channel › Beta** to get release candidates before everyone else; Stable stays the default.
- Opens the video tutorials from **Help › Video Tutorials**.

### Improved

- Remembers whether the sidebar was open, so it comes back the way you left it. (#152)
- Updates KaTeX, which draws formulas.

### Fixed

- Turns `**bold**`, `*italic*` and the other marks into formatting when the `*` comes from a Chinese input method. (#134)
- Shows images whose relative path contains escapes such as `%20`. (#135)
- Ticks a task checkbox in Typewriter Mode without the page jumping. (#136)
- Keeps what you type after `***` inside the bold-italic text instead of dropping it. (#148)
- Follows links with `Ctrl` + click (`⌘` + click on a Mac): another Markdown file opens in a new tab, a `#heading` scrolls to it, and web links open in your browser instead of a broken page. (#152)
- Keeps the top and bottom page margins clear in exported PDFs when a code block, table, quote or list runs across pages. (#151)

### Platform notes

- **macOS:** lets you drag the window while the first-launch language card is open (#149), and now requires macOS 11 or later.
- **Windows:** Source Code Mode and code use a monospaced font again instead of falling back to SimSun. (#132)

### New

- Plugins can remind you on a schedule: a system notification at a time, every day or every so often, which opens the note it is about when you click it. Reminders set while Textus was closed come once when it starts again. A plugin asks for the new Notifications permission first.
- Plugins can also do work on a schedule in the background - syncing, say - for at most 30 seconds at a time, with no access to the editor. With Keep running in the background on, this goes on with every window closed. A plugin asks for the new Run in the background permission first.

### Platform notes

- Clicking a plugin's notification opens its note on macOS and Windows, also after Textus has quit; on Linux while Textus is running, on desktops whose notifications have actions (GNOME and KDE do).

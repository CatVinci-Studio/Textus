### New

- Makes themes, plugins and skills with Textus AI in **Settings › Extensions › Create**: say what you want, start from an example, and install, try and change what it makes without leaving the page.

### Improved

- Shows a plugin's likely problems on its install card under a Textus AI reply - code that can't draw on the page, a permission it never asked for - and the first error it hits once installed, with **Fix with AI**.
- Gives each plugin one place in the window bar: a plugin with several readouts or commands shows one, and a click opens all of them under its name.
- Opens a plugin's **Edit with AI** in **Settings › Extensions › Create**; Textus AI's panel keeps to Write, Review and Research.

### Fixed

- Plugins Textus AI makes no longer fail with "No folder is open." when no folder is open, and no longer try to draw buttons or colours on the page, which never showed; colour changes become themes.

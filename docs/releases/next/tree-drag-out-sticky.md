### New

- Drag files and folders from the file tree out of the window to Finder, File Explorer, the desktop, a mail or any other app, and they arrive there as copies of the real files. Pick several rows first to drag them together.

### Improved

- While you scroll through a long folder in the file tree, its row stays at the top, with the folders it sits in above it, so you always see where you are. Click it to fold the folder.
- Rows you picked in the file tree turn quieter while you work elsewhere, and come back when you return to the tree.

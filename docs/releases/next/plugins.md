### New

- Plugins, none of which comes with Textus: **Settings › Plugins › Get plugins** lists the ones you can install, with who made each - Official for CatVinci Studio's - and downloads one when you install it, checking that it is the package listed. Installing it turns it on, after asking for the permissions it needs in plain words: reading the document in front, suggesting edits, reading or changing files in the open folder, the clipboard, a website.
- Each installed plugin is a card - its name, what it does, who made it, its switch - that opens a page of its own: its settings, drawn like Textus's own, what it needs, what it adds, its permissions (each can be taken back), and Uninstall. An update the list has shows on its card. One switch turns every plugin off.
- A plugin can say a Textus setting it needs on - Quick Notes, background mode - and offers to turn it on.
- A plugin runs sealed off from Textus and your files: it can do only what you allowed, and an edit it makes to a document is a suggestion you accept or reject, like Textus AI's. A plugin that stops answering or keeps failing is turned off, and Textus says which and why.
- Plugins can add commands with their own shortcuts, items in the editor's right-click menu, in a new Plugins menu and in background mode's tray or menu-bar menu (there with every window closed), sidebar tabs, settings, a status in the window bar, and tabs of their own - a file type they open, or a view.
- Install a plugin from a file (.textusplugin), or load a plugin folder you are writing; Reload picks up your changes. docs/dev/writing-plugins.md is the guide.
- Eleven official plugins to install:
  - PDF Viewer: PDFs in a tab, pages drawn as you reach them, text to select and copy.
  - Word Reader: Word documents as Word lays them out; Edit as Markdown turns one into a document of yours.
  - Image Viewer: pictures and SVG files in a tab, with zoom and an SVG's source.
  - Web View: web pages in a tab beside your notes.
  - Quick Notes: notes in the sidebar, jotted down from anywhere (⌘⌥N / Ctrl+Alt+N) - and, with background mode on, from the tray or menu bar with every window closed - to insert or open later.
  - Calendar & Daily Notes: a calendar in the sidebar and a note for each day (⌘⌥D / Ctrl+Alt+D for today's).
  - Tasks: every task in the open folder in one list, ticked off there.
  - Kanban: boards of cards in lists, kept as Markdown files (name.kanban.md).
  - Version History: each save kept as a version, compared with the text now and brought back as a suggestion.
  - Zotero: cite from your Zotero library as you write (⌘⌥C / Ctrl+Alt+C).
  - Graph View: your notes and the links between them as a graph, for the whole folder or around the document in front.

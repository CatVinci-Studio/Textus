### New

- Picks several files and folders in the file tree at once: ⌘-click (Ctrl-click on Windows and Linux) adds or removes one, Shift-click picks a run. Drag them into a folder together, or right-click to open them or move them all to the Trash. ⌘/Ctrl-click no longer opens a file in a new window; drag its tab out of the window instead.

### New

- Obsidian's image size in the alt text, `![cat|300](cat.png)`, draws the picture 300 pixels wide. The file keeps the size as written.
- GitHub's maths: `` $`E=mc^2`$ `` and ```` ```math ```` blocks draw as formulas.

### Improved

- `\[…\]` is a formula only when it looks like LaTeX (`\[x^2\]`, `\[\frac{a}{b}\]`). Escaped brackets such as `\[optional\]` in a README now read as brackets, as on GitHub.

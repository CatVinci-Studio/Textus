### New

- View › Format Bar puts the format bar at the top, the left, the right, or hides it; the same choice is in Settings › Editor.
- Settings › Shortcuts has keys for the sidebar's own tabs (Files, Outline, Search): a key shows its tab, and again puts the sidebar away. (#687)
- Note links (`[[Note]]`) get Open Link and Copy Link in the right-click menu.

### Improved

- Source mode takes the same keys as the rendered editor: highlight, strikethrough, inline code, link, headings and lists, code fences, indent, moving lines and a new line below. A heading key at a line's start leaves the cursor after the new `#`.
- A to-do copied whole pastes back as a to-do, and Backspace at a to-do's start turns it into plain text.
- Closing the tab in use goes back to the tab you used before it.

### Fixed

- A heading key pressed while an input method is still composing no longer doubles the text.

### New

- Plugin API 1.7: a page kit and page tools for plugin pages, consistent names and version rules, and page logs. Plugin pages can use the editor tables' grip and lift (`tx-table-grip`, `tx-cell-lifted`, `tx-making-room`).
- Built-in AI tools for the folder's tasks, backlinks and tags.
- `textus.git`: a plugin reads the folder's Git status, a file's history and its text at a commit, and commits the files the user picks (`git.commit` permission, desktop). New official Git plugin: changed files marked in the sidebar, the branch in the status bar, a Commit command, and AI tools for the changes and history. Version History lists a document's commits beside its versions.
- `documentTypes`: a plugin opens other text file types as documents in the editor, keeping the syntax it names exactly as written.

### Improved

- The plugin store installs the newest version of a plugin that this Textus can run.

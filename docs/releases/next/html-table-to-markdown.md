### New

- Pasting the source of a simple HTML table (no merged cells, only text and inline formatting in its cells) inserts a Markdown table: the header from `<th>` or the first row, bold, italics, code, links, sub- and superscripts as Markdown, `<br>` kept, column alignment carried over and `$ x $` tightened to `$x$`.
- Right-click an HTML table already in a document for **Convert to Markdown Table**, one undo step. When it can't be converted, the item says why (merged cells, or lists and paragraphs in a cell).

### Improved

- Track My Changes shows its changes in the review bar under the document, as Textus AI's edits do: how many there are, the previous and next one, Accept or Reject for all of them, and the same three views - all in the text with ✓ and ✕ beside each change, the original with the changes in the margin, or the result with the originals in the margin. In a narrow window or on a phone, where no cards fit beside the text, the bar is how you step through them.

### Fixed

- Track My Changes marks only the characters you changed in Chinese and Japanese text, instead of the whole clause around them.

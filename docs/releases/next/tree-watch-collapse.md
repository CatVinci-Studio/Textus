### Improved

- The file tree updates by itself when files change on disk, from Git, a sync service or another app, without switching away and back. On phones and tablets it still updates when you come back to Textus.
- The file tree's New File and New Folder buttons create the item in the folder you last clicked, or in the folder of the file you last clicked, instead of always at the top.
- A slash in a new file or folder name creates the folders on the way: `2026/March/plan` makes the folders `2026` and `March` and the document `plan.md` in them.

### New

- Collapse All folds every folder in the file tree. It is in the tree's Sort menu and in the right-click menu of the tree's blank area.

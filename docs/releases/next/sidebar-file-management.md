### New

- Makes the sidebar's file tree a small file manager on the desktop:
  - right-click a folder, a file or the empty space below to make a **New Document** or a **New Folder** there;
  - drag a file or folder onto another folder to move it, and an open document follows it to its new place;
  - **Sort** orders the tree by name or by date modified.
  - Nothing is replaced: a name already taken is refused.

### Improved

- Takes the tree up a level with the parent folder's name above it, "‹ Documents / notes", one click away, instead of an arrow that read as "collapse".
- Applies the filter beside the search box, **All files** or **Documents only**, to the tree as well. It used to change only the search results, so with no search the two looked the same.
- Leaves the Open Folder button out of an unsaved document's empty Files tab; **File › Open Folder…** and the button in the tree's toolbar remain.

### New

- Plugins can put in the Format menu's blocks - headings, lists, task lists, quotes, code, formulas, dividers and tables - and a plugin's `/` items are found by their English name in any language and, for Chinese ones, by pinyin.

### Fixed

- Text a plugin or Textus AI puts in mid-sentence keeps a wiki link or bold words it starts with, instead of turning them into plain text.

### Fixed

- Makes more of Markdown editing behave as expected: `Ctrl/⌘ + B` and `Ctrl/⌘ + I` take bold and italic off again; Tab and Shift+Tab never move the focus out of the text; Format › Bullet or Ordered List switches a list over; Backspace at the start of a heading makes it body text at any level, and at a callout's first line keeps the callout (a second press makes it a plain quote); `~~~` starts a code block, `---` on the first line front matter and `1) ` a list, while `===` stays text; HTML, `<br>` and footnote references typed out are saved as typed; Enter before a space no longer saves `&#x20;`; ← moves one character over inline HTML as → does; bold-italic opens in one arrow press; deleting the last word of bold-italic around code no longer loses both; edited paragraphs keep two-space line breaks and tables line up Chinese, Japanese and Korean text; Word lists paste as lists, and a heading pasted mid-line keeps its `#`; and Settings › Shortcuts names the fixed shortcut a key belongs to.

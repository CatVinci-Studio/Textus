### Improved

- A Textus AI tab is named for who answers in it (Claude Code, Codex or Textus AI), and each conversation gets a short title from Textus AI after its first exchange, shown in History and on its tab's hover.
- A long command Claude Code or Codex asks to run says how many commands it holds, its text in code type and cut to a few lines until you open it; long steps in a reply show two lines.
- Opening a web page file (`.html`) offers HTML View, which shows it as a page; declined, it opens as text as before.

### Fixed

- With Claude Code or Codex answering, Textus AI's own button no longer lights up beside theirs; pressed, it switches back to Textus AI.
- A reply streaming in no longer shows a list's next bullet, a quote's bar or code's ground ahead of the words before it.

### Improved

- Settings › Shortcuts lists the editor's own block keys (⌘⌥0–8 for paragraph, headings and lists, ⌘⌥C code block, ⌘⇧B quote, ⌘[ and ⌘] for list indent), and a key you record there that macOS keeps for itself (⌘H, ⌘M, ⌘⌥D and the like) is refused with the reason.

### Fixed

- A plugin's default key no longer takes over a key Textus, the editor or macOS already uses (Zotero's ⌘⌥C used to replace Code Block): the command stays in the command palette without a key, and one note says which key and where to set another.

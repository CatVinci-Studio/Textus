### Improved

- ⌘N (Ctrl+N) now makes a new file, as in Typora, Obsidian and VS Code; a new window moved to ⌘⇧N (Ctrl+Shift+N).
- New keys: ⌘K (Ctrl+K) inserts a link, ⌘⌥F (Ctrl+Alt+F) opens Replace, ⌘G (Ctrl+G) finds the next match, and Typora's Ctrl+` and Ctrl+Shift+` make inline code and strikethrough - Control on a Mac too.

### Improved

- On iPhone, iPad and Android, Interface Size follows the system's text size (iOS's Text Size, Android's font size) unless you pick one, and has two more steps, Extra Large and Largest. Each step sizes text, icons, rows and spacing together; the bars at the top and the format bar stop growing at Large so their buttons still fit. With the document's text size on Automatic, the document grows with it too.
- On Android, text no longer grows twice under a larger system font (once by the system, once by the interface).
- On a touch screen every button takes a 44-point tap: an iPad's format bar and tab row, the sidebar's resize grip, search boxes, dropdowns and Settings rows.

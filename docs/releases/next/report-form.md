### Improved

- Report a Problem asks what kind of report it is, what part of Textus it is about and, for a bug, how bad it is, and takes an email or WeChat if you're happy to be asked more. **Send** files it for you as an issue on GitHub, with no GitHub account needed, and says its number; **Submit on GitHub** opens GitHub's form instead. A contact you leave goes to the team only, never into the public issue.

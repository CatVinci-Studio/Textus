### Improved

- Web pages in a tab (the Web View plugin) open every site on macOS and Windows: the page is the system's own web view laid over the tab, with its own cookies, so sites that refused to show in a frame - GitHub, Google and many more - now work, and side by side with a document through Split Panes. A link that leaves the web opens in your browser. On Linux the page stays a frame for now.

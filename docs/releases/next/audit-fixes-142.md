### Fixed

- A plugin's badge on a file now shows on Windows, and in a folder opened through a link on macOS.
- An outside agent that can't read images now says so when a message carries one, instead of answering without it.
- Esc ends the tour only when nothing else takes it: closing completion, the find bar or a menu, or typing, no longer ends it. Back in the tour no longer bounces on a step that is already done.
- A plugin rewriting a block (Tasks sorting a list) keeps your selected text selected.
- Bold on a selection that reaches into bold italic text now formats it.
- iPad and Android tablets: an island split under another no longer leaves a status bar's height of empty space above its tabs.
- The window's top-right island keeps room for the bar's buttons when a status appears there, and when those buttons need more than an island's least width.
- Phone: a sideways swipe that scrolls a long name, a table or a text field no longer opens or closes the sidebar.
- Inline code (Ctrl+`) works like bold: a selection holding bold or other code becomes one code, and a code it reaches into is taken in whole.
- The tour dims the window again after a step that left it undimmed.
- A window too narrow for a split, with the sidebar open, now folds the split into one island and puts it back when there is room.
- Help › Sponsor Textus, and a small link under the version in Settings › About, open the sponsor page (not on iOS).
- Tables: Copy Table in the right-click menu copies the whole table as Markdown.
- Linux: the window's buttons are small and round, close together as in GNOME's own apps; the menu button matches the sidebar's in size and tone.
- A narrow window that folded two islands puts both back as they were, keeps the document you were on in use, and never folds an island into the one above it.
- A plugin can take its badge off a file that was deleted or renamed; badges on files in subfolders show on Windows.
- The tour no longer skips a step when the sidebar or the AI opens with two quick updates.
- Android: the phone menu no longer lists Documents, which only iOS has; picking up a tab gives a light haptic as on iOS; Word files open from plain paths.
- Bold, italic, strikethrough, highlight and inline code come off a selection that has one end inside the formatting, and off bold-italic across several lines.
- Typing Chinese with an input method into a new heading no longer leaves the text in front of its "##".

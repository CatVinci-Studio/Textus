### New

- With Save Automatically on and a folder open, an untitled document gets a file in that folder once its title is written (or after half a minute's rest), and the file is renamed as the title changes until you name it yourself. With no folder open, untitled documents stay drafts, kept by crash recovery as before.
- A new document with no level-one heading is named by Textus AI, in the background while you write, so Save As and autosave propose a short title instead of the first line. It follows Textus AI and "Suggest a filename when saving a new file"; the first line is used while there is no title yet.

### New

- Attaches several files at once with the **+** button, and many more kinds: any text or code file, zip archives (unpacked so Textus AI reads each file inside), and BMP, TIFF and - on a Mac - HEIC and AVIF pictures, converted for every service. Very large pictures are made smaller instead of refused. Each file is copied into the conversation's own temporary folder, and Textus AI reads the whole of a long one when it needs it.

### Improved

- Opens only the folder you open in the sidebar or choose to Textus AI. A document opened on its own no longer gives it the whole folder it sits in, such as Downloads or the Desktop: it reads that document and the files you attach.
- Keeps what Textus AI makes for a project - its memories, research papers and changes you haven't decided on yet - in Textus's own folders instead of your project folder. What earlier versions left in a project's `.textus/` folder moves there by itself.

### Improved

- Switching back to a long document's tab is quicker: its text is matched with the file once the page is drawn, not before, and nothing is worked out for suggestions it doesn't have.
- Dragging a block in a long document lifts at once and moves smoothly: only the blocks near the screen are measured and moved.
- Typing, Enter and pasting in a long document with folded headings no longer restyle every block in it.

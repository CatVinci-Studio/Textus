### Improved

- The file tree keeps the folder's name and its buttons at the top while you scroll, above the folders' rows that stay.
- A sidebar panel with nothing to show says why, in the list's own text, with the buttons to begin: an empty file tree and Search offer Open Folder, and the outline tells "No document is open" from "This document has no headings yet".
- While the file tree follows the open document instead of an opened folder, its Open This Folder button stays in sight.
- A document opened from Finder, a second launch or Open Recent goes to the window that already has it open, else to the window whose folder holds it, else to the window in front.

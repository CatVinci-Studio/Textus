### New

- Formulas written as `$…$` or `\(…\)` inside HTML blocks and HTML tables are drawn, as on GitHub and in Typora. Code inside them is left alone.

### Fixed

- In a Markdown table, `\|` inside a formula draws as one bar instead of a double bar, and a `|` typed into a cell's formula is saved as `\|`, so it no longer splits the cell.

### Improved

- The tab keys work as in a browser: Cmd/Ctrl+T opens a new tab in the window, whatever Settings says files open in, and Cmd/Ctrl+N a new window (it was Cmd/Ctrl+Shift+N). File › New File is now New Tab.

### New

- File › Reopen Closed Tab (Cmd/Ctrl+Shift+T) brings back the documents closed in the window, the latest first.

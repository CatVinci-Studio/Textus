### Fixed

- The sidebar no longer slides across for a moment when the window crosses into or out of the phone's layout, or steps aside as the window narrows.
- The tour's card appears beside the part it is about, instead of flashing in the window's top left corner first.
- Windows and Linux: the caption buttons change as soon as the window is maximized or restored, not after a pause, and Windows 10's window edge is there from the first frame.

With the start page chosen and nothing to reopen, the start page is there from the first frame, and a tab dragged out into a new window is there as the window appears.

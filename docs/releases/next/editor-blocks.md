### Improved

- Makes Textus AI's edits land where it means them: it is shown the document as the editor holds it, paragraph by paragraph - a list or a quote is one piece, a table one, a picture one - and an edit names the piece it changes, so it is placed there, never on another copy of the same words elsewhere in the document. A few words changed inside a paragraph are found inside that paragraph only.
- Tells a picture, a table, a code block or a formula in Textus AI's rewrite apart the way the editor does, so each is decided as one change, the same in the rewrite as in your document.

### Fixed

- Shows an edit as it streams in even when Textus AI writes the words it changes before naming their paragraph; it used to wait for the whole edit.

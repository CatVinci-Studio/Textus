### Improved

- On iPhone, iPad and Android, plugins now know when you leave Textus for another app and when you come back, so a plugin such as WakaTime can send what it has waiting before the system pauses Textus.

### Fixed

- On iPhone and iPad, a plugin that moves a file to the Trash now puts it in Recently Deleted in the Files app, where you can put it back. Before, it always failed. On Android, which has no Trash, the plugin is told so clearly and the file stays where it is.

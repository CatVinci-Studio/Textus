### Improved

- Phones: the tab row is not drawn. The document's name in the bar, with the count of open tabs, opens a menu of every tab in the row's order (pinned first), the one in front ticked; then New File (or, over a conversation, a new one), as the row's + was; then the tab in front's own menu: Read Only, Pin, Close and closing many. Tabs are no longer dragged into order on a phone. The desktop and tablets keep their tab row.

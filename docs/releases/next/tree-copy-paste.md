### New

- Cut, Copy and Paste files in the file tree, with the keys or from the right-click menu: a paste goes into the selected folder, or the folder of the selected file. Cut moves them, and links follow as for a drag; a cut file stays faded until it is pasted. Duplicate (⌘D or Ctrl+D) makes a copy beside the original, named as Finder names one: "plan copy.md", then "plan copy 2.md", in your system's language.
- Hold ⌥ (Ctrl on Windows and Linux) while dragging in the file tree to copy instead of move.
- When a file or folder of the same name is already where you move, paste or copy to, the file tree asks: Replace (the one there goes to the Trash), Keep Both (the new one is numbered), or Cancel. Every copy, paste and replace can be undone.

### Improved

- The right-click menu of several selected files and folders has Cut, Copy, Duplicate and Copy Path besides Open and Move to Trash.

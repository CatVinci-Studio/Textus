### Fixed

- Enter at the end of a code or maths block inside a list adds a line to the block, instead of starting a new list item.
- Enter on a code line holding only indentation keeps you in the block: the line is left empty and the indentation carries on, so blank lines inside indented code (a Python function) no longer end the block. Enter on an empty line, or Cmd/Ctrl+Enter anywhere, still leaves it.

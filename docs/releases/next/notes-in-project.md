### Improved

- Your notes on a document now live with the folder: in its project's `.textus/notes/` (the open folder counts), so they travel with the folder and can be shared through Git or a synced drive. Notes kept the old way are moved there when the document or its folder is opened, and they still follow a file or folder moved in Textus. A file opened on its own, outside any folder, keeps its notes in the app's data as before.

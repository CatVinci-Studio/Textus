### New

- Pick an icon theme for files and folders in **Settings › Appearance › File icons**: a plugin's icons show in the sidebar's files, search results and quick open, and **Default** keeps Textus's own. The new official plugin Material Icon Theme brings the icons of VS Code's Material Icon Theme. (#776)
- Give files and folders icons of your own from a plugin: `contributes.fileIconThemes` (API 1.10) points to an icon theme JSON in VS Code's shape, by extension, file name and folder name, with icons for the light appearance.

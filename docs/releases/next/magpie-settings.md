### Improved

- Textus takes in a change made to its settings file by another program (a hand edit, a tool that sets up its AI) while it runs, and keeps the fields its windows changed meanwhile; before, its next save wrote the file over the change.
- Settings › AI: a service on this computer (Magpie, Ollama) can be given another address than its usual one, such as Magpie on another port or Ollama on another machine.
- Settings › AI notes when Magpie is running on this computer and the AI uses another service, with a button to switch to it.

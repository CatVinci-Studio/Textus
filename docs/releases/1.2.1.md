## What's new

Textus 1.2.1 fixes what 1.2.0's first readers ran into - an arrow key that changed a document, a drag selection that wouldn't scroll on Linux, a second window after an update - and finishes the sidebar's file tree with Rename, Move to Trash and opening a file in a new window; diagrams can now be enlarged.

### Improved

- Renames a file or folder, or moves it to the Trash (the Recycle Bin on Windows), from its right-click menu in the sidebar's file tree. An open document follows its new name, a document renamed without an extension stays a Markdown file, a name already taken is refused, and nothing goes to the Trash without asking first. (#351)
- ⌘-click (Ctrl-click on Windows and Linux) a file in the sidebar's file tree to open it in a new window, leaving the window you are in as it is. (#348)
- Enlarges a diagram to look at it closely: the button in a drawn diagram's corner opens it over the window, where scrolling or a pinch zooms in on the point under the pointer, dragging moves it, a double click fits it again and Escape closes it. The button stays out of PDFs, exports and printouts.

### Fixed

- Moving through a document with the arrow keys no longer changes it: Up on the first line or Down on the last only moves the caret, instead of adding an empty line that made a document you had only read ask to be saved. Where a code block, formula, table or front matter starts or ends the document, the line the caret steps onto goes again if you leave it without typing. (#350)
- Selecting by dragging past the bottom or top of the document scrolls it and takes the selection along, faster the further past the edge you go. On Linux it didn't scroll down at all and crept up a line at a time. (#219)
- Restarting to finish an update restarts Textus in place, instead of opening a second window while the old one closed. (#349)
- Enter on an empty task nested in a task list moves it up a level as a task, instead of turning it into a plain bullet. (#355)
- With line numbers on, long lines in a code block wrap as they do without them, each number beside the start of its line. (#353)
- Settings › Extensions › Themes shows the theme gallery in one box, not a box inside a box.

Installers for macOS (Apple silicon and Intel), Windows and Linux (x64 and ARM64) are below; the app updates itself.
